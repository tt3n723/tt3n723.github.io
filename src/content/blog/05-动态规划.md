## DP 概念与编码方法

### 一句话

有一道规模 $n\le 10^5$ 的最优化题：你选定状态、写出转移之后，要从初始状态把状态一个一个推出来，给出最优值，必要时把取到最优的那条方案也输出。**时间最坏 $O(n)$ 或 $O(n\log n)$（视转移而定），空间 $O(n)$，滚动后为 $O(1)$ 维。**

### 原理

### 实现

（状态 + 转移 + 边界 + 答案，四件事写清楚；转移只依赖「已经算好的更小规模」。）

```c++
const int N = 100005;
const ll NEG = -(ll)4e18;
ll dp[N];
int a[N], n;

// 以「最大子段和」为例：dp[i] = 以 i 结尾的最大和
ll max_subarray() {
    ll best = NEG;
    for (int i = 1; i <= n; i++) {
        dp[i] = (i == 1) ? a[i] : max(dp[i - 1] + a[i], (ll)a[i]);
        best = max(best, dp[i]);
    }
    return best;
}
```

### 应用

#### 记忆化搜索（自顶向下）

状态之间的依赖是 DAG 时，直接递归 + 记忆化最省心；注意「未计算」和「答案是 0」要用不同的标记区分。

```c++
ll memo[105][105];
bool vis[105][105];
ll f(int i, int j) {
    if (i > j) return 0;
    if (vis[i][j]) return memo[i][j];
    vis[i][j] = true;
    memo[i][j] = NEG;
    for (int k = i; k <= j; k++)
        memo[i][j] = max(memo[i][j], f(i, k - 1) + f(k + 1, j));
    return memo[i][j];
}
// 用 vis 数组区分「没算过」与「答案是 0 / 负」；直接把初值当哨兵容易出错
```

#### 滚动数组 / 降维

转移只依赖前一层时，把第一位丢掉、倒序（或正序）枚举即可；关键是判断「同一层内会不会读到本轮刚写的值」。

```c++
ll nx[N];
void knapsack_roll(vector<int>& w, vector<int>& v, int W) {
    vector<ll> f(W + 1, NEG);
    f[0] = 0;
    for (size_t i = 0; i < w.size(); i++)
        for (int j = W; j >= w[i]; j--)          // 倒序：保证每件物品只用一次
            if (f[j - w[i]] > NEG) f[j] = max(f[j], f[j - w[i]] + v[i]);
}
// 完全背包改成正序即可（同一件可以重复取）；分组背包要在组内先复制一份旧数组
```

#### 刷表法与填表法

填表法从「谁能转移到我」出发；刷表法从「我能转移到谁」出发。刷表法在转移较稀疏时更快。

```c++
// 填表：dp[i] = max(dp[i], dp[j] + cost(j, i))
// 刷表：for (i) for (j 是 i 的后继) dp[j] = max(dp[j], dp[i] + cost(i, j))
void push_dp(int n) {
    vector<ll> f(n + 1, NEG);
    f[1] = 0;
    for (int i = 1; i <= n; i++) {
        if (f[i] == NEG) continue;
        for (int j = i + 1; j <= n && j <= i + 3; j++)   // 后继有限
            f[j] = max(f[j], f[i] + (j - i) * (j - i));
    }
}
```

#### 输出方案

额外记一个「决策」数组，从答案状态倒推；如果空间紧张，就用「重新算一遍」的方式找决策。

```c++
int pre[N];
void print_pick(int n, vector<int>& w, vector<int>& v, int W) {
    vector<ll> f(W + 1, NEG);
    f[0] = 0;
    vector<vector<int>> choose(w.size() + 1, vector<int>(W + 1, -1));
    for (size_t i = 0; i < w.size(); i++)
        for (int j = W; j >= w[i]; j--)
            if (f[j - w[i]] > NEG && f[j - w[i]] + v[i] > f[j]) {
                f[j] = f[j - w[i]] + v[i];
                choose[i + 1][j] = i;            // 记录这次选了第 i 件
            }
    // 从 f[W] 出发往前回溯即可（这里省略具体回溯）
    (void)choose; (void)pre; (void)n;
}
```

## 线性 DP

### 一句话

给两个长度分别为 $n,m$ 的序列（$n,m\le 5000$），要你逐位比较着往右扫：一边配出两个序列的最长公共子序列、算出把一个改成另一个所需的最少编辑次数，一边在单个序列上找出最长的上升子序列。**时间 $O(nm)$，空间 $O(\min(n,m))$。**

### 原理

### 实现

```c++
int n, m;
int f[N][N];

int lcs(string& A, string& B) {              // A、B 从下标 1 开始
    n = A.size() - 1, m = B.size() - 1;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            f[i][j] = max(f[i - 1][j], f[i][j - 1]);
            if (A[i] == B[j]) f[i][j] = max(f[i][j], f[i - 1][j - 1] + 1);
        }
    return f[n][m];
}
```

### 应用

#### 编辑距离

插入 / 删除 / 替换的代价都是 1 时，$f_{i,j}=\min(f_{i-1,j},f_{i,j-1},f_{i-1,j-1}+[A_i\ne B_j])+1$。

```c++
int edit_distance(string& A, string& B) {
    n = A.size() - 1, m = B.size() - 1;
    for (int i = 0; i <= n; i++) f[i][0] = i;
    for (int j = 0; j <= m; j++) f[0][j] = j;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            f[i][j] = min({f[i - 1][j] + 1, f[i][j - 1] + 1,
                           f[i - 1][j - 1] + (A[i] != B[j])});
        }
    return f[n][m];
}
// 空间可以滚到 O(m)：只需要上一行
```

#### 带权 LIS / 上升子序列计数

LIS 用「以 i 结尾的最长长度」，配合树状数组按值域维护最大值；带权版本把 max 换成权值和。

```c++
int bit[N], lim;
void bit_upd(int i, int v) { for (; i <= lim; i += i & -i) bit[i] = max(bit[i], v); }
int bit_qry(int i) { int r = 0; for (; i > 0; i -= i & -i) r = max(r, bit[i]); return r; }
int lis(vector<int>& a) {                    // a 已离散化到 1..lim
    lim = a.size();
    int best = 0;
    for (int x : a) { int c = bit_qry(x - 1) + 1; bit_upd(x, c); best = max(best, c); }
    return best;
}
// 若要求「非严格上升」，把 bit_qry(x-1) 换成 bit_qry(x)
```

#### 最长不降 / 下降子序列

把比较号反过来就行；用 upper_bound / lower_bound 的贪心解法可以做到 $O(n\log n)$。

```c++
int lis_nlogn(vector<int>& a) {              // 最长「非降」子序列
    vector<int> t;
    for (int x : a) {
        auto it = upper_bound(t.begin(), t.end(), x);   // 严格上升换成 lower_bound
        if (it == t.end()) t.push_back(x);
        else *it = x;
    }
    return t.size();
}
```

## 背包问题

### 一句话

有 $n$ 件物品和容量为 $W$ 的背包（$n,W\le 10^5$），每件物品有重量和价值，可以取一次、取有限次或取无限次，要你选出总重不超过 $W$ 的取法使总价值最大，物品一件一件拿来考虑。**时间 $O(nW)$（多重背包用单调队列同样 $O(nW)$），空间 $O(W)$。**

### 原理

### 实现

```c++
ll f[N];

void zero_one(vector<int>& w, vector<int>& v, int W) {   // 0/1 背包
    for (size_t i = 0; i < w.size(); i++)
        for (int j = W; j >= w[i]; j--) f[j] = max(f[j], f[j - w[i]] + v[i]);
}
void complete(vector<int>& w, vector<int>& v, int W) {   // 完全背包
    for (size_t i = 0; i < w.size(); i++)
        for (int j = w[i]; j <= W; j++) f[j] = max(f[j], f[j - w[i]] + v[i]);
}
```

### 应用

#### 多重背包的单调队列优化

第 $i$ 件有 $c_i$ 个时，按「模 $w_i$ 的余数」分组，每组内是一个滑动窗口取最大值，用单调队列 $O(W)$ 处理一种物品。

```c++
ll mf[N];
int q[N];
void multiple(vector<int>& w, vector<int>& v, vector<int>& c, int W) {
    for (size_t i = 0; i < w.size(); i++) {
        int wi = w[i], ci = c[i];
        memcpy(mf, f, sizeof(ll) * (W + 1));
        for (int r = 0; r < wi; r++) {
            int head = 0, tail = 0;
            for (int j = r, k = 0; j <= W; j += wi, k++) {
                if (head < tail && q[head] < k - ci) head++;              // 超出个数限制
                while (head < tail && mf[q[tail - 1] * wi + r] + (ll)(k - q[tail - 1]) * v[i]
                                      <= mf[j]) tail--;
                q[tail++] = k;
                f[j] = max(f[j], mf[q[head] * wi + r] + (ll)(k - q[head]) * v[i]);
            }
        }
    }
}
```

#### 分组背包

每组最多选一个：外层枚举组，内层倒序枚举容量，再枚举组内物品。

```c++
void group_knapsack(vector<vector<pair<int, int>>>& groups, int W) {
    for (auto& g : groups)
        for (int j = W; j >= 0; j--)
            for (auto [w, v] : g)
                if (j >= w) f[j] = max(f[j], f[j - w] + v);
}
// 必须先枚举容量再枚举组内物品，否则会「一组选多个」
```

#### 树上背包

$f_{u,j}$ 表示「$u$ 的子树内选容量 $j$ 的最大收益」；合并儿子时做卷积，用「子树大小」限制枚举上界就得到 $O(n^2)$。

```c++
vector<int> g[N];
int sz[N];
ll tdp[N][M];
void dfs_bag(int u, int p, int W) {
    sz[u] = 1;
    for (int v : g[u]) {
        if (v == p) continue;
        dfs_bag(v, u, W);
        for (int j = min(sz[u], W); j >= 0; j--)
            for (int k = 1; k <= min(sz[v], W - j); k++)
                tdp[u][j + k] = max(tdp[u][j + k], tdp[u][j] + tdp[v][k]);
        sz[u] += sz[v];
    }
}
// 关键：内层只枚举到「当前已合并的子树大小」，总复杂度才是 O(n^2) 而不是 O(n^3)
```

#### 求方案数 / 输出方案

把 max 换成加法就是方案数；要输出方案就额外记录转移来源。

```c++
ll cnt[N];
void count_ways(vector<int>& w, int W) {
    vector<ll> ways(W + 1, 0);
    ways[0] = 1;
    for (int wi : w)
        for (int j = W; j >= wi; j--) ways[j] = (ways[j] + ways[j - wi]) % MOD;
    // ways[W] 就是方案数
}
```

## 区间 DP

### 一句话

给一个长度为 $n$ 的序列（$n\le 500$，或 $n\le 5000$ 配合四边形不等式），要你把相邻的两段反复合并成一段并算出合并的最优代价，靠由小区间推大区间，中间还要数出括号匹配方案数、找出最长的回文子序列。**时间 $O(n^2)$（或 $O(n^3)$），空间 $O(n^2)$。**

### 原理

### 实现

```c++
ll idp[N][N], sum[N];

ll range_dp(ll* a, int n_) {                 // 石子合并
    int n = n_;
    for (int i = 1; i <= n; i++) idp[i][i] = 0;
    for (int i = 1; i <= n; i++) sum[i] = sum[i - 1] + a[i];
    for (int len = 2; len <= n; len++)
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            idp[i][j] = (ll)4e18;
            for (int k = i; k < j; k++)
                idp[i][j] = min(idp[i][j], idp[i][k] + idp[k + 1][j] + sum[j] - sum[i - 1]);
        }
    return idp[1][n];
}
```

### 应用

#### 四边形不等式优化

若代价函数满足「区间包含单调 + 四边形不等式」，则最优决策点单调，可以把 $O(n^3)$ 降到 $O(n^2)$。

```c++
int opt[N][N];
ll range_dp_opt(ll* a, int n) {
    for (int i = 1; i <= n; i++) idp[i][i] = 0, opt[i][i] = i, sum[i] = sum[i - 1] + a[i];
    for (int len = 2; len <= n; len++)
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            idp[i][j] = (ll)4e18;
            // 决策点只在 [opt[i][j-1], opt[i+1][j]] 里找
            for (int k = opt[i][j - 1]; k <= opt[i + 1][j]; k++) {
                ll cur = idp[i][k] + idp[k + 1][j] + sum[j] - sum[i - 1];
                if (cur < idp[i][j]) idp[i][j] = cur, opt[i][j] = k;
            }
        }
    return idp[1][n];
}
// 用之前最好先验证「代价满足四边形不等式」，否则会算错
```

#### 环形区间 DP

把环断开：要么「枚举断点」跑 $n$ 次，要么把数组复制一倍、只取长度为 $n$ 的区间。

```c++
ll ring_dp(ll* a, int n) {
    // 复制一倍：a[1..2n]，只考虑长度恰好为 n 的区间
    for (int i = 1; i <= 2 * n; i++) sum[i] = sum[i - 1] + a[(i - 1) % n + 1];
    for (int len = 2; len <= n; len++)
        for (int i = 1; i + len - 1 <= 2 * n; i++) {
            int j = i + len - 1;
            idp[i][j] = (ll)4e18;
            for (int k = i; k < j; k++)
                idp[i][j] = min(idp[i][j], idp[i][k] + idp[k + 1][j] + sum[j] - sum[i - 1]);
        }
    ll best = (ll)4e18;
    for (int i = 1; i <= n; i++) best = min(best, idp[i][i + n - 1]);
    return best;
}
```

#### 括号序列 / 回文串

「区间内最多能匹配多少对括号」与「最长回文子序列」都是 $O(n^2)$ 的经典区间 DP。

```c++
int lps[N][N];
int longest_palindrome_subseq(string s) {    // s 从下标 1 开始
    int n = s.size() - 1;
    for (int i = 1; i <= n; i++) lps[i][i] = 1;
    for (int len = 2; len <= n; len++)
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            if (s[i] == s[j]) lps[i][j] = lps[i + 1][j - 1] + 2;
            else lps[i][j] = max(lps[i + 1][j], lps[i][j - 1]);
        }
    return lps[1][n];
}
// 括号匹配把「+2」换成「+2 当且仅当 s[i] 与 s[j] 配对」
```

## 树形 DP

### 一句话

给一棵 $n$ 个点的树（$n\le 10^5$，带权时 $n\le 2000$），要你从叶子往根逐点决定选或不选：选出最少的点盖住每条边、选出最多的两两不相邻的点，并依次把每个点拎起来当根重新算一遍。**时间 $O(n)$（树上背包为 $O(n^2)$），空间 $O(n)$。**

### 原理

### 实现

```c++
vector<int> g[N];
int f0[N], f1[N];                            // f0：不选 u；f1：选 u
void dfs_dp(int u, int p) {
    f0[u] = 0, f1[u] = 1;
    for (int v : g[u]) {
        if (v == p) continue;
        dfs_dp(v, u);
        f0[u] += f1[v];                      // u 不选，儿子必须选
        f1[u] += min(f0[v], f1[v]);          // u 选了，儿子随意
    }
}
int min_vertex_cover(int root) { dfs_dp(root, 0); return min(f0[root], f1[root]); }
```

### 应用

#### 最小点覆盖 / 最大匹配（树上）

树上最大匹配另开一维「这个点有没有被匹配」，转移时枚举「$u$ 匹配给哪个儿子」。

```c++
int gm[N][2];
void dfs_match(int u, int p) {
    gm[u][0] = 0, gm[u][1] = -(int)1e9;
    for (int v : g[u]) {
        if (v == p) continue;
        dfs_match(v, u);
        int a = gm[u][0], b = gm[u][1];
        gm[u][0] = a + max(gm[v][0], gm[v][1]);                       // u 没被匹配
        gm[u][1] = max(b + max(gm[v][0], gm[v][1]), a + gm[v][0] + 1); // u 匹配给 v
    }
}
// 答案 = max(gm[root][0], gm[root][1])
```

#### 换根 DP（rerooting）

先求「以 1 为根」的子树答案，再用「父亲那一边的答案」推出每个点为根时的答案。

```c++
int rsz[N];
ll down[N], ans[N];
void dfs1(int u, int p) {
    rsz[u] = 1, down[u] = 0;
    for (int v : g[u]) {
        if (v == p) continue;
        dfs1(v, u);
        rsz[u] += rsz[v], down[u] += down[v] + rsz[v];
    }
}
void dfs2(int u, int p, int n) {
    for (int v : g[u]) {
        if (v == p) continue;
        ans[v] = ans[u] + n - 2 * rsz[v];    // 把 v 这棵子树「换」到外侧
        dfs2(v, u, n);
    }
}
// 初始化 ans[1] = down[1]，再 dfs2(1, 0, n)
```

#### 依赖型背包（树上背包）

选儿子必须先选父亲：把「子树内选容量 j」的 DP 自底向上合并，复杂度 $O(nW)$ 级别。

```c++
ll tb[N][M];
int tsz[N];
void dfs_bag2(int u, int p, int W) {
    tsz[u] = 1;
    for (int v : g[u]) {
        if (v == p) continue;
        dfs_bag2(v, u, W);
        for (int j = min(tsz[u], W); j >= 0; j--)
            for (int k = 1; k <= min(tsz[v], W - j); k++)
                tb[u][j + k] = max(tb[u][j + k], tb[u][j] + tb[v][k]);
        tsz[u] += tsz[v];
    }
}
```

#### 直径 / 最长链

维护「以 $u$ 为端点向下延伸的最长路」，合并两个儿子时更新答案，$O(n)$。

```c++
ll down2[N], diam;
void dfs_diam(int u, int p) {
    down2[u] = 0;
    for (int v : g[u]) {
        if (v == p) continue;
        dfs_diam(v, u);
        diam = max(diam, down2[u] + down2[v] + 1);
        down2[u] = max(down2[u], down2[v] + 1);
    }
}
// 带权时把 +1 换成 +w
```

## DAG 上的 DP

### 一句话

给一个有 $n$ 个点、$m$ 条边的有向无环图（$n,m\le 10^6$），要你按拓扑序一个点一个点地推：算出从起点到终点的最长路与最短路、数出有多少条路径，并指出哪条是关键路径。**时间 $O(n+m)$，空间 $O(n+m)$。**

### 原理

### 实现

```c++
vector<pair<int, int>> dag[N];
int indeg[N], ord[N], on;
ll dist[N];

void topo(int n) {                           // 拓扑排序
    queue<int> q;
    for (int i = 1; i <= n; i++) if (!indeg[i]) q.push(i);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        ord[on++] = u;
        for (auto [v, w] : dag[u]) if (--indeg[v] == 0) q.push(v);
    }
}
void dag_longest(int n) {
    fill(dist + 1, dist + n + 1, NEG);
    dist[1] = 0;
    for (int i = 0; i < on; i++) {
        int u = ord[i];
        if (dist[u] == NEG) continue;
        for (auto [v, w] : dag[u]) dist[v] = max(dist[v], dist[u] + w);
    }
}
```

### 应用

#### 最长路 / 最短路（DAG）

按拓扑序递推：最长路取 max，最短路取 min。注意最短路要把初值设成 INF 并判可达。

```c++
ll shortest[N];
void dag_shortest(int n) {
    fill(shortest + 1, shortest + n + 1, (ll)4e18);
    shortest[1] = 0;
    for (int i = 0; i < on; i++) {
        int u = ord[i];
        if (shortest[u] == (ll)4e18) continue;
        for (auto [v, w] : dag[u]) shortest[v] = min(shortest[v], shortest[u] + w);
    }
}
```

#### 路径计数

路径条数按拓扑序累加：$cnt_v$ 加上所有入边的 $cnt_u$。

```c++
ll pcnt[N];
void path_count(int n) {
    fill(pcnt + 1, pcnt + n + 1, 0);
    pcnt[1] = 1;
    for (int i = 0; i < on; i++) {
        int u = ord[i];
        for (auto [v, w] : dag[u]) pcnt[v] = (pcnt[v] + pcnt[u]) % MOD;
    }
}
```

#### 关键路径

「最早开始时间」按拓扑序正推，「最晚开始时间」按逆拓扑序倒推；两者相等的活动就是关键活动。

```c++
ll est[N], lst[N];
void critical_path(int n) {
    for (int i = 1; i <= n; i++) est[i] = 0;
    for (int i = 0; i < on; i++)
        for (auto [v, w] : dag[ord[i]]) est[v] = max(est[v], est[ord[i]] + w);
    ll T = 0;
    for (int i = 1; i <= n; i++) T = max(T, est[i]);
    for (int i = 1; i <= n; i++) lst[i] = T;
    for (int i = on - 1; i >= 0; i--) {
        int u = ord[i];
        for (auto [v, w] : dag[u]) lst[u] = min(lst[u], lst[v] - w);
    }
    // est[u] == lst[u] 的点在关键路径上
}
```


## 环形 DP 与后效性处理

### 一句话

给一个首尾相接的环（$n\le 10^5$，DP 状态 $O(1)$ 维），要你沿着环一格一格做决策，还要处理某一步的转移会反过来依赖后面几步、或者首尾的状态互相牵制的情况。**时间 $O(n)$ 或 $O(n\log n)$，空间 $O(1)$ 维。**

### 原理

### 实现

```c++
// ---------- 后效性：把「首尾相接」拆成两种情况 ----------
ll ring_independent(ll* w, int n) {          // 环形相邻不能同时选
    if (n == 1) return max(0LL, w[1]);
    // 情况一：第 1 个点不选 -> 对 2..n 做链式 DP
    ll a0 = 0, a1 = NEG;
    for (int i = 2; i <= n; i++) {
        ll t0 = max(a0, a1), t1 = a0 + w[i];
        a0 = t0, a1 = t1;
    }
    ll best = max(a0, a1);
    // 情况二：第 1 个点选 -> 第 2、n 个点都不能选
    ll b0 = 0, b1 = w[1];
    for (int i = 3; i <= n - 1; i++) {
        ll t0 = max(b0, b1), t1 = b0 + w[i];
        b0 = t0, b1 = t1;
    }
    if (n >= 3) best = max(best, max(b0, b1) + w[1]);
    return best;
}
```

### 应用

#### 环形区间 DP

把环复制一倍变成 $2n$ 的链，再只统计长度为 $n$ 的区间；或者枚举「第一个点的状态」跑两次。

```c++
ll ring_stone(ll* a, int n) {                // 环形石子合并（最小代价）
    static ll s[N], g[505][505];
    for (int i = 1; i <= 2 * n; i++) s[i] = s[i - 1] + a[(i - 1) % n + 1];
    for (int i = 1; i <= 2 * n; i++) g[i][i] = 0;
    for (int len = 2; len <= n; len++)
        for (int i = 1; i + len - 1 <= 2 * n; i++) {
            int j = i + len - 1;
            g[i][j] = (ll)4e18;
            for (int k = i; k < j; k++)
                g[i][j] = min(g[i][j], g[i][k] + g[k + 1][j] + s[j] - s[i - 1]);
        }
    ll best = (ll)4e18;
    for (int i = 1; i <= n; i++) best = min(best, g[i][i + n - 1]);
    return best;
}
// 例：a = {1,2,3} 时最优是 1+2=3、再 3+3=6，共 9
```

#### 状态里补一维

当转移需要知道「更早」的信息时，把那点信息放进状态：例如「连续选了几个」「上一个选的是谁」。

```c++
// 例：不能连续选超过 2 个，求最大和
ll no_three_in_a_row(ll* a, int n) {
    // f[i][j]：前 i 个、当前连续选了 j 个（j = 0,1,2）
    vector<array<ll, 3>> f(n + 1);
    f[0] = {0, NEG, NEG};
    for (int i = 1; i <= n; i++) {
        f[i][0] = max({f[i - 1][0], f[i - 1][1], f[i - 1][2]});
        f[i][1] = f[i - 1][0] + a[i];
        f[i][2] = f[i - 1][1] + a[i];
    }
    return max({f[n][0], f[n][1], f[n][2]});
}
```

#### 基环树 DP

先找环、把环上的点标出来，对每个环上点「挂着的子树」做树形 DP，再在环上做一次环形 DP。

```c++
vector<int> bg[N];
int bdeg[N];
bool oncyc[N];
vector<int> cyc;

void find_cyc(int n) {                       // 拓扑排序找环
    queue<int> q;
    for (int i = 1; i <= n; i++) { bdeg[i] = bg[i].size(); if (bdeg[i] == 1) q.push(i); }
    fill(oncyc + 1, oncyc + n + 1, true);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        oncyc[u] = false;
        for (int v : bg[u]) if (oncyc[v] && --bdeg[v] == 1) q.push(v);
    }
    for (int i = 1; i <= n; i++) if (oncyc[i]) cyc.push_back(i);
}
ll bf[N][2], bw[N];
void dfs_branch(int u, int p) {              // 只走非环儿子
    bf[u][0] = 0, bf[u][1] = bw[u];
    for (int v : bg[u]) {
        if (v == p || oncyc[v]) continue;
        dfs_branch(v, u);
        bf[u][0] += max(bf[v][0], bf[v][1]);
        bf[u][1] += bf[v][0];
    }
}
// 环上不能选相邻点：把「环上不选」的收益设为 bf[u][0]、「选」设为 bf[u][1]，
// 再对环数组跑一遍「环形不能相邻」的 DP（枚举第一个环点的状态）
```

## 悬线法

### 一句话

给一个 $n\times m$ 的 01 矩阵（$n,m\le 2000$），要你一行一行往下扫，对每个格子算出以它为底能向上延伸多高的全 1 竖线，再向左右撑开找到最大的全 1 子矩形，并数出全 1 子矩形的个数。**时间 $O(nm)$，空间 $O(m)$。**

### 原理

### 实现

（对每个格子维护「向上能延伸多高」$h$、「向左 / 向右能延伸到哪」$L,R$，答案由 $h\times(R-L+1)$ 给出。）

```c++
int a[N][N], hh[N], LL[N], RR[N], n, m;

int max_rect() {
    int best = 0;
    memset(hh, 0, sizeof hh);                // 同样必须清零
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) hh[j] = a[i][j] ? hh[j] + 1 : 0;
        for (int j = 1; j <= m; j++) {                 // 左边界
            LL[j] = j;
            while (LL[j] > 1 && hh[LL[j] - 1] >= hh[j]) LL[j] = LL[LL[j] - 1];
        }
        for (int j = m; j >= 1; j--) {                 // 右边界
            RR[j] = j;
            while (RR[j] < m && hh[RR[j] + 1] >= hh[j]) RR[j] = RR[RR[j] + 1];
        }
        for (int j = 1; j <= m; j++) best = max(best, hh[j] * (RR[j] - LL[j] + 1));
    }
    return best;
}
```

### 应用

#### 最大全 1 矩形（单调栈版）

把每一行当成柱状图，用单调栈求最大矩形面积；与悬线法等价。

```c++
int max_rect_stack() {
    int best = 0;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) hh[j] = a[i][j] ? hh[j] + 1 : 0;
        stack<int> st;
        for (int j = 1; j <= m + 1; j++) {
            int cur = (j <= m) ? hh[j] : 0;
            while (!st.empty() && hh[st.top()] >= cur) {
                int ht = hh[st.top()]; st.pop();
                int l = st.empty() ? 1 : st.top() + 1;
                best = max(best, ht * (j - l));
            }
            st.push(j);
        }
    }
    return best;
}
```

#### 全 1 子矩形计数

用「以每个位置为右下角」的贡献法：对每行做单调栈，把不同高度的矩形个数累加。

```c++
ll count_rects() {
    ll total = 0;
    memset(hh, 0, sizeof hh);                // 必须清零！hh 是全局的，上一次调用会留下脏数据
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) hh[j] = a[i][j] ? hh[j] + 1 : 0;
        static ll cdp[N];
        vector<int> st;
        for (int j = 1; j <= m; j++) {
            while (!st.empty() && hh[st.back()] >= hh[j]) st.pop_back();
            int l = st.empty() ? 0 : st.back();
            cdp[j] = cdp[l] + (ll)hh[j] * (j - l);
            total += cdp[j];
            st.push_back(j);
        }
    }
    return total;
}
// 例：全 1 的 2x2 矩阵应当得到 9（4 个 1x1 + 2 个 1x2 + 2 个 2x1 + 1 个 2x2）
```


## 状态压缩 DP

### 一句话

给一个规模 $n\le 20$ 的集合问题（或 $n\times m\le 100$ 的棋盘），把「选了哪些元素」压成一个二进制数，要你在这 $2^n$ 个状态之间一个一个转移，选出最优的覆盖或划分方案。**时间 $O(2^nn)$ 或 $O(3^n)$，空间 $O(2^n)$。**

### 原理

### 实现

```c++
int full;
ll sdp[1 << 20];

// 状压的基本操作
void bit_ops() {
    int S = full;
    int low = S & -S;                        // 最低位的 1
    int nxt = (S - 1) & S;                   // 去掉最低位 1 后的子集
    (void)low; (void)nxt;
}
```

### 应用

#### 枚举子集（$O(3^n)$）

把「$S$ 拆成两个不相交子集」的转移写成子集枚举；总循环次数是 $3^n$，不是 $4^n$。

```c++
ll subset_dp(int n) {
    int N = 1 << n;
    static ll g[1 << 20];
    for (int S = 1; S < N; S++) {
        g[S] = 0;
        for (int T = S; T; T = (T - 1) & S) {
            // 用 cost[T] 和 g[S ^ T] 更新 g[S]
            g[S] = max(g[S], g[S ^ T]);
        }
    }
    return g[N - 1];
}
// 注意：内层是「枚举子集」，总循环次数是 3^n
```

#### 状压 + 最短路 / 分层图

把「已经访问过的点集」作为最短路的状态，在状态图上跑 Dijkstra，复杂度 $O(2^n m\log)$。

```c++
ll tsp[1 << 16][16];
// dist[S][u]：已访问集合为 S、当前在 u 的最短路
// 转移：从 (S,u) 走边 (u,v) 到 (S | (1<<v), v)
// 状态数是 2^n * n，直接在隐式图上跑 Dijkstra 即可
```

#### 骨牌 / 棋盘覆盖的状态设计

按「行」压缩时，状态是「本行哪些位置被上一行伸下来的骨牌占用」；转移时枚举本行的摆放，判断不冲突。

```c++
// dp[i][S]：前 i 行已填满，第 i+1 行被「从第 i 行伸下来」的格子集合为 S
// 转移：枚举第 i+1 行的摆放 T（不与 S 冲突），算出它会伸到第 i+2 行的集合
int n_, m_;
ll rowdp[13][1 << 12];

ll count_by_row(int n, int m) {              // n 行 m 列，用 1x2 / 2x1 铺满
    n_ = n, m_ = m;
    memset(rowdp, 0, sizeof rowdp);
    rowdp[0][0] = 1;
    for (int i = 0; i < n; i++)
        for (int S = 0; S < (1 << m); S++) {
            ll v = rowdp[i][S];
            if (!v) continue;
            // 用 DFS 枚举本行所有合法摆放，得到「伸到下一行」的集合 ns
            function<void(int, int, int)> gen = [&](int j, int cur, int ns) {
                if (j == m) { rowdp[i + 1][ns] += v; return; }
                if (cur >> j & 1) { gen(j + 1, cur, ns); return; }   // 被上一行占了
                gen(j + 1, cur, ns | (1 << j));                       // 竖着放
                if (j + 1 < m && !(cur >> (j + 1) & 1))
                    gen(j + 2, cur, ns);                              // 横着放
            };
            gen(0, S, 0);
        }
    return rowdp[n][0];
}
// n = 2, m = 3 时答案是 3；n = m = 8 时答案是 12988816
```

## 插头 DP 与轮廓线 DP

### 一句话

给一个 $n\times m$ 的网格（$n,m\le 12$，或 $m\le 30$ 配合矩阵），要你一格一格地摆骨牌把整个网格铺满，或者从起点走到终点且中途必须经过指定的必经点，数出方案数。**时间 $O(nm\cdot 2^m)$（轮廓线）或 $O(nm\cdot S)$（插头，$S$ 是括号序列状态数），空间 $O(2^m)$。**

### 原理

### 实现

（轮廓线 DP：逐格推进，状态是「当前格子前 $m$ 个格子的占用情况」。）

```c++
int n, m;
ll dp[2][1 << 12];

ll domino_tiling(int n_, int m_) {           // 用 1x2 / 2x1 骨牌铺满的方案数
    n = n_, m = m_;
    if (n < m) swap(n, m);                   // 让 m 更小，状态数更少
    memset(dp, 0, sizeof dp);
    dp[0][0] = 1;
    int cur = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            int nxt = cur ^ 1;
            memset(dp[nxt], 0, sizeof(ll) * (1 << m));
            for (int S = 0; S < (1 << m); S++) {
                ll v = dp[cur][S];
                if (!v) continue;
                if (S >> j & 1) {                        // 这一格已被占用
                    dp[nxt][S ^ (1 << j)] += v;          // 把它从轮廓里去掉
                } else {
                    if (j + 1 < m && !(S >> (j + 1) & 1))    // 横着放
                        dp[nxt][S | (1 << (j + 1))] += v;
                    if (i + 1 < n)                            // 竖着放
                        dp[nxt][S | (1 << j)] += v;
                }
            }
            cur = nxt;
        }
    }
    return dp[cur][0];                       // 全部铺满后轮廓为空
}
// n = m = 8 时答案是 12988816；n = 2, m = 3 时答案是 3
```

### 应用

#### 带权 / 带限制的铺法

把方案数换成最大值（dp 取 max），或者给格子加「不能放」的限制（在枚举时跳过）。

```c++
bool blocked[13][13];
ll wdp[13][1 << 12];
ll max_gain(int n, int m, int gain) {        // 每放一块得 gain 分，障碍格不能放
    memset(wdp, 0, sizeof wdp);
    wdp[0][0] = 0;
    for (int i = 0; i < n; i++)
        for (int S = 0; S < (1 << m); S++) {
            ll v = wdp[i][S];
            if (v < 0) continue;
            function<void(int, int, int, ll)> gen = [&](int j, int cur, int ns, ll got) {
                if (j == m) {
                    if (blocked[i + 1][ns]) return;    // 下一行的接缝落在障碍上
                    wdp[i + 1][ns] = max(wdp[i + 1][ns], v + got);
                    return;
                }
                if (cur >> j & 1) { gen(j + 1, cur, ns, got); return; }
                if (!blocked[i][j]) {
                    if (!blocked[i + 1][j]) gen(j + 1, cur, ns | (1 << j), got + gain);   // 竖放
                    if (j + 1 < m && !(cur >> (j + 1) & 1) && !blocked[i][j + 1])
                        gen(j + 2, cur, ns, got + gain);                                   // 横放
                }
                gen(j + 1, cur, ns, got);              // 这一格空着（不要求铺满时）
            };
            gen(0, S, 0, 0);
        }
    return wdp[n][0];
}
// 求「铺满」就要求在格子没被占且不是障碍时必须铺；求「最大收益」则允许空着
```


## 数位 DP

### 一句话

给一个区间 $[L,R]$（$R\le 10^{18}$），要你从高位往低位一位一位地填数、同时卡住上界，数出区间里满足某条数位限制的数有多少个、或者它们的数位和是多少。**时间 $O(\text{位数}\times\text{状态数})$，空间 $O(\text{状态数})$。**

### 原理

### 实现

（记忆化搜索：pos 是当前位、limit 表示是否贴着上界、lead 表示是否还有前导零，再带上题目需要的额外状态。）

```c++
ll memod[20][2][2][20];
bool visd[20][2][2][20];
int dig[20];

ll dfs_digit(int pos, bool limit, bool lead, int extra) {
    if (pos < 0) return 1;                   // 走到这里说明这个数合法
    if (visd[pos][limit][lead][extra]) return memod[pos][limit][lead][extra];
    visd[pos][limit][lead][extra] = true;
    ll res = 0;
    int up = limit ? dig[pos] : 9;
    for (int d = 0; d <= up; d++) {
        if (lead && d == 0) {                // 仍然是前导零
            res += dfs_digit(pos - 1, limit && d == up, true, 0);
        } else {
            // 这里换成题目要求的合法性判断
            res += dfs_digit(pos - 1, limit && d == up, false, d);
        }
    }
    return memod[pos][limit][lead][extra] = res;
}
ll solve_digit(ll x) {
    if (x < 0) return 0;
    int len = 0;
    while (x) dig[len++] = x % 10, x /= 10;
    memset(visd, 0, sizeof visd);
    return dfs_digit(len - 1, true, true, 0);
}
// 注意：这样写出来的计数包含「0 这个数」！
// 区间 [L, R] 的答案要用 solve_digit(R) - solve_digit(L - 1)，
// 若题目要求「正整数」且不把 0 算作合法，就要在最后减掉 0 贡献的那 1
```

### 应用

#### 前导零的处理

前导零会让「000123」和「123」被当成不同的数，所以必须用 lead 标记，且这一位不能计入「上一位是谁」等状态。

```c++
// 对比：不区分前导零 vs 区分前导零
ll bad_way(int pos, bool limit, int last) {  // 错误示范：把前导零也当成一位数字
    if (pos < 0) return 1;
    ll res = 0;
    int up = limit ? dig[pos] : 9;
    for (int d = 0; d <= up; d++) {
        if (d < last) continue;              // 前导的 0 会让 last 变成 0，限制变强
        res += bad_way(pos - 1, limit && d == up, d);
    }
    return res;
}
ll good_way(int pos, bool limit, bool lead, int last) {   // 正确：用 lead 跳过前导零
    if (pos < 0) return 1;
    ll res = 0;
    int up = limit ? dig[pos] : 9;
    for (int d = 0; d <= up; d++) {
        if (lead && d == 0) { res += good_way(pos - 1, limit && d == up, true, 10); continue; }
        if (d < last) continue;
        res += good_way(pos - 1, limit && d == up, false, d);
    }
    return res;
}
// 记忆化的下标里要包含 lead（或把 last 用 10 表示「还没开始」来合并）
// 例：求 [1, 100] 内「数字不降」的个数 -> 用 good_way 得到 55
```

#### 数字不降 / 不含某数字

「不降」把「上一位数字」放进状态；「不含 4」在枚举时直接跳过。

```c++
// 关键：last 的初值必须取 0（而不是 10 之类的「哨兵」）！
// 否则第一个非零数字会被下面的 d < last 直接跳过，整个计数就漏了
ll dfs_nondecr(int pos, bool limit, bool lead, int last) {
    if (pos < 0) return 1;
    ll res = 0;
    int up = limit ? dig[pos] : 9;
    for (int d = 0; d <= up; d++) {
        if (lead && d == 0) { res += dfs_nondecr(pos - 1, limit && d == up, true, last); continue; }
        if (!lead && d < last) continue;     // 不降（前导零阶段不比较）
        if (d == 4) continue;                // 不含 4
        res += dfs_nondecr(pos - 1, limit && d == up, false, d);
    }
    return res;
}
// 记忆化时 last 也要参与下标（初值 0 表示「还没有任何非零位」）
```

#### 计数 + 求和

同时维护「个数」和「和」：每位数字 d 的贡献是 d 乘上这一位的位权再乘「后面有多少种填法」。

```c++
// 返回 (个数, 数位和)
pair<ll, ll> dfs_sum(int pos, bool limit, bool lead) {
    if (pos < 0) return {1, 0};
    ll c = 0, s = 0;
    int up = limit ? dig[pos] : 9;
    for (int d = 0; d <= up; d++) {
        auto pr = dfs_sum(pos - 1, limit && d == up, lead && d == 0);
        c += pr.first;
        s += pr.second + (ll)d * pr.first * /* 这一位的位权 */ 1;
    }
    return {c, s};
}
// 「位权」通常是 10^pos
```

## 计数 DP

### 一句话

有一道规模 $n\le 10^6$ 的计数题，要你把方案按最后一步拆开、把规模从小到大一个一个数出来，给出方案数。**时间 $O(n)$ 或 $O(n\log n)$（含组合数预处理），空间 $O(n)$。**

### 原理

### 实现

```c++
ll fac[N], ifac[N];
ll qpow(ll a, ll b, ll mod) {
    ll r = 1;
    for (a %= mod; b; b >>= 1, a = (__int128)a * a % mod)
        if (b & 1) r = (__int128)r * a % mod;
    return r;
}
void init_comb(int n) {
    fac[0] = 1;
    for (int i = 1; i <= n; i++) fac[i] = fac[i - 1] * i % MOD;
    ifac[n] = qpow(fac[n], MOD - 2, MOD);
    for (int i = n; i >= 1; i--) ifac[i - 1] = ifac[i] * i % MOD;
}
ll C(int n, int k) {
    if (k < 0 || k > n) return 0;
    return fac[n] * ifac[k] % MOD * ifac[n - k] % MOD;
}
```

### 应用

#### 加法原理与乘法原理

「或者」相加、「并且」相乘；DP 计数的每一步就是把这两个原理写成状态转移。

```c++
ll cat_dp(int n) {                           // 卡特兰数：C(2n,n) - C(2n,n+1)
    return (C(2 * n, n) - C(2 * n, n + 1) + MOD) % MOD;
}
```

#### 组合数预处理

$O(n)$ 预处理阶乘与逆阶乘后，单次询问组合数是 $O(1)$；范围小的时候也可以直接用杨辉三角。

```c++
void pascal(int n) {
    static ll cc[1005][1005];
    for (int i = 0; i <= n; i++) {
        cc[i][0] = 1;
        for (int j = 1; j <= i; j++) cc[i][j] = (cc[i - 1][j - 1] + cc[i - 1][j]) % MOD;
    }
}
```

#### 容斥 + 计数

「至少有 k 个位置重合」这类问题先按「钦定」计数，再用二项式系数容斥修正。

```c++
ll derangement(int n) {                      // 错排数
    static ll d[N];
    d[0] = 1;
    if (n >= 1) d[1] = 0;
    for (int i = 2; i <= n; i++) d[i] = (i - 1) * (d[i - 1] + d[i - 2]) % MOD;
    return d[n];
}
```

## 概率与期望 DP

### 一句话

有一个状态数为 $n$ 的随机过程（$n\le 10^5$，需要解方程时 $n\le 500$），每一步按给定概率从一个状态跳到另一个状态，要你算出到达目标状态的概率或期望步数。**时间 $O(n)$（递推）或 $O(n^3)$（高斯消元），空间 $O(n)$。**

### 原理

### 实现

（期望的线性性：$E[X+Y]=E[X]+E[Y]$，无论是否独立，这是把复杂期望拆开的关键。）

```c++
double pexp[N];

// 倒推式期望：E[i] = 1 + sum_j p_j * E[j]，从终态往回推
double expected_steps(int n) {
    pexp[n] = 0;
    for (int i = n - 1; i >= 0; i--) {
        // 等号两边都有 E[i] 时要把 E[i] 移项解出来
        // 例：E[i] = 1 + 0.5 * E[i+1] + 0.5 * E[i]  =>  E[i] = 2 + E[i+1]
        pexp[i] = 2 + pexp[i + 1];
    }
    return pexp[0];
}
```

### 应用

#### 期望的线性性

把「总期望」拆成「每个元素贡献的期望之和」，常常能把 $O(n^2)$ 变成 $O(n)$。

```c++
// 经典：n 个球放进 n 个盒子，求「空盒子的期望个数」
//   每个盒子为空的概率是 (1 - 1/n)^n，答案 = n * 该概率（线性性！）
double expected_empty(int n) {
    return (double)n * pow(1.0 - 1.0 / n, n);
}
```

#### 概率 DP（正推 / 倒推）

求「到终态的概率」通常倒推（f[i] = 从 i 出发的成功率），求「从起点到达各状态的概率」则正推。

```c++
double prob[N], nprob[N];
void prob_forward(int n) {                   // 正推：从起点出发
    for (int i = 0; i <= n; i++) prob[i] = 0;
    prob[0] = 1;
    for (int i = 0; i < n; i++) {
        if (prob[i] == 0) continue;
        nprob[i + 1] += prob[i] * 0.5;       // 往右走一步
        nprob[i] += prob[i] * 0.5;           // 停在原地
        for (int j = 0; j <= n; j++) { prob[j] += nprob[j]; nprob[j] = 0; }
    }
}
// 有自环时不能直接正推（会无限累积），要移项或用高斯消元
```

#### 高斯消元解期望方程

转移有环时，列出「E_i 减去所有后继的 p 倍」的线性方程组，用高斯消元 $O(n^3)$ 解出。

```c++
double A[505][505];
void gauss_expected(int n) {
    for (int c = 0; c < n; c++) {
        int p = c;
        for (int i = c + 1; i < n; i++) if (fabs(A[i][c]) > fabs(A[p][c])) p = i;
        swap(A[c], A[p]);
        for (int i = 0; i < n; i++) {
            if (i == c || fabs(A[i][c]) < 1e-12) continue;
            double t = A[i][c] / A[c][c];
            for (int j = c; j <= n; j++) A[i][j] -= t * A[c][j];
        }
    }
    for (int i = 0; i < n; i++) A[i][n] /= A[i][i];
    // A[i][n] 就是 E_i
}
```

## 动态 DP

### 一句话

给一棵树或一个序列，每个点带权，另有 $m$ 次操作（$n,m\le 10^5$），每次操作是「把某个点的权值改成 $v$」，改完后立刻询问当前的全局最优值，两种操作交替出现。**时间 $O(\log^2 n)$ 或 $O(\log n)$ 每次修改，空间 $O(n)$。**

### 原理

### 实现

（把 DP 的转移写成矩阵（或广义矩阵），用线段树 / 树链剖分维护「一串转移的复合」。）

```c++
const ll NEG = -(ll)4e18;
// 以「最大权独立集」为例：转移是
//   f[u][0] = sum max(f[v][0], f[v][1])
//   f[u][1] = w[u] + sum f[v][0]
// 写成广义矩阵（乘法是 +，加法是 max）：
struct M {
    ll a[2][2];
    M operator*(const M& o) const {
        M r;
        for (int i = 0; i < 2; i++)
            for (int j = 0; j < 2; j++)
                r.a[i][j] = max(a[i][0] + o.a[0][j], a[i][1] + o.a[1][j]);
        return r;
    }
};
M identity_gm() { return {{{0, NEG}, {NEG, 0}}}; }   // 广义矩阵的单位元
```

### 应用

#### 带修改的序列 DP

把「每个位置的转移」看成一个矩阵，线段树维护矩阵乘积；单次修改就是把一个叶子的矩阵换掉。

```c++
M segm[N << 2];
void build_m(int o, int l, int r, M* arr) {
    if (l == r) { segm[o] = arr[l]; return; }
    int mid = (l + r) >> 1;
    build_m(o << 1, l, mid, arr), build_m(o << 1 | 1, mid + 1, r, arr);
    segm[o] = segm[o << 1] * segm[o << 1 | 1];
}
void upd_m(int o, int l, int r, int pos, M v) {
    if (l == r) { segm[o] = v; return; }
    int mid = (l + r) >> 1;
    if (pos <= mid) upd_m(o << 1, l, mid, pos, v);
    else upd_m(o << 1 | 1, mid + 1, r, pos, v);
    segm[o] = segm[o << 1] * segm[o << 1 | 1];
}
// 注意乘法方向：先复合左边、再复合右边
```

#### 带修改的树形 DP

树上用「树链剖分 + 线段树维护矩阵」：每个点的矩阵用它的轻儿子的贡献拼出来，重链上的转移交给线段树。

```c++
// 关键：把「重儿子的贡献」放进矩阵，把「轻儿子的贡献」折进矩阵的常数里
int hfa[N], hsz[N], heavy[N], top[N], dfn[N], timer;
ll lw[N];                                    // 轻儿子的贡献（f[轻儿子][0] 与 max(f[轻儿子][0], f[轻儿子][1]) 之和）
M mat[N], segd[N << 2];

void dfs_h1(int u, int p) {
    hfa[u] = p, hsz[u] = 1, heavy[u] = 0;
    for (int v : g[u]) {
        if (v == p) continue;
        dfs_h1(v, u);
        hsz[u] += hsz[v];
        if (hsz[v] > hsz[heavy[u]]) heavy[u] = v;
    }
}
void dfs_h2(int u, int t) {
    top[u] = t, dfn[u] = ++timer;
    if (heavy[u]) dfs_h2(heavy[u], t);
    for (int v : g[u]) if (v != hfa[u] && v != heavy[u]) dfs_h2(v, v);
}
// 修改点 u 的权值后：从 u 往上，每次「在线段树上改一个叶子、取整条重链的乘积」，
// 再用链顶的结果去更新它父亲的轻儿子贡献，跳到下一条链，直到根
// 单次 O(log^2 n)
```

#### 与矩阵快速幂的关系

「带修改的 DP」是「矩阵快速幂」的局部版本：矩阵快速幂求的是「固定转移重复 n 次」，线段树维护的是「转移逐个不同」。

```c++
// 转移完全相同 -> 矩阵快速幂 O(k^3 log n)
ll MOD_ = 998244353;
struct MM {
    ll a[2][2];
    MM operator*(const MM& o) const {
        MM r{};
        for (int i = 0; i < 2; i++)
            for (int k = 0; k < 2; k++) {
                if (!a[i][k]) continue;
                for (int j = 0; j < 2; j++) r.a[i][j] = (r.a[i][j] + a[i][k] * o.a[k][j]) % MOD_;
            }
        return r;
    }
};
MM mpow(MM b, ll e) {
    MM r{{{1, 0}, {0, 1}}};
    for (; e; e >>= 1, b = b * b) if (e & 1) r = r * b;
    return r;
}
ll fib_fast(ll n) {                          // 固定转移重复 n 次
    MM b{{{1, 1}, {1, 0}}};
    return mpow(b, n).a[0][1];
}
// 广义矩阵（max-plus）同样适用，只要把单位元设成「对角线 0、其余 -inf」
```


## 前缀和优化

### 一句话

有一道 $n\le 10^6$ 的 DP，每一步都要把前面一整段状态的和拿来做转移，老老实实从头加一遍就会退化成 $O(n^2)$。**时间 $O(n)$（每步 $O(1)$ 求和），空间 $O(n)$。**

### 原理

### 实现

```c++
ll pre[N];
ll prefix_opt(int n, ll* a) {
    for (int i = 1; i <= n; i++) pre[i] = pre[i - 1] + a[i];
    // 例：dp[i] = min over j < i of (dp[j] + pre[i] - pre[j])
    //          = pre[i] + min over j < i of (dp[j] - pre[j])
    // 后半部分边扫边维护最小值即可 O(n)
    vector<ll> dp(n + 1, (ll)4e18);
    dp[0] = 0;
    ll best = dp[0] - pre[0];                // 初值必须来自 j = 0，不能给 INF！
    for (int i = 1; i <= n; i++) {
        if (i > 1) best = min(best, dp[i - 1] - pre[i - 1]);
        dp[i] = pre[i] + best;
    }
    return dp[n];
}
```

### 应用

#### 区间和型转移

转移里出现 $sum(j,i)$ 时，先用前缀和把它拆成 $pre_i-pre_{j-1}$，把与 $i$ 有关的部分提到 min/max 外面。

```c++
// dp[i] = min_{j<i}( dp[j] - k * pre[j] ) + k * pre[i]
ll dp_pre[N];
ll transfer_with_prefix(int n, ll* a, ll k) {
    for (int i = 1; i <= n; i++) pre[i] = pre[i - 1] + a[i];
    const ll INF = (ll)4e18;
    fill(dp_pre, dp_pre + n + 1, INF);
    dp_pre[0] = 0;
    ll best = dp_pre[0] - k * pre[0];        // 初值来自 j = 0（否则 dp[1] 会是 INF）
    for (int i = 1; i <= n; i++) {
        if (i > 1) best = min(best, dp_pre[i - 1] - k * pre[i - 1]);
        dp_pre[i] = best + k * pre[i];
    }
    return dp_pre[n];
}
// 关键：把「与 i 有关的项」整体提到 min 外面，剩下的部分与 i 无关 -> 边扫边维护 O(1)
```

#### 二维前缀和

转移依赖「矩形内的和」时，用二维前缀和（容斥）把它变成 $O(1)$。

```c++
ll s2[N][N];
void build_2d_prefix(int n, int m) {
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            s2[i][j] += s2[i - 1][j] + s2[i][j - 1] - s2[i - 1][j - 1];
}
ll rect_sum(int x1, int y1, int x2, int y2) {
    return s2[x2][y2] - s2[x1 - 1][y2] - s2[x2][y1 - 1] + s2[x1 - 1][y1 - 1];
}
// 例：网格 DP 里「从某个矩形区域转移过来」-> 预处理后每次 O(1)
```

## 单调队列优化 DP

### 一句话

有一道 $n\le 10^6$ 的 DP，递推式是 $dp_i=\min_{j\in[i-m,\,i-1]}\big(dp_j\big)+w_i$，也就是每步要从前面长度为 $m$ 的滑动窗口里取最小值来往后推。**时间 $O(n)$，空间 $O(m)$。**

### 原理

### 实现

（队列里存下标，值单调；先弹过期、再弹更差的、最后取队首。）

```c++
int dq[N];
ll mono_queue(int n, ll* a, int m) {
    vector<ll> dp(n + 1, (ll)4e18);
    dp[0] = 0;
    int head = 0, tail = 0;
    dq[tail++] = 0;
    for (int i = 1; i <= n; i++) {
        while (head < tail && dq[head] < i - m) head++;           // 弹出过期
        dp[i] = dp[dq[head]] + a[i];
        while (head < tail && dp[dq[tail - 1]] >= dp[i]) tail--;  // 弹出更差的
        dq[tail++] = i;
    }
    return dp[n];
}
// 队列里存的是「下标」，比较的是 dp 值；注意先弹过期再取最优
```

### 应用

#### 滑动窗口最值型转移

只要「候选集合是一个定长滑动窗口」，就能用单调队列把 $O(nm)$ 降到 $O(n)$。

```c++
// dp[i] = max_{j in [i-k, i-1]} dp[j] + a[i]
ll dp_win[N];
int dqwin[N];
ll jump_dp(int n, ll* a, int k) {
    const ll NEG = (ll)-4e18;
    fill(dp_win, dp_win + n + 1, NEG);
    dp_win[0] = 0;
    int head = 0, tail = 0;
    dqwin[tail++] = 0;
    for (int i = 1; i <= n; i++) {
        while (head < tail && dqwin[head] < i - k - 1) head++;      // 窗口是 [i-k-1, i-1]
        if (head < tail) dp_win[i] = dp_win[dqwin[head]] + a[i];
        if (dp_win[i] == NEG) continue;
        while (head < tail && dp_win[dqwin[tail - 1]] <= dp_win[i]) tail--;
        dqwin[tail++] = i;
    }
    return dp_win[n];
}
// 验证：a 全为 0、k = 1、n = 5 -> 答案 0（一路跳过来）
```

#### 多重背包（单调队列）

把每种物品按「模重量 $w$ 的余数」分组，组内是一个滑动窗口取最大值，每种物品 $O(W)$。

```c++
ll mf[N];
int q2[N];
void multiple_knapsack(vector<int>& w, vector<int>& v, vector<int>& c, int W, ll* f) {
    for (size_t i = 0; i < w.size(); i++) {
        int wi = w[i], ci = c[i];
        memcpy(mf, f, sizeof(ll) * (W + 1));
        for (int r = 0; r < wi; r++) {
            int head = 0, tail = 0;
            for (int j = r, k = 0; j <= W; j += wi, k++) {
                if (head < tail && q2[head] < k - ci) head++;
                while (head < tail &&
                       mf[q2[tail - 1] * wi + r] + (ll)(k - q2[tail - 1]) * v[i] <= mf[j]) tail--;
                q2[tail++] = k;
                f[j] = max(f[j], mf[q2[head] * wi + r] + (ll)(k - q2[head]) * v[i]);
            }
        }
    }
}
```

## 斜率优化与凸壳优化

### 一句话

有一道 $n\le 10^5$ 的 DP，递推式是 $dp_i=\min_j\big(a_jb_i+dp_j\big)+c_i$，每一步都要在若干个一次函数里挑出在 $b_i$ 处取值最小的那个。**时间 $O(n)$（$b_i$ 单调时，单调栈加指针）或 $O(n\log n)$（$b_i$ 不单调时，凸壳上二分），空间 $O(n)$。**

### 原理

### 实现

（把每个 $j$ 看成「斜率 $a_j$、截距 $dp_j$ 的直线」，维护下凸壳。）

```c++
ll hull_k[N], hull_b[N];                     // 凸壳（单调栈维护）
int hsz;
// b 在 a、c 中间时是否「没用」。约定：斜率递增插入、维护下凸壳
// 判据推导：设 a、b 的交点横坐标为 x_ab，b、c 的为 x_bc。
//   斜率递增时，x → -∞ 处「斜率最大」的线最优，所以沿凸壳下标增大方向
//   最优区间对应的 x 是**递减**的；于是 b 还有用当且仅当 x_ab > x_bc，
//   反过来 b 无用就是 x_ab <= x_bc。
bool bad(int a, int b, int c) {
    return (__int128)(hull_b[b] - hull_b[a]) * (hull_k[b] - hull_k[c])
         <= (__int128)(hull_b[c] - hull_b[b]) * (hull_k[a] - hull_k[b]);
}
void hull_add(ll k, ll b) {
    hull_k[hsz] = k, hull_b[hsz] = b;
    while (hsz >= 2 && bad(hsz - 2, hsz - 1, hsz)) hull_k[hsz - 1] = k, hull_b[hsz - 1] = b, hsz--;
    hsz++;
}
```

### 应用

#### 凸壳维护

插入一条直线时，若它让「中间的直线永远不可能最优」就把中间那条弹掉；斜率相等时保留截距更优的那条。

```c++
// 带「斜率相等」处理的凸壳插入（求最小值）
void hull_add_safe(ll k, ll b) {
    if (hsz && hull_k[hsz - 1] == k) {       // 斜率相同：只保留截距更小的那条
        if (hull_b[hsz - 1] <= b) return;
        hsz--;
    }
    hull_k[hsz] = k, hull_b[hsz] = b;
    while (hsz >= 2 && bad(hsz - 2, hsz - 1, hsz)) {
        hull_k[hsz - 1] = k, hull_b[hsz - 1] = b;
        hsz--;
    }
    hsz++;
}
// 前提一：直线必须按**斜率单调**的顺序插入 —— bad() 与单调指针都依赖这一点；
//   斜率不单调时要改用李超树，或者「分治 + 对每段单独建凸壳」
// 前提二：斜率相等时必须先比较截距，否则 bad() 会退化成相等的叉积，
//   弹栈的判断（>=）会误弹，凸壳被破坏，后续查询就会给出偏大的值
// 前提三：求最大值的凸壳方向与求最小值相反（保上凸 / 下凸）
```

#### 查询：$x$ 单调用指针、否则二分

$b_i$ 单调时，最优决策点在凸壳上只会朝一个方向移动，用一个指针即可；否则在凸壳上二分。

> 方向要按约定数清楚：**斜率递增 + 下凸壳**时，$x$ 增大则最优直线的下标从右往左移（斜率越小越适合大的 $x$）；把方向搞反会漏掉最优解。

```c++
// 指针查询的前提：斜率单调递增插入，且查询的 x 单调递增
// 此时「最优直线」的下标只会从右往左移动（斜率越小，越适合大的 x）
int hull_ptr;
void hull_reset_ptr() { hull_ptr = hsz - 1; }   // 每次重建凸壳后必须重置
ll hull_query_mono(ll x) {                   // 要求 x 单调递增
    while (hull_ptr > 0 &&
           hull_k[hull_ptr] * x + hull_b[hull_ptr] >
           hull_k[hull_ptr - 1] * x + hull_b[hull_ptr - 1]) hull_ptr--;
    return hull_k[hull_ptr] * x + hull_b[hull_ptr];
}
ll hull_query_bin(ll x) {                    // x 不单调时在凸壳上二分
    int lo = 0, hi = hsz - 1;
    while (lo < hi) {
        int mid = (lo + hi) >> 1;
        if (hull_k[mid] * x + hull_b[mid] <= hull_k[mid + 1] * x + hull_b[mid + 1]) hi = mid;
        else lo = mid + 1;
    }
    return hull_k[lo] * x + hull_b[lo];
}
// 例：dp[i] = min_j ( dp[j] + (pre[i]-pre[j])^2 )
//   直线斜率 -2*pre[j]、截距 dp[j]+pre[j]^2，查询 x = pre[i]
```

## Slope Trick

### 一句话

有一道 $n\le 10^5$ 的 DP，它的 DP 函数是凸的，每次转移只是在函数上加一个绝对值、做一次前缀取 min 或者整体平移一下，于是用两个堆就能把这整条凸函数维护住。**时间 $O(\log n)$ 每次转移、总 $O(n\log n)$，空间 $O(n)$。**

### 原理

### 实现

（用两个堆维护「斜率变化的拐点」，堆是「左侧拐点（大根堆）」与「右侧拐点（小根堆）」。）

```c++
priority_queue<ll> L;                        // 左侧拐点（大根堆）
priority_queue<ll, vector<ll>, greater<ll>> R;   // 右侧拐点（小根堆）
ll mn = 0;                                   // 函数的最小值
void add_abs(ll a) {                         // f(x) += |x - a|
    L.push(a);
    if (L.top() > R.top()) {
        ll x = L.top(); L.pop();
        ll y = R.top(); R.pop();
        L.push(y), R.push(x);
        mn += x - y;
    }
    R.push(a);
    if (L.top() > R.top()) {
        ll x = L.top(); L.pop();
        ll y = R.top(); R.pop();
        L.push(y), R.push(x);
        mn += x - y;
    }
}
```

### 应用

#### 前缀取 min

$f(x)\leftarrow\min_{y\le x}f(y)$ 表示「右侧的拐点全部无效」，直接把右堆清空并把最小值加上去。

```c++
void prefix_min() {                          // f(x) = min_{y <= x} f(y)
    while (!R.empty()) {
        mn = min(mn, mn);                    // 最小值不变
        R.pop();                             // 右侧拐点全部失去意义
    }
}
// 例：dp[i][x] = min_{y <= x} dp[i-1][y] —— 典型的「只降不升」约束
```

#### 平移与整体加

「$f(x)\to f(x-\Delta)$」给两个堆整体打一个加法标记；「$f(x)\to f(x)+c$」只改最小值。

```c++
ll addL = 0, addR = 0;                       // 两个堆的平移标记
void shift(ll d) { addL += d, addR += d; }
void add_const(ll c) { mn += c; }
// 注意：入堆时要减掉对应标记，出堆时要加回来，否则会算错
// 例：dp[i][x] = dp[i-1][x-w] + cost —— 平移就是 shift(w)
```

## 四边形不等式与决策单调性

### 一句话

有一道 $n\le 5000$ 的 DP，递推式是 $dp_i=\min_{j<i}\big(dp_j+w(j,i)\big)$，每一步都要枚举前面的分界点 $j$，而最优的 $j$ 会随着 $i$ 增大单调右移（区间 DP 同理）。**时间 $O(n\log n)$（分治）或 $O(n)$（单调队列），空间 $O(n)$。**

### 原理

### 实现

（分治求决策：算出 $mid$ 的最优决策点后，左右两半的决策点范围就确定了。）

```c++
ll cost(int l, int r);                       // 代价函数，O(1) 或 O(log)
vector<ll> dp2;
void solve_opt(int l, int r, int ql, int qr) {   // 求 dp2[l..r]，决策点在 [ql,qr]
    if (l > r) return;
    int mid = (l + r) >> 1, bestk = ql;
    ll best = (ll)4e18;
    for (int k = ql; k <= min(qr, mid); k++) {
        ll cur = 0 /* dp_prev[k] */ + cost(k, mid);
        if (cur < best) best = cur, bestk = k;
    }
    dp2[mid] = best;
    solve_opt(l, mid - 1, ql, bestk);
    solve_opt(mid + 1, r, bestk, qr);
}
// 每一层的总枚举量是 O(n)，共 O(log n) 层，总计 O(n log n)
```

### 应用

#### 分治求决策（$O(n\log n)$）

适用条件是「决策点单调」，即 $opt_i\le opt_{i+1}$；用之前先用小数据暴力验证这个性质。

```c++
// 用 O(n^2) 暴力检查「决策点是否单调」——用之前先验证
bool opt_is_monotone(int n, function<ll(int, int)> cost) {
    vector<ll> dpv(n + 1, (ll)4e18);
    vector<int> opt(n + 1, 0);
    dpv[0] = 0;
    for (int i = 1; i <= n; i++)
        for (int j = 0; j < i; j++) {
            ll cur = dpv[j] + cost(j, i);
            if (cur < dpv[i]) dpv[i] = cur, opt[i] = j;
        }
    for (int i = 1; i < n; i++) if (opt[i] > opt[i + 1]) return false;
    return true;
}
// 例：cost(j,i) = (pre[i]-pre[j])^2 -> 单调成立，可以用分治
// 若返回 false，说明这个代价函数不满足决策单调性，分治会算错
```

#### 区间 DP 的 opt 数组（$O(n^2)$）

区间 DP 里记 $opt_{i,j}$ 为 $dp_{i,j}$ 的最优分割点；若满足四边形不等式，则 $opt_{i,j-1}\le opt_{i,j}\le opt_{i+1,j}$。

```c++
int opt[505][505];
ll range_dp_opt(ll* a, int n) {
    static ll dp3[505][505], s[505];
    for (int i = 1; i <= n; i++) s[i] = s[i - 1] + a[i];
    for (int i = 1; i <= n; i++) dp3[i][i] = 0, opt[i][i] = i;
    for (int len = 2; len <= n; len++)
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            dp3[i][j] = (ll)4e18;
            for (int k = opt[i][j - 1]; k <= opt[i + 1][j]; k++) {
                ll cur = dp3[i][k] + dp3[k + 1][j] + s[j] - s[i - 1];
                if (cur < dp3[i][j]) dp3[i][j] = cur, opt[i][j] = k;
            }
        }
    return dp3[1][n];
}
// 例：石子合并 a = {1,2,3} -> 答案是 9
```

## 数据结构优化

### 一句话

有一道 $n\le 10^5$ 的 DP，每一步可供转移的候选集合是一个随位置变化的区间，要你随时往集合里加入、删除状态并取出最值或和，用线段树 / 树状数组维护。**时间 $O(\log n)$ 每次转移、总 $O(n\log n)$，空间 $O(n)$。**

### 原理

### 实现

（把「$dp_j+cost(j)$」放进数据结构，转移时查询区间最值。）

```c++
ll segmin[N << 2];
void seg_upd(int o, int l, int r, int pos, ll v) {
    if (l == r) { segmin[o] = v; return; }
    int mid = (l + r) >> 1;
    if (pos <= mid) seg_upd(o << 1, l, mid, pos, v);
    else seg_upd(o << 1 | 1, mid + 1, r, pos, v);
    segmin[o] = min(segmin[o << 1], segmin[o << 1 | 1]);
}
ll seg_qry(int o, int l, int r, int ql, int qr) {
    if (qr < l || r < ql) return (ll)4e18;
    if (ql <= l && r <= qr) return segmin[o];
    int mid = (l + r) >> 1;
    return min(seg_qry(o << 1, l, mid, ql, qr), seg_qry(o << 1 | 1, mid + 1, r, ql, qr));
}
```

### 应用

#### 线段树维护区间最值

转移候选是「值域 / 下标区间」时，按区间查询最值即可。

```c++
// 用线段树优化 LIS：dp[v] = 1 + max_{u < v} dp[u]
ll segmax[N << 2];
void seg_upd_max(int o, int l, int r, int pos, ll v) {
    if (l == r) { segmax[o] = max(segmax[o], v); return; }
    int mid = (l + r) >> 1;
    if (pos <= mid) seg_upd_max(o << 1, l, mid, pos, v);
    else seg_upd_max(o << 1 | 1, mid + 1, r, pos, v);
    segmax[o] = max(segmax[o << 1], segmax[o << 1 | 1]);
}
ll seg_qry_max(int o, int l, int r, int ql, int qr) {
    if (qr < l || r < ql) return 0;
    if (ql <= l && r <= qr) return segmax[o];
    int mid = (l + r) >> 1;
    return max(seg_qry_max(o << 1, l, mid, ql, qr), seg_qry_max(o << 1 | 1, mid + 1, r, ql, qr));
}
ll lis_seg(vector<int>& a, int lim) {         // a 已离散化到 1..lim
    ll best = 0;
    for (int x : a) {
        ll c = seg_qry_max(1, 1, lim, 1, x - 1) + 1;
        seg_upd_max(1, 1, lim, x, c);
        best = max(best, c);
    }
    return best;
}
// 例：a = {2,1,3}（离散化后 {2,1,3}）-> LIS 长度 2
```

#### 树状数组维护前缀最值

候选集合是「前缀」时用树状数组（常数更小），但要注意它只能做「可合并且可减」或「前缀」型操作。

```c++
int bitv[N], lim2;
void bit_upd_max(int i, int v) { for (; i <= lim2; i += i & -i) bitv[i] = max(bitv[i], v); }
int bit_qry_max(int i) { int r = 0; for (; i > 0; i -= i & -i) r = max(r, bitv[i]); return r; }
// 例：LIS 的 O(n log n) 解法 —— dp[i] = 1 + max_{v < a[i]} dp
// 注意：树状数组的「区间最值」不能做「任意区间」，只能做前缀 / 后缀
```

## 倍增优化

### 一句话

有一道 $n\le 10^5$ 的题，同一种转移要重复至多 $10^9$ 次，一步步跳显然跑不完，改成先预处理出跳 $2^k$ 步后的结果再按二进制把答案拼起来。**时间 $O(n\log n)$ 预处理、$O(\log n)$ 单次查询，空间 $O(n\log n)$。**

### 原理

### 实现

（预处理「跳 $2^j$ 次」的结果，查询时把次数按二进制拆开拼起来。）

```c++
int up[N][20], sumup[N][20];
void build_doubling(int n, int* fa, int* w) {
    for (int i = 1; i <= n; i++) up[i][0] = fa[i], sumup[i][0] = w[i];
    for (int j = 1; j < 20; j++)
        for (int i = 1; i <= n; i++) {
            up[i][j] = up[up[i][j - 1]][j - 1];
            sumup[i][j] = sumup[i][j - 1] + sumup[up[i][j - 1]][j - 1];
        }
}
```

### 应用

#### 树上跳 $k$ 步的聚合值

把「跳 $k$ 步的点权和 / 边权最值」预处理成倍增表，单次 $O(\log k)$。

```c++
ll jump_k_sum(int u, int k) {                // 从 u 往上跳 k 步，求经过的点权和
    ll res = 0;
    for (int j = 0; j < 20; j++)
        if (k >> j & 1) res += sumup[u][j], u = up[u][j];
    return res;
}
// 把 sumup 换成 maxup / minup 就是「路径上的最值」
```

#### 倍增求 LCA / 第 $k$ 个祖先

先跳到同一深度，再一起往上跳；求第 $k$ 个祖先就是把 $k$ 按二进制拆开。

```c++
int kth_ancestor(int u, int k) {
    for (int j = 0; j < 20; j++) if (k >> j & 1) u = up[u][j];
    return u;
}
// 例：树高 1e5 时倍增表只要 17 层（2^17 > 1e5）
// 记忆点：倍增的「步数必须是 2 的幂的拼接」，所以 k 要用二进制拆
```

## 矩阵优化

### 一句话

有一个状态数为 $k\le 100$ 的线性递推，每一步的转移方式完全一样，要你求出第 $n$ 项（$n\le 10^{18}$），直接递推跑不到头。**时间 $O(k^3\log n)$，空间 $O(k^2)$。**

### 原理

### 实现

```c++
struct MM {
    ll a[2][2];
    MM operator*(const MM& o) const {
        MM r{};
        for (int i = 0; i < 2; i++)
            for (int k = 0; k < 2; k++) {
                if (!a[i][k]) continue;
                for (int j = 0; j < 2; j++) r.a[i][j] = (r.a[i][j] + a[i][k] * o.a[k][j]) % 998244353;
            }
        return r;
    }
};
MM mpow(MM b, ll e) {
    MM r{{{1, 0}, {0, 1}}};
    for (; e; e >>= 1, b = b * b) if (e & 1) r = r * b;
    return r;
}
```

### 应用

#### 一维骨牌铺法（斐波那契型）

「用 $1\times2$ 骨牌铺满 $2\times n$」满足 $f_n=f_{n-1}+f_{n-2}$，矩阵快速幂 $O(\log n)$。

```c++
ll domino_2xn(ll n) {
    if (n <= 2) return n;
    MM b{{{1, 1}, {1, 0}}};
    MM r = mpow(b, n);
    return r.a[0][0] + r.a[0][1];            // = F[n+1]
}
// 验证：n=1 -> 1，n=2 -> 2，n=3 -> 3，n=4 -> 5，n=10 -> 89
// 状态数 k 时复杂度 O(k^3 log n)；用「特征多项式 + Kitamasa」能降到 O(k^2 log n)
```

#### 广义矩阵（max-plus）优化 DP

把「乘法换成加法、加法换成 max」就得到广义矩阵，可以优化「最长路型」的 DP。

```c++
struct GM {
    ll a[2][2];
    GM operator*(const GM& o) const {
        GM r{};
        for (int i = 0; i < 2; i++)
            for (int j = 0; j < 2; j++) {
                r.a[i][j] = (ll)-4e18;
                for (int k = 0; k < 2; k++)
                    if (a[i][k] > (ll)-4e18 / 2 && o.a[k][j] > (ll)-4e18 / 2)
                        r.a[i][j] = max(r.a[i][j], a[i][k] + o.a[k][j]);
            }
        return r;
    }
};
// 单位元是「对角线 0、其余 -inf」；例：恰好走 k 条边的最长路
```

## WQS 二分

### 一句话

有一道 $n\le 10^5$ 的最优化题，要求恰好选 $k$ 个（$k\le n$），而最优值关于 $k$ 是凸的；做法是给每件物品额外挂一个代价 $\lambda$，先不限个数地求最优，再二分 $\lambda$ 把个数的约束逼到 $k$。**时间 $O(n\log C)$，空间 $O(n)$，其中 $C$ 是权值范围。**

### 原理

### 实现

（给每个「选」额外加一个代价 $\lambda$，去掉「恰好 $k$ 个」的限制做无限制 DP，再二分 $\lambda$ 使最优解恰好选 $k$ 个。）

```c++
// 以「恰好选 k 段的最大和」为例（答案关于 k 是上凸的）
ll dpv[N];                                   // 最优值
int dpc[N];                                  // 对应的段数
ll a[N];
int n, K;

// 二分 lambda，返回 (最优值, 段数)
pair<ll, int> check(ll lam) {
    dpv[0] = 0, dpc[0] = 0;
    for (int i = 1; i <= n; i++) {
        // 选：新开一段，付出 lam 的代价
        ll take = dpv[i - 1] + a[i];         // 接着上一段（这里简化成单元素）
        (void)take;
        dpv[i] = dpv[i - 1];
        dpc[i] = dpc[i - 1];
    }
    return {dpv[n], dpc[n]};
}
```

### 应用

#### 恰好选 $k$ 个

对「选」加一个权值 $\lambda$（最大化和时减去 $\lambda$，最小化和时加上 $\lambda$），二分出使段数恰好为 $k$ 的 $\lambda$。

```c++
ll wqs(ll lo, ll hi) {
    // 注意用「整数二分」时要保证循环能结束：
    while (lo < hi) {
        ll mid = lo + (hi - lo) / 2;         // 必须这样写，不能写 (lo+hi)/2
        auto pr = check(mid);
        if (pr.second >= K) lo = mid + 1;    // 段数够多，说明 lambda 太小
        else hi = mid;
    }
    auto pr = check(lo);
    return pr.first + (ll)K * lo;            // 把 lambda 的代价还原回去
}
// 关键：用 lo + (hi - lo) / 2 而不是 (lo + hi) / 2，
//   否则在「全为负数」的区间上会死循环
// 另外：凸性出问题时（例如答案不是凸的）这个做法会给出错误答案，务必先验证凸性
```

#### 恰好 $k$ 段 / 恰好 $k$ 次操作

同一条思路可以用来做「恰好分成 $k$ 段」「恰好执行 $k$ 次操作」「恰好选 $k$ 个不相交区间」。

```c++
// 例：把序列恰好分成 k 段，使「每段的和」的平方和最小
ll pre[N];
// 无限制 DP：每新开一段付出 lam 的代价，返回 (最优值, 段数)
pair<ll, int> chk_seg(int n, ll lam) {
    vector<ll> f(n + 1, (ll)4e18);
    vector<int> c(n + 1, 0);
    f[0] = 0;
    for (int i = 1; i <= n; i++)
        for (int j = 0; j < i; j++) {
            ll s = pre[i] - pre[j];
            ll cand = f[j] + s * s + lam;
            // 注意「取段数最多」的约定，否则二分方向会摇摆
            if (cand < f[i] || (cand == f[i] && c[j] + 1 > c[i])) f[i] = cand, c[i] = c[j] + 1;
        }
    return {f[n], c[n]};
}
ll wqs_segments(int n, int K) {
    ll lo = -(ll)1e12, hi = (ll)1e12;
    while (lo < hi) {
        ll mid = lo + (hi - lo) / 2;
        auto pr = chk_seg(n, mid);
        if (pr.second >= K) lo = mid + 1;
        else hi = mid;
    }
    auto pr = chk_seg(n, lo);
    return pr.first - (ll)K * lo;            // 把 lam 的代价还原
}
// 这里内层是 O(n^2)，只适合验证；真正的题目通常能用单调队列 / 斜率优化把内层降到 O(n)
```

#### 凸性的判定与陷阱

WQS 二分成立的**前提**是「答案关于 $k$ 是凸的」；做题时先用 $O(nk)$ 的暴力打表看相邻差值是否单调，再决定用不用。

```c++
// 打表方法：对每个 k 跑一遍朴素 DP，把答案列出来，看一阶差分是否单调
vector<ll> brute_by_k(int n) {
    vector<ll> res(n + 1);
    // dp[i][j]：前 i 个里选 j 段的最优值
    static ll bdp[505][505];
    for (int i = 0; i <= n; i++) for (int j = 0; j <= n; j++) bdp[i][j] = (ll)-4e18;
    bdp[0][0] = 0;
    // ... 按题意转移 ...
    for (int k = 0; k <= n; k++) res[k] = bdp[n][k];
    return res;
}
// 陷阱一：答案不凸 -> 二分出来的 lambda 对应的段数会「跳过」k
// 陷阱二：段数有多个 lambda 都能达到 k（平台），要规定「取段数最多的那个」并据此调整二分方向
// 陷阱三：(lo + hi) / 2 在 lo、hi 都是负数时会向 0 取整，导致死循环
```
