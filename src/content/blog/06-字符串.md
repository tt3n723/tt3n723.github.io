## 字符串哈希

### 一句话

给一个长度为 $n$ 的字符串（$n\le 10^6$），先把它预处理一遍，之后反复询问：圈出两段子串问它们是否相等、有多长的公共前缀，或者问指定的一段是不是回文、允许 $k$ 次失配时能匹配到哪里。**时间 $O(n)$ 预处理、$O(1)$ 单次查询，空间 $O(n)$。**

### 原理

### 实现

```c++
using ull = unsigned long long;
const ull BASE = 131;
ull pw[N], h[N];
int n;
char s[N];

void build_hash() {                          // s 从下标 1 开始
    pw[0] = 1;
    for (int i = 1; i <= n; i++) {
        pw[i] = pw[i - 1] * BASE;
        h[i] = h[i - 1] * BASE + (unsigned char)s[i];
    }
}
ull sub(int l, int r) { return h[r] - h[l - 1] * pw[r - l + 1]; }   // 子串 [l,r] 的哈希
bool same_sub(int l1, int r1, int l2, int r2) {
    return r1 - l1 == r2 - l2 && sub(l1, r1) == sub(l2, r2);
}
```

### 应用

#### 最长公共前缀（二分 + 哈希）

两个后缀的 LCP 有单调性，二分长度再用哈希 $O(1)$ 判定，单次 $O(\log n)$。

```c++
int lcp_hash(int i, int j) {                 // 后缀 i 与后缀 j 的最长公共前缀
    int lo = 0, hi = min(n - i + 1, n - j + 1);
    while (lo < hi) {
        int mid = (lo + hi + 1) >> 1;
        if (sub(i, i + mid - 1) == sub(j, j + mid - 1)) lo = mid;
        else hi = mid - 1;
    }
    return lo;
}
```

#### 回文判定

「子串 $[l,r]$ 回文」等价于「正着读的哈希等于反着读的哈希」；预处理正序与逆序两套哈希即可 $O(1)$ 判定。

```c++
ull rh[N];
void build_rev() {                           // 逆序串的哈希：rh[i] 对应 s[n..n-i+1]
    for (int i = 1; i <= n; i++) rh[i] = rh[i - 1] * BASE + (unsigned char)s[n - i + 1];
}
ull rsub(int l, int r) {                     // 原串 [l,r] 在逆序串里的对应段
    return rh[n - l + 1] - rh[n - r] * pw[r - l + 1];
}
bool is_pal(int l, int r) { return sub(l, r) == rsub(l, r); }
```

#### 允许 $k$ 次失配的匹配

逐段跳：用 LCP 一次跳过一整段相等部分，遇到失配就跳过 1 个字符，总共 $k+1$ 段，复杂度 $O((k+1)\log n)$。

```c++
int match_k_mismatch(int pos, int L, int k) {   // 文本从 pos 开始，模式长 L
    int cnt = 0, p = pos;
    while (p + L - 1 <= n) {
        int l = lcp_hash(p, /* 模式串在 s 中的位置 */ pos);
        if (l == L) return p;
        if (++cnt > k) return -1;
        p += l + 1;
    }
    return -1;
}
// 实际写法：把模式串和文本拼成一个串（中间加分隔符），把「模式串起点」固定住
```

#### 被卡的应对（双哈希 / 随机基）

单哈希会被构造数据卡掉，竞赛里常用「随机基 + 双模数」或直接用 $2^{64}$ 自然溢出配随机基。

```c++
using ull = unsigned long long;
ull rbase;                                   // 随机基（奇数，且不要太小）
void init_rbase() {
    mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
    rbase = (rng() | 1ULL) % 1000000000ULL + 131;
}
// 双模数版本：同时对两个模数取哈希，两个都相等才算相等
const ull M1 = 1000000007, M2 = 998244353;
ull h1[N], h2[N], p1[N], p2[N];
```

## KMP

### 一句话

给一个长为 $m$ 的模式串 $P$ 和一个长为 $n$ 的文本 $T$（$n\le 10^6$），要你从头到尾扫一遍文本，找出 $P$ 在其中出现的每一个位置。**时间 $O(n+m)$，空间 $O(m)$。**

### 原理

### 实现

```c++
int nxt[N];                                  // nxt[i]：s[1..i] 的最长真 border 长度
void build_kmp(const char* s, int len) {
    nxt[1] = 0;
    for (int i = 2, j = 0; i <= len; i++) {
        while (j && s[i] != s[j + 1]) j = nxt[j];
        if (s[i] == s[j + 1]) j++;
        nxt[i] = j;
    }
}
void kmp_match(const char* t, int tn, const char* p, int pn) {
    for (int i = 1, j = 0; i <= tn; i++) {
        while (j && t[i] != p[j + 1]) j = nxt[j];
        if (t[i] == p[j + 1]) j++;
        if (j == pn) { /* 匹配位置：i - pn + 1 */ j = nxt[j]; }
    }
}
```

### 应用

#### 最长 border / 最小循环节

最长 border 是 $\pi_n$；最小循环节长度是 $n-\pi_n$（当 $n$ 能被它整除时才是完整的循环）。

```c++
int min_period(int len) {                    // s[1..len] 的最小循环节长度
    int t = len - nxt[len];
    return (len % t == 0) ? t : len;         // 不能整除说明「不完整」，整串才是周期
}
int max_border(int len) { return nxt[len]; }
```

#### 前缀出现次数

每个前缀 $s[1..i]$ 都会出现在它的所有「祖先」前缀里；在失配树上按子树大小统计即可。

```c++
int cntp[N];
void count_prefix_occ(int len) {
    for (int i = 1; i <= len; i++) cntp[i] = 1;
    for (int i = len; i >= 2; i--) cntp[nxt[i]] += cntp[i];   // 自底向上累加
}
// cntp[i] 就是前缀 s[1..i] 在整串里出现的次数
```

#### 失配树（nxt 树）上的性质

把 $i$ 连向 $\mathrm{nxt}[i]$ 得到一棵树；$s[1..i]$ 的所有 border 就是根到 $i$ 的路径上的点。

```c++
// 失配树上：i 到根路径上的所有点，恰好是 s[1..i] 的所有 border 长度
// 求「最长的不重叠 border」时可以在树上倍增，或二分 + 哈希
int up_b[N][20];
void build_fail_tree(int len) {
    for (int i = 1; i <= len; i++) up_b[i][0] = nxt[i];
    for (int j = 1; j < 20; j++)
        for (int i = 1; i <= len; i++) up_b[i][j] = up_b[up_b[i][j - 1]][j - 1];
}
```

#### KMP 自动机

把「匹配失败后跳到哪」预处理成转移表，字母表大小为 $\sigma$ 时状态数 $\times\sigma$；之后每个字符 $O(1)$ 转移。

```c++
int go_[N][26];                              // 自动机转移
void build_auto(const char* p, int pn, int sigma) {
    build_kmp(p, pn);
    for (int i = 0; i < pn; i++) {           // 状态 i 表示「已匹配 i 个字符」
        for (int c = 0; c < sigma; c++) {
            if (p[i + 1] == char('a' + c)) go_[i][c] = i + 1;
            else go_[i][c] = (i == 0) ? 0 : go_[nxt[i]][c];
        }
    }
}
// 有了自动机，DP 类问题（不能出现模式串）就能直接在上面跑
```

## Z 函数（扩展 KMP）

### 一句话

给一个长度为 $n$ 的字符串（$n\le 10^6$），要你对每个位置 $i$ 求出后缀 $s[i..n]$ 与整个串的最长公共前缀 $z_i$。**时间 $O(n)$，空间 $O(n)$。**

### 原理

### 实现

（用「已经算出的最右匹配段 $[l,r]$」把 $z_i$ 的初值直接继承过来。）

```c++
int z[N];
void build_z(const char* s, int len) {       // s 从下标 1 开始
    z[1] = len;
    int l = 1, r = 0;
    for (int i = 2; i <= len; i++) {
        if (i > r) z[i] = 0;
        else z[i] = min(r - i + 1, z[i - l + 1]);   // 注意 i > r 时必须清零
        while (i + z[i] <= len && s[z[i] + 1] == s[i + z[i]]) z[i]++;
        if (i + z[i] - 1 > r) l = i, r = i + z[i] - 1;
    }
}
```

### 应用

#### 字符串匹配

把「模式 + 分隔符 + 文本」拼成一个串，$z_i \ge |P|$ 的位置就是匹配位置。

```c++
int z_match(const char* p, int pn, const char* t, int tn) {
    static char u[N * 2];
    int m = 0;
    for (int i = 0; i < pn; i++) u[++m] = p[i];
    u[++m] = '#';                            // 分隔符，保证不会跨越边界匹配
    for (int i = 0; i < tn; i++) u[++m] = t[i];
    build_z(u, m);
    int cnt = 0;
    for (int i = pn + 2; i <= m; i++) if (z[i] >= pn) cnt++;   // 这里就是一个匹配位置
    return cnt;
}
// 匹配位置（文本下标 0 基）= (i - pn - 2)
```

#### 公共前缀之和

$\sum_i z_i$ 就是「每个后缀与整串的 LCP 之和」，直接累加即可。

```c++
ll sum_z(int len) { ll s = 0; for (int i = 1; i <= len; i++) s += z[i]; return s; }
```

#### 扩展 KMP（两个串之间）

求「$T$ 的每个后缀与 $P$ 的 LCP」：先对 $P$ 求 $z$，再用完全相同的逻辑扫 $T$。

```c++
int ext[N];
void exkmp(const char* p, int pn, const char* t, int tn) {
    build_z(p, pn);
    int l = 0, r = -1;                       // 用 0 基写法更容易对齐
    for (int i = 1; i <= tn; i++) {
        ext[i] = (i > r) ? 0 : min(r - i + 1, z[i - l + 1]);
        while (i + ext[i] <= tn && ext[i] < pn && t[i + ext[i]] == p[ext[i] + 1]) ext[i]++;
        if (i + ext[i] - 1 > r) l = i, r = i + ext[i] - 1;
    }
}
```

## 最小表示法

### 一句话

给一个长度为 $n$ 的字符串（$n\le 10^6$），它的每个循环位移都是一种读法，要你找出字典序最小（或最大）的那种读法的起始位置。**时间 $O(n)$，空间 $O(1)$ 额外。**

### 原理

### 实现

（双指针：$i$、$j$ 是两个候选起点，$k$ 是已比较的公共长度；哪边「更大」就整段跳过。）

```c++
int min_representation(const char* s, int n) {   // s 从下标 0 开始
    int i = 0, j = 1, k = 0;
    while (i < n && j < n && k < n) {
        char a = s[(i + k) % n], b = s[(j + k) % n];
        if (a == b) { k++; continue; }
        if (a > b) i = i + k + 1; else j = j + k + 1;
        if (i == j) j++;
        k = 0;
    }
    return min(i, j);                        // 返回起始下标
}
```

### 应用

#### 判断两串是否循环同构

分别求最小表示，再逐字符比较；相同则循环同构，$O(n)$。

```c++
bool cyclic_isomorphic(const char* a, const char* b, int n) {
    int ia = min_representation(a, n), ib = min_representation(b, n);
    for (int t = 0; t < n; t++)
        if (a[(ia + t) % n] != b[(ib + t) % n]) return false;
    return true;
}
```

#### 最大表示

把比较符反过来：$a<b$ 时跳 $i$，得到最大表示。

```c++
int max_representation(const char* s, int n) {
    int i = 0, j = 1, k = 0;
    while (i < n && j < n && k < n) {
        char a = s[(i + k) % n], b = s[(j + k) % n];
        if (a == b) { k++; continue; }
        if (a < b) i = i + k + 1; else j = j + k + 1;
        if (i == j) j++;
        k = 0;
    }
    return min(i, j);
}
```

## Manacher

### 一句话

给一个长度为 $n$ 的字符串（$n\le 10^6$），要你以每个位置为中心向两边撑开，求出那里最长的回文半径。**时间 $O(n)$，空间 $O(n)$。**

### 原理

### 实现

（插入分隔符把奇偶回文统一；用「当前最右回文段的对称点」直接继承半径。）

```c++
char t[N * 2];
int R[N * 2], m;                             // R[i]：以 i 为中心的回文半径（不含中心）

void build_manacher(const char* s, int n) {
    m = 0;
    t[++m] = '#';
    for (int i = 0; i < n; i++) t[++m] = s[i], t[++m] = '#';
    t[m + 1] = 0;
    int c = 0, r = 0;
    for (int i = 1; i <= m; i++) {
        R[i] = (i < r) ? min(R[2 * c - i], r - i) : 0;
        while (i - R[i] - 1 >= 1 && i + R[i] + 1 <= m && t[i - R[i] - 1] == t[i + R[i] + 1]) R[i]++;
        if (i + R[i] > r) c = i, r = i + R[i];
    }
}
```

### 应用

#### 回文子串计数

以每个中心 $i$ 的回文子串个数是 $\lceil R_i/2\rceil$，累加起来就是总个数（按中心计）。

```c++
ll count_palindromes() {
    ll total = 0;
    for (int i = 1; i <= m; i++) total += (R[i] + 1) / 2;
    return total;
}
// 「本质不同」的回文子串个数要用回文自动机，Manacher 只能数「所有出现」
```

#### 以每个位置开头 / 结尾的最长回文

用一个差分数组把「以 $i$ 为中心的半径」摊到区间上，再做前后缀 max。

```c++
int st_pal[N], en_pal[N];                    // 原串下标 0..n-1
void pal_ends(int n) {
    // 中心 i 对应原串位置 (i-1)/2；奇数回文覆盖 [p-R/2, p+R/2]
    for (int i = 1; i <= m; i++) {
        int len = R[i];                      // t 上的半径
        // 还原到原串区间：左端 l = (i - len + 1) / 2，右端 r = (i + len - 1) / 2
        int l = (i - len + 1) / 2, r = (i + len - 1) / 2;
        if (l < 0 || r >= n) continue;
        st_pal[l] = max(st_pal[l], r - l + 1);
        en_pal[r] = max(en_pal[r], r - l + 1);
    }
}
// 求「以每个位置开头的最长回文」还可以用「区间取 max + 前后缀」的技巧
```


## Trie 树

### 一句话

给 $n$ 个字符串（总长 $\le 10^6$，字母表大小 $\sigma$），把它们按字符一层层挂到树上，之后每次询问一个串 $s$，要你沿着树走一遍回答它作为前缀出现了多少次（$|s|$ 是这次问的串长）。**时间 $O(\text{总长})$ 建树、$O(|s|)$ 单次查询，空间 $O(\text{总长}\times\sigma)$。**

### 原理

### 实现

```c++
int ch[N][26], cnt_end[N], trie_tot;

void trie_insert(const char* s) {
    int u = 0;
    for (int i = 0; s[i]; i++) {
        int c = s[i] - 'a';
        if (!ch[u][c]) ch[u][c] = ++trie_tot;
        u = ch[u][c];
        cnt_end[u]++;                        // u 这个前缀被走过多少次
    }
}
int trie_query(const char* s) {              // 返回以 s 为前缀的串个数
    int u = 0;
    for (int i = 0; s[i]; i++) {
        int c = s[i] - 'a';
        if (!ch[u][c]) return 0;
        u = ch[u][c];
    }
    return cnt_end[u];
}
```

### 应用

#### 01-Trie（异或最值）

把数按二进制位从高到低插进 Trie；查询「与 $x$ 异或最大」时每一步尽量走相反位。

```c++
int ch01[N * 31][2], tot01;
void ins01(int x) {
    int u = 0;
    for (int b = 30; b >= 0; b--) {
        int c = (x >> b) & 1;
        if (!ch01[u][c]) ch01[u][c] = ++tot01;
        u = ch01[u][c];
    }
}
int qry01(int x) {                           // 返回与 x 异或最大的值
    int u = 0, res = 0;
    for (int b = 30; b >= 0; b--) {
        int c = (x >> b) & 1;
        if (ch01[u][c ^ 1]) u = ch01[u][c ^ 1], res |= (1 << b);
        else u = ch01[u][c];
    }
    return res;
}
```

#### 可持久化 Trie

对每个前缀建一棵 Trie，查询 $[l,r]$ 时用两个版本的「计数差」判断某条分支里有没有元素。

```c++
int pch[N * 32][2], pcnt[N * 32], ptot, proot[N];
void pinsert(int pre, int& o, int x, int bit) {
    o = ++ptot;
    pch[o][0] = pch[pre][0], pch[o][1] = pch[pre][1];
    pcnt[o] = pcnt[pre] + 1;
    if (bit < 0) return;
    int b = (x >> bit) & 1;
    pinsert(pch[pre][b], pch[o][b], x, bit - 1);
}
int pqry(int lo, int ro, int x, int bit, int cur) {
    if (bit < 0) return cur;
    int b = ((x >> bit) & 1) ^ 1;
    if (pcnt[pch[ro][b]] - pcnt[pch[lo][b]] > 0)
        return pqry(pch[lo][b], pch[ro][b], x, bit - 1, cur | (1 << bit));
    return pqry(pch[lo][b ^ 1], pch[ro][b ^ 1], x, bit - 1, cur);
}
// 区间最大异或和：pqry(proot[l-1], proot[r], x, 30, 0)
```

#### 字典序排序

把所有串插进 Trie，按「先 0 后 1」的字典序 DFS 输出，就是字典序排序（$O(\text{总长})$）。

```c++
void dfs_order(int u, string& cur, vector<string>& out) {
    if (cnt_end[u]) { /* 需要区分「有串在这里结束」与「前缀计数」 */ }
    for (int c = 0; c < 26; c++)
        if (ch[u][c]) { cur.push_back(char('a' + c)); dfs_order(ch[u][c], cur, out); cur.pop_back(); }
}
// 实际排序用 std::sort 更简单；Trie 排序的优势是「可以边插边输出」
```

## AC 自动机

### 一句话

给 $n$ 个模式串（总长 $\le 10^6$）和一个文本，要你把所有模式串建成自动机后拿文本在上面跑一遍，数出每个模式串在文本里出现了多少次。**时间 $O(\text{总长}+\text{文本长})$，空间 $O(\text{总长}\times\sigma)$。**

### 原理

### 实现

（Trie + 失败指针；建完 fail 后可以像 KMP 一样扫文本。）

```c++
int ac[N][26], fail[N], ac_tot;
int cnt_end[N];

void ac_insert(const char* s, int id) {
    int u = 0;
    for (int i = 0; s[i]; i++) {
        int c = s[i] - 'a';
        if (!ac[u][c]) ac[u][c] = ++ac_tot;
        u = ac[u][c];
    }
    cnt_end[u]++;                            // 也可以记下 id，最后统一统计
}
int acorder[N], acordtot;
void ac_build() {
    queue<int> q;
    acordtot = 0;
    for (int c = 0; c < 26; c++)
        if (ac[0][c]) fail[ac[0][c]] = 0, q.push(ac[0][c]);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        acorder[acordtot++] = u;             // 顺便记下 BFS 序（就是「按深度排序」）
        for (int c = 0; c < 26; c++) {
            if (ac[u][c]) fail[ac[u][c]] = ac[fail[u]][c], q.push(ac[u][c]);
            else ac[u][c] = ac[fail[u]][c];  // 补全转移，省掉 while 跳 fail
        }
    }
}
// 注意：补全转移之后就不能再用 fail[ac[u][c]] == u 来找真儿子了！
// 真儿子的 fail 是指向失败链的，不会等于 u。所以 BFS 序必须在建 fail 时一起存。
```

### 应用

#### 模式串出现次数

扫文本时每到一个状态就给它的「计数」加一，最后在 fail 树上自底向上累加。

```c++
int vis[N];
void ac_match(const char* t) {
    int u = 0;
    for (int i = 0; t[i]; i++) {
        u = ac[u][t[i] - 'a'];
        vis[u]++;                            // 记「经过了 u 这个状态」
    }
    // 按 fail 树的拓扑序（BFS 逆序）自底向上累加
    // for (int i = ac_tot; i >= 1; i--) vis[fail[order[i]]] += vis[order[i]];
}
// 注意：直接对每个 u 沿 fail 往上跳会退化；必须先在 fail 树上做子树和
```

#### 多模式串匹配（禁止串 DP）

求「长度 $L$ 且不含任何模式串的串的个数」时，把自动机的转移当边跑 DP，标出「含模式串」的状态（本身命中或 fail 链上有命中）。

```c++
bool bad[N];
void mark_bad() {
    queue<int> q;
    for (int c = 0; c < 26; c++) if (ac[0][c]) q.push(ac[0][c]);
    bad[0] = cnt_end[0] > 0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        bad[u] = bad[fail[u]] || cnt_end[u] > 0;      // fail 链上有命中也算「坏」
        for (int c = 0; c < 26; c++) if (ac[u][c]) q.push(ac[u][c]);
    }
}
```

#### 拓扑排序优化

fail 树的子树和可以用「按 BFS 序的逆序」直接累加，不必显式建树。

```c++
// BFS 序在 ac_build 里已经存进 acorder[]（acordtot 是长度）
void ac_propagate() {
    for (int i = acordtot - 1; i >= 0; i--) {     // 逆着 BFS 序 = 从深到浅
        int u = acorder[i];
        vis[fail[u]] += vis[u];                   // 把子树（fail 树）的计数累加到父亲
    }
}
// vis 的初值：扫文本时每到一个状态就 vis[u]++
// 这样 vis[u] 最终就是「状态 u 代表的串作为某些模式串的后缀出现的次数」
```

## 序列自动机

### 一句话

给一个长度为 $n$ 的字符串（$n\le 10^6$，字母表大小 $\sigma$），预处理出每个位置往后各字符第一次出现的位置，之后每次给你一个串 $s$，要你从前往后跳着看它是不是子序列。**时间 $O(n\sigma)$ 预处理、$O(|s|)$ 单次判定，空间 $O(n\sigma)$。**

### 原理

### 实现

（nxt[i][c] = 从位置 i 往后第一个字符 c 的位置。）

```c++
int snxt[N][26];
void build_seq_auto(const char* s, int n) {
    for (int c = 0; c < 26; c++) snxt[n][c] = -1;
    for (int i = n - 1; i >= 0; i--) {
        for (int c = 0; c < 26; c++) snxt[i][c] = snxt[i + 1][c];
        snxt[i][s[i] - 'a'] = i + 1;         // 用 1 基位置更方便
    }
}
```

### 应用

#### 子序列判定

从位置 0 出发，每读一个字符就跳到它的下一次出现；跳不过去就不是子序列。

```c++
bool is_subseq(const char* t) {
    int p = 0;
    for (int i = 0; t[i]; i++) {
        int c = t[i] - 'a';
        if (snxt[p][c] == -1) return false;
        p = snxt[p][c];
    }
    return true;
}
```

#### 最短未出现子序列

从后往前：$f_i$ 表示「从位置 $i$ 出发，能拼出的最短未出现子序列长度」，若某个字符从 $i$ 起再没出现，则 $f_i=1$。

```c++
int f_sub[N];
int shortest_missing(int n) {
    f_sub[n] = 1;
    for (int i = n - 1; i >= 0; i--) {
        f_sub[i] = (int)1e9;
        for (int c = 0; c < 26; c++)
            f_sub[i] = min(f_sub[i], (snxt[i][c] == -1) ? 1 : f_sub[snxt[i][c]] + 1);
    }
    return f_sub[0];
}
// 从后往前维护「每个字符下一次出现的位置」会把 O(n*26) 降到 O(n + 26)
```

#### 子序列计数 / 本质不同子序列

$g_i$（以下标 $i$ 结尾的本质不同子序列数）用「上一次同字符出现位置」去重。

```c++
ll sub_count(int n) {                        // 本质不同子序列个数（含空串）
    vector<ll> g(n + 1, 0);
    vector<int> last(26, -1);
    g[0] = 1;                                // 空串
    ll total = 1;
    for (int i = 1; i <= n; i++) {
        int c = 0;                           // 这里换成 s[i-1] 对应的字符
        g[i] = total;                        // 接在所有已有子序列后面
        if (last[c] != -1) g[i] = (g[i] - g[last[c]] + MOD) % MOD;   // 去掉重复
        total = (total + g[i]) % MOD;
        last[c] = i - 1;
    }
    return total % MOD;
}
// 不含空串就减 1
```


## 后缀数组（SA）

### 一句话

给一个长度为 $n$ 的字符串（$n\le 10^6$），要你把它的所有后缀按字典序排好，求出排名数组 $sa$、$rank$ 以及相邻后缀的高度数组 $height$。**时间 $O(n\log n)$（倍增）或 $O(n)$（SA-IS），空间 $O(n)$。**

### 原理

### 实现

```c++
int sa[N], rk[N], tmp[N], height[N], LOG_[N];
int st_lcp[N][21];

void build_sa(const char* s, int n) {        // s 从下标 1 开始，最好在 s[n+1] 放一个 0 哨兵
    int m = max(n, 300);
    // 关键：倍增里会读到 tmp2[sa[i] + k]，下标可以到 2n；
    // 多组数据时这些位置残留的脏值会导致排序出错，所以必须先清零
    memset(rk, 0, sizeof(int) * (2 * n + 2));
    memset(tmp2, 0, sizeof(int) * (2 * n + 2));
    vector<int> cnt(max(n, 300) + 1, 0);
    for (int i = 1; i <= n; i++) cnt[rk[i] = (unsigned char)s[i]]++;
    for (int i = 1; i <= m; i++) cnt[i] += cnt[i - 1];
    for (int i = n; i >= 1; i--) sa[cnt[rk[i]]--] = i;
    for (int k = 1; k < n; k <<= 1) {
        int p = 0;
        for (int i = n - k + 1; i <= n; i++) tmp[++p] = i;
        for (int i = 1; i <= n; i++) if (sa[i] > k) tmp[++p] = sa[i] - k;
        fill(cnt.begin(), cnt.end(), 0);
        for (int i = 1; i <= n; i++) cnt[rk[i]]++;
        for (int i = 1; i <= m; i++) cnt[i] += cnt[i - 1];
        for (int i = n; i >= 1; i--) sa[cnt[rk[tmp[i]]]--] = tmp[i];
        swap(rk, tmp);
        rk[sa[1]] = p = 1;
        for (int i = 2; i <= n; i++) {
            if (tmp[sa[i]] != tmp[sa[i - 1]] ||
                tmp[sa[i] + k] != tmp[sa[i - 1] + k]) p++;
            rk[sa[i]] = p;
        }
        m = p;
        if (m == n) break;
    }
}
void build_height(const char* s, int n) {
    for (int i = 1, k = 0; i <= n; i++) {
        if (rk[i] == 1) { k = 0; continue; }
        if (k) k--;
        int j = sa[rk[i] - 1];
        while (i + k <= n && j + k <= n && s[i + k] == s[j + k]) k++;
        height[rk[i]] = k;
    }
}
```

### 应用

#### 任意两后缀的 LCP

两后缀的 LCP 等于它们排名之间 $height$ 的最小值，用 ST 表 $O(1)$ 查询。

```c++
void build_lcp_st(int n) {
    LOG_[1] = 0;
    for (int i = 2; i <= n; i++) LOG_[i] = LOG_[i >> 1] + 1;
    for (int i = 1; i <= n; i++) st_lcp[i][0] = height[i];
    for (int j = 1; (1 << j) <= n; j++)
        for (int i = 1; i + (1 << j) - 1 <= n; i++)
            st_lcp[i][j] = min(st_lcp[i][j - 1], st_lcp[i + (1 << (j - 1))][j - 1]);
}
int lcp_sa(int i, int j) {                   // 后缀 i、j 的 LCP
    if (i == j) return /* n - i + 1 */ 0;
    int a = rk[i], b = rk[j];
    if (a > b) swap(a, b);
    a++;                                     // height 的区间是 (a, b]
    int k = LOG_[b - a + 1];
    return min(st_lcp[a][k], st_lcp[b - (1 << k) + 1][k]);
}
```

#### 本质不同子串个数

每个后缀的新增子串数是「后缀长度减掉它和上一个后缀的 LCP」，累加即可。

```c++
ll distinct_substrings(int n) {
    ll total = 0;
    for (int i = 1; i <= n; i++) total += (ll)n - sa[i] + 1 - height[i];
    return total;
}
```

#### 至少出现 $k$ 次的最长子串

出现至少 $k$ 次的子串对应「连续的 $k-1$ 个 $height$ 都 $\ge L$」，二分 $L$ 后用滑动窗口检查。

```c++
bool check_k(int k, int L, int n) {
    if (k == 1) return true;
    int cnt = 1;
    for (int i = 2; i <= n; i++) {
        if (height[i] >= L) { if (++cnt >= k) return true; }
        else cnt = 1;
    }
    return false;
}
int longest_at_least_k(int k, int n) {
    int lo = 0, hi = n;
    while (lo < hi) {
        int mid = (lo + hi + 1) >> 1;
        if (check_k(k, mid, n)) lo = mid; else hi = mid - 1;
    }
    return lo;
}
```

把两串拼起来（中间加一个不会出现的分隔符），求「来自不同串的两个后缀的 LCP 最大值」。


## 后缀自动机（SAM）

### 一句话

给一个长度为 $n$ 的字符串（$n\le 10^6$），要你在线地往里一个个加字符、建出它的后缀自动机，从而数出本质不同子串的个数和每个子串的出现次数。**时间 $O(n)$ 建机，空间 $O(n)$。**

### 原理

### 实现

```c++
int sam_ch[N][26], sam_link[N], sam_len[N], sam_tot, sam_last;
ll occ[N];                                   // 每个状态的 endpos 大小

void sam_init() { sam_tot = sam_last = 1; }
void sam_extend(int c) {
    int cur = ++sam_tot;
    sam_len[cur] = sam_len[sam_last] + 1;
    occ[cur] = 1;                            // 新状态代表一个前缀
    int p = sam_last;
    for (; p && !sam_ch[p][c]; p = sam_link[p]) sam_ch[p][c] = cur;
    if (!p) sam_link[cur] = 1;
    else {
        int q = sam_ch[p][c];
        if (sam_len[p] + 1 == sam_len[q]) sam_link[cur] = q;
        else {
            int clone = ++sam_tot;
            sam_len[clone] = sam_len[p] + 1;
            memcpy(sam_ch[clone], sam_ch[q], sizeof sam_ch[q]);
            sam_link[clone] = sam_link[q];
            for (; p && sam_ch[p][c] == q; p = sam_link[p]) sam_ch[p][c] = clone;
            sam_link[q] = sam_link[cur] = clone;
            occ[clone] = 0;                  // clone 不额外贡献
        }
    }
    sam_last = cur;
}
```

### 应用

#### 本质不同子串个数

每个状态贡献 $\mathrm{len}(v)-\mathrm{len}(\mathrm{link}(v))$ 个不同子串，累加即可。

```c++
ll distinct_sam() {
    ll total = 0;
    for (int i = 2; i <= sam_tot; i++) total += sam_len[i] - sam_len[sam_link[i]];
    return total;
}
```

#### 子串出现次数

把 occ 按 len 从大到小（即拓扑序）累加到 link 上，$occ[v]$ 就是状态 $v$ 代表的子串出现次数。

```c++
int buc[N], ord_sam[N];
void count_occ(int n) {
    for (int i = 1; i <= sam_tot; i++) buc[sam_len[i]]++;
    for (int i = 1; i <= n; i++) buc[i] += buc[i - 1];
    for (int i = sam_tot; i >= 1; i--) ord_sam[buc[sam_len[i]]--] = i;
    for (int i = sam_tot; i >= 1; i--) occ[sam_link[ord_sam[i]]] += occ[ord_sam[i]];
}
```

#### 两个串的最长公共子串

在 SAM 上跑另一个串：能走就走、长度加一；走不动就跳 link 并缩短长度。

```c++
int longest_common(const char* t) {
    int v = 1, l = 0, best = 0;
    for (int i = 0; t[i]; i++) {
        int c = t[i] - 'a';
        while (v && !sam_ch[v][c]) v = sam_link[v], l = sam_len[v];
        if (sam_ch[v][c]) v = sam_ch[v][c], l++;
        else v = 1, l = 0;
        best = max(best, l);
    }
    return best;
}
```

#### 广义 SAM（多串）

每插入一个新串时把 sam_last 重置为 1；若要严格处理重复子串，插入前还要判「这个转移是否已存在且长度匹配」。

```c++
void sam_insert_string(const char* s) {
    sam_last = 1;                            // 每个串都从根开始
    for (int i = 0; s[i]; i++) sam_extend(s[i] - 'a');
}
// 广义 SAM 的节点数是 O(总长)；occ 的统计方式与单串相同
```

## 后缀树

### 一句话

给一个长度为 $n$ 的字符串（$n\le 10^6$），要你把它所有后缀的公共前缀组织成一棵压缩过的树，树里每个内部结点都对应着一个重复子串。**时间 $O(n)$ 建树（常用 $O(n\log n)$ 的 SA + LCP 建法），空间 $O(n)$。**

### 原理

### 实现

（后缀树 = 所有后缀的压缩 Trie；用后缀数组 + $height$ 的笛卡尔树可以等效地建出来。）

```c++
// 用 SA + height 建「后缀树的等价结构」：height 的笛卡尔树
// 笛卡尔树上的每个内部结点对应一个 LCP 区间 [l, r]，它的深度是 min(height[l..r])
int lc_c[N], rc_c[N], stk_c[N];
int build_cartesian(int* height, int n) {    // height[1..n]，height[1] = 0
    int top = 0;
    for (int i = 1; i <= n; i++) {
        int last = 0;
        while (top && height[stk_c[top]] > height[i]) last = stk_c[top--];
        lc_c[i] = last;
        if (top) rc_c[stk_c[top]] = i;
        stk_c[++top] = i;
    }
    return stk_c[1];                         // 笛卡尔树的根
}
```

### 应用

#### 后缀树上的统计

每个内部结点对应的子串「出现了多少次」= 它子树的叶子数；用它可以直接求重复子串。

```c++
int leaf_cnt[N];
void dfs_cart(int u) {
    leaf_cnt[u] = (lc_c[u] == 0 && rc_c[u] == 0) ? 1 : 0;
    if (lc_c[u]) { dfs_cart(lc_c[u]); leaf_cnt[u] += leaf_cnt[lc_c[u]]; }
    if (rc_c[u]) { dfs_cart(rc_c[u]); leaf_cnt[u] += leaf_cnt[rc_c[u]]; }
}
// 结点 u 的「深度」（即它代表的 LCP 长度）= height[u]
// 「出现至少 k 次的最长子串」= 找子树叶子数 >= k 的结点中 height 最大的
```

#### 最长重复子串

就是 $height$ 数组的最大值（至少出现两次的最长子串）。

```c++
int longest_repeat(int n) {
    int best = 0;
    for (int i = 2; i <= n; i++) best = max(best, height[i]);
    return best;
}
// 「出现至少 k 次」则是「长度为 k-1 的窗口内 height 的最小值的最大值」，
// 用单调队列 O(n) 或二分 O(n log n)
```

## 后缀平衡树

### 一句话

一开始有一个字符串，接下来有若干次操作（总长 $n$），每次操作是「在末尾追加一个字符」或「在开头插入一个字符」，插入之后随时可以问任意两个后缀谁的字典序更小，两种操作交替出现。**时间 $O(\log n)$ 单次插入、$O(1)$ 比较，空间 $O(n)$。**

### 原理

### 实现

（用一棵平衡树按字典序存所有后缀；比较两个后缀时可以用「哈希 + 二分」或者维护的「标签」。）

```c++
using ull = unsigned long long;
const ull SB = 131;
ull sh[N], sp[N];
int slen;

// 哈希 + 二分比较两个后缀的字典序：O(log n) 一次比较
int cmp_suffix(int i, int j) {               // 返回 -1 / 0 / 1
    int lo = 0, hi = min(slen - i + 1, slen - j + 1);
    while (lo < hi) {
        int mid = (lo + hi + 1) >> 1;
        ull a = sh[i + mid - 1] - sh[i - 1] * sp[mid];
        ull b = sh[j + mid - 1] - sh[j - 1] * sp[mid];
        if (a == b) lo = mid; else hi = mid - 1;
    }
    if (lo == min(slen - i + 1, slen - j + 1)) return 0;
    return sh[i + lo] < sh[j + lo] ? -1 : 1;
}
```

### 应用

#### 在线比较后缀

用「哈希 + 二分」可以在 $O(\log n)$ 内比较两个后缀；配合平衡树就能维护「按字典序排序的后缀集合」。

```c++
// 用替罪羊树维持「按字典序排序的后缀序列」：
int sbt_ls[N], sbt_rs[N], sbt_sz[N], sbt_root, sbt_tot;
int sbt_new() { ++sbt_tot; sbt_ls[sbt_tot] = sbt_rs[sbt_tot] = 0; sbt_sz[sbt_tot] = 1; return sbt_tot; }
void sbt_pushup(int o) { if (o) sbt_sz[o] = sbt_sz[sbt_ls[o]] + sbt_sz[sbt_rs[o]] + 1; }
int sbt_insert(int o, int suf) {             // 返回新的子树根
    if (!o) return sbt_new(), sbt_suf[sbt_tot] = suf, sbt_tot;
    if (cmp_suffix(suf, sbt_suf[o]) < 0) sbt_ls[o] = sbt_insert(sbt_ls[o], suf);
    else sbt_rs[o] = sbt_insert(sbt_rs[o], suf);
    sbt_pushup(o);
    return o;
}
// 单次插入 O(树高 × 比较代价) = O(log^2 n)
// 失衡时把子树中序拍平后重建，就得到替罪羊式的均摊保证
```

#### 后缀平衡树的核心：标签比较

维护「每个点的实数标签」，比较两个后缀时只要比较标签，就得到 $O(1)$ 比较；失衡时重建整棵子树并重新分配标签。

```c++
double tag[N];
// 插入时：tag[new] = (tag[pred] + tag[succ]) / 2
// 若两个标签太接近（精度不够），就把整棵子树拍平、重新均匀分配标签
// 这样比较就是 O(1)，插入均摊 O(log n)
```

## 回文自动机（PAM）

### 一句话

给一个长度为 $n$ 的字符串（$n\le 10^6$），要你一个个字符往里加、建出回文自动机，数出其中本质不同的回文子串有多少个、每个回文子串出现了多少次。**时间 $O(n)$ 建机，空间 $O(n)$。**

### 原理

### 实现

（两个根：长度 $-1$ 的奇根和长度 $0$ 的偶根；每个结点代表一个本质不同的回文串。）

```c++
int pam_ch[N][26], pam_fail[N], pam_len[N], pam_tot, pam_last;
char pstr[N];
int cnt_pam[N];

void pam_init() {
    pam_tot = 1, pam_last = 0;
    pam_len[0] = -1, pam_fail[0] = 0;        // 奇根，fail 指向自己
    pam_len[1] = 0, pam_fail[1] = 0;         // 偶根
    memset(pam_ch, 0, sizeof pam_ch);
}
int get_fail(int u, int pos) {
    while (pos - pam_len[u] - 1 < 0 || pstr[pos - pam_len[u] - 1] != pstr[pos]) u = pam_fail[u];
    return u;
}
void pam_extend(int pos) {                   // pstr 从 0 开始，pos 是当前位置
    int c = pstr[pos] - 'a';
    int u = get_fail(pam_last, pos);
    if (!pam_ch[u][c]) {
        int nw = ++pam_tot;
        pam_len[nw] = pam_len[u] + 2;
        pam_fail[nw] = (pam_len[nw] == 1) ? 1 : pam_ch[get_fail(pam_fail[u], pos)][c];
        pam_ch[u][c] = nw;
    }
    pam_last = pam_ch[u][c];
    cnt_pam[pam_last]++;                     // 记录「到这里结束的最长回文」出现一次
}
```

### 应用

#### 本质不同回文子串个数

除两个根以外的结点数就是答案。

```c++
int count_distinct_pal() { return pam_tot - 1; }
```

#### 每个回文子串出现次数

按 len 从大到小，把 cnt 累加到 fail 上（fail 树上的子树和）。

```c++
void count_pal_occ(int n) {
    static int buc2[N], ord2[N];
    for (int i = 0; i <= n; i++) buc2[i] = 0;
    for (int i = 1; i <= pam_tot; i++) buc2[pam_len[i]]++;
    for (int i = 1; i <= n; i++) buc2[i] += buc2[i - 1];
    for (int i = pam_tot; i >= 1; i--) ord2[buc2[pam_len[i]]--] = i;
    for (int i = pam_tot; i >= 1; i--) cnt_pam[pam_fail[ord2[i]]] += cnt_pam[ord2[i]];
}
```

#### 回文划分

$f_i$ 由「所有以 $i$ 结尾的回文串」转移，用 fail 链上的等差性质可以把 $O(n^2)$ 降到 $O(n\log n)$。

```c++
// 朴素做法：枚举 fail 链上的所有回文长度，最坏 O(n^2)
ll pal_partition(int n) {
    static ll f[N];
    f[0] = 1;
    for (int k = 0; k < n; k++) {
        pam_extend(k);                       // 处理完第 k 个字符（0 基）
        f[k + 1] = 0;
        for (int u = pam_last; u > 1; u = pam_fail[u])       // 所有以 k 结尾的回文后缀
            f[k + 1] = (f[k + 1] + f[k + 1 - pam_len[u]]) % MOD;
    }
    return f[n];
}
// 例："aaa" 的划分方案数是 4（a|a|a、aa|a、a|aa、aaa）
// 优化：记录 series_ans（同一等差数列的贡献和），把 fail 链上的等差部分整体转移，
//   复杂度降到 O(n log n)
```

## Burrows–Wheeler 变换（BWT）

### 一句话

给一个长度为 $n$ 的字符串（$n\le 10^6$），要你把它所有循环位移排好序，取出每个位移的最后一个字符，再能从这一串字符还原回原串。**时间 $O(n\log n)$（用 SA）或 $O(n)$，空间 $O(n)$。**

### 原理

### 实现

```c++
int bwt_sa[N];
char bwt_out[N];

void bwt_encode(const char* s, int n) {      // s 从下标 0 开始
    // 1. 求 s 的后缀数组（见「后缀数组」一节）
    // 2. BWT 的第 i 个字符 = s[(sa[i] - 1 + n) % n]
    for (int i = 0; i < n; i++) {
        int p = bwt_sa[i];
        bwt_out[i] = s[(p - 1 + n) % n];
    }
    // 3. 用小于所有字符的哨兵标记「原串结尾」，逆变换才能唯一确定
}
```

### 应用

#### 数据压缩

BWT 之后相同字符会聚集，再配合游程编码（RLE）与 MTF 就能大幅压缩。

```c++
void mtf(char* b, int n) {                   // 把字符换成「上次出现距离」
    vector<int> alpha(256);
    iota(alpha.begin(), alpha.end(), 0);
    for (int i = 0; i < n; i++) {
        int pos = find(alpha.begin(), alpha.end(), (unsigned char)b[i]) - alpha.begin();
        int orig = alpha[pos];
        b[i] = (char)pos;
        alpha.erase(alpha.begin() + pos);
        alpha.insert(alpha.begin(), orig);
    }
}
// 完整流程：BWT -> MTF -> RLE -> Huffman，这就是 bzip2 的核心链路
```

#### 逆变换的正确性

逆变换靠「L 列（排序后的第一列）与 F 列」的对应关系迭代还原。

```c++
char bwt_decode(char* lastc, int n) {
    // 1. 统计每个字符出现次数，得到 L 列到 F 列的映射 nxt[]
    int cntc[256] = {}, pos_of[256];
    for (int i = 0; i < n; i++) cntc[(unsigned char)lastc[i]]++;
    int sum = 0;
    for (int c = 0; c < 256; c++) { pos_of[c] = sum; sum += cntc[c]; }
    vector<int> nxt(n);
    for (int i = 0; i < n; i++) nxt[pos_of[(unsigned char)lastc[i]]++] = i;
    // 2. 从哨兵所在位置出发，沿 nxt 走 n 步还原原串
    int p = 0;
    for (int i = 0; i < n; i++) p = nxt[p];
    return lastc[p];
}
// 关键：lastc[] 必须是「按 SA 顺序取前一字符」得到的，且含唯一哨兵
```

## Lyndon 分解

### 一句话

给一个长度为 $n$ 的字符串（$n\le 10^6$），要你从左到右把它切成若干段，使每一段都严格小于自己的所有真后缀。**时间 $O(n)$，空间 $O(1)$ 额外。**

### 原理

### 实现

（Duval 算法：维护「当前 Lyndon 串的周期」，逐字符扩张。）

```c++
// Duval 算法：把 s 分解成 s = w1 w2 ... wk，每个 wi 是 Lyndon 串且 w1 >= w2 >= ... >= wk
void duval(const char* s, int n, vector<pair<int, int>>& parts) {
    int i = 0;
    while (i < n) {
        int j = i + 1, k = i;
        while (j < n && s[k] <= s[j]) {
            if (s[k] < s[j]) k = i;
            else k++;
            j++;
        }
        while (i <= k) {
            parts.push_back({i, i + (j - k - 1)});   // 这一段是 [i, i + (j-k-1)]
            i += j - k;
        }
    }
}
```

### 应用

#### 最小表示法

Lyndon 分解的最后一个 Lyndon 串的起点，就是最小表示的起点。

```c++
int min_by_lyndon(const char* s, int n) {
    // 把 s 复制一倍，找「长度 >= n 的第一个 Lyndon 段的起点」
    // 或者直接用双指针最小表示法，两者复杂度都是 O(n)
    int i = 0, j = 1, k = 0;
    while (i < n && j < n && k < n) {
        char a = s[(i + k) % n], b = s[(j + k) % n];
        if (a == b) { k++; continue; }
        if (a > b) i = i + k + 1; else j = j + k + 1;
        if (i == j) j++;
        k = 0;
    }
    return min(i, j);
}
```

#### 最小后缀

「最小后缀」指所有后缀中字典序最小的那个；它一定出现在 Lyndon 分解的最后一段。

```c++
int min_suffix_brute(const char* s, int n) {
    int best = 0;
    for (int i = 1; i < n; i++)
        if (strcmp(s + i, s + best) < 0) best = i;
    return best;                             // O(n^2)，仅用于对拍验证
}
// Lyndon 分解可以在 O(n) 内得到最小后缀：
//   答案是最后一个 Lyndon 段，或它的某个周期重复位置
```


## 字符串 DP

### 一句话

给两个长度不超过 $n$ 的字符串（$n\le 5000$），要你逐位比较着往右扫，求出它们的最长公共子序列长度，并在单个串上找出最长回文子序列、判断带通配符的两个串能否匹配。**时间 $O(n^2)$，空间 $O(\min(n,m))$。**

### 原理

### 实现

```c++
int sdp[N][N];
int lcs_dp(const char* a, int n, const char* b, int m) {   // 从下标 1 开始
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            sdp[i][j] = max(sdp[i - 1][j], sdp[i][j - 1]);
            if (a[i] == b[j]) sdp[i][j] = max(sdp[i][j], sdp[i - 1][j - 1] + 1);
        }
    return sdp[n][m];
}
```

### 应用

#### 最长回文子序列

区间 DP：两端字符相同时长度加 2，否则取「去掉一端」的较大值。

```c++
int lps_dp(const char* s, int n) {           // s 从下标 1 开始
    for (int i = 1; i <= n; i++) sdp[i][i] = 1;
    for (int len = 2; len <= n; len++)
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            if (s[i] == s[j]) sdp[i][j] = sdp[i + 1][j - 1] + 2;
            else sdp[i][j] = max(sdp[i + 1][j], sdp[i][j - 1]);
        }
    return n ? sdp[1][n] : 0;
}
```

#### 通配符 / 正则匹配

通配符问号匹配任意一个字符、星号匹配任意长度（含空），用二维 DP 递推；星号那一维可以只用一行滚动。

```c++
bool wild_match(const char* s, int n, const char* p, int m) {
    vector<char> f(m + 1, 0), g(m + 1, 0);
    f[0] = 1;
    for (int j = 1; j <= m; j++) f[j] = (p[j] == '*') ? f[j - 1] : 0;
    for (int i = 1; i <= n; i++) {
        fill(g.begin(), g.end(), 0);
        for (int j = 1; j <= m; j++) {
            if (p[j] == '*') g[j] = (g[j - 1] || f[j]) ? 1 : 0;
            else if (p[j] == '?' || p[j] == s[i]) g[j] = f[j - 1];
        }
        f.swap(g);
    }
    return f[m] != 0;
}
// 注意 p 里可能有连续的星号，上面的写法天然能处理
```

## 自动机上 DP

### 一句话

先给若干模式串建成 AC 自动机（状态数 $S\le 10^5$），再考虑所有长度为 $L$ 的串（$L\le 10^{18}$），要你沿着自动机一位一位地走，数出其中不包含任何模式串的串有多少个。**时间 $O(S\sigma L)$（$L$ 大时用矩阵快速幂降到 $O(S^3\log L)$），空间 $O(S)$。**

### 原理

### 实现

```c++
ll adp[N], nadp[N];
ll ac_count_len(int L) {                     // 在 AC 自动机上跑 L 步，统计路径数
    memset(adp, 0, sizeof adp);
    adp[0] = 1;
    for (int step = 0; step < L; step++) {
        memset(nadp, 0, sizeof nadp);
        for (int u = 0; u <= ac_tot; u++) {
            if (!adp[u] || bad[u]) continue;          // bad[]：命中模式串的状态
            for (int c = 0; c < 26; c++) {
                int v = ac[u][c];
                if (bad[v]) continue;
                nadp[v] = (nadp[v] + adp[u]) % MOD;
            }
        }
        memcpy(adp, nadp, sizeof(ll) * (ac_tot + 1));
    }
    ll total = 0;
    for (int u = 0; u <= ac_tot; u++) if (!bad[u]) total = (total + adp[u]) % MOD;
    return total;
}
```

### 应用

#### 长度很大时用矩阵快速幂

$L\le 10^{18}$ 时把转移写成 $S\times S$ 的矩阵（$S$ 是自动机状态数），用快速幂。

```c++
// 只在 S 较小（<= 100 左右）时可用：复杂度 O(S^3 log L)
// 做法：矩阵 M[a][b] = 「从状态 a 走一步到状态 b 的字符数」
//   初始向量是「状态 0 处为 1」，答案 = (v * M^L) 在所有非 bad 状态上的和
static const int AS = 105;
ll amat[AS][AS], atmp[AS][AS];
// 若 S 很大，用「特征多项式 + Kitamasa」或对自动机做分治合并
```

#### 出现至少一次 / 恰好 $k$ 次

把「命中次数」也放进状态（多一维 $0..k$），或者在自动机上标记「已经命中过」。

```c++
// 状态 = (自动机结点, 命中次数)：命中次数超过 K 就剪掉
ll ac_exact_k(int L, int K, int sigma) {
    vector<vector<ll>> g(ac_tot + 1, vector<ll>(K + 1, 0)), ng;
    g[0][0] = 1;
    for (int step = 0; step < L; step++) {
        ng.assign(ac_tot + 1, vector<ll>(K + 1, 0));
        for (int u = 0; u <= ac_tot; u++)
            for (int t = 0; t <= K; t++) {
                if (!g[u][t]) continue;
                for (int c = 0; c < sigma; c++) {
                    int v = ac[u][c];
                    int nt = t + (cnt_end[v] > 0 ? 1 : 0);
                    if (nt > K) continue;
                    ng[v][nt] = (ng[v][nt] + g[u][t]) % MOD;
                }
            }
        g.swap(ng);
    }
    ll total = 0;
    for (int u = 0; u <= ac_tot; u++) total = (total + g[u][K]) % MOD;
    return total;
}
// 「至少出现一次」= 总数 - 「一次都不出现」
```

#### 与 KMP 自动机的配合

只有一个模式串时用 KMP 自动机（状态数等于模式串长度），比 AC 自动机省时间空间。

```c++
// KMP 自动机的状态就是「已匹配的长度」（0..|P|）
// 用「不能出现模式串」的 DP：走到状态 |P| 就剪掉
ll kmp_count(int pn, int L) {
    vector<ll> f(pn + 1, 0), nf(pn + 1, 0);
    f[0] = 1;
    for (int step = 0; step < L; step++) {
        fill(nf.begin(), nf.end(), 0);
        for (int u = 0; u < pn; u++) {
            if (!f[u]) continue;
            for (int c = 0; c < 26; c++) {
                int v = go_[u][c];
                if (v == pn) continue;       // 出现模式串，剪掉
                nf[v] = (nf[v] + f[u]) % MOD;
            }
        }
        f.swap(nf);
    }
    ll total = 0;
    for (int i = 0; i < pn; i++) total = (total + f[i]) % MOD;
    return total;
}
```
