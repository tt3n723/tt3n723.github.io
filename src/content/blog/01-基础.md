## 时间与空间复杂度

### 一句话

给你时限 $1$ 秒、内存 $256$ MB 和一道题的数据范围（$n$ 最大到 $10^7$），要你在动手写代码之前先估出「什么样的复杂度能过」，再据此挑算法。**时间 $O(1)$（判断本身），空间按所选算法计。**

### 原理


### 实现

（先估规模，再定复杂度：$n\le 20$ 指状压、$n\le 500$ 指 $O(n^3)$、$n\le 5000$ 指 $O(n^2)$、$n\le 10^5$ 指 $O(n\log n)$、$n\le 10^7$ 指 $O(n)$。）

```c++
// 常见规模的「可接受复杂度」速查（1 秒、约 1e8 次简单运算）
// n <= 20        -> O(2^n), O(n*2^n)
// n <= 100       -> O(n^3)（约 1e6）
// n <= 500       -> O(n^3) 勉强、O(n^2) 稳
// n <= 5000      -> O(n^2)
// n <= 1e5       -> O(n log n), O(n sqrt n)
// n <= 1e6       -> O(n), O(n log n) 需卡常
// n <= 1e7       -> O(n)，且常数要很小
ll work_count(double n, int logn) {          // 粗略估算运算次数
    return (ll)(n * logn);
}
```

### 应用


#### 常见规模与可接受复杂度
把上面的表背下来（或者现场估），能避免「算法对了但复杂度超了」的常见翻车。

```c++
// 把「规模 -> 可接受复杂度」写成表，用程序算一下就知道会不会超时
const char* suggest(long long n) {
    if (n <= 20) return "O(2^n) 或 O(n*2^n)";
    if (n <= 100) return "O(n^3)";
    if (n <= 500) return "O(n^3) 勉强，O(n^2) 稳";
    if (n <= 5000) return "O(n^2)";
    if (n <= 100000) return "O(n log n) 或 O(n sqrt n)";
    if (n <= 1000000) return "O(n) 或卡常的 O(n log n)";
    return "O(n)，且常数必须很小";
}
// 例：n = 2000 时给 O(n^2)（4e6 次，可行）
// 例：n = 200000 时给 O(n log n)（约 3.4e6 次，可行）；O(n^2) = 4e10 必然超时
```

#### 空间估算
整数数组 $10^7$ 个 int 约 40 MB；二维 $5000\times5000$ 的 long long 就是 200 MB，必须降维。

```c++
// 常用估算：int 4 B、long long 8 B、double 8 B
// 1e7 个 int  = 40 MB
// 1e7 个 ll   = 80 MB
// 5000 x 5000 的 ll = 2e8 B = 200 MB（超 256 MB 限额的一半以上，慎用）
size_t mem_estimate(size_t cnt, int bytes_per_unit) { return cnt * bytes_per_unit; }
```

## 平摊分析与势能分析

### 一句话

给你一个「单次最坏很慢、但总量很快」的结构（如单调栈、并查集、双指针），要你说明它为什么总复杂度是线性的。**时间摊还单次 $O(1)$（并查集为 $O(\alpha(n))$），空间 $O(n)$。**

### 原理


### 实现

（用「势能」记账：定义势能 $\Phi$ 为结构里「还没被消耗的余量」，把每次操作的「真实代价 $+\Delta\Phi$」累加起来，中间的项会两两抵消，只剩下首尾。）

```c++
// 以单调栈为例：每个元素最多进栈一次、出栈一次
int stk[N], top_;
void monotonic(int a[], int n) {
    for (int i = 0; i < n; i++) {
        while (top_ && stk[top_] <= a[i]) top_--;   // 出栈：全程累计不超过 n 次
        stk[++top_] = a[i];                          // 入栈：共 n 次
    }
}
// 势能取 Φ = 栈的大小。第 i 次操作的真实代价 = 1 + (本次出栈数)，
// 而 ΔΦ = -(本次出栈数)，所以摊还代价 = 1 + 出栈数 - 出栈数 = O(1)。
// 求和后总代价 = n + (总出栈数) <= 2n = O(n)。

// 并查集同理：Φ 取「每个点到根的距离之和」，路径压缩把它大幅压低，
// 于是单次摊还 O(α(n))；双指针、单调队列、KMP 的失配跳转都是这一类。
```

### 应用

### 一句话

```c++
inline int readInt() {

    char ch = getchar();
    while (ch < '0' || ch > '9') { if (ch == '-') f = -1; ch = getchar(); }
    while (ch >= '0' && ch <= '9') x = x * 10 + (ch - '0'), ch = getchar();

```

## 高精度运算


### 一句话

给两个十进制大整数 $a,b$，位数都不超过 $10^5$（位数 $n\le 10^5$），要你像竖式一样算出 $a+b$、$a-b$、$a\times b$、$a\div b$ 并比较大小，低位对齐地从个位往上扫，加减、乘法、试商交替出现。**时间 $O(n)$（加减、比较）、$O(n^2)$（朴素乘除）或 $O(n\log n)$（FFT/NTT），空间 $O(n)$。**


### 原理


### 实现

（用 int 数组倒着存每一位，低位在前；所有运算从低位往高位扫。）

```c++
struct Big {
    vector<int> d;                           // d[0] 是个位
    static const int BASE = 10000, W = 4;    // 压 4 位
    Big(long long x = 0) { while (x) d.push_back(x % BASE), x /= BASE; }
    bool zero() const { return d.empty(); }
};
void trim(Big& a) { while (!a.d.empty() && a.d.back() == 0) a.d.pop_back(); }
int cmp(const Big& a, const Big& b) {        // -1 / 0 / 1
    if (a.d.size() != b.d.size()) return a.d.size() < b.d.size() ? -1 : 1;
    for (int i = (int)a.d.size() - 1; i >= 0; i--)
        if (a.d[i] != b.d[i]) return a.d[i] < b.d[i] ? -1 : 1;
    return 0;
}
Big add(const Big& a, const Big& b) {
    Big r;
    int carry = 0;
    for (size_t i = 0; i < max(a.d.size(), b.d.size()) || carry; i++) {
        int s = carry;
        if (i < a.d.size()) s += a.d[i];
        if (i < b.d.size()) s += b.d[i];
        r.d.push_back(s % Big::BASE), carry = s / Big::BASE;
    }
    return r;
}
Big sub(const Big& a, const Big& b) {        // 保证 a >= b
    Big r;
    int borrow = 0;
    for (size_t i = 0; i < a.d.size(); i++) {
        int s = a.d[i] - borrow - (i < b.d.size() ? b.d[i] : 0);
        if (s < 0) s += Big::BASE, borrow = 1; else borrow = 0;
        r.d.push_back(s);
    }
    trim(r);
    return r;
}
Big mul(const Big& a, const Big& b) {
    Big r;
    r.d.assign(a.d.size() + b.d.size(), 0);
    for (size_t i = 0; i < a.d.size(); i++) {
        int carry = 0;
        for (size_t j = 0; j < b.d.size() || carry; j++) {
            long long cur = r.d[i + j] + (long long)a.d[i] * (j < b.d.size() ? b.d[j] : 0) + carry;
            r.d[i + j] = cur % Big::BASE, carry = cur / Big::BASE;
        }
    }
    trim(r);
    return r;
}
```


### 应用


#### 高精度除法

除以一个「小整数」$O(n)$；除以大整数用「试商」（每位试 0..9）$O(n\cdot\text{位数})$。

```c++
Big div_small(const Big& a, int b, int& rem) {   // 除以小整数，b != 0
    Big r;
    r.d.assign(a.d.size(), 0);
    long long cur = 0;
    for (int i = (int)a.d.size() - 1; i >= 0; i--) {
        cur = cur * Big::BASE + a.d[i];
        r.d[i] = (int)(cur / b);
        cur %= b;
    }
    rem = (int)cur;
    trim(r);
    return r;
}
// 大数除大数：从高位开始逐位试商 0..BASE-1，配合乘法与减法
```


#### 高精度比较与排序

先比位数、再比最高位；排序时用这个比较函数即可（注意负数与符号位）。

```c++
// 一组排序用的比较器（把 Big 放进 vector 后用 sort）
bool bigLess(const Big& a, const Big& b) { return cmp(a, b) < 0; }
void sort_big(vector<Big>& v) {
    sort(v.begin(), v.end(), bigLess);
}
// 验证：{123, 45, 6789, 45} 排序后应当是 45, 45, 123, 6789
// 注意：vector 里的 Big 会拷贝，位数很大时建议存指针或下标
```


## 枚举与暴力

### 一句话

### 原理


### 实现

```c++
// 枚举的基本骨架：确定枚举对象、枚举范围、判定条件
int brute_count(int n) {
    int cnt = 0;
    for (int i = 1; i <= n; i++)
        for (int j = i; j <= n; j++)
            if ((i + j) % 3 == 0) cnt++;
    return cnt;                              // 例：n = 3 -> (1,2),(3,3) 共 2
}
```

## 折半枚举（Meet in the Middle）


### 一句话

给 $n\le 40$ 个物品和一条「选出哪些才算合法」的规则（$2^n$ 太大但 $2^{n/2}$ 可行），你要把物品均分成两半、各自枚举出所有子集，再在两半之间排序、二分或双指针配对，枚举与配对交替出现。**时间 $O(2^{n/2}\log 2^{n/2})$，空间 $O(2^{n/2})$。**


### 原理


### 实现

（把集合分成两半，各自枚举全部 $2^{n/2}$ 种情况，再用排序 + 二分 / 双指针配对。）

```c++
// 例：从 n 个数里选若干个，使和等于 target（n <= 40）
int n_;
ll a[N];
vector<ll> gen(int l, int r) {               // 生成 [l, r] 的所有子集和
    vector<ll> res;
    int len = r - l + 1;
    for (int mask = 0; mask < (1 << len); mask++) {
        ll s = 0;
        for (int i = 0; i < len; i++) if (mask >> i & 1) s += a[l + i];
        res.push_back(s);
    }
    sort(res.begin(), res.end());
    return res;
}
ll meet_in_middle(ll target) {
    int mid = n_ / 2;
    auto L = gen(1, mid), R = gen(mid + 1, n_);
    ll cnt = 0;
    for (ll x : L) cnt += upper_bound(R.begin(), R.end(), target - x) - lower_bound(R.begin(), R.end(), target - x);
    return cnt;                              // 等于 target 的方案数
}
```


### 应用


#### 子集计数 / 判存在

把「是否存在」或「有多少种」转成「左边枚举 + 右边二分」，$2^{40}$ 降到 $2^{20}\times20$。

```c++
// 判存在 + 求最大可行和
bool exists_sum(ll target) {
    auto L = gen(1, n_ / 2), R = gen(n_ / 2 + 1, n_);
    for (ll x : L) {
        auto it = lower_bound(R.begin(), R.end(), target - x);
        if (it != R.end() && *it == target - x) return true;
    }
    return false;
}
ll max_sum_le(ll target) {
    auto L = gen(1, n_ / 2), R = gen(n_ / 2 + 1, n_);
    ll best = -1;
    for (ll x : L) {
        auto it = upper_bound(R.begin(), R.end(), target - x);
        if (it != R.begin()) best = max(best, x + *prev(it));
    }
    return best;
}
// 例：a = {1,2,3,4,5}、target = 7 -> 存在（2+5），最大不超过 7 的和就是 7
```


#### 分成三份

$n\le 60$ 时可以分三份 $2^{20}$，再用「排序 + 双指针」配对两份、对第三份二分。

```c++
// 分成三份：枚举 A、B 的和，把 A+B 排序去重，再对 C 二分
ll three_way_count(ll target) {
    int k = n_ / 3;
    auto A = gen(1, k), B = gen(k + 1, 2 * k), C = gen(2 * k + 1, n_);
    vector<ll> AB;
    for (ll x : A) for (ll y : B) AB.push_back(x + y);
    sort(AB.begin(), AB.end());
    ll cnt = 0;
    for (ll z : C)
        cnt += upper_bound(AB.begin(), AB.end(), target - z) - lower_bound(AB.begin(), AB.end(), target - z);
    return cnt;
}
// 适用：n <= 60 且只关心「和」；如果还要关心「选了哪些」则不适合
```


## 位运算


### 一句话

给一个 $n\le 20$ 的集合（$n\le 20$），每个元素只有在或不在两种归属，你要拿一个整数的第 $i$ 位表示第 $i$ 个元素在不在里面，再在位与位之间转移状态、枚举子集，判断某一位与整段做与 / 或 / 异或 / 移位交替出现。**时间 $O(1)$（单次位操作）、$O(2^n)$ 或 $O(3^n)$（子集枚举），空间 $O(2^n)$。**


### 原理


### 实现

```c++
// 常用位运算
int lowbit(int x) { return x & -x; }         // 最低位的 1
int popcount(int x) { return __builtin_popcount(x); }
bool has(int S, int i) { return (S >> i) & 1; }
int add(int S, int i) { return S | (1 << i); }
int del(int S, int i) { return S & ~(1 << i); }
int toggle(int S, int i) { return S ^ (1 << i); }
```


### 应用


#### 子集枚举与 SOS DP

枚举 $S$ 的所有子集是 $O(3^n)$；求「子集和」用 SOS DP 是 $O(n2^n)$。

```c++
// 枚举子集（总复杂度 O(3^n)）
void enum_subsets(int n) {
    for (int S = 1; S < (1 << n); S++)
        for (int T = S; T; T = (T - 1) & S) { /* 处理子集 T */ }
}
// SOS DP：f[S] = sum_{T 是 S 的子集} a[T]
void sos(vector<ll>& f, int n) {
    for (int i = 0; i < n; i++)
        for (int S = 0; S < (1 << n); S++)
            if (S >> i & 1) f[S] += f[S ^ (1 << i)];
}
```


#### 状态的位压缩

把「若干个 yes/no」压成一个整数，转移就是位运算；注意位宽上限（int 32 位、long long 64 位）。

```c++
// 例：5 种属性的组合 -> 用一个 5 位整数表示
```

#### 异或的性质

$x\oplus x=0$、$x\oplus0=x$，所以「出现两次的抵消」类问题常用异或；配合前缀异或能做区间异或查询。

```c++
int xor_range(int l, int r, vector<int>& px) { return px[r] ^ px[l - 1]; }
// 例：数组里只有一个数出现奇数次，其余都出现偶数次 -> 全部异或起来就是答案
int odd_one(vector<int>& a) { int x = 0; for (int v : a) x ^= v; return x; }
```


#### lowbit 与树状数组

$x\&(-x)$ 取出最低位 1，用来找父节点 / 子节点；Gosper's Hack 可以枚举「恰好 $k$ 个 1」的掩码。

```c++
// 枚举所有「恰好 k 个 1」的 n 位掩码（Gosper's Hack）
void gosper(int n, int k) {
    if (k == 0) { /* 只有 0 这一个 */ return; }
    int S = (1 << k) - 1;
    while (S < (1 << n)) {
        // 处理 S
        int c = S & -S, r = S + c;
        S = (((r ^ S) >> 2) / c) | r;        // 注意 k = 0 时 c = 0 会除零
    }
}
```


## 递推与递归


### 一句话

给一个能一项项往后算的问题（$n\le 10^6$），你要么从初值开始从小到大把每一项推出来、要么把原问题拆成同形状的更小子问题递归下去，推进与回溯交替出现。**时间 $O(n)$ 或 $O(n\log n)$，空间 $O(n)$（或滚动后的 $O(1)$）。**


### 原理


### 实现

```c++
ll fib_iter(int n) {                         // 递推：从前往后
    ll a = 0, b = 1;
    for (int i = 0; i < n; i++) { ll t = a + b; a = b; b = t; }
    return a;
}
```


### 应用


#### 记忆化搜索

状态之间的依赖是 DAG 时，递归 + 记忆化能让「每个状态只算一次」，避免指数级重复。

```c++
ll memo[1005][1005];
bool vis[1005][1005];
ll f(int a, int b) {
    if (a == 0 || b == 0) return 1;
    if (vis[a][b]) return memo[a][b];
    vis[a][b] = true;
    memo[a][b] = (f(a - 1, b) + f(a, b - 1)) % 998244353;
    return memo[a][b];
}
// 记忆化必须保证「同一份参数只算一次」；参数里带引用 / 指针时要特别小心
```


#### 全排列与子集枚举

$O(n!)$ 的排列用 next_permutation；$O(2^n)$ 的子集用位掩码。

```c++
void permutations(int n) {
    vector<int> p(n);
    iota(p.begin(), p.end(), 1);
    do {
        // 处理排列 p
    } while (next_permutation(p.begin(), p.end()));
}
// 注意：next_permutation 从「最小的排列」开始才能枚举完整；否则要先 sort
```


#### 递归深度与栈溢出

递归深度到 $10^5$ 就可能爆栈；要么改成显式栈的迭代写法，要么开大栈（Windows 下可加大）。

```c++

int stk[N], top_;
void dfs_iter(int root, vector<vector<int>>& g) {
    stk[top_++] = root;
    while (top_) {
        int u = stk[--top_];
        for (int v : g[u]) stk[top_++] = v;
    }
}
```


## 分治


### 一句话

给一个规模为 $n$ 的问题（$n\le 10^5$ 或 $n\le 5\times10^5$），你要把区间从中间劈成两半、各自递归求解，再把左右两半的答案并起来，拆分与合并交替出现。**时间 $O(n\log n)$，空间 $O(n)$。**


### 原理


### 实现

（模板：拆成两半 -> 递归 -> 合并；复杂度由 $T(n)=2T(n/2)+O(f(n))$ 给出。）

```c++
void solve(int l, int r) {
    if (l >= r) return;                      // 递归边界
    int mid = (l + r) >> 1;
    solve(l, mid);
    solve(mid + 1, r);
    // merge(l, mid, r);                     // 合并
}
```


### 应用


#### 归并排序与逆序对

归并时「右边先出来」就说明右边这个数比左边剩下的都小，逆序对加上左边剩余个数。

```c++
int a[N], tmp[N];
ll inv_cnt;
void merge_sort(int l, int r) {
    if (l >= r) return;
    int mid = (l + r) >> 1;
    merge_sort(l, mid), merge_sort(mid + 1, r);
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else inv_cnt += mid - i + 1, tmp[k++] = a[j++];   // 左边剩下都比 a[j] 大
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (int t = l; t <= r; t++) a[t] = tmp[t];
}
// 例：{2, 1, 3} 的逆序对是 1
```


#### 快速幂 / 快速乘

$O(\log b)$ 的快速幂；模数到 $10^{18}$ 时用 __int128 或「倍增的快速乘」避免溢出。

```c++
ll qpow_(ll a, ll b, ll mod) {
    ll r = 1;
    for (a %= mod; b; b >>= 1, a = (__int128)a * a % mod)
        if (b & 1) r = (__int128)r * a % mod;
    return r;
}
ll mul_slow(ll a, ll b, ll mod) {            // 不用 __int128 时的快速乘
    ll r = 0;
    for (a %= mod; b; b >>= 1, a = (a + a) % mod)
        if (b & 1) r = (r + a) % mod;
    return r;
}
```


#### 平面最近点对

分治 + 「按 y 归并」，只检查中线附近、纵坐标差小于当前答案的点，每层线性。

```c++
// 分治求平面最近点对（按 x 排序后分治，返回时按 y 归并）
struct Pt { double x, y; };
vector<Pt> pts, buf;
double closest;
void solve_cp(int l, int r) {
    if (r - l <= 1) {
        if (r - l == 1) {
            closest = min(closest, hypot(pts[l].x - pts[r].x, pts[l].y - pts[r].y));
            if (pts[l].y > pts[r].y) swap(pts[l], pts[r]);   // 必须保持按 y 有序！
        }
        return;
    }
    int mid = (l + r) >> 1;
    double midx = pts[mid].x;
    solve_cp(l, mid), solve_cp(mid + 1, r);
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) buf[k++] = (pts[i].y < pts[j].y ? pts[i++] : pts[j++]);
    while (i <= mid) buf[k++] = pts[i++];
    while (j <= r) buf[k++] = pts[j++];
    for (int t = l; t <= r; t++) pts[t] = buf[t];
    k = 0;
    for (int t = l; t <= r; t++)
        if (fabs(pts[t].x - midx) < closest) buf[k++] = pts[t];
    for (int a = 0; a < k; a++)
        for (int b = a + 1; b < k && buf[b].y - buf[a].y < closest; b++)
            closest = min(closest, hypot(buf[a].x - buf[b].x, buf[a].y - buf[b].y));
}
// 关键：递归返回前必须已经按 y 有序（所以用归并而不是另开一个 sort）
// 特别注意 base case：只有 2 个点时也要手动保证它们按 y 有序，否则父层的归并会拿到
// 未排序的一半，条带检查里的「纵坐标差 < closest」就不再成立，答案会偏大
```


## 前缀和与差分


### 一句话

给一个长度 $n\le 10^6$ 的序列，要你回答 $\sum_{i=l}^r a_i$ 是多少，或把区间 $[l,r]$ 里每个数都加上 $x$，询问与区间加交替出现。**时间 $O(n)$ 预处理、$O(1)$ 单次查询，空间 $O(n)$。**


### 原理


### 实现

```c++
ll pre2[N], dif2[N];
void build_prefix(vector<ll>& a, int n) {
    for (int i = 1; i <= n; i++) pre2[i] = pre2[i - 1] + a[i];
}
ll range_sum2(int l, int r) { return pre2[r] - pre2[l - 1]; }

void build_diff(vector<ll>& a, int n) {      // 差分数组
    for (int i = 1; i <= n; i++) dif2[i] = a[i] - a[i - 1];
}
void range_add_d(int l, int r, ll v) { dif2[l] += v, dif2[r + 1] -= v; }
ll point_get_d(int i) {                      // 单点查 = 差分的前缀和
    ll s = 0;
    for (int j = 1; j <= i; j++) s += dif2[j];
    return s;
}
```


### 应用


#### 静态区间和

预处理前缀和后每次 $O(1)$；这是最简单也最常用的优化。

```c++
// 可运行的验证
```

#### 差分做区间修改

## 二分与三分


### 一句话

给一个在整数上单调、或先增后减的函数 / 判定（$n\le 10^6$ 或答案值域 $\le 10^{18}$），要你在 $[L,R]$ 上二分出最小的满足条件的位置，或在单峰函数上三分出极值点，每次判定后砍掉一段区间。**时间 $O(\log C)$ 次判定 / 求值，空间 $O(1)$。**


### 原理


### 实现

```c++
// 整数二分：找第一个 >= x 的位置（lower_bound 手写版）
int lower_bound_(vector<int>& a, int x) {
    int lo = 0, hi = a.size();
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;        // 用减法避免溢出；不能用 (lo+hi)/2
        if (a[mid] < x) lo = mid + 1; else hi = mid;
    }
    return lo;
}
// 找最后一个 <= x 的位置
int upper_bound_(vector<int>& a, int x) {
    int lo = 0, hi = a.size();
    while (lo < hi) {
        int mid = lo + (hi - lo + 1) / 2;
        if (a[mid] <= x) lo = mid; else hi = mid - 1;
    }
    return lo - 1;
}
```


### 应用


#### 二分答案

「最大值最小 / 最小值最大」通常二分答案 + 判定；判定的复杂度乘上 $\log C$ 就是总复杂度。

```c++
// 例：把 n 个数分成 k 段使「最大段和」最小，二分最大段和并贪心判定
bool feasible(vector<int>& a, int k, ll limit) {
    int cnt = 1;
    ll s = 0;
    for (int x : a) {
        if (x > limit) return false;
        if (s + x > limit) cnt++, s = 0;
        s += x;
    }
    return cnt <= k;
}
```


#### 三分与凸性

单峰（凸）函数用三分：比较 $m_1,m_2$ 处的值，把「不可能最优」的那一段丢掉。

```c++
// 求单峰函数的最大值（整数版）
ll ternary(ll lo, ll hi, function<ll(ll)> f) {
    while (hi - lo > 2) {
        ll m1 = lo + (hi - lo) / 3, m2 = hi - (hi - lo) / 3;
        if (f(m1) < f(m2)) lo = m1; else hi = m2;
    }
    ll best = f(lo);
    for (ll x = lo + 1; x <= hi; x++) best = max(best, f(x));
    return best;
}
// 浮点三分：迭代 200 次即可；整数三分要小心「平台」，最后一定暴力扫完剩余区间
```

## 0/1 分数规划


### 一句话

给 $n$ 个「收益 $a_i$、代价 $b_i$」对（$n\le 10^5$，$b_i>0$），要你选一个子集 $S$ 让 $\frac{\sum_{i\in S}a_i}{\sum_{i\in S}b_i}$ 最大，做法是猜一个答案 $x$、把每项换成 $a_i-xb_i$ 再判定是否存在正和，猜测与判定交替出现。**时间 $O(n\log C)$（二分答案），空间 $O(n)$，精度 $10^{-6}$ 约 60 次迭代。**


### 原理


### 实现

（二分比值 $x$，判断「是否存在 $S$ 使 $\sum(a_i-xb_i)>0$」；每一项变成 $a_i-xb_i$，按正负贪心安。）

```c++
const double EPS_D = 1e-9;
ll A[N], B[N];
bool check_ratio(double x, int n, int need) {
    // 选出「收益最大」的若干个（通常要求至少 / 恰好 need 个）
    vector<double> v(n);
    for (int i = 0; i < n; i++) v[i] = A[i] - x * B[i];
    sort(v.rbegin(), v.rend());
    double s = 0;
    for (int i = 0; i < need; i++) s += v[i];
    return s >= 0;                           // 存在更优的解
}
double max_ratio(int n, int need) {
    double lo = 0, hi = 1e9;
    for (int it = 0; it < 80; it++) {        // 二分 80 次足够到 1e-12
        double mid = (lo + hi) / 2;
        if (check_ratio(mid, n, need)) lo = mid; else hi = mid;
    }
    return lo;
}
```


### 应用


#### 最大化平均值

「选 $k$ 个数使平均值最大」是最简单的 0/1 分数规划：$\sum(a_i-x)>0$。

#### 精度与迭代次数

定理：二分 $k$ 次后精度约 $\frac{hi-lo}{2^k}$；要 $10^{-6}$ 就取 50~60 次，$10^{-9}$ 取 80 次。

## 双指针与滑动窗口


### 一句话

给一个序列（$n\le 10^6$），要你数出有多少个连续子段满足某个性质、或求出其中最优的一段，做法是让左右指针只往右移：一边把右端点的元素收进窗口、一边把左端点往外放，收与放交替出现。**时间 $O(n)$ 总时间，空间 $O(n)$ 或 $O(1)$。**


### 原理


### 实现

（双指针的合法性：当右端点右移时，最小的合法左端点不会左移。）

```c++
// 例：最短的「和 >= S」的连续子段长度
int min_len_ge(vector<int>& a, ll S) {
    int n = a.size(), best = INT_MAX, l = 0;
    ll sum = 0;
    for (int r = 0; r < n; r++) {
        sum += a[r];
        while (sum >= S) {                   // 收缩左端点
            best = min(best, r - l + 1);
            sum -= a[l++];
        }
    }
    return best == INT_MAX ? 0 : best;
}
```


### 应用


#### 尺取法

「和不超过 / 不少于某值」的区间计数：右端点单调右移、左端点单调右移，总 $O(n)$。

```c++
ll count_segments_le(vector<int>& a, ll S) {   // 所有「和 <= S」的连续子段个数（a 非负）
    int n = a.size(), l = 0;
    ll sum = 0, cnt = 0;
    for (int r = 0; r < n; r++) {
        sum += a[r];
        while (sum > S) sum -= a[l++];
        cnt += r - l + 1;                    // 以 r 结尾、左端点在 [l, r] 的都合法
    }
    return cnt;
}
// 前提：a 非负！有负数时「左端点单调」不再成立，要用前缀和 + 二分或 ST 表
```

## 排序与离散化

```c++
// 离散化：把「大值域」压成「名次 1..m」，保持相对大小不变
```

## 倍增


### 一句话

给一个长度 $n\le 10^6$ 的静态序列（$n\le 10^6$，值不会改），要你反复回答「$[l,r]$ 的最大值 / gcd 是多少」，也可以在一棵树上反复问「从 $u$ 往上跳 $k$ 步到哪、$u$ 与 $v$ 的 LCA 是谁」，预处理与查询交替出现。**时间预处理 $O(n\log n)$、单次查询 $O(1)$，空间 $O(n\log n)$；树上倍增预处理 $O(n\log n)$、单次 $O(\log n)$。**


### 原理


### 实现

```c++
int lg_[N], st[N][21];
void build_st(vector<int>& a, int n) {       // 区间最大值
    lg_[1] = 0;
    for (int i = 2; i <= n; i++) lg_[i] = lg_[i >> 1] + 1;
    for (int i = 1; i <= n; i++) st[i][0] = a[i];
    for (int j = 1; (1 << j) <= n; j++)
        for (int i = 1; i + (1 << j) - 1 <= n; i++)
            st[i][j] = max(st[i][j - 1], st[i + (1 << (j - 1))][j - 1]);
}
int query_st(int l, int r) {
    int k = lg_[r - l + 1];
    return max(st[l][k], st[r - (1 << k) + 1][k]);   // 两段可以重叠
}
```


### 应用


#### 可重复贡献

$\max$、$\min$、$\gcd$、按位或 / 与都满足「重叠不影响结果」；而「和」不满足（重叠会算两次），所以不能用 ST 表。

```c++
// 可重复贡献 = f(x, x) = x
// max(a, a) = a：可以重叠
// a + a != a：不能重叠 -> 求和要用前缀和或树状数组
ll sum_st_wrong(int l, int r) { (void)l; (void)r; return 0; }   // 错误示范
```


#### 树上倍增与 LCA

预处理每个点向上 $2^j$ 步的祖先，查询 LCA 时先跳到同一深度、再一起往上跳。

```c++
int up_[N][20], dep_[N];
void build_lca(int u, int p) {
    up_[u][0] = p, dep_[u] = dep_[p] + 1;
    for (int j = 1; j < 20; j++) up_[u][j] = up_[up_[u][j - 1]][j - 1];
    // 递归子结点（略）
}
int lca(int u, int v) {
    if (dep_[u] < dep_[v]) swap(u, v);
    int d = dep_[u] - dep_[v];
    for (int j = 0; j < 20; j++) if (d >> j & 1) u = up_[u][j];
    if (u == v) return u;
    for (int j = 19; j >= 0; j--) if (up_[u][j] != up_[v][j]) u = up_[u][j], v = up_[v][j];
    return up_[u][0];
}
```

## 贪心


### 一句话

给 $n\le 10^5$ 个物品或任务（$n\le 10^5$），要你按某个关键字从前往后一个个决定选不选，而且这一步选完不影响后面还能选什么，偶尔还要用堆把先前贪错的决定反悔回来，选择与反悔交替出现。**时间 $O(n\log n)$（通常瓶颈是排序）或 $O(n\log n)$（反悔贪心用堆），空间 $O(n)$。**


### 原理


### 实现

（贪心的两步：确定「按什么排序」，再证明「交换不会变差」。）

```c++
// 例：区间调度——按右端点排序，能选就选
struct Seg { int l, r; };
int max_nonoverlap(vector<Seg>& seg) {
    sort(seg.begin(), seg.end(), [](const Seg& a, const Seg& b) { return a.r < b.r; });
    int cnt = 0, last = -1;
    for (auto& s : seg)
        if (s.l >= last) cnt++, last = s.r;
    return cnt;
}
```


### 应用


#### 交换论证

证明贪心正确性的标准套路：假设最优解与贪心解在某处不同，交换两个元素后不更差，从而可以逐步把最优解变成贪心解。

```c++
// 例：按「每小时收益」排序做任务调度
//   设最优解里相邻两个任务 A、B 与贪心顺序相反，
//   比较 AB 与 BA 的收益，若贪心序不差，则可以交换 -> 归纳证明
bool better(pair<ll, ll> a, pair<ll, ll> b) {   // a 是否应该排在 b 前面
    return (__int128)a.first * b.second > (__int128)b.first * a.second;   // 用交叉相乘避免浮点
}
```


#### 排序关键字的选择

「按比值排」「按差值排」「按右端点排」都是常见关键字；选错就会 WA，必须用交换论证确认。

```c++
// 例：n 个任务，每个任务有「截止时间 d 和耗时 t」，按什么顺序做能完成最多？
// 结论：按 d 从小到大（同 d 按 t 从小到大）；下面的比较器写成一个通用形式
struct Job { ll d, t; };
bool jobLess(const Job& a, const Job& b) {
    if (a.d != b.d) return a.d < b.d;
    return a.t < b.t;
}
// 例：n 个数两两配对，使「两两乘积之和」最大 -> 排序后最大配最大
// 例：交叉相乘的比值比较器
bool ratioLess(pair<ll, ll> a, pair<ll, ll> b) {
    return (__int128)a.first * b.second < (__int128)b.first * a.second;
}
```


#### 反悔贪心

「当前选它最优、但以后可能后悔」时，用一个堆维护「已选」并支持「替换」，等价于把一个决策的收益拆成两半。

```c++
// 经典：股票买卖（最多 k 次交易）用「反悔堆」
ll max_profit(vector<ll>& p, int k) {
    priority_queue<ll, vector<ll>, greater<ll>> pq;
    ll ans = 0;
    for (size_t i = 1; i < p.size(); i++) {
        ll diff = p[i] - p[i - 1];
        if (diff > 0) ans += diff, pq.push(diff);
        // 反悔：把「已选的最小收益」换成当前这个
        // 实际题目里通常还要限制次数 k，做法是「每次选最大的、并把反悔项放回堆」
    }
    return ans;
}
// 反悔贪心的核心：把「撤销一个选择」也变成一个可选的决策，塞回堆里
```


## 拟阵与拟阵交


### 一句话

给 $n\le 2\times10^5$ 个带权元素和一个「哪些能一起选」的合法族（满足拟阵公理），要你选出权值和最大的子集，做法是把元素按权从大到小排好、每次问「加上它以后还合法吗」，加入与替换交替出现。**时间 $O(n\log n)$（拟阵贪心）或 $O(n^3)$（拟阵交），空间 $O(n)$。**


### 原理


### 实现

（拟阵 = 独立集族 + 遗传性 + 交换性；拟阵上的贪心「按权从大到小、能加就加」就是最优解。）

```c++
// 抽象拟阵贪心：只需要提供「加入 e 后是否仍然独立」的 oracle
template <class Oracle>
vector<int> matroid_greedy(vector<int>& order, Oracle independent) {

    for (int e : order) {                    // order 已按权值从大到小排好
        chosen.push_back(e);
```

### 应用


#### Kruskal 与图拟阵

「无环的边集」构成图拟阵，Kruskal 就是拟阵贪心：按边权从小到大，能加就加。

```c++
struct Edge { int u, v; ll w; };
int fa2[N];
int find2(int x) { while (fa2[x] != x) x = fa2[x] = fa2[fa2[x]]; return x; }
ll kruskal(vector<Edge>& es, int n) {
    sort(es.begin(), es.end(), [](const Edge& a, const Edge& b) { return a.w < b.w; });
    for (int i = 1; i <= n; i++) fa2[i] = i;
    ll total = 0;

    for (auto& e : es) {
        int x = find2(e.u), y = find2(e.v);
        if (x == y) continue;                // 加了会成环 -> 不独立
        fa2[y] = x, total += e.w, cnt++;
        if (cnt == n - 1) break;
    }
    return cnt == n - 1 ? total : -1;        // -1 表示不连通
}
```

## 数组与链表

### 一句话

给你一个要频繁在中间插入 / 删除的序列（长度到 $10^6$），要你选一种线性结构存它，并说清「随机访问」与「插入删除」的取舍。**时间随机访问 $O(1)$、中间插入 $O(n)$（链表反之），空间 $O(n)$。**

### 原理


### 实现

（数组和链表是最基础的两种线性结构，区别只有一条：内存连续还是不连续。）

```c++

int a[N];

// 链表：靠指针串起来。插入 / 删除 O(1)，但要先走到那个位置，随机访问 O(n)。
// 竞赛里几乎都用「数组模拟链表」，比 new/delete 快得多：
int nxt[N], val[N], head, cnt;
void init_list(int n) {                      // n 个元素初始化成链
    head = 1, cnt = n, nxt[n] = 0;
    for (int i = 1; i <= n; i++) val[i] = i, nxt[i] = (i == n ? 0 : i + 1);
}
void insert_after(int p, int v) { val[++cnt] = v, nxt[cnt] = nxt[p], nxt[p] = cnt; }
void erase_after(int p) { nxt[p] = nxt[nxt[p]]; }
void traverse() { for (int i = head; i; i = nxt[i]) use(val[i]); }
// 双向链表再存一个 pre[] 即可；每个元素最多被删一次，所以「边遍历边删」是 O(n)。
```

```c++
    while (!dq.empty()) {
        int u = dq.front(); dq.pop_front();

            if (dist01[u] + w < dist01[v]) {
```

## 哈希表


### 一句话

给 $n$ 个元素（$n\le 10^6$），要你反复做三件事：问某个值出现过没有、问它出现了几次、把值映射到它携带的信息，插入与查询交替出现。**时间平均 $O(1)$ 单次操作，空间 $O(n)$；被卡时用随机化或手写哈希。**


### 原理


### 实现

```c++
// 手写哈希表（开放寻址）：比 unordered_map 快很多，也不会被卡
const int HSZ = 1 << 21;
int hkey[HSZ], hval[HSZ], hvis[HSZ], htim;
int HASH_INT(int x) { return (int)((unsigned)(x * 2654435761u) >> 11) & (HSZ - 1); }
void hclear() { htim++; }
int& href(int x) {
    int i = HASH_INT(x);
    while (hvis[i] == htim && hkey[i] != x) i = (i + 1) & (HSZ - 1);
    if (hvis[i] != htim) hvis[i] = htim, hkey[i] = x, hval[i] = 0;
    return hval[i];
}
```


### 应用


#### 判重与计数

把「值」映射到「出现次数」；也可以用一个「时间戳」数组支持多组数据下的清零。

```c++

}
// 时间戳写法避免了每组数据都 memset 整个哈希表
```


#### 为什么 unordered_map 会被卡

标准库的哈希函数对某些输入会大量冲突；攻击者（或出题人）可以构造这些输入，让复杂度退化到 $O(n^2)$。

```c++
// 解决办法：自定义哈希函数 + 随机种子
struct RndHash {
    static uint64_t splitmix64(uint64_t x) {
        x += 0x9e3779b97f4a7c15ULL;
        x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ULL;
        x = (x ^ (x >> 27)) * 0x94d049bb133111ebULL;
        return x ^ (x >> 31);
    }
    size_t operator()(uint64_t x) const {
        static const uint64_t FIXED_RANDOM = chrono::steady_clock::now().time_since_epoch().count();
        return splitmix64(x + FIXED_RANDOM);
    }
};
// 用法：unordered_map<ll, int, RndHash> mp;
```

## 二叉堆与优先队列

### 一句话

给你 $n$ 次「插入一个数」和「取出当前最小（大）的数」的操作（$n\le 10^6$），要你在 $O(\log n)$ 内完成每一次。**时间单次 $O(\log n)$，空间 $O(n)$。**

### 原理


### 实现

```c++
// 默认是最大堆；最小堆要写 greater
priority_queue<int> maxheap;
priority_queue<int, vector<int>, greater<int>> minheap;

// 手写小根堆（常数更小）
int hp[N], hsz;
void hpush(int x) {
    hp[++hsz] = x;
    int i = hsz;
    while (i > 1 && hp[i] < hp[i >> 1]) swap(hp[i], hp[i >> 1]), i >>= 1;
}
int hpop() {
    int r = hp[1];
    hp[1] = hp[hsz--];
    int i = 1;
    while (true) {
        int l = i << 1, rr = l | 1, s = i;
        if (l <= hsz && hp[l] < hp[s]) s = l;
        if (rr <= hsz && hp[rr] < hp[s]) s = rr;
        if (s == i) break;
        swap(hp[i], hp[s]), i = s;
    }
    return r;
}
```

### 应用


#### 对顶堆
一个大根堆放「较小的一半」、一个小根堆放「较大的一半」，随时取中位数；插入时调整两边大小。

```c++
priority_queue<ll> lo;                                       // 存较小的一半（堆顶是最大）
priority_queue<ll, vector<ll>, greater<ll>> hi;              // 存较大的一半（堆顶是最小）
void add_median(ll x) {
    if (lo.empty() || x <= lo.top()) lo.push(x); else hi.push(x);
    if (lo.size() > hi.size() + 1) hi.push(lo.top()), lo.pop();
    if (hi.size() > lo.size()) lo.push(hi.top()), hi.pop();
}
double get_median() {
    if (lo.size() == hi.size()) return (lo.top() + hi.top()) / 2.0;
    return (double)lo.top();
}
```

#### 堆优化 Dijkstra
每轮从堆里取当前距离最小的未确定点，用它松弛邻居；复杂度 $O((n+m)\log n)$。

```c++
vector<pair<int, ll>> g2[N];
ll dist2[N];
void dijkstra(int s, int n) {
    fill(dist2, dist2 + n + 1, (ll)4e18);
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<>> pq;
    dist2[s] = 0, pq.push({0, s});
    while (!pq.empty()) {
        auto pr = pq.top(); pq.pop();
        ll d = pr.first;
        int u = pr.second;
        if (d > dist2[u]) continue;          // 过期条目，直接跳过
        for (auto& e : g2[u]) {
            int v = e.first;
            ll w = e.second;
            if (d + w < dist2[v]) dist2[v] = d + w, pq.push({dist2[v], v});
        }
    }
}
// 关键：允许堆里存在重复条目，靠 d > dist[u] 跳过；这比「修改堆中元素」简单得多
```

```c++
int pre_[N], in_[N], pos_in[N];
int build_tree(int pl, int pr, int il, int ir) {
    if (pl > pr) return 0;
    int root = pre_[pl];
    int k = pos_in[root];                    // root 在中序里的位置
    int leftLen = k - il;
    // 递归建左右子树（返回下标）
    return root;
}
// 关键：用「值 -> 中序位置」的映射把定位从 O(n) 降到 O(1)，整体才 O(n)
```

## 哈夫曼树

### 一句话

给你 $n$ 个带权叶子（$n\le 10^5$），要你构造一棵二叉树，使「每个叶子的权值乘上它到根的路径长度」之和最小。**时间 $O(n\log n)$，空间 $O(n)$。**

### 原理


### 实现

每次取权值最小的两个结点合并，用优先队列 $O(n\log n)$；合并出来的树带权路径长度最小。

```c++
ll huffman(vector<ll>& w) {
    priority_queue<ll, vector<ll>, greater<ll>> pq(w.begin(), w.end());
    ll total = 0;
    while (pq.size() > 1) {
        ll a = pq.top(); pq.pop();
        ll b = pq.top(); pq.pop();
        total += a + b;
        pq.push(a + b);
    }
    return total;                            // 最小带权路径长度
}
// 例：w = {1, 2, 3, 4} -> 答案是 19
```

## 迭代加深（IDDFS）

#### 双向 BFS（特殊搜索）

从起点和终点各 BFS 一半，任一侧扩展到对面访问过的点就相遇（见「搜索优化」一节）。

```c++
// 双向 BFS：两侧各扩一整层，任一侧遇到「对面访问过」的点就相遇
int dA[N], dB[N];                            // 两侧的距离；-1 表示未访问
int bidir_bfs(int s, int t, vector<vector<int>>& adj, int n) {
    if (s == t) return 0;
    fill(dA, dA + n, -1);
    fill(dB, dB + n, -1);
    queue<int> qa, qb;
    dA[s] = 0, qa.push(s);
    dB[t] = 0, qb.push(t);
    while (!qa.empty() && !qb.empty()) {
        // 每次扩「层更小」的那一侧一整层
        bool expandA = (qa.size() <= qb.size());
        queue<int>& q = expandA ? qa : qb;
        int* dSelf = expandA ? dA : dB;
        int* dOther = expandA ? dB : dA;
        for (int cnt = q.size(); cnt > 0; cnt--) {
            int u = q.front(); q.pop();
            for (int v : adj[u]) {
                if (dSelf[v] != -1) continue;
                dSelf[v] = dSelf[u] + 1;
                if (dOther[v] != -1) return dSelf[v] + dOther[v];   // 相遇
                q.push(v);
            }
        }
    }
    return -1;                               // 不连通
}
// 例：一条长度为 L 的链，从两端同时搜，扩展的状态数是 2^(L/2) 而不是 2^L
// 关键：必须「整层扩展」，否则可能错过更短的解
```

## A* 与 IDA*

### 一句话

给你一个状态数巨大、但有「乐观下界」可估的最短路 / 最优化问题，要你用估价函数把搜索导向目标。**时间取决于展开的状态数，空间 $O(\text{展开状态数})$ 或 $O(\text{深度})$。**

### 原理


### 实现

用「已走代价 + 估价函数 $h$」作为堆的键；只要 $h$ 不高估（可采纳），第一次弹出终点就是最优解。

```c++
ll h_est(int state);                         // 估价函数：必须是「乐观下界」（不高估）
ll a_star(int start, int goal) {
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<>> pq;
    vector<ll> g(/* 状态数 */ 1, (ll)4e18);
    g[start] = 0;
    pq.push({h_est(start), start});
    while (!pq.empty()) {
        auto pr = pq.top(); pq.pop();
        ll f = pr.first;
        int u = pr.second;
        if (u == goal) return g[u];          // 第一次弹出终点即最优
        // 枚举后继 v，代价 w：若 g[u] + w < g[v] 则更新并压入 (g[v] + h(v), v)
    }
    return -1;
}
// 例：八数码的 h 取「每个数字到目标位置的曼哈顿距离之和」（不高估）
```

### 应用

#### IDA*

迭代加深 + 估价剪枝：限制 $f=g+h$ 不超过当前阈值，超过就剪掉，并记下「被剪的最小 $f$」作为下一轮阈值。

```c++
int ida_bound;
bool ida_dfs(int state, int g, int depth_limit) {
    int f = g + (int)h_est(state);
    if (f > ida_bound) return false;
    if (h_est(state) == 0) return true;      // 到达目标
    if (g >= depth_limit) return false;
    // 枚举后继，递归 ida_dfs(next, g + 1, depth_limit)
    return false;
}
int ida_star(int start, int depth_limit) {
    ida_bound = (int)h_est(start);
    while (ida_bound <= depth_limit) {
        if (ida_dfs(start, 0, depth_limit)) return ida_bound;
        ida_bound++;                         // 更精细的做法是把「被剪掉的最小 f」作为新阈值
    }
    return -1;
}
// IDA* 的空间是 O(深度)，适合「状态数爆炸但解很深」的题
```
