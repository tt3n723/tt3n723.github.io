## 整除与 GCD、LCM


### 一句话

一开始给你若干整数（值域 $\le 10^{18}$，个数 $\le 10^6$），每次询问其中两个数的最大公约数 $\gcd$ 与最小公倍数 $\mathrm{lcm}$，两种询问交替出现。**时间单次 $O(\log)$，空间 $O(1)$。**


### 原理


### 实现

```c++
ll gcd_(ll a, ll b) { while (b) { ll t = a % b; a = b; b = t; } return a; }
ll lcm_(ll a, ll b) { return a / gcd_(a, b) * b; }   // 先除后乘，避免溢出
```


### 应用


#### 多个数的 gcd / lcm

逐个合并即可；注意 lcm 可能迅速超过 long long，需要 __int128 或取模。

```c++
ll gcd_all(vector<ll>& v) {
    ll g = 0;
    for (ll x : v) g = gcd_(g, x);
    return g;                                // gcd(0, x) = x
}
__int128 lcm_all(vector<ll>& v) {
    __int128 l = 1;
    for (ll x : v) l = l / gcd_((ll)l, x) * x;   // 可能溢出，实际题目通常要求取模
    return l;
}
// 例：{12, 18, 24} 的 gcd 是 6、lcm 是 72
```


#### 分数化简

分子分母同除 gcd，并把负号统一放到分子上。

```c++
struct Frac {
    ll p, q;                                 // p / q，q > 0，已约分
    Frac(ll p_ = 0, ll q_ = 1) : p(p_), q(q_) {
        if (q < 0) p = -p, q = -q;
        ll g = gcd_(llabs(p), q);
        if (g) p /= g, q /= g;
    }
    Frac operator+(const Frac& o) const { return Frac(p * o.q + o.p * q, q * o.q); }
};
// 例：Frac(4, 6) 化简成 2/3；Frac(1, -2) 规范化成 -1/2
```


#### 区间的 gcd 与 ST 表

区间 gcd 可以用 ST 表 $O(n\log n)$ 预处理、$O(1)$ 查询（gcd 可重复计算，满足区间重叠）。

```c++
int lg2[N], stg[N][20];
void build_gcd_st(vector<ll>& a, int n) {
    lg2[1] = 0;
    for (int i = 2; i <= n; i++) lg2[i] = lg2[i >> 1] + 1;
    for (int i = 1; i <= n; i++) stg[i][0] = a[i];
    for (int j = 1; (1 << j) <= n; j++)
        for (int i = 1; i + (1 << j) - 1 <= n; i++)
            stg[i][j] = gcd_(stg[i][j - 1], stg[i + (1 << (j - 1))][j - 1]);
}
ll query_gcd(int l, int r) {
    int k = lg2[r - l + 1];
    return gcd_(stg[l][k], stg[r - (1 << k) + 1][k]);
}
```


## 扩展欧几里得


### 一句话

给你两个整数 $a,b$（$|a|,|b|\le 10^{18}$），要你找出一组整数 $x,y$ 使 $ax+by=\gcd(a,b)$。**时间 $O(\log)$，空间 $O(1)$。**


### 原理


### 实现

```c++
ll exgcd(ll a, ll b, ll& x, ll& y) {         // 返回 gcd(a,b)，并给出一组解
    if (!b) { x = 1, y = 0; return a; }
    ll g = exgcd(b, a % b, y, x);
    y -= a / b * x;
    return g;
}
```


### 应用


#### 线性丢番图方程

$ax+by=c$ 有解当且仅当 $\gcd(a,b)\mid c$；通解是「特解加上 $\frac{b}{g}t$」。

```c++
bool diophantine(ll a, ll b, ll c, ll& x, ll& y) {
    ll g = exgcd(a, b, x, y);
    if (c % g) return false;
    x *= c / g, y *= c / g;                  // 一组特解
    // 通解：x + (b/g)*t, y - (a/g)*t
    return true;
}
// 例：3x + 5y = 1 的一组解是 x = 2, y = -1
```


#### 求逆元

$ax\equiv 1\pmod m$ 等价于 $ax+my=1$；用 exgcd 求出 $x$ 后取正即可（要求 $\gcd(a,m)=1$）。

```c++
ll inv_exgcd(ll a, ll m) {
    ll x, y;
    ll g = exgcd(a, m, x, y);
    if (g != 1) return -1;                   // 不互质，逆元不存在
    return (x % m + m) % m;
}
// 模数为素数时也可以直接用费马小定理：inv = qpow(a, m-2, m)
```


#### 同余方程组（逐条合并）

两条同余式 $x\equiv r_1\pmod{m_1}$、$x\equiv r_2\pmod{m_2}$ 可以用 exgcd 合并成一条模 $\mathrm{lcm}$ 的同余式。

```c++
bool merge_cong(ll r1, ll m1, ll r2, ll m2, ll& r, ll& m) {
    ll x, y;
    ll g = exgcd(m1, m2, x, y);
    if ((r2 - r1) % g) return false;         // 无解
    ll l = m1 / g * m2;                      // 新的模数
    x = (x % (m2 / g) + (m2 / g)) % (m2 / g);
    r = (r1 + (__int128)((r2 - r1) / g) % l * x % l * m1) % l;
    r = (r % l + l) % l, m = l;
    return true;
}
```


## 素数判定

### 一句话

给定 $q$ 个整数（$q\le 10^5$，每个 $\le 10^{12}$），每次给你一个数，问你它是不是素数。**时间单次 $O(\sqrt n)$（试除）或 $O(\log^2 n)$（Miller–Rabin），空间 $O(1)$。**

### 原理


### 实现

> 说明：单个数判素的代码见下面的「应用」一节；区间筛的做法在 `埃氏筛与线性筛` 一节里。

### 应用


#### 单个数判素

试除到 $\sqrt x$ 即可，复杂度和常数都很小（$x\le 10^{12}$ 时够用）。

```c++
bool is_prime_small(ll x) {
    if (x < 2) return false;
    for (ll d = 2; d * d <= x; d++) if (x % d == 0) return false;
    return true;
}
// x 到 1e18 时要用 Miller-Rabin
```


#### 快速分解质因数

先用筛法预处理出 $\le\sqrt{\max x}$ 的素数，再逐个试除；配合 Pollard-Rho 可处理 $10^{18}$。

```c++
vector<pair<ll, int>> factorize(ll x) {
    vector<pair<ll, int>> res;
    for (int i = 1; i <= pcnt && (ll)primes[i] * primes[i] <= x; i++) {
        if (x % primes[i]) continue;
        int c = 0;
        while (x % primes[i] == 0) x /= primes[i], c++;
        res.push_back({primes[i], c});
    }
    if (x > 1) res.push_back({x, 1});
    return res;
}
```


## 埃氏筛与线性筛


### 一句话

给定上界 $n\le 10^7$（或单个数 $x\le 10^{18}$），要你把 $1$ 到 $n$ 的素数全部打表，并顺带记下每个数的最小质因子（对单个数 $x$ 则判定它是不是素数），两种规模交替出现。**时间 $O(n)$（线性筛）或 $O(\sqrt x)$（单数判素），空间 $O(n)$。**


### 原理


### 实现

```c++
bool is_comp[N];
int primes[N], pcnt;
int minp[N], phi[N], mu[N];

void linear_sieve(int n) {                   // 线性筛：顺便求积性函数
    phi[1] = 1, mu[1] = 1;
    for (int i = 2; i <= n; i++) {
        if (!is_comp[i]) primes[++pcnt] = i, minp[i] = i, phi[i] = i - 1, mu[i] = -1;
        for (int j = 1; j <= pcnt && (ll)i * primes[j] <= n; j++) {
            int p = primes[j], t = i * p;
            is_comp[t] = true, minp[t] = p;
            if (i % p == 0) {
                phi[t] = phi[i] * p, mu[t] = 0;
                break;                       // 关键：保证每个合数只被最小质因子筛一次
            }
            phi[t] = phi[i] * (p - 1), mu[t] = -mu[i];
        }
    }
}
```


### 应用


#### 区间筛

求 $[L,R]$ 内的素数（$R-L\le 10^6$、$R\le 10^{12}$）：用 $\le\sqrt R$ 的素数去筛这段区间。

```c++
vector<char> seg_sieve(ll L, ll R) {
    vector<char> isp(R - L + 1, true);
    if (L == 1) isp[0] = false;
    for (int i = 1; i <= pcnt && (ll)primes[i] * primes[i] <= R; i++) {
        ll p = primes[i];
        for (ll j = max(p * p, (L + p - 1) / p * p); j <= R; j += p)
            isp[j - L] = false;
    }
    return isp;
}
// 注意起点要取 max(p*p, 第一个 >= L 的倍数)，否则会把 p 自己筛掉
```


## Miller–Rabin 素性测试


### 一句话

给定一个数 $x\le 10^{18}$，要你以极高概率判断它是不是素数，还要把它分解成质因子，两种询问交替出现。**时间 $O(k\log^3 x)$（素性判定）、期望 $O(x^{1/4})$（分解），空间 $O(1)$。**


### 原理


### 实现

```c++
using u64 = unsigned long long;
u64 mul_mod(u64 a, u64 b, u64 m) { return (__int128)a * b % m; }
u64 pow_mod(u64 a, u64 b, u64 m) {
    u64 r = 1;
    for (a %= m; b; b >>= 1, a = mul_mod(a, a, m))
        if (b & 1) r = mul_mod(r, a, m);
    return r;
}
bool is_prime_mr(u64 n) {                    // 对 1e18 用这组基是确定性的
    if (n < 2) return false;
    for (u64 p : {2ULL, 3ULL, 5ULL, 7ULL, 11ULL, 13ULL, 17ULL, 19ULL, 23ULL, 29ULL, 31ULL, 37ULL})
        if (n % p == 0) return n == p;
    u64 d = n - 1;
    int s = 0;
    while (!(d & 1)) d >>= 1, s++;
    for (u64 a : {2ULL, 3ULL, 5ULL, 7ULL, 11ULL, 13ULL, 17ULL, 19ULL, 23ULL, 29ULL, 31ULL, 37ULL}) {
        u64 x = pow_mod(a, d, n);
        if (x == 1 || x == n - 1) continue;
        bool ok = false;
        for (int i = 1; i < s; i++) {
            x = mul_mod(x, x, n);
            if (x == n - 1) { ok = true; break; }
        }
        if (!ok) return false;
    }
    return true;
}
```

## Pollard–Rho 因数分解

### 一句话

给你一个大整数 $n$（$n\le 2^{62}$），要你把它分解成质因子的乘积。**时间期望 $O(n^{1/4})$，空间 $O(\log n)$。**

### 原理


### 实现

> 说明：Pollard–Rho 的代码见下面的「应用」一节；它依赖的快速幂与 Miller–Rabin 在 `Miller–Rabin 素性测试` 一节里。

### 应用


#### 分解大数的质因子

Pollard-Rho：用 $f(x)=x^2+c$ 生成伪随机序列，配合 gcd 累积（Brent 优化能再快一倍）。

```c++
u64 pollard(u64 n) {
    if (n % 2 == 0) return 2;
    if (is_prime_mr(n)) return n;
    while (true) {
        u64 c = (u64)rand() % (n - 1) + 1;
        auto f = [&](u64 x) { return (mul_mod(x, x, n) + c) % n; };
        u64 x = 0, y = 0, d = 1;
        do {
            x = f(x), y = f(f(y));
            d = std::gcd(x > y ? x - y : y - x, n);
        } while (d == 1);
        if (d != n) return d;
    }
}
void factor(u64 n, vector<u64>& out) {
    if (n == 1) return;
    if (is_prime_mr(n)) { out.push_back(n); return; }
    u64 d = pollard(n);
    factor(d, out), factor(n / d, out);
}
```


#### 由质因数求约数个数 / 约数和

$d(n)=\prod(e_i+1)$；$\sigma(n)=\prod\frac{p_i^{e_i+1}-1}{p_i-1}$，都在 $O(\log n)$ 内算出。

```c++
pair<u64, u64> divisors_count_sum(vector<u64>& fac) {   // fac 是排好序的质因子列表
    u64 dc = 1, ds = 1;
    for (size_t i = 0; i < fac.size(); ) {
        size_t j = i;
        while (j < fac.size() && fac[j] == fac[i]) j++;
        u64 e = j - i, t = 1, s = 1, pw = 1;
        for (u64 k = 0; k < e; k++) pw *= fac[i], t++, s += pw;
        dc *= t, ds *= s;
        i = j;
    }
    return {dc, ds};
}
// 例：n = 12 = 2^2 * 3 -> 约数个数 (2+1)*(1+1) = 6，约数和 (1+2+4)*(1+3) = 28
```


## 高级筛法与素数计数（Min_25）


### 一句话

给你一个 $n\le 10^{10}$，要你数出 $1$ 到 $n$ 里有多少个素数，或求出某个积性函数的前缀和，两种询问交替出现。**时间 $O(n^{3/4}/\log n)$，空间 $O(\sqrt n)$。**


### 原理


### 实现

（Min_25 筛分两步：先求「质数位置的前缀和」，再把合数按最小质因子递归。）

```c++
// 第一步：用「埃氏筛」的思路对每个 v = n/l 求出质数位置的 f 之和
ll w[N], g[N], id1[N], id2[N];
int m_, sq;

void min25_init(ll n) {
    m_ = 0, sq = (int)sqrtl((long double)n);
    for (ll l = 1, r; l <= n; l = r + 1) {   // 整除分块的 O(sqrt n) 个取值
        r = n / (n / l);
        w[++m_] = n / l;
        if (w[m_] <= sq) id1[w[m_]] = m_; else id2[n / w[m_]] = m_;
    }
}
int idx_of(ll v) { return v <= sq ? id1[v] : id2[/**/ 0]; }   // 实际要用 n / v
// 第二步：S(n, i) = 「最小质因子 > p_i 的部分」的贡献，递归展开
// 复杂度 O(n^{3/4} / log n)，只适合单点 n 很大、f(p) 是低次多项式的情形
```


### 应用


#### 素数计数（Lucy_Hedgehog 的 $O(n^{3/4})$ 做法）

取 $f(x)=1$，逐个质数 $p$ 去更新所有 $v\ge p^2$ 的 $g[v]$，最后 $g[n]$ 就是 $\pi(n)$。

```c++
ll count_primes(ll n) {
    vector<ll> v, g;
    for (ll l = 1, r; l <= n; l = r + 1) { r = n / (n / l); v.push_back(n / l); }
    int s = v.size();
    for (int i = 0; i < s; i++) g.push_back(v[i] - 1);   // 先假设 2..v 都是质数
    for (ll p = 2; p * p <= n; p++) {
        if (g[s - p] == g[s - p + 1]) continue;          // p 不是质数
        ll sp = g[s - p + 1];                            // 「< p 的质数个数」
        ll p2 = p * p;
        for (int i = 0; i < s && v[i] >= p2; i++) {
            // v[i]/p 对应的下标
            int k = (v[i] / p <= (ll)sqrtl((long double)n)) ? 0 : 0;   // 用下标映射表
            (void)k;
            g[i] -= g[/* idx(v[i]/p) */ 0] - sp;
        }
    }
    return g[0];                             // v[0] = n
}
// 完整实现需要一张 idx(v) 的映射表：v <= sqrt(n) 时存原值，否则存 n/v
```


## 模运算与逆元


### 一句话

给定模数 $m$（$m\le 10^{18}$，可能合数），你要在模 $m$ 下做加减乘、求一个数的逆元，并在预处理后回答组合数 $\binom{n}{k}$ 的询问，几种询问交替出现。**时间取模 $O(1)$、逆元 $O(\log m)$、组合数预处理 $O(n)$ 后单次 $O(1)$，空间 $O(n)$。**


### 原理


### 实现

```c++
ll qpow(ll a, ll b, ll mod) {
    ll r = 1;
    for (a %= mod; b; b >>= 1, a = (__int128)a * a % mod)
        if (b & 1) r = (__int128)r * a % mod;
    return r;
}
ll norm(ll x, ll mod) { return (x % mod + mod) % mod; }   // 负数取模归一到 [0, mod)
```


### 应用


#### 组合数取模

$m$ 是素数且 $n<m$ 时用阶乘 + 逆元；$n\ge m$ 时用 Lucas；$m$ 是合数时用扩展 Lucas。

```c++
const int MAXN = 1000005;
ll fac[MAXN], ifac[MAXN];
void init_fac(int n, ll mod) {
    fac[0] = 1;
    for (int i = 1; i <= n; i++) fac[i] = fac[i - 1] * i % mod;
    ifac[n] = qpow(fac[n], mod - 2, mod);
    for (int i = n; i >= 1; i--) ifac[i - 1] = ifac[i] * i % mod;
}
ll comb(ll n, ll k, ll mod) {
    if (k < 0 || k > n) return 0;
    return fac[n] * ifac[k] % mod * ifac[n - k] % mod;
}
```


#### 阶乘逆元倒推

只算一次 $\mathrm{ifac}[n]$，再倒着推 $\mathrm{ifac}[i-1]=\mathrm{ifac}[i]\cdot i$，整体 $O(n)$。

```c++
// 只算一次 ifac[n]，再倒着推：ifac[i-1] = ifac[i] * i
void build_inv_fac(int n, ll mod) {
    ll f = 1;
    for (int i = 1; i <= n; i++) f = f * i % mod;
    ll iv = qpow(f, mod - 2, mod);           // 只求这一次逆元
    static ll ifc[N];
    ifc[n] = iv;
    for (int i = n; i >= 1; i--) ifc[i - 1] = ifc[i] * i % mod;
}
// 这样整体是 O(n + log mod)，比「每个 i 都求一次逆元」的 O(n log mod) 快很多
```


#### 模数是合数

此时不能直接用费马小定理；要么用扩展欧几里得求逆（要求互质），要么用扩展 Lucas 把模数分解后合并。

```c++
ll inv_coprime(ll a, ll m) {                 // 要求 gcd(a, m) = 1
    ll x, y;
    exgcd(a, m, x, y);
    return (x % m + m) % m;
}
// gcd(a, m) != 1 时逆元不存在，「组合数取模」要改用扩展 Lucas
```


#### 负数取模

C++ 的取模运算会给出负的结果，所有「取模后比较」的地方都要先归一化。

```c++
// C++ 的 % 是「向零取整」，负数会得到负结果
// 例：(-1) % 3 == -1，而不是 2
ll norm_ex(ll x, ll mod) { return (x % mod + mod) % mod; }
int main_check() {
    assert((-1) % 3 == -1);
    assert(norm_ex(-1, 3) == 2);
    assert(norm_ex(-4, 3) == 2);
    return 0;
}
// 所有「哈希 / 计数 / 比较」的地方都要先 norm；尤其是减法的结果
```


## 费马小定理与欧拉定理


### 一句话

给定底数 $a$、模数 $m$ 与一个巨大的指数 $b$（$b$ 以字符串或递推形式给出，长度 $\le 10^6$），要你算出 $a^b\bmod m$。**时间 $O(|b|+\log m)$，空间 $O(1)$。**


### 原理


### 实现

```c++
ll phi_of(ll n) {                            // 单点求欧拉函数 O(sqrt n)
    ll r = n;
    for (ll d = 2; d * d <= n; d++) {
        if (n % d) continue;
        while (n % d == 0) n /= d;
        r = r / d * (d - 1);
    }
    if (n > 1) r = r / n * (n - 1);
    return r;
}
```


### 应用


#### 费马小定理

$m$ 是素数且 $a\not\equiv 0$ 时，$a^{m-1}\equiv1$，于是 $a^b\equiv a^{b\bmod(m-1)}$。

```c++
ll pow_mod_prime(ll a, ll b, ll p) {         // p 是素数
    if (b < 0) return 0;
    return qpow(a, b % (p - 1), p);
}
// 前提是 a % p != 0；a 是 p 的倍数时答案恒为 0
```


#### 欧拉定理

一般地 $a^{\varphi(m)}\equiv1\pmod m$（要求 $\gcd(a,m)=1$）；指数可以对 $\varphi(m)$ 取模。

```c++
ll pow_mod_phi(ll a, ll b, ll m) {           // 要求 gcd(a, m) = 1
    return qpow(a % m, b % phi_of(m), m);
}
```


#### 威尔逊定理

$p$ 是素数当且仅当 $(p-1)!\equiv-1\pmod p$，可用于判素（但效率远不如 Miller-Rabin）。

```c++
bool wilson_prime(ll p) {
    if (p < 2) return false;
    ll f = 1;
    for (ll i = 2; i <= p - 1; i++) f = (__int128)f * i % p;
    return f == p - 1;
}
// 只适合很小的 p；实战判素用 Miller-Rabin
```


#### 递归降幂（指数本身又是幂）

求 $a^{b}\bmod m$ 且 $b$ 很大时：若 $\gcd(a,m)=1$ 就取 $b\bmod\varphi$；否则在 $b\ge\varphi$ 时用 $b\bmod\varphi+\varphi$。

```c++
ll pow_mod_big(ll a, ll b, ll m) {           // 这里的 b 已经很大，可能超过 phi
    if (m == 1) return 0;
    ll ph = phi_of(m);
    bool big = (b >= ph);                    // b 与 ph 的大小关系要单独保留
    ll e = b % ph + (big ? ph : 0);
    if (std::gcd(a, m) == 1) e = b % ph;     // 互质时不需要 +ph
    return qpow(a % m, e, m);
}
// 例：2^100 mod 5，phi(5) = 4，答 2^(100 mod 4) = 2^0 = 1
```


## 同余方程


### 一句话

给你同余方程 $ax\equiv b\pmod m$（$m\le 10^{18}$），要你求出它的通解，或者判定它无解。**时间 $O(\log m)$，空间 $O(1)$。**


### 原理


### 实现

```c++
bool solve_congruence(ll a, ll b, ll m, ll& x0, ll& mod, ll& cnt) {
    ll x, y;
    ll g = exgcd(a, m, x, y);
    if (b % g) return false;                 // 无解
    ll mm = m / g;
    x0 = norm((__int128)(b / g) % mm * (x % mm) % mm, mm);   // 最小非负解
    mod = mm, cnt = g;                       // 模 mm 下有 g 个解
    return true;
}
```


### 应用


#### 解一次同余方程

见上面的写法；解的个数是 $\gcd(a,m)$。

```c++
// 用求解函数验证一遍

    bool ok = solve_congruence(6, 4, 10, x0, mod, cnt);
    assert(ok && cnt == 2 && mod == 5 && x0 == 4);
    // 暴力核对：x 在 [0, 10) 内满足 6x % 10 == 4 的正好是 4 和 9
    int c = 0;
    for (ll x = 0; x < 10; x++) if (6 * x % 10 == 4) c++;
    assert(c == 2);
}
```


#### 高次同余

$x^k\equiv a\pmod p$ 在 $p$ 是素数时用「离散对数 + BSGS」；$k=2$ 时用二次剩余（Cipolla）。

```c++
ll kth_root_mod(ll a, ll k, ll p, ll g) {    // 解 x^k = a (mod p)，g 是原根

    if (s < 0) return -1;

    return qpow(g, x0, p);                   // 共 cnt = gcd(k, p-1) 个解
}
// 例：p = 7, g = 3, k = 3, a = 1 -> x 满足 x^3 = 1 (mod 7)（1, 2, 4 都是解）
```


## 中国剩余定理（CRT）与扩展 CRT


### 一句话

给你 $k$ 条同余式 $x\equiv r_i\pmod{m_i}$（$k\le 10^5$，$m_i\le 10^{18}$，不要求两两互质），要你求出同时满足它们的最小非负 $x$。**时间 $O(k\log)$，空间 $O(k)$。**


### 原理


### 实现

（扩展 CRT：逐条合并，用 exgcd 求出「模数不互质」时的修正量。）

```c++
// 合并两条同余式：x ≡ r1 (mod m1), x ≡ r2 (mod m2)
bool crt_merge(ll r1, ll m1, ll r2, ll m2, ll& r, ll& m) {
    ll x, y;
    ll g = exgcd(m1, m2, x, y);
    if ((r2 - r1) % g) return false;
    ll l = m1 / g * m2;                      // 新的模数（可能溢出，用 __int128）
    ll mg = m2 / g;
    ll t = norm((__int128)((r2 - r1) / g) % mg * (x % mg) % mg, mg);
    r = norm((__int128)r1 + (__int128)m1 * t, l);
    m = l;
    return true;
}
ll crt_all(vector<ll>& rs, vector<ll>& ms, bool& ok) {
    ll r = 0, m = 1;
    for (size_t i = 0; i < rs.size(); i++)
        if (!crt_merge(r, m, rs[i], ms[i], r, m)) { ok = false; return -1; }
    ok = true;
    return norm(r, m);
}
```


### 应用


#### 合并同余式

上面的写法；模数两两互质时也可以用「直接构造」的经典 CRT 公式。

```c++
ll crt_coprime(vector<ll>& rs, vector<ll>& ms, ll M) {   // M = prod ms，要求两两互质
    ll res = 0;
    for (size_t i = 0; i < rs.size(); i++) {
        ll Mi = M / ms[i];
        ll inv = inv_coprime(Mi % ms[i], ms[i]);            // 互质即可，不要求 ms[i] 是素数
        res = (res + (__int128)rs[i] * Mi % M * inv) % M;
    }
    return res;
}
```

## 卢卡斯定理与扩展卢卡斯


### 一句话

给你 $n,k$（$n\le 10^{18}$）与模数 $m$（$m\le 10^6$，可能合数），要你算出 $\binom{n}{k}\bmod m$。**时间 $O(m)$ 预处理后单次 $O(\log_m n\cdot\log)$，空间 $O(m)$。**


### 原理


### 实现

```c++
ll lucas(ll n, ll k, ll p) {                 // p 必须是素数
    if (k == 0) return 1;
    return comb(n % p, k % p, p) * lucas(n / p, k / p, p) % p;
}
// 需要预先对 [0, p) 算好阶乘与逆阶乘
```


### 应用


#### 组合数模小素数

直接用 Lucas，$O(p)$ 预处理 + $O(\log_p n)$ 单次查询。

```c++
void check_lucas() {

    assert(lucas(10, 3, 7) == 1);
    // 直接暴力核对：C(10,3) = 120，120 % 7 = 1
    assert(120 % 7 == 1);
}
// 注意：lucas 里的 comb 用的是「模 p 的阶乘表」，阶乘表只需要开到 p-1
```


#### 模数不为素数

把模数分解成素数幂 $p^e$，对每个素数幂用扩展 Lucas（处理含 $p$ 的因子），再 CRT 合并。

```c++

    res = qpow(res, n / pk, pk);
    for (ll i = 1; i <= n % pk; i++) if (i % p) res = res * i % pk;
    return res * exlucas_fac(n / p, p, pk) % pk;
}

    // 2. 对每个 p^e 求 C(n,m)（用上面的 exlucas_fac 处理 p 的幂次）
    // 3. 把结果与模数分别推进 outs / mods，最后用 CRT 合并
    (void)n; (void)m; (void)outs; (void)mods;
}
```


## 二次剩余


### 一句话

给你奇素数 $p$ 与整数 $a$（$p\le 10^{18}$），要你判断 $x^2\equiv a\pmod p$ 是否有解，有解时还要给出一个 $x$，两种结果交替出现。**时间期望 $O(\log^2 p)$，空间 $O(1)$。**


### 原理


### 实现

（Cipolla 算法：在扩域 $\mathbb{F}_{p^2}$ 上做快速幂。）

```c++
struct Fp2 {                                 // a + b*w，其中 w^2 = n（非剩余）
    ll a, b, w, p;
    Fp2(ll a, ll b, ll w, ll p) : a(a), b(b), w(w), p(p) {}
    Fp2 operator*(const Fp2& o) const {
        return Fp2((a * o.a + (__int128)b * o.b % p * w) % p,
                   (a * o.b + b * o.a) % p, w, p);
    }
};
Fp2 fp2_pow(Fp2 b, ll e) {
    Fp2 r(1, 0, b.w, b.p);
    for (; e; e >>= 1, b = b * b) if (e & 1) r = r * b;
    return r;
}
ll cipolla(ll n, ll p) {                     // 返回一个 x 使 x^2 = n (mod p)
    n = norm(n, p);
    if (n == 0) return 0;
    if (qpow(n, (p - 1) / 2, p) != 1) return -1;   // 欧拉判别法：无解
    if (p % 4 == 3) return qpow(n, (p + 1) / 4, p);
    ll a;
    mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
    while (true) {
        a = rng() % p;
        ll w = ((__int128)a * a % p - n + p) % p;
        if (qpow(w, (p - 1) / 2, p) == p - 1)
            return fp2_pow(Fp2(a, 1, w, p), (p + 1) / 2).a;
    }
}
```


### 应用


#### 解二次同余方程


## 原根、离散对数与 BSGS


### 一句话

给你素数 $p\le 10^{12}$ 与两个数 $a,b$，要你求出满足 $a^x\equiv b\pmod p$ 的最小非负 $x$。**时间 $O(\sqrt p)$，空间 $O(\sqrt p)$。**


### 原理


### 实现

```c++
ll bsgs(ll a, ll b, ll p) {                  // 求 a^x = b (mod p)，要求 gcd(a,p)=1
    a = norm(a, p), b = norm(b, p);
    if (b == 1) return 0;
    ll m = (ll)sqrtl((long double)p) + 1;
    unordered_map<ll, ll> mp;
    ll cur = b;
    for (ll j = 0; j < m; j++) { mp[cur] = j; cur = (__int128)cur * a % p; }
    ll am = qpow(a, m, p);
    cur = 1;
    for (ll i = 1; i <= m; i++) {
        cur = (__int128)cur * am % p;
        auto it = mp.find(cur);
        if (it != mp.end()) return i * m - it->second;
    }
    return -1;
}
```


### 应用


#### 离散对数

$p$ 是素数时用上面的 BSGS；注意返回值可能为负，实现里保证了它是最小非负解。

```c++
void check_bsgs() {
    assert(bsgs(2, 5, 13) == 9);
    assert(bsgs(2, 1, 13) == 0);
    // 暴力核对：找出最小的 x 使 2^x = 5 (mod 13)
    ll cur = 1;
    for (ll x = 0; x < 100; x++) {
        if (cur == 5) { assert(x == 9); break; }
        cur = cur * 2 % 13;
    }
}
// 注意：p 到 1e12 时用 sqrt(p) 的哈希表会比较大，实际要控制内存
```


#### 扩展 BSGS

$\gcd(a,p)\ne1$ 时，先把 $a$ 与 $p$ 的公因子除掉、化为互质的情形。

```c++
ll exbsgs(ll a, ll b, ll p) {
    a = norm(a, p), b = norm(b, p);
    if (b == 1 || p == 1) return 0;
    ll g, k = 0, add = 1;
    while ((g = std::gcd(a, p)) > 1) {
        if (b % g) return -1;                // 无解
        p /= g, b /= g, add = (__int128)add * (a / g) % p, k++;
        if (add == b) return k;
    }
    // 此时 gcd(a, p) = 1，等价于解 a^(x-k) = b * add^{-1} (mod p)
    ll invadd = inv_coprime(add, p);
    ll x = bsgs(a, (__int128)b * invadd % p, p);
    return x == -1 ? -1 : x + k;
}
```


#### 高次同余

$x^k\equiv a\pmod p$：取原根 $g$，$a=g^s$（BSGS），解 $k t\equiv s\pmod{p-1}$。

```c++

```


#### 原根的个数与判定

$p$ 的原根存在，个数是 $\varphi(p-1)$；判定 $g$：对 $p-1$ 的每个质因子 $q$ 都要 $g^{(p-1)/q}\not\equiv1$。

```c++

    return true;

// 求最小原根：从小到大枚举 g 并判定，期望很快
```

## 欧拉函数


### 一句话

给定 $n\le 10^{12}$（或需要 $\varphi$ 的前缀和到 $n\le 10^{10}$），每次让你求一个数的 $\varphi$、把 $1..N$ 的 $\varphi$ 全部筛出来，或求 $\sum_{i=1}^{n}\varphi(i)$，几种规模交替出现。**时间单点 $O(\sqrt n)$、筛 $1..N$ 为 $O(N)$、前缀和用杜教筛 $O(n^{2/3})$，空间 $O(\sqrt n)$。**


### 原理


### 实现

```c++
ll phi_ll(ll n) {                            // 单点求欧拉函数 O(sqrt n)
    ll r = n;
    for (ll d = 2; d * d <= n; d++) {
        if (n % d) continue;
        while (n % d == 0) n /= d;
        r = r / d * (d - 1);
    }
    if (n > 1) r = r / n * (n - 1);
    return r;
}
```


### 应用


#### 求和恒等式

$\sum_{d\mid n}\varphi(d)=n$，这是「$\varphi$ 与恒等函数 $1$ 的卷积」的直接推论，也是杜教筛的基础。

```c++
ll sum_identity(ll n) { return n; }          // sum_{d|n} phi(d) = n
```


#### 线性筛求 $\varphi$

$\varphi(p)=p-1$；$p\mid i$ 时 $\varphi(ip)=p\varphi(i)$；否则 $\varphi(ip)=(p-1)\varphi(i)$。

```c++
int phi_s[N], pr_s[N], pc_s;
bool comp_s[N];
void sieve_phi(int n) {                      // 标准的线性筛版
    phi_s[1] = 1;
    for (int i = 2; i <= n; i++) {
        if (!comp_s[i]) pr_s[++pc_s] = i, phi_s[i] = i - 1;
        for (int j = 1; j <= pc_s && (ll)i * pr_s[j] <= n; j++) {
            int p = pr_s[j];
            comp_s[i * p] = true;
            if (i % p == 0) { phi_s[i * p] = phi_s[i] * p; break; }
            phi_s[i * p] = phi_s[i] * (p - 1);
        }
    }
}
```


## 约数与约数函数


### 一句话

给定上界 $n\le 10^6$（或单个数 $x\le 10^{18}$），要你求一个数的约数个数与约数和，或把 $1..N$ 的约数个数整体筛出来，两种规模交替出现。**时间 $O(\sqrt x)$（单点枚举）、$O(N\log N)$（筛约数个数前缀和）或 $O(N)$（线性筛），空间 $O(N)$。**


### 原理


### 实现

```c++
// ---------- 单点枚举约数 ----------
vector<ll> divisors(ll x) {
    vector<ll> res;
    for (ll d = 1; d * d <= x; d++) {
        if (x % d) continue;
        res.push_back(d);
        if (d != x / d) res.push_back(x / d);
    }
    sort(res.begin(), res.end());
    return res;
}
// ---------- 筛选：d[i] = 约数个数 ----------
int dcnt[N], pe[N], e_[N];
void sieve_d(int n) {
    vector<int> pr; vector<char> comp(n + 1, 0);
    dcnt[1] = 1;
    for (int i = 2; i <= n; i++) {
        if (!comp[i]) { pr.push_back(i); dcnt[i] = 2; pe[i] = i; e_[i] = 1; }
        for (int p : pr) {
            if ((ll)i * p > n) break;
            comp[i * p] = 1;
            if (i % p == 0) {
                pe[i * p] = pe[i] * p, e_[i * p] = e_[i] + 1;
                dcnt[i * p] = dcnt[i] / (e_[i] + 1) * (e_[i] + 2);
                break;
            }
            pe[i * p] = p, e_[i * p] = 1;
            dcnt[i * p] = dcnt[i] * 2;
        }
    }
}
```


### 应用


#### 暴力求约数个数之和

$\sum_{i=1}^{N}d(i)=\sum_{d=1}^{N}\lfloor N/d\rfloor$，用整除分块可以 $O(\sqrt N)$ 求出。

```c++
ll sum_divisor_count(ll N) {
    ll res = 0;
    for (ll l = 1, r; l <= N; l = r + 1) {
        r = N / (N / l);
        res += (r - l + 1) * (N / l);
    }
    return res;
}
// 例：N = 5 -> d(1..5) = 1,2,2,3,2，和是 10
```


#### 约数和等于自身的数（完全数）

$\sigma(n)=2n$ 时叫完全数（这里把「除自己以外的约数和」记为 $s(n)$，$s(n)=n$ 即完全数）。

```c++
bool is_perfect(ll n) {
    ll s = 0;
    for (ll d = 1; d * d <= n; d++) {
        if (n % d) continue;
        s += d;
        if (d != 1 && d != n / d) s += n / d;
    }
    return s == n;
}
// 前几个完全数：6, 28, 496, 8128
```


#### 与积性函数的关系

$d(n)$ 与 $\sigma(n)$ 都是积性函数（不是完全积性），所以都能线性筛。

```c++
// 用同一个框架求约数和 sigma（完全积性部分用等比数列）
int sd[N], pe2[N];
void sieve_sigma(int n) {
    vector<int> pr; vector<char> comp(n + 1, 0);
    sd[1] = 1;
    for (int i = 2; i <= n; i++) {
        if (!comp[i]) { pr.push_back(i); sd[i] = i + 1; pe2[i] = 1 + i; }
        for (int p : pr) {
            if ((ll)i * p > n) break;
            comp[i * p] = 1;
            if (i % p == 0) {
                // sigma(i*p) = sigma(i) / pe2[i] * (pe2[i] * p + 1)
                pe2[i * p] = pe2[i] * p + 1;
                sd[i * p] = sd[i] / pe2[i] * pe2[i * p];
                break;
            }
            pe2[i * p] = 1 + p;
            sd[i * p] = sd[i] * (p + 1);
        }
    }
}
// 例：sigma(6) = 1+2+3+6 = 12；sigma(28) = 56
```


## 莫比乌斯反演


### 一句话

给定 $n\le 10^7$，要你统计 $\sum_{i,j}[\gcd(i,j)=1]$ 这类互质数对计数，或求出 $\sum_{i=1}^{n}\mathrm{lcm}(i,n)$ 这样的式子，几种求和交替出现。**时间先化成「$\mu$ 的倍数形式」再 $O(n\log n)$ 或 $O(n)$ 求前缀，空间 $O(n)$。**


### 原理


### 实现

（莫比乌斯反演：$f(n)=\sum_{d\mid n}g(d)\iff g(n)=\sum_{d\mid n}\mu(d)f(n/d)$。）

```c++
int mu[N], Smu[N];
void sieve_mu(int n) {
    vector<int> pr; vector<char> comp(n + 1, 0);
    mu[1] = 1;
    for (int i = 2; i <= n; i++) {
        if (!comp[i]) pr.push_back(i), mu[i] = -1;
        for (int p : pr) {
            if ((ll)i * p > n) break;
            comp[i * p] = 1;
            if (i % p == 0) { mu[i * p] = 0; break; }
            mu[i * p] = -mu[i];
        }
    }
    for (int i = 1; i <= n; i++) Smu[i] = Smu[i - 1] + mu[i];
}
```


### 应用


#### 互质数对计数

$\sum_{i=1}^{n}\sum_{j=1}^{m}[\gcd(i,j)=1]=\sum_{d}\mu(d)\lfloor n/d\rfloor\lfloor m/d\rfloor$，用整除分块 $O(\sqrt n)$。

```c++
ll coprime_pairs(ll n, ll m) {               // 需要 mu 的前缀和 Smu
    ll res = 0, lim = min(n, m);
    for (ll l = 1, r; l <= lim; l = r + 1) {
        r = min(n / (n / l), m / (m / l));
        res += (ll)(Smu[r] - Smu[l - 1]) * (n / l) * (m / l);
    }
    return res;
}
// 例：n = m = 3 -> 7（(1,1),(1,2),(1,3),(2,1),(2,3),(3,1),(3,2)）
```


#### 最小公倍数之和

$\sum_{i=1}^{n}\mathrm{lcm}(i,n)=n\sum_{d\mid n}\varphi(d)\cdot\frac nd$ 之类的形式，按约数枚举即可。

```c++
ll sum_lcm_with_n(ll n) {
    ll res = 0;
    for (ll d = 1; d * d <= n; d++) {
        if (n % d) continue;
        res += d;
        if (d != n / d) res += n / d;
    }
    return res;
}
// 实际做法：把 lcm(i,n) = i*n/gcd(i,n) 按 g = gcd(i,n) 分类，用 phi 求和
```


## 杜教筛


### 一句话

给你一个 $n\le 10^{10}$ 与积性函数 $f$，要你算出它的前缀和 $S(n)=\sum_{i=1}^{n}f(i)$。**时间 $O(n^{2/3})$，空间 $O(\sqrt n)$。**


### 原理


### 实现

（核心恒等式：$g(1)S(n)=\sum_{i=1}^{n}(f*g)(i)-\sum_{i=2}^{n}g(i)S(\lfloor n/i\rfloor)$。）

```c++
const int SIEVE_N = 5000005;
ll Sphi2[N], Smu2[N];
unordered_map<ll, ll> mem_phi, mem_mu;

ll sum_phi(ll n) {                           // S(n) = sum_{i<=n} phi(i)
    if (n < SIEVE_N) return Sphi2[n];
    auto it = mem_phi.find(n);
    if (it != mem_phi.end()) return it->second;
    ll res = (ll)((__int128)n * (n + 1) / 2 % MOD);   // sum_{i<=n} (phi * 1)(i) = sum i
    for (ll l = 2, r; l <= n; l = r + 1) {
        r = n / (n / l);
        res = (res - (r - l + 1) % MOD * sum_phi(n / l)) % MOD;
    }
    res = (res % MOD + MOD) % MOD;
    return mem_phi[n] = res;
}
ll sum_mu(ll n) {                            // S(n) = sum_{i<=n} mu(i)
    if (n < SIEVE_N) return Smu2[n];
    auto it = mem_mu.find(n);
    if (it != mem_mu.end()) return it->second;
    ll res = 1;                              // sum_{i<=n} (mu * 1)(i) = [n >= 1]
    for (ll l = 2, r; l <= n; l = r + 1) {
        r = n / (n / l);
        res -= (r - l + 1) * sum_mu(n / l);
    }
    return mem_mu[n] = res;
}
// 注意：sum_mu 返回的是真实值（可能是负数），不要取模
```


### 应用


#### 莫比乌斯前缀和

取 $f=\mu$、$g=1$：因为 $\mu*1=\varepsilon$，所以 $S(n)=1-\sum_{i=2}^{n}S(\lfloor n/i\rfloor)$。

```c++
// 用法：先线性筛到 n^(2/3)，再对大值走杜教筛
void check_sum_mu(ll n) {
    // 小值直接查表，大值走杜教筛；这里用「sum mu 在若干点上的值与暴力一致」来验证
    ll brute = 0;
    for (ll i = 1; i <= 1000; i++) {
        // 用线性筛得到的 mu 累加
        brute += mu[i];
        if (i <= 1000) assert(sum_mu(i) == brute);
    }
}
// 结论：sum_{i<=n} mu(i) 的量级是 O(sqrt n)，所以在 1e10 处开散列表是安全的
```


#### 欧拉函数前缀和

取 $f=\varphi$、$g=1$：因为 $\varphi*1=\mathrm{id}$，所以 $S(n)=\frac{n(n+1)}2-\sum_{i=2}^{n}S(\lfloor n/i\rfloor)$。

```c++
// 用法与验证
void check_sum_phi() {
    ll brute = 0;
    for (ll i = 1; i <= 1000; i++) {
        brute += phi_ll(i) % MOD;
        brute %= MOD;
        assert(sum_phi(i) == brute);
    }
}
// 恒等式：sum_{i<=n} phi(i) = n(n+1)/2 - sum_{i=2}^{n} sum_{j<=n/i} phi(j)
// 这正是杜教筛的递推式
```


#### 与线性筛结合

先用线性筛求出 $1..n^{2/3}$ 的前缀和，超过的部分才走杜教筛；这样总复杂度是 $O(n^{2/3})$。

```c++
void init_sieve(int lim) {                   // 线性筛 phi、mu 并做前缀和
    vector<int> pr; vector<char> comp(lim + 1, 0);
    phi_s[1] = 1, mu[1] = 1;
    for (int i = 2; i <= lim; i++) {
        if (!comp[i]) pr.push_back(i), phi_s[i] = i - 1, mu[i] = -1;
        for (int p : pr) {
            if ((ll)i * p > lim) break;
            comp[i * p] = 1;
            if (i % p == 0) { phi_s[i * p] = phi_s[i] * p; mu[i * p] = 0; break; }
            phi_s[i * p] = phi_s[i] * (p - 1), mu[i * p] = -mu[i];
        }
    }
    for (int i = 1; i <= lim; i++) Sphi2[i] = Sphi2[i - 1] + phi_s[i], Smu2[i] = Smu2[i - 1] + mu[i];
}
```


## 整除分块


### 一句话

给你一个 $n\le 10^{12}$，要你算出 $\sum_{i=1}^{n}f(\lfloor n/i\rfloor)$ 这类按商分组的求和。**时间 $O(\sqrt n)$，空间 $O(1)$。**


### 原理


### 实现

（$\lfloor n/i\rfloor$ 只有 $O(\sqrt n)$ 种取值；每一段的右端点是 $n/(n/l)$。）

```c++
ll sum_floor(ll n, function<ll(ll)> f) {     // sum_{i=1}^{n} f(n / i)
    ll res = 0;
    for (ll l = 1, r; l <= n; l = r + 1) {
        r = n / (n / l);
        res += (r - l + 1) * f(n / l);
    }
    return res;
}
```


### 应用


#### 数论函数前缀和

$\sum_{i=1}^{n}d(i)=\sum_{d=1}^{n}\lfloor n/d\rfloor$，直接整除分块 $O(\sqrt n)$。

```c++
ll sum_d(ll n) {
    ll res = 0;
    for (ll l = 1, r; l <= n; l = r + 1) {
        r = n / (n / l);
        res += (r - l + 1) * (n / l);
    }
    return res;
}
// 例：n = 10 -> 27
```


#### 二维整除分块

$\sum_{i,j}\lfloor n/i\rfloor\lfloor m/j\rfloor$：每段的右端点取两个商的右端点中较小的那个。

```c++
ll sum_2d(ll n, ll m) {
    ll res = 0;
    for (ll l = 1, r; l <= min(n, m); l = r + 1) {
        r = min(n / (n / l), m / (m / l));   // 关键：取两个右端点的较小值
        res += (r - l + 1) * (n / l) * (m / l);
    }
    return res;
}
```


#### 常见变形

$\sum\lfloor n/i\rfloor$ 的常见变形还有 $\sum i\lfloor n/i\rfloor$、$\sum f(\lfloor n/i\rfloor)$ 等，都是「整段一起算」。

```c++
ll sum_i_floor(ll n) {                       // sum_{i=1}^{n} i * (n / i)
    ll res = 0;
    for (ll l = 1, r; l <= n; l = r + 1) {
        r = n / (n / l);
        res += (l + r) * (r - l + 1) / 2 * (n / l);   // 等差数列求和
    }
    return res;
}
```


## 斐波那契数列


### 一句话

给你 $n\le 10^{18}$ 与模数 $m$，要你算出第 $n$ 项斐波那契数 $F_n$。**时间 $O(\log n)$（矩阵快速幂 / 快速倍增），空间 $O(1)$。**


### 原理


### 实现

```c++
// 快速倍增法：一次算出 (F_k, F_{k+1})
pair<ll, ll> fib_pair(ll n, ll mod) {
    if (n == 0) return {0, 1};
    auto pr = fib_pair(n >> 1, mod);
    ll a = pr.first, b = pr.second;              // a = F_k, b = F_{k+1}
    ll c = a * ((2 * b - a + mod) % mod) % mod;  // F_{2k} = F_k (2F_{k+1} - F_k)
    ll d = (a * a + b * b) % mod;                // F_{2k+1} = F_k^2 + F_{k+1}^2
    if (n & 1) return {d, (c + d) % mod};
    return {c, d};
}
ll fib_fast(ll n, ll mod) { return fib_pair(n, mod).first; }
```


### 应用


#### 通项与性质

$F_n=\frac{\phi^n-\psi^n}{\sqrt5}$；常用性质：$\gcd(F_a,F_b)=F_{\gcd(a,b)}$、$\sum F_i=F_{n+2}-1$。

```c++
ll fib_sum(ll n, ll mod) { return (fib_fast(n + 2, mod) - 1 + mod) % mod; }
// 前 n 项和 = F_{n+2} - 1
```


#### 求循环节（Pisano 周期）

$F_n\bmod m$ 一定会循环，周期用暴力找只能对付很小的 $m$；大 $m$ 要按「素数幂的周期取 lcm」。

```c++
ll pisano_brute(ll m) {                      // 暴力找周期，只适合小 m
    ll a = 0, b = 1;
    for (ll i = 0; i < 6 * m + 10; i++) {
        ll t = (a + b) % m;
        a = b, b = t;
        if (a == 0 && b == 1) return i + 1;
    }
    return -1;
}
// 验证：pi(2)=3, pi(3)=8, pi(10)=60
```
