## 树的存储与遍历


### 一句话

给定一棵 $n$ 个点的树（$n\le 10^6$），要求从根出发沿边把整棵树走一遍（不能因为递归太深而爆栈），并求出每个点的子树大小、深度和父节点。**时间 $O(n)$，空间 $O(n)$。**


### 原理


### 实现

```c++
int n;
vector<int> g[N];
int fa[N], dep[N], sz[N];

// ---------- 递归 DFS：最直观，但 n 大时会爆栈 ----------
void dfs(int u, int p) {
    fa[u] = p, sz[u] = 1;
    dep[u] = dep[p] + 1;
    for (int v : g[u])
        if (v != p) { dfs(v, u); sz[u] += sz[v]; }
}

// ---------- 迭代 DFS：用显式栈，不怕爆栈 ----------
int stk[N], par[N];                          // par 复用为「当前走到第几个儿子」的光标
void dfs_iter(int root) {
    int top = 0;
    stk[top] = root, par[root] = 0, dep[root] = 1, sz[root] = 1;
    while (top >= 0) {
        int u = stk[top];
        if (par[u] < (int)g[u].size()) {
            int v = g[u][par[u]++];
            if (v == fa[u]) continue;
            fa[v] = u, dep[v] = dep[u] + 1, sz[v] = 1, par[v] = 0;
            stk[++top] = v;                  // 往下走
        } else {
            top--;                           // 子树处理完了
            if (top >= 0) sz[stk[top]] += sz[u];
        }
    }
}
```


### 应用


#### 按深度分层（BFS 序）

BFS 得到的层序可以直接当「从上到下的 DP 顺序」用；每层的点放在一起，也方便做分层统计。

```c++
vector<int> level[N];
void bfs_levels(int root) {
    queue<int> q;
    q.push(root), dep[root] = 1, fa[root] = 0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        level[dep[u]].push_back(u);
        for (int v : g[u]) if (v != fa[u]) { fa[v] = u, dep[v] = dep[u] + 1, q.push(v); }
    }
}
// 从下往上做树形 DP 时，只要按深度从大到小遍历 level 即可
```


#### 换根 DP（rerooting）

先以 $1$ 为根算出一遍「子树内的贡献」，再顺着边把根换过去。下面求的是「每个点到其余所有点的距离之和」。

```c++
ll down[N], ans[N];
void dfs_down(int u, int p) {                // 第一遍：子树内到 u 的距离和与子树大小
    sz[u] = 1, down[u] = 0;
    for (int v : g[u]) {
        if (v == p) continue;
        dfs_down(v, u);
        sz[u] += sz[v];
        down[u] += down[v] + sz[v];          // v 子树里每个点都要多走一条边
    }
}
void dfs_reroot(int u, int p) {              // 第二遍：把根换到每个儿子
    for (int v : g[u]) {
        if (v == p) continue;
        // 从 u 换到 v：v 子树里的点少走一条边，其余点多走一条边
        ans[v] = ans[u] + n - 2 * sz[v];
        dfs_reroot(v, u);
    }
}
// 调用：dfs_down(1, 0); ans[1] = down[1]; dfs_reroot(1, 0);
```


## 树的直径

### 一句话

给你一棵 $n$ 个点的带权树（$n\le 10^5$），要你求出树上最长路径的长度，以及这条路径的两个端点。**时间 $O(n)$，空间 $O(n)$。**

### 原理


### 实现

```c++
int n;
vector<pair<int, int>> g[N];                 // {邻居, 边权}

// ---------- 带权树的直径：树形 DP，down[u] 是「从 u 往下走的最长路径」 ----------
ll down[N], diameter;
void dfs_diam(int u, int p) {
    down[u] = 0;
    for (auto [v, w] : g[u]) {
        if (v == p) continue;
        dfs_diam(v, u);
        diameter = max(diameter, down[u] + down[v] + w);   // 两条最长的下行路径拼起来
        down[u] = max(down[u], down[v] + w);
    }
}

```


### 应用


#### 直径的端点性质（两遍 DFS）
任取一点 $A$ 求最远点 $B$，再从 $B$ 求最远点 $C$，$BC$ 就是直径；无权时两遍 BFS 更省事。

```c++
// 无权树的两遍 BFS 求直径
int dist[N];
int bfs_far(int start, int n, int& far) {
    fill(dist + 1, dist + n + 1, -1);
    queue<int> q;
    dist[start] = 0, q.push(start), far = start;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        if (dist[u] > dist[far]) far = u;
        for (auto [v, w] : g[u]) if (dist[v] == -1) dist[v] = dist[u] + 1, q.push(v);
    }
    return dist[far];                        // 返回最远距离
}
// 调用：int a, b; bfs_far(1, n, a); int d = bfs_far(a, n, b);   // d 就是直径
```

## 树的重心

### 一句话

给你一棵 $n$ 个点的树，要你求出一个点，使删掉它之后剩下的最大连通块最小。**时间 $O(n)$，空间 $O(n)$。**

### 原理


### 实现

```c++
int n;                                       // 点数（建树时读入）
vector<pair<int, int>> g[N];                 // {邻居, 边权}

// ---------- 重心：最大的那块子树 <= n/2 ----------
int sz[N], centroid;
void dfs_centroid(int u, int p) {
    sz[u] = 1;
    int mx = 0;
    for (auto [v, w] : g[u]) {
        if (v == p) continue;
        dfs_centroid(v, u);
        sz[u] += sz[v];
        mx = max(mx, sz[v]);
    }
    mx = max(mx, n - sz[u]);                 // 换根之后「上面那一块」的大小
    if (mx * 2 <= n) centroid = u;           // 满足条件的就是重心（最多两个）
}
```

### 应用


#### 重心的性质与合并
两棵树用一条边连起来后，新重心一定在原来两个重心之间的路径上；从重心出发，每个子树大小不超过 $n/2$。

```c++
// 求所有重心（可能有两个）
vector<int> all_centroids(int root) {
    dfs_centroid(root, 0);
    vector<int> res{centroid};
    // 另一个重心通常是与它相邻的那个「大小为 n/2」的子树根
    return res;
}
// 重心使「所有点到它的距离之和」最小，也常用于点分治
```

## 树的中心

### 一句话

给你一棵 $n$ 个点的带权树，要你求出一个点，使它到最远点的距离最小。**时间 $O(n)$，空间 $O(n)$。**

### 原理


### 实现

> 说明：本模块的具体做法与代码见下面的「应用」一节。

### 应用


#### 树的中心
树的中心（到最远点距离最小的点）一定在**直径的中点**上：从直径端点跑一遍 BFS 记录前驱，回溯到中点即可。

```c++
int pre[N], dist2[N];
int tree_center(int a, int b, int n_) {       // a、b 是直径的两个端点
    fill(dist2 + 1, dist2 + n_ + 1, -1);
    queue<int> q;
    dist2[a] = 0, pre[a] = 0, q.push(a);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (auto [v, w] : g[u])
            if (dist2[v] == -1) dist2[v] = dist2[u] + 1, pre[v] = u, q.push(v);
    }
    int d = dist2[b], c = b;
    for (int i = 0; i < (d + 1) / 2; i++) c = pre[c];   // 回溯到直径中点
    return c;                                 // 另一个中心是 pre[c]
}
```

## 树上差分


### 一句话

给定一棵 $n$ 个点的树和 $m$ 条路径（$n,m\le 10^5$），要求统计每条边被多少条路径经过，或每个点被多少条路径经过。**时间 $O((n+m)\log n)$，空间 $O(n)$。**


### 原理


### 实现

（把路径的贡献拆到两个端点与 LCA 上，最后自底向上累加一次即可。）

```c++
int n;
vector<int> g[N];
int fa[N][20], dep[N];

void dfs_lca(int u, int p) {
    fa[u][0] = p, dep[u] = dep[p] + 1;
    for (int j = 1; j < 20; j++) fa[u][j] = fa[fa[u][j - 1]][j - 1];
    for (int v : g[u]) if (v != p) dfs_lca(v, u);
}
int lca(int u, int v) {
    if (dep[u] < dep[v]) swap(u, v);
    for (int j = 19; j >= 0; j--) if (dep[fa[u][j]] >= dep[v]) u = fa[u][j];
    if (u == v) return u;
    for (int j = 19; j >= 0; j--) if (fa[u][j] != fa[v][j]) u = fa[u][j], v = fa[v][j];
    return fa[u][0];
}
int diff[N], cnt[N];

// ---------- 边差分：路径 u-v 上每条边 +1 ----------
void add_edge_path(int u, int v) {
    int w = lca(u, v);
    diff[u]++, diff[v]++, diff[w] -= 2;      // LCA 处减 2
}
void push_up(int u, int p) {                 // 自底向上累加
    cnt[u] = diff[u];
    for (int v : g[u]) if (v != p) { push_up(v, u); cnt[u] += cnt[v]; }
    // 此时 cnt[u] 表示「u 到它父亲这条边」被经过的次数
}
```


### 应用


#### 点差分

路径上的**点**加一：两个端点 +1，LCA 与 LCA 的父亲各 −1，最后自底向上累加。

```c++
void add_vertex_path(int u, int v) {
    int w = lca(u, v);
    diff[u]++, diff[v]++, diff[w]--, diff[fa[w][0]]--;
}
// 累加完成后，cnt[u] 就是「点 u 被多少条路径经过」
```


#### 子树加、单点查

把树拍成 DFS 序后，子树是一段连续区间，「子树加」就是区间加、「单点查」就是单点求值，用差分数组 $O(1)$ 修改、$O(n)$ 还原。

```c++
int dfn[N], out[N], timer;
void dfs_dfn(int u, int p) {
    dfn[u] = ++timer;
    for (int v : g[u]) if (v != p) dfs_dfn(v, u);
    out[u] = timer;                          // 子树对应 [dfn[u], out[u]]
}
// 子树加：dif[dfn[u]] += x, dif[out[u] + 1] -= x
// 单点查：求 dif 的前缀和
```


#### 单点加、子树查

反过来：单点加就是差分数组上的一次区间修改，子树查就是求子树区间和，用树状数组即可。

```c++
// dfn 序上的树状数组
ll bit2[N];
void badd(int i, ll v) { for (; i <= n; i += i & -i) bit2[i] += v; }
ll bqry(int i) { ll r = 0; for (; i > 0; i -= i & -i) r += bit2[i]; return r; }
// 点 u 加 v：badd(dfn[u], v)
// 子树 u 的和：bqry(out[u]) - bqry(dfn[u] - 1)
```


## 树上倍增

### 一句话

给你一棵 $n$ 个点的树和 $q$ 次询问（$n,q\le 10^5$），每次问「从某个点往上跳 $k$ 步到哪个点」或者「路径上的最值与和」。**时间 $O(n\log n)$ 预处理、$O(\log n)$ 单次，空间 $O(n\log n)$。**

### 原理


### 实现

```c++
int n;
vector<int> g[N];
int fa[20][N], dep[N];

void dfs_lca(int u, int p) {
    fa[0][u] = p, dep[u] = dep[p] + 1;
    for (int j = 1; j < 20; j++) fa[j][u] = fa[j - 1][fa[j - 1][u]];
    for (int v : g[u]) if (v != p) dfs_lca(v, u);
}
```

### 应用


#### 维护路径上的最值 / 异或和
把「$u$ 到根的路径」上的信息用倍增表存下来，询问时拆成两段再合并。

```c++
int mx[20][N];                                // mx[j][u]：u 往上 2^j 步这段的最大值
void dfs_max(int u, int p, int w) {           // w 是 u 到父亲这条边的边权
    fa[0][u] = p, dep[u] = dep[p] + 1;
    mx[0][u] = w;
    for (int j = 1; j < 20; j++) {
        fa[j][u] = fa[j - 1][fa[j - 1][u]];
        mx[j][u] = max(mx[j - 1][u], mx[j - 1][fa[j - 1][u]]);
    }
    for (auto [v, ew] : gw[u]) if (v != p) dfs_max(v, u, ew);
}
int query_max_up(int u, int steps) {           // 从 u 往上走 steps 条边的最大边权
    int res = 0;
    for (int j = 0; j < 20; j++) if (steps >> j & 1) res = max(res, mx[j][u]), u = fa[j][u];
    return res;
}
// 路径最值 = max( u 到 lca、v 到 lca 这两段 )；异或和同理把 max 换成 ^
```

## 最近公共祖先（LCA）

### 一句话

给你一棵 $n$ 个点的树和 $q$ 次询问，每次给你两个点，问它们的最近公共祖先是谁、以及两点之间的距离。**时间 $O(n\log n)$ 预处理、$O(\log n)$ 单次（欧拉序 + ST 表可做到 $O(1)$），空间 $O(n\log n)$。**

### 原理


### 实现

```c++
int n;                                       // 点数
vector<int> g[N];
int fa[20][N], dep[N];                       // 倍增表与深度（建树时用 dfs 预处理）

int lca(int u, int v) {
    if (dep[u] < dep[v]) swap(u, v);
    int d = dep[u] - dep[v];
    for (int j = 0; j < 20; j++) if (d >> j & 1) u = fa[j][u];
    if (u == v) return u;
    for (int j = 19; j >= 0; j--)
        if (fa[j][u] != fa[j][v]) u = fa[j][u], v = fa[j][v];
    return fa[0][u];
}
```

### 应用


#### 两点距离
$\mathrm{dist}(u,v)=\mathrm{dep}(u)+\mathrm{dep}(v)-2\,\mathrm{dep}(\mathrm{lca}(u,v))$；注意这里 $\mathrm{dep}$ 从根开始数（根为 $1$）。

```c++
int dist_uv(int u, int v) {
    return dep[u] + dep[v] - 2 * dep[lca(u, v)];
}
```

#### O(1) LCA（欧拉序 + ST 表）
在欧拉序上，$\mathrm{lca}(u,v)$ 就是「$u$、$v$ 第一次出现位置之间」深度最小的那个点；用 ST 表维护区间最小值下标即可 $O(1)$ 查询。

```c++
int euler[2 * N], first[N], depth_e[2 * N], etot;
void dfs_euler(int u, int p, int d) {
    first[u] = ++etot, euler[etot] = u, depth_e[etot] = d;
    for (int v : g[u]) if (v != p) {
        dfs_euler(v, u, d + 1);
        euler[++etot] = u, depth_e[etot] = d;
    }
}
int lg_[2 * N], st[21][2 * N];
void build_lca_st() {
    lg_[1] = 0;
    for (int i = 2; i <= etot; i++) lg_[i] = lg_[i >> 1] + 1;
    for (int i = 1; i <= etot; i++) st[0][i] = i;
    for (int j = 1; (1 << j) <= etot; j++)
        for (int i = 1; i + (1 << j) - 1 <= etot; i++) {
            int a = st[j - 1][i], b = st[j - 1][i + (1 << (j - 1))];
            st[j][i] = (depth_e[a] < depth_e[b]) ? a : b;
        }
}
int lca_o1(int u, int v) {
    int l = first[u], r = first[v];
    if (l > r) swap(l, r);
    int j = lg_[r - l + 1];
    int a = st[j][l], b = st[j][r - (1 << j) + 1];
    return euler[(depth_e[a] < depth_e[b]) ? a : b];
}
```

#### 路径上第 $k$ 个点

把 $u\to v$ 的路径拆成「$u$ 到 LCA」和「LCA 到 $v$」两段，比较 $k$ 与上半段长度决定往哪边走。

```c++
int kth_on_path(int u, int v, int k) {       // k 从 1 开始
    int w = lca(u, v);
    int up = dep[u] - dep[w] + 1;            // u 到 LCA 这一段有几个点（含两端）
    if (k <= up) {
        int d = k - 1;                        // 从 u 往上走 d 步
        for (int j = 0; j < 20; j++) if (d >> j & 1) u = fa[j][u];
        return u;
    }
    int d = (dep[v] - dep[w]) - (k - up);     // 从 v 往上走这么多步
    for (int j = 0; j < 20; j++) if (d >> j & 1) v = fa[j][v];
    return v;
}
```

## 重链剖分

### 一句话

给你一棵 $n$ 个点的树和 $q$ 次操作，每次操作是「把一条路径上所有点的权值改成同一个值」或「询问一条路径上点权的最大值 / 和」，两种操作交替出现。**时间 $O(n)$ 预处理、单次 $O(\log^2 n)$，空间 $O(n)$。**

### 原理


### 实现

（重链剖分：两次 DFS 求出重儿子、链顶与 DFS 序；剖分后每条路径被拆成 $O(\log n)$ 条「DFS 序上的连续区间」。）

```c++
int n;
vector<int> g[N];
int fa[N], dep[N], sz[N], heavy[N];
int top[N], dfn[N], rnk[N], timer;
int a[N];                                    // 点权

void dfs1(int u, int p) {                    // 求重儿子
    fa[u] = p, dep[u] = dep[p] + 1, sz[u] = 1, heavy[u] = 0;
    for (int v : g[u]) {
        if (v == p) continue;
        dfs1(v, u);
        sz[u] += sz[v];
        if (sz[v] > sz[heavy[u]]) heavy[u] = v;
    }
}
void dfs2(int u, int t) {                    // 定链顶、给 DFS 序
    top[u] = t, dfn[u] = ++timer, rnk[timer] = u;
    if (heavy[u]) dfs2(heavy[u], t);         // 重儿子接着同一条链
    for (int v : g[u])
        if (v != fa[u] && v != heavy[u]) dfs2(v, v);   // 轻儿子开新链
}
// ---------- 线段树（区间最大值） ----------
int seg[N << 2];
void build(int o, int l, int r) {
    if (l == r) { seg[o] = a[rnk[l]]; return; }
    int mid = (l + r) >> 1;
    build(o << 1, l, mid), build(o << 1 | 1, mid + 1, r);
    seg[o] = max(seg[o << 1], seg[o << 1 | 1]);
}
void update(int o, int l, int r, int pos, int v) {
    if (l == r) { seg[o] = v; return; }
    int mid = (l + r) >> 1;
    if (pos <= mid) update(o << 1, l, mid, pos, v);
    else update(o << 1 | 1, mid + 1, r, pos, v);
    seg[o] = max(seg[o << 1], seg[o << 1 | 1]);
}
int query(int o, int l, int r, int ql, int qr) {
    if (qr < l || r < ql) return -0x3f3f3f3f;
    if (ql <= l && r <= qr) return seg[o];
    int mid = (l + r) >> 1;
    return max(query(o << 1, l, mid, ql, qr), query(o << 1 | 1, mid + 1, r, ql, qr));
}
// ---------- 路径查询 ----------
int path_max(int u, int v) {
    int res = -0x3f3f3f3f;
    while (top[u] != top[v]) {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        res = max(res, query(1, 1, n, dfn[top[u]], dfn[u]));
        u = fa[top[u]];
    }
    if (dep[u] > dep[v]) swap(u, v);
    return max(res, query(1, 1, n, dfn[u], dfn[v]));
}
```

### 应用


#### 路径赋值（区间覆盖）
把线段树换成「支持区间赋值的懒标记线段树」，$O(\log^2 n)$ 就能整段路径覆盖。

```c++
// 懒标记：tag[o] = -1 表示没有赋值，否则表示整段被赋成 tag[o]
void push_down(int o) {
    if (tag[o] == -1) return;
    seg[o << 1] = seg[o << 1 | 1] = tag[o << 1] = tag[o << 1 | 1] = tag[o];
    tag[o] = -1;
}
// 其余与普通线段树一致；路径上的操作照搬 path_max 的循环
```

#### 求 LCA（顺带）
轻重链剖分后求 LCA 只要不断地「把链顶更深的那个点跳到它父亲」，$O(\log n)$。

```c++
int lca_hld(int u, int v) {
    while (top[u] != top[v]) {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        u = fa[top[u]];
    }
    return dep[u] < dep[v] ? u : v;
}
```

### 一句话

给你一棵 $n$ 个点的树，要你支持「$O(1)$ 求出某个点的 $k$ 级祖先」，或者优化与深度有关的树形 DP。**时间 $O(n\log n)$ 预处理、$O(1)$ 单次，空间 $O(n)$。**

### 原理


### 实现

> 说明：本模块的具体做法与代码见下面的「应用」一节。

### 应用


#### 长链剖分（$O(1)$ 求 $k$ 级祖先、优化深度相关 DP）
按「子树内最深深度」定重儿子；求 $k$ 级祖先时先跳 $2^{\lfloor\log k\rfloor}$ 步再查表，$O(1)$；优化 DP 时每个点直接继承重儿子的数组（指针偏移），总空间 $O(n)$。

```c++
int son[N], len[N], *f[N], buf[N], *ptr = buf;
void dfs_long1(int u, int p) {                // len[u]：u 子树内最深的深度（从 u 数）
    len[u] = 1;
    for (int v : g[u]) {
        if (v == p) continue;
        dfs_long1(v, u);
        if (len[v] + 1 > len[u]) len[u] = len[v] + 1, son[u] = v;
    }
}
void dfs_long2(int u, int p) {                // f[u][d]：u 子树内深度为 d（相对 u）的点数
    f[u][0] = 1;
    if (son[u]) {
        f[son[u]] = f[u] + 1;                 // 重儿子直接复用父亲的数组，只偏移一格
        dfs_long2(son[u], u);
    }
    for (int v : g[u]) {
        if (v == p || v == son[u]) continue;
        f[v] = ptr, ptr += len[v];            // 轻儿子另开一段
        dfs_long2(v, u);
        for (int d = 1; d <= len[v]; d++) f[u][d] += f[v][d - 1];
    }
}
// 调用前：f[1] = ptr; ptr += len[1]; dfs_long2(1, 0);
// 总复杂度 O(n)：每个点只在它所在的链头被暴力合并一次
```

## 点分治

### 一句话

给你一棵 $n$ 个点的带权树（$n\le 10^5$），要你统计满足「两点距离恰好等于 / 不超过 $K$」的点对个数。**时间 $O(n\log n)$ 或 $O(n\log^2 n)$，空间 $O(n)$。**

### 原理


### 实现

（点分治：每次找出当前连通块的重心，统计过重心的路径，再递归到各个子树；每一层的总规模是 $O(n)$，共 $O(\log n)$ 层。另有「边分治」：每次取一条边把连通块分成两半，但要先把每个点的度数三度化（加虚点把度数降到 $3$），否则菊花图会把复杂度卡到 $O(n^2)$。）

```c++
int n, K;
vector<pair<int, int>> g[N];                 // {邻居, 边权}
bool removed[N];
int sz[N], mx[N], root;
int q[N], qn;                                // 当前连通块内的深度列表
ll ans;

void get_size(int u, int p) {
    sz[u] = 1;
    for (auto [v, w] : g[u]) if (v != p && !removed[v]) { get_size(v, u); sz[u] += sz[v]; }
}
void get_root(int u, int p, int tot) {
    mx[u] = tot - sz[u];
    for (auto [v, w] : g[u]) {
        if (v == p || removed[v]) continue;
        get_root(v, u, tot);
        mx[u] = max(mx[u], sz[v]);
    }
    if (mx[u] < mx[root]) root = u;
}
void get_depth(int u, int p, int d) {
    if (d > K) return;                       // 超过 K 就没必要再往下
    q[qn++] = d;
    for (auto [v, w] : g[u]) if (v != p && !removed[v]) get_depth(v, u, d + w);
}
// 统计「经过 u 且长度 <= K」的路径条数
ll count_through(int u, int extra) {
    qn = 0;
    get_depth(u, 0, extra);
    sort(q, q + qn);
    ll cnt = 0;
    for (int l = 0, r = qn - 1; l < r; ) {
        if (q[l] + q[r] <= K) cnt += r - l, l++;
        else r--;
    }
    return cnt;
}
void solve(int u) {
    get_size(u, 0);
    root = 0, mx[0] = n + 1;
    get_root(u, 0, sz[u]);
    ans += count_through(root, 0);
    removed[root] = true;
    for (auto [v, w] : g[root])
        if (!removed[v]) {
            ans -= count_through(v, w);       // 容斥掉「同一条子树内」的路径
            solve(v);
        }
}
```

### 应用


#### 排序 + 双指针统计
把一层里所有点的深度收集起来排序，再用双指针数「两端深度和不超过 $K$」的有序位置对；同一个子树内部的贡献先减去。单层 $O(n\log n)$。

```c++
ll count_pairs(int* q, int qn) {             // q 已经排好序
    ll cnt = 0;
    for (int l = 0, r = qn - 1; l < r; ) {
        if (q[l] + q[r] <= K) cnt += r - l, l++;   // q[l] 能和 q[l+1..r] 全部配对
        else r--;
    }
    return cnt;
}
// 在 solve() 里：ans += count_pairs(全层深度)；再对每个儿子 ans -= count_pairs(该子树深度)
```

#### 点分治 + 桶统计
把「距离恰好为 $d$ 的点数」装进桶，每加入一个点就查桶配对，单层 $O(n)$（不用排序）。

```c++
// 统计「长度恰好为 K」的路径条数（点分治 + 桶，单层 O(n)）
int cntK[N], mxd;                            // cntK[d]：已处理的子树里深度为 d 的点数

// 在 solve() 里：
//   cntK[0] = 1, mxd = 0;                    // 先放重心自己
//   for (auto [v, w] : g[root]) {
```

## 边分治

### 一句话

给你一棵 $n$ 个点的带权树，同样是统计满足距离条件的点对；当树退化成链或者度数很大时，点分治会变慢，这时改用边分治。**时间 $O(n\log n)$，空间 $O(n)$。**

### 原理


### 实现

（先把树「三度化」，保证每个点的度数不超过 $3$；再每次选一条「两侧大小最接近」的边把树分成两半，处理跨过这条边的路径，然后递归。）

```c++
// ---------- 第一步：三度化，让每个点至多 3 个邻居 ----------
vector<pair<int, ll>> eg[N];
int btot;                                     // 虚点编号从这里往上加
void make_binary(int u, int p) {              // 把 u 的儿子两两配对，中间插虚点
    vector<pair<int, ll>> ch;
    for (auto& e : eg[u]) if (e.first != p) ch.push_back(e);
    for (size_t i = 0; i + 1 < ch.size(); i += 2) {
        int v1 = ch[i].first, v2 = ch[i + 1].first;
        ll w1 = ch[i].second, w2 = ch[i + 1].second;
        int z = ++btot;                       // 新建虚点
        eg[u].push_back({z, 0});              // u 到虚点：边权 0
        eg[z].push_back({u, 0});
        eg[z].push_back({v1, w1});            // 虚点接到原来的两个儿子
        eg[v1].push_back({z, w1});
        eg[z].push_back({v2, w2});
        eg[v2].push_back({z, w2});
    }
    for (auto& e : ch) if (e.first != p) make_binary(e.first, u);
    // 注意：这里要先把 eg[u] 重建一遍（去掉原来的儿子边、换成经虚点的边）
}

// ---------- 第二步：边分治 ----------
int bsz[N];
bool bvis[N * 2];                             // 边是否已被删掉
void get_size(int u, int p) {
    bsz[u] = 1;
    for (int i = 0; i < (int)eg[u].size(); i++) {
        auto [v, w] = eg[u][i];
        if (v == p || bvis[i]) continue;
        get_size(v, u);
        bsz[u] += bsz[v];
    }
}
// 找「两侧大小最接近一半」的那条边（按有向边的下标标记被删的边）
void solve_edge(int u, int tot) {
    // 1) get_size(u, 0) 求出各子树大小
    // 2) 沿重的一侧往下走，直到子树大小 <= tot/2，此时父边就是中心边
    // 3) 对两条被分开的子树分别求点到根的距离、排序后双指针统计
    // 4) 标记这条边已删，递归两侧
}
// 复杂度 O(n log n)；树退化成链或度数很大时，点分治会退化而边分治不会。
// 代价是三度化会新建 O(n) 个虚点、O(n) 条边，所以数组要开 3 倍。
```

## 点分树（动态点分治）


### 一句话

给定一棵 $n$ 个点的带权树（$n\le 10^5$）和 $q\le 10^5$ 次操作，每次操作是「把某个点的权值改成新值」或「询问所有点到 $u$ 的距离乘以各自权值后的总和」，两种操作交替出现。**时间单次操作 $O(\log^2 n)$，空间 $O(n)$。**


### 原理


### 实现

（点分树：把点分治每层的重心按父子关系连起来，深度是 $O(\log n)$；改动一个点就沿点分树往上跳 $O(\log n)$ 个结点更新。）

```c++
int n;
vector<pair<int, int>> g[N];
int sz[N], mx[N], root;
bool removed[N];
int fa_dt[N];                                // 点分树上的父亲
ll distSum[N], distFa[N];                    // 到本层重心的距离和、到上层重心的距离和
ll cntSub[N];                                // 本层子树的点数（或权值和）

// ---------- 建点分树 ----------
void get_size(int u, int p) {
    sz[u] = 1;
    for (auto [v, w] : g[u]) if (v != p && !removed[v]) { get_size(v, u); sz[u] += sz[v]; }
}
void get_root(int u, int p, int tot) {
    mx[u] = tot - sz[u];
    for (auto [v, w] : g[u]) if (v != p && !removed[v]) { get_root(v, u, tot); mx[u] = max(mx[u], sz[v]); }
    if (mx[u] < mx[root]) root = u;
}
int build_dt(int u, int p) {                 // 返回 u 所在连通块的重心
    get_size(u, p);
    root = 0, mx[0] = n + 1;
    get_root(u, p, sz[u]);
    int c = root;
    removed[c] = true, fa_dt[c] = p;
    for (auto [v, w] : g[c])
        if (!removed[v]) {
            int sub = build_dt(v, c);        // 递归建子树，返回它的重心
            (void)sub;
        }
    return c;
}
// 需要一份 LCA 求树上距离（见「倍增与 LCA」一节）
int dist_uv(int u, int v) { return dep[u] + dep[v] - 2 * dep[lca(u, v)]; }

// ---------- 修改点 u 的权值，增量是 v ----------
void update(int u, ll v) {
    for (int x = u; x; x = fa_dt[x]) {
        ll d = dist_uv(u, x);
        distSum[x] += v * d, cntSub[x] += v;
        if (fa_dt[x]) distFa[x] += v * dist_uv(u, fa_dt[x]);
    }
}
// ---------- 询问「所有点到 u 的加权距离和」 ----------
ll query(int u) {
    ll res = 0;
    for (int x = u, pre = 0; x; pre = x, x = fa_dt[x]) {
        res += distSum[x] + cntSub[x] * dist_uv(u, x);
        if (pre) res -= distFa[pre] + cntSub[pre] * dist_uv(u, x);
    }
    return res;
}
```


### 应用


#### 沿点分树二分的「距离 $\le K$ 的点数」

把每个点 $x$ 在点分树里管辖的点的**距离**收集成一个有序数组，询问「离 $u$ 不超过 $K$ 的点数」时沿点分树跳，每层二分一次。$O(\log^2 n)$ 一次询问。

```c++
vector<ll> distList[N];                       // distList[x]：x 这一层所有点到 x 的距离（有序）
vector<ll> distListFa[N];                     // 到 fa_dt[x] 的距离（用于容斥）

int count_le(int u, ll K) {
    int res = 0;
    for (int x = u, pre = 0; x; pre = x, x = fa_dt[x]) {
        ll du = dist_uv(u, x);
        // 本层里「距离 x 不超过 K - du」的点数
        res += upper_bound(distList[x].begin(), distList[x].end(), K - du) - distList[x].begin();
        if (pre) {
            ll df = dist_uv(u, fa_dt[x]);
            res -= upper_bound(distListFa[pre].begin(), distListFa[pre].end(), K - df) - distListFa[pre].begin();
        }
    }
    return res;
}
// 建树时顺便把 distList 填好（每个重心遍历一次它管辖的连通块），总代价 O(n log n)
```


#### 动态「距离 $\le K$ 的点权和」

把「距离和」换成「按距离排序的树状数组」，就能回答带阈值的权值和；每层用距离二分把问题压到「前缀和」，再用容斥减掉重复。

```c++
vector<int> ds[N];                            // 本层所有点到本层重心的距离（有序）
vector<ll> bitv[N];                           // 与 ds 等长的树状数组，存权值和
vector<int> dsFa[N];                          // 到上一层重心的距离（用于容斥）
vector<ll> bitFa[N];

void bit_add(vector<ll>& b, int i, ll v) { for (; i < (int)b.size(); i += i & -i) b[i] += v; }
ll bit_sum(vector<ll>& b, int i) { ll r = 0; for (; i > 0; i -= i & -i) r += b[i]; return r; }

void change(int u, ll v) {                    // 点 u 的权值增加 v
    for (int x = u; x; x = fa_dt[x]) {
        int k = lower_bound(ds[x].begin(), ds[x].end(), dist_uv(u, x)) - ds[x].begin() + 1;
        bit_add(bitv[x], k, v);
        if (fa_dt[x]) {
            int k2 = lower_bound(dsFa[x].begin(), dsFa[x].end(), dist_uv(u, fa_dt[x])) - dsFa[x].begin() + 1;
            bit_add(bitFa[x], k2, v);
        }
    }
}
ll query(int u, ll K) {                       // 离 u 不超过 K 的点权和
    ll res = 0;
    for (int x = u, pre = 0; x; pre = x, x = fa_dt[x]) {
        int k = upper_bound(ds[x].begin(), ds[x].end(), K - dist_uv(u, x)) - ds[x].begin();
        res += bit_sum(bitv[x], k);
        if (pre) {                            // 减去上一棵子树里被重复计入的那部分
            int k2 = upper_bound(dsFa[pre].begin(), dsFa[pre].end(), K - dist_uv(u, x)) - dsFa[pre].begin();
            res -= bit_sum(bitFa[pre], k2);
        }
    }
    return res;
}
// 建点分树时顺便把 ds[x]、dsFa[x] 填好（每个重心遍历一次它管辖的连通块），总代价 O(n log n)
```


## DSU on tree（树上启发式合并）


### 一句话

给定一棵 $n$ 个点的树，每个点有一个颜色 $c_i$（$n\le 2\times10^5$），要求对每个点 $u$ 回答：以 $u$ 为根的子树里出现次数最多的那种颜色出现了多少次，以及子树里共有多少种不同的颜色。**时间 $O(n\log n)$，空间 $O(n)$。**


### 原理


### 实现

（每个点只保留重儿子的统计结果，轻儿子暴力重算；每个点最多被搬动 $O(\log n)$ 次。）

```c++
int n;
vector<int> g[N];
int col[N], sz[N], heavy[N];
int cnt[N], curMax, distinct;
int ansMax[N], ansDistinct[N];

void dfs_size(int u, int p) {
    sz[u] = 1, heavy[u] = 0;
    for (int v : g[u]) {
        if (v == p) continue;
        dfs_size(v, u);
        sz[u] += sz[v];
        if (sz[v] > sz[heavy[u]]) heavy[u] = v;
    }
}
// 一次性维护三个量：每种颜色的计数、最大计数、不同颜色数
// 注意 distinct 必须在「加」和「减」两条路径上都维护，否则轻子树会漏算
void add_subtree(int u, int p, int delta, int skip) {
    if (cnt[col[u]] == 0) distinct++;        // 这个颜色此前没出现过
    cnt[col[u]] += delta;
    if (cnt[col[u]] == 0) distinct--;        // 减完正好归零，颜色消失
    if (delta > 0) curMax = max(curMax, cnt[col[u]]);
    for (int v : g[u])
        if (v != p && v != skip) add_subtree(v, u, delta, skip);
}
void dfs_solve(int u, int p, bool keep) {
    for (int v : g[u])                       // 先算轻儿子，算完清空
        if (v != p && v != heavy[u]) dfs_solve(v, u, false);
    if (heavy[u]) dfs_solve(heavy[u], u, true);   // 重儿子保留结果
    for (int v : g[u])                       // 轻儿子暴力补进来
        if (v != p && v != heavy[u]) add_subtree(v, u, 1, 0);
    if (cnt[col[u]] == 0) distinct++;        // 最后把 u 自己加进去
    cnt[col[u]]++;
    curMax = max(curMax, cnt[col[u]]);
    ansMax[u] = curMax, ansDistinct[u] = distinct;
    if (!keep) {                             // 不用保留就整体撤销
        add_subtree(u, p, -1, 0);
        curMax = 0, distinct = 0;
    }
}
```


### 应用


#### 子树内「深度为 $d$ 的点数」

把颜色换成深度即可：$cnt[d]$ 记录深度为 $d$ 的点数；对每个 $u$ 求「子树内和 $u$ 距离恰好为 $k$ 的点数」就是 $cnt[dep_u+k]$。

```c++
int cntDep[N];
void add_dep(int u, int p, int delta, int skip) {
    cntDep[dep[u]] += delta;
    for (int v : g[u]) if (v != p && v != skip) add_dep(v, u, delta, skip);
}
// 其余流程与上面完全一样，只是把 col[u] 换成 dep[u]、去掉 distinct 的维护
// 若还想知道「深度为 d 的点数」的最大值，再维护一个 curMaxDep 即可
```


#### 子树内权值落在 $[L,R]$ 的点数（DSU + 树状数组）

把计数数组换成树状数组，加/删子树时就做单点加减，询问时区间求和。

```c++
int bval[N];                                 // 每个点的权值
ll bitwt[N];
int MAXV;                                    // 权值上界（BIT 的下标是权值，不是点数！）
void badd(int i, ll v) { for (; i <= MAXV; i += i & -i) bitwt[i] += v; }
ll bsum(int i) { ll r = 0; for (; i > 0; i -= i & -i) r += bitwt[i]; return r; }
void add_wt(int u, int p, int delta, int skip) {
    badd(bval[u], delta);
    for (int v : g[u]) if (v != p && v != skip) add_wt(v, u, delta, skip);
}
// dfs_solve 里：先处理重儿子并保留，再暴力加轻儿子，最后查
//   ans[u] = bsum(R) - bsum(L - 1);          // 子树内权值落在 [L, R] 的点数
```


## 虚树


### 一句话

给定一棵 $n$ 个点的树（$n\le 5\times10^5$）和 $q$ 组询问（所有组的关键点总数 $\le 5\times10^5$），每组询问给出若干关键点，要求只保留这些关键点，再补上它们之间两两的最近公共祖先，在这张缩小后的树上做树形 DP。**时间预处理 $O(n\log n)$ 后每组 $O(k\log k)$（$k$ 是该组关键点数），空间 $O(n\log n)$。**


### 原理


### 实现

（虚树：把关键点按 DFS 序排序，相邻两点求 LCA 后一起建一棵只含关键点与它们 LCA 的树；总点数 $O(\sum k)$。）

```c++
int n;
vector<int> g[N];
int fa[20][N], dep[N], dfn[N], out[N], timer;
vector<int> vt[N];                            // 虚树的邻接表
int stk[N], top;
vector<int> extra[N];                         // 记录每个虚点连出去的边，便于清空

void dfs_base(int u, int p) {
    fa[0][u] = p, dep[u] = dep[p] + 1, dfn[u] = ++timer;
    for (int j = 1; j < 20; j++) fa[j][u] = fa[j - 1][fa[j - 1][u]];
    for (int v : g[u]) if (v != p) dfs_base(v, u);
    out[u] = timer;
}
int lca(int u, int v) {
    if (dep[u] < dep[v]) swap(u, v);
    for (int j = 19; j >= 0; j--) if (dep[fa[j][u]] >= dep[v]) u = fa[j][u];
    if (u == v) return u;
    for (int j = 19; j >= 0; j--) if (fa[j][u] != fa[j][v]) u = fa[j][u], v = fa[j][v];
    return fa[0][u];
}
void build_vt(vector<int> key) {              // key 里是关键点
    sort(key.begin(), key.end(), [](int a, int b) { return dfn[a] < dfn[b]; });
    int m = key.size();
    for (int i = 0; i + 1 < m; i++) key.push_back(lca(key[i], key[i + 1]));
    sort(key.begin(), key.end(), [](int a, int b) { return dfn[a] < dfn[b]; });
    key.erase(unique(key.begin(), key.end()), key.end());
    top = 0;
    for (int u : key) {
        if (!top) { stk[++top] = u; continue; }
        int w = lca(u, stk[top]);
        while (top >= 2 && dep[stk[top - 1]] >= dep[w]) {
            vt[stk[top - 1]].push_back(stk[top]);
            extra[stk[top - 1]].push_back(stk[top]);
            top--;
        }
        if (stk[top] != w) {
            vt[w].push_back(stk[top]);
            extra[w].push_back(stk[top]);
            stk[top] = w;
        }
        stk[++top] = u;
    }
    while (top >= 2) {
        vt[stk[top - 1]].push_back(stk[top]);
        extra[stk[top - 1]].push_back(stk[top]);
        top--;
    }
}
void clear_vt() {                             // 只清空改动过的点
    for (int u = 1; u <= n; u++)
        for (int v : extra[u]) vt[u].clear();
    for (int u = 1; u <= n; u++) extra[u].clear();
}
```


### 应用


#### 树上「关键点」DP

虚树建好后，在虚树上跑普通的树形 DP；虚边上要补上「原树这条边上的信息」（例如边权是原树上两点距离）。

```c++
ll dp[N];
void vt_dp(int u) {                           // 在虚树上做树形 DP
    dp[u] = 0;
    for (int v : vt[u]) {
        vt_dp(v);
        // 这里用「原树上 u 到 v 的距离」当虚边的边权
        dp[u] += dp[v] + dist_uv(u, v);
    }
}
// dist_uv 用 dep 的差：dep[v] - dep[u]（因为 v 是 u 的子孙）
```


#### 虚树上的「最少删边使关键点互不连通」

经典用法：$f[u]$ 表示「$u$ 子树里的关键点已经互相隔开」的最小代价，分「$u$ 本身是不是关键点」两类转移。

```c++
bool isKey[N];
ll f[N], mnEdge[N];
void dp_cut(int u) {
    f[u] = 0;
    for (int v : vt[u]) {
        dp_cut(v);
        if (isKey[v]) f[u] += mnEdge[v];      // v 是关键点，只能把这条边断掉
        else f[u] += min(f[v], mnEdge[v]);    // 要么在 v 里解决，要么断掉这条边
    }
}
// mnEdge[v]：原树上 u 到 v 这条路径上的最小边权（用倍增预处理）
```


#### 清空虚树

虚树的结点是所有关键点加上它们的 LCA，共 $O(\sum k)$ 个；但**不能**每次 memset 整张表，要记录「这次动过哪些点」再逐个清空，或者用时间戳。

```c++
// ---------- 方案一：记录改动过的点 ----------
vector<int> touched;
void clear_vt() {
    for (int u : touched) vt[u].clear();
    touched.clear();
}
// build_vt 里每往 vt[u] 里加一条边，就 touched.push_back(u)（去重可以最后 un：unique）

// ---------- 方案二：时间戳（更省事） ----------
int tag[N], curTag;
vector<int> vt2[N];
void vt2_add(int u, int v) {
    if (tag[u] != curTag) tag[u] = curTag, vt2[u].clear();
    vt2[u].push_back(v);
}
// 每组询问开始前 ++curTag 即可，不需要清空
```


## 基环树


### 一句话

给定一张 $n$ 个点、$n$ 条边的连通无向图（$n\le 10^6$），要求求出图中相距最远的一对点之间的距离。**时间 $O(n)$，空间 $O(n)$。**


### 原理


### 实现

（先把环找出来：拓扑排序删掉所有度数为 $1$ 的点，剩下的就是环。）

```c++
int n;
vector<pair<int, int>> g[N];                 // {邻居, 边权}
vector<int> cyc;
int deg[N];
bool oncycle[N];

void find_cycle() {
    queue<int> q;
    for (int i = 1; i <= n; i++) {
        deg[i] = g[i].size();
        if (deg[i] == 1) q.push(i);
    }
    fill(oncycle + 1, oncycle + n + 1, true);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        oncycle[u] = false;
        for (auto [v, w] : g[u])
            if (oncycle[v] && --deg[v] == 1) q.push(v);
    }
    for (int i = 1; i <= n; i++) if (oncycle[i]) cyc.push_back(i);
}
```


### 应用


#### 环上 DP（断开环）

基环树的 DP 通常「先对每棵挂着的子树做树形 DP，再把环上的结果拼起来」；环上问题可以枚举「第一个点选 / 不选」断成两次链式 DP。

```c++
// 例：环上相邻的点不能同时选，求最大权独立集
ll dp[N][2], val[N];
ll solve_chain(vector<int>& c) {              // 链式：dp[i][0/1]
    ll r0 = 0, r1 = -4e18;
    for (int x : c) {
        ll n0 = max(r0, r1), n1 = r0 + val[x];
        r0 = n0, r1 = n1;
    }
    return max(r0, r1);
}
ll solve_cycle() {
    vector<int> a(cyc.begin(), cyc.end());
    ll best = solve_chain(a);                 // 情况一：第一个点不选
    ll keep = val[a[0]];
    val[a[0]] = -4e18;                        // 情况二：强制第一个点不选（等价于把它禁掉）
    best = max(best, solve_chain(a) + keep - keep);
    val[a[0]] = keep;
    return best;
}
// 更干净的做法是把环复制一遍、跑单调队列优化的 DP
```


#### 基环树直径

直径要么完全在某一棵子树里，要么跨过环上的两个点；后者要把环上的「挂子树的最深深度」排成一个环，求「两两之间距离 + 各自深度」的最大值。

```c++
ll down[N], subtreeDiam[N], answer;
void dfs_sub(int u, int p) {                  // 对每棵挂着的子树求深度与内部直径
    down[u] = 0;
    for (auto [v, w] : g[u]) {
        if (v == p || oncycle[v]) continue;   // 环上的边单独处理
        dfs_sub(v, u);
        answer = max(answer, down[u] + down[v] + w);
        down[u] = max(down[u], down[v] + w);
    }
}
// 环上的部分：把环拉成链（长度翻倍），对每个 i 求
//   max over j in (i-m, i) of ( down[cyc[j]] + distOnCycle(j, i) ) + down[cyc[i]]
// 用单调队列做到 O(m)
```


#### 不止一个环（基环森林）

$n$ 个点 $n$ 条边时可能不连通，每个连通块都是一棵基环树；一次拓扑排序能把所有连通块的环一起标出来，再按连通块分别处理。

```c++
int comp[N];
int label_components(int n) {                 // 返回连通块个数，comp[i] 是 i 的块号
    find_cycle();                            // 见上面，填好 oncycle[]
    fill(comp + 1, comp + n + 1, 0);
    int c = 0;
    for (int s = 1; s <= n; s++) {
        if (comp[s]) continue;
        ++c;
        vector<int> st{s};
        comp[s] = c;
        while (!st.empty()) {
            int u = st.back(); st.pop_back();
            for (auto [v, w] : g[u])
                if (!comp[v]) comp[v] = c, st.push_back(v);
        }
    }
    return c;
}
// 每个连通块内恰有一个环（n 个点 n 条边）；对每个块分别找环、环上 DP，再把各块的答案汇总
```


## 树哈希与 AHU 算法


### 一句话

给定两棵各 $n$ 个点的树（$n\le 10^5$），要求判断它们的结构是否完全相同——即忽略点的编号后，能否把一棵树的点与另一棵树的点一一对应起来，使边也一一对应。**时间 $O(n\log n)$，空间 $O(n)$。**


### 原理


### 实现

（有根树：把儿子的哈希值排序后滚动组合；无根树再对每个点求一次「以它为根」的哈希，取最小值当指纹。）

```c++
using ull = unsigned long long;
int n;
vector<int> g[N];
ull hsub[N], parHash[N], reroot[N];

// splitmix64：把任意 64 位整数打散成一个看起来随机的值
ull rnd(ull x) {
    x += 0x9e3779b97f4a7c15ULL;
    x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ULL;
    x = (x ^ (x >> 27)) * 0x94d049bb133111ebULL;
    return x ^ (x >> 31);
}
// 加法式哈希：h[u] = 1 + sum_{v 是 u 的儿子} rnd(h[v])
// 好处是「去掉一个儿子」只要做一次减法，换根时非常方便
void dfs_rooted(int u, int p) {
    ull h = 1;
    for (int v : g[u]) if (v != p) { dfs_rooted(v, u); h += rnd(hsub[v]); }
    hsub[u] = h;
}
// parHash[u]：整棵树去掉 u 的子树后，「父亲那一侧」作为一棵有根树（根是 u 的父亲）的哈希
// reroot[u]：整棵树以 u 为根时的哈希
void dfs_reroot(int u, int p) {
    ull total = 1;
    for (int v : g[u]) if (v != p) total += rnd(hsub[v]);
    if (p) total += rnd(parHash[u]);
    reroot[u] = total;
    for (int v : g[u]) {
        if (v == p) continue;
        parHash[v] = total - rnd(hsub[v]);    // 减掉 v 那一份就是「u 以 v 的视角看出去」的哈希
        dfs_reroot(v, u);
    }
}
// 无根树的指纹 = min over u of reroot[u]
```


### 应用


#### 判断两棵树是否同构

无根树的指纹 = 「所有点作为根时哈希的最小值」；两棵树的指纹相等则同构（碰撞概率可忽略）。

```c++
ull tree_fingerprint() {
    dfs_rooted(1, 0);                        // 以 1 为根算一遍子树哈希
    dfs_reroot(1, 0);                        // 换根求出 reroot[u]：以 u 为根的整树哈希
    ull best = ~0ULL;
    for (int i = 1; i <= n; i++) best = min(best, reroot[i]);
    return best;
}
// 两棵树各跑一次 tree_fingerprint()，相等就（几乎必然）同构
// 注意：调用前要先把 n、g 换成对应的那棵树
```


#### AHU 算法（同构的规范编号）

最直观的办法是把「儿子子树」的规范形式递归拼成一个字符串；AHU 则把它优化到 $O(n\log n)$（每轮用 map 把「儿子标签的多重集」映射成新标签）。

```c++
// ---------- 递归规范形式：简单直观，最坏 O(n^2)（链会退化） ----------
string canonical(int u, int p) {
    vector<string> ch;
    for (int v : g[u]) if (v != p) ch.push_back(canonical(v, u));
    sort(ch.begin(), ch.end());               // 排序消除儿子顺序
    string s = "(";
    for (string& t : ch) s += t;
    return s + ")";
}
// 两棵有根树同构 <=> canonical(root) 相等

// ---------- AHU：迭代 O(log n) 轮，每轮把「儿子标签序列」映射到新标签 ----------
vector<int> ahu(int root, int n) {
    vector<int> par(n + 1, 0), order;
    vector<int> st{root};
    par[root] = 0;
    while (!st.empty()) {                     // 先得到一棵「以 root 为根」的生成顺序
        int u = st.back(); st.pop_back();
        order.push_back(u);
        for (int v : g[u]) if (v != par[u]) { par[v] = u; st.push_back(v); }
    }
    vector<int> label(n + 1, 0), nl(n + 1, 0);
    int rounds = 0, cnt = 0;
    do {
        map<vector<int>, int> mp;
        cnt = 0;
        for (int i = (int)order.size() - 1; i >= 0; i--) {   // 从下往上
            int u = order[i];
            vector<int> key;
            for (int v : g[u]) if (v != par[u]) key.push_back(label[v]);
            sort(key.begin(), key.end());
            auto it = mp.find(key);
            if (it == mp.end()) it = mp.emplace(key, ++cnt).first;
            nl[u] = it->second;
        }
        label = nl;
    } while (++rounds <= 20 && cnt < n);      // 标签数不再增加就稳定了
    return label;
}
// 有根树同构比较：两棵树用同一个 mp 跑同一轮，根编号相同即同构
```


#### 多重集哈希 / 随机权

```c++
}
```
