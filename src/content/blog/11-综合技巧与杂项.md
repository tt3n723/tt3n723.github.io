## Erdős–Szekeres 定理与一维中位数

### 一句话

给你一个长度为 $n$ 的序列（$n\le 10^5$），要你求一个数 $x$，使 $\sum_i |a_i-x|$ 最小；或利用 Erdős–Szekeres 定理把二维偏序问题降到一维。**时间 $O(n\log n)$，空间 $O(n)$。**

### 原理


### 实现

任意长度 $(r-1)(s-1)+1$ 的序列必含长 $r$ 的上升或长 $s$ 的下降子序列；而 $\sum|a_i-x|$ 在 $x$ 取中位数时最小，后者可以 $O(n)$ 直接算。

```c++
ll median_cost(vector<ll> a) {
    int n = a.size();
    nth_element(a.begin(), a.begin() + n / 2, a.end());
    ll m = a[n / 2], s = 0;
    for (ll x : a) s += llabs(x - m);
    return s;
}
// 曼哈顿距离下 x、y 可以各取各的中位数：
//   ans = median_cost(xs) + median_cost(ys)
```

## 启发式合并

### 一句话

给你 $n$ 个集合（$n\le 10^5$），要你不断把两个集合合并、并随时查询合并后的信息（如最大值、不同元素个数）。**时间总计 $O(n\log n)$，空间 $O(n)$。**

### 原理


### 实现

（DSU on tree / 树上启发式合并：每个点只保留「重儿子」的统计结果，轻儿子暴力重算。）

```c++
int n, K;                                    // K：颜色种类数上限
vector<int> g[N];
int col[N], sz[N], heavy[N];
int cnt[N], curMax;
int ans[N];

void dfs_size(int u, int p) {                // 第一遍：求子树大小与重儿子
    sz[u] = 1, heavy[u] = 0;
    for (int v : g[u]) {
        if (v == p) continue;
        dfs_size(v, u);
        sz[u] += sz[v];
        if (sz[v] > sz[heavy[u]]) heavy[u] = v;
    }
}
// 把 u 的整棵子树加进 / 移出统计，skip 用来跳过一个儿子
void add_subtree(int u, int p, int delta, int skip) {
    cnt[col[u]] += delta;
    if (delta > 0) curMax = max(curMax, cnt[col[u]]);
    for (int v : g[u]) {
        if (v == p || v == skip) continue;
        add_subtree(v, u, delta, skip);
    }
}
void dfs_solve(int u, int p, bool keep) {
    for (int v : g[u])                       // 先算轻儿子，算完清空
        if (v != p && v != heavy[u]) dfs_solve(v, u, false);
    if (heavy[u]) dfs_solve(heavy[u], u, true);   // 重儿子保留结果
    for (int v : g[u])                       // 轻儿子暴力补进来
        if (v != p && v != heavy[u]) add_subtree(v, u, 1, 0);
    cnt[col[u]]++;                           // 再加上自己
    curMax = max(curMax, cnt[col[u]]);
    ans[u] = curMax;
    if (!keep) {                             // 不用保留就整体撤销
        add_subtree(u, p, -1, 0);
        curMax = 0;
    }
}
```

### 应用


#### 小并大（启发式合并集合）
每次把小的集合合并进大的，每个元素最多被搬 $O(\log n)$ 次，所以合并总代价 $O(n\log^2 n)$（集合本身还带一层内部查找）。

```c++
void merge_set(set<int>& a, set<int>& b) {
    if (a.size() < b.size()) swap(a, b);      // 保证 a 是大的
    for (int x : b) a.insert(x);
    b.clear();
}
// 一般配合 DSU 使用：把每个点自己的集合自底向上并起来
```

## 二进制分组

### 一句话

给你 $q$ 次「插入一个元素」和「查询整体信息」的操作（$q\le 10^5$），要求在线回答，或者对若干个静态块分别预处理后合并答案。**时间单次 $O(\log q)$，空间 $O(q\log q)$。**

### 原理


### 实现

把「在线插入」按二进制拆成 $O(\log n)$ 个块，每块大小是 $2$ 的幂；新插入就按进位合并，均摊每次 $O(\log n)$ 次重建。下面支持「插入数字 + 查询总体第 $k$ 小」。

```c++
vector<vector<int>> blocks;                   // 第 i 块大小是 2^i，块内有序
void bg_insert(int x) {
    vector<int> cur = {x};
    int i = 0;
    while (i < (int)blocks.size() && !blocks[i].empty()) {
        cur.insert(cur.end(), blocks[i].begin(), blocks[i].end());
        blocks[i].clear();
        i++;
    }
    sort(cur.begin(), cur.end());
    if (i == (int)blocks.size()) blocks.push_back(cur);
    else blocks[i] = cur;
}
int bg_kth(int k) {                           // 二分答案，数每块里 <= mid 的个数
    int lo = -1000000000, hi = 1000000000;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2, c = 0;
        for (auto& b : blocks) c += upper_bound(b.begin(), b.end(), mid) - b.begin();
        if (c >= k) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}
```

## 离线处理

### 一句话

给你一张有 $q$ 次询问的题（$q\le 10^5$），允许先把所有询问读进来再做（离线），要你按某种顺序处理它们以减少重复计算。**时间 $O((n+q)\log n)$，空间 $O(n+q)$。**

### 原理


### 实现

（CDQ 分治：按第一维排序后不再动它，递归时用第二维归并、第三维用树状数组统计。）

```c++
struct Node {
    int a, b, c, cnt, ans;                   // cnt：完全相同的三元组个数
};
vector<Node> p, tmp;
int K;                                       // 第三维取值范围

int bit[N];
void add(int i, int v) { for (; i <= K; i += i & -i) bit[i] += v; }
int qry(int i) { int r = 0; for (; i > 0; i -= i & -i) r += bit[i]; return r; }

bool cmpa(const Node& x, const Node& y) {
    if (x.a != y.a) return x.a < y.a;
    if (x.b != y.b) return x.b < y.b;
    return x.c < y.c;
}
void cdq(int l, int r) {
    if (l == r) return;
    int mid = (l + r) >> 1;
    cdq(l, mid), cdq(mid + 1, r);
    // 左半区间的 a 一定不大于右半区间，按 b 归并，用树状数组数 c
    int i = l, j = mid + 1, k = l;
    while (j <= r) {
        while (i <= mid && p[i].b <= p[j].b) add(p[i].c, p[i].cnt), tmp[k++] = p[i++];
        p[j].ans += qry(p[j].c);
        tmp[k++] = p[j++];
    }
    for (int t = l; t < i; t++) add(p[t].c, -p[t].cnt);   // 撤销，保持树状数组干净
    while (i <= mid) tmp[k++] = p[i++];
    for (int t = l; t <= r; t++) p[t] = tmp[t];
}
void solve3d() {
    sort(p.begin(), p.end(), cmpa);
    // 先合并完全相同的三元组
    int m = 0;
    for (size_t i = 0; i < p.size(); i++) {
        if (m && p[m - 1].a == p[i].a && p[m - 1].b == p[i].b && p[m - 1].c == p[i].c) p[m - 1].cnt++;
        else p[m] = p[i], p[m].cnt = 1, m++;
    }
    p.resize(m);
    cdq(0, m - 1);
    // 每个点的答案是 ans + cnt - 1（减掉自己）
}
```

### 应用


#### 二维偏序 / 逆序对
只有两维时不需要分治：把值离散化当第二维，从右往左扫，用树状数组问「已经出现过且比我小的有几个」，累加就是逆序对数。

```c++
int disc(vector<int>& v) {                    // 离散化到 1..K，返回 K
    vector<int> t = v;
    sort(t.begin(), t.end());
    t.erase(unique(t.begin(), t.end()), t.end());
    for (int& x : v) x = lower_bound(t.begin(), t.end(), x) - t.begin() + 1;
    return t.size();
}
ll inv_count(vector<int> v) {
    int n = v.size();
    K = disc(v);                              // 复用实现里的树状数组
    memset(bit, 0, sizeof(int) * (K + 2));
    ll res = 0;
    for (int i = n - 1; i >= 0; i--) {
        res += qry(v[i] - 1);                 // 已出现且严格小于自己的个数
        add(v[i], 1);
    }
    return res;
}
```

## 随机化技巧与随机化哈希

### 一句话

给你两棵树的括号序列或两个结构（$n\le 10^5$），要你判断它们是否同构；或者用随机权值把「判定」变成「比较哈希值」。**时间 $O(n\log n)$，空间 $O(n)$。**

### 原理


### 实现

（随机化哈希：给每个元素一个随机的 $64$ 位权值，集合的哈希取这些权值的异或和。）

```c++
using ull = unsigned long long;
mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());

ull w[N];
void init_hash(int m) {                      // 给每个元素一个随机权值
    for (int i = 1; i <= m; i++) w[i] = rng();
}
// 集合 S 的哈希：xor 上 S 中每个元素的权值
// 空集哈希为 0；增删元素都只要 xor 一次，天然可逆
ull set_hash(const vector<int>& S) {
    ull h = 0;
    for (int x : S) h ^= w[x];
    return h;
}
// 只增删一个元素时的增量维护
// h ^= w[x]   加入 x
// h ^= w[x]   删除 x（异或两次还原）

// 字符串哈希的随机基数：把 BASE 也随机化，避免被构造数据卡掉
ull random_base() { return (rng() | 1) % 1000000 + 131; }
```

### 应用


#### 树哈希与同构判定
有根树：把儿子的哈希值排序（消除顺序影响）后用多项式滚动组合。无根树再对每个点求一次「以它为根」的哈希，取最小值作为整棵树的指纹。

```c++
ull tree_hash[N];
vector<int> gh[N];
void dfs_tree_hash(int u, int p) {
    vector<ull> ch;
    for (int v : gh[u]) if (v != p) { dfs_tree_hash(v, u); ch.push_back(tree_hash[v]); }
    sort(ch.begin(), ch.end());              // 关键：先排序，消除儿子的顺序
    ull h = 1;
    for (ull x : ch) h = h * 1000003ULL + x + 1;
    tree_hash[u] = h;
}
// 判同构：两棵树分别求出「所有点作为根的哈希」的最小值，相等则同构
```

## 模拟退火与爬山

### 一句话

给你一个「状态空间很大、目标函数没有单调性」的最优化问题，要你在时限内找一个尽量好的解。**时间按迭代次数计 $O(T)$，空间 $O(1)$。**

### 原理


### 实现

从初始解出发不断小扰动，按温度决定是否接受更差的解。下面是「平面上找一个点使得到所有给定点的距离之和最小」。

```c++
int n2;
double px[N], py[N];
double cost_sa(double x, double y) {
    double s = 0;
    for (int i = 0; i < n2; i++) s += sqrt((x - px[i]) * (x - px[i]) + (y - py[i]) * (y - py[i]));
    return s;
}
double anneal() {
    uniform_real_distribution<double> ur(-1, 1);
    double x = 0, y = 0, T = 10000, cool = 0.997, best = cost_sa(x, y);
    while (T > 1e-8) {
        double nx = x + ur(rng) * T, ny = y + ur(rng) * T;
        double d = cost_sa(nx, ny) - cost_sa(x, y);
        if (d < 0 || exp(-d / T) > (double)(rng() % 1000000) / 1e6) x = nx, y = ny;
        best = min(best, cost_sa(x, y));
        T *= cool;
    }
    return best;
}
// 爬山就是「只接受更优」（去掉概率接受那一支），容易卡在局部最优
```

## 打表与找规律

### 一句话

给你一道看不出递推式的题，要你先写暴力跑出前若干项、观察规律或用 BM 拟合出线性递推，再求远处的项。**时间 $O(n)$ 打表 + $O(k^2\log n)$ 求项，空间 $O(n)$。**

### 原理


### 实现

小规模先暴力打表，再用 Berlekamp–Massey 恢复递推（见「线性代数与多项式」一章）；复杂度对了仍 TLE 就上快读、关同步、位运算代替取模。

```c++
namespace FastIO {
    const int SZ = 1 << 20;
    char buf[SZ];
    int len = 0, pos = 0;
    inline char gc() {
        if (pos == len) { len = fread(buf, 1, SZ, stdin), pos = 0; if (len <= 0) return 0; }
        return buf[pos++];
    }
    inline ll read() {
        ll x = 0; int f = 1; char c = gc();
        while (c && (c < '0' || c > '9')) { if (c == '-') f = -1; c = gc(); }
        while (c >= '0' && c <= '9') { x = x * 10 + (c - '0'); c = gc(); }
        return x * f;
    }
}
// 另一条路是打表：先写暴力跑出 n = 1..20 的答案，再用 BM 求线性递推，最后用 Kitamasa 求远处项
```

## 对拍与调试

### 一句话

给你一份自己写的解法和一份暴力，要你随机生成小数据、跑两边比答案，从而在交题之前把 bug 找出来。**时间每次 $O(\text{生成}+\text{两个解法})$，空间 $O(\text{数据规模})$。**

### 原理


### 实现

（三个程序：gen 随机造数据、brute 慢但对、mine 你要交的解法。用一个循环反复跑，第一次不同就停下来把数据留下。）

```bash
#!/bin/bash
# gen.cpp / brute.cpp / mine.cpp 各自编译成可执行文件
for i in $(seq 1 1000); do
    ./gen            > in.txt           # 生成一组小数据
    ./brute < in.txt > out1.txt         # 暴力
    ./mine  < in.txt > out2.txt         # 你的解法
    if ! diff -q out1.txt out2.txt >/dev/null; then
        echo "WA on test $i"; cat in.txt; break
    fi
done
echo done
```
```c++
// 对拍的三个关键点：
//   1. 数据要「小」——小数据才能被暴力跑完，也更容易复现 bug
//   2. 数据要「随机但覆盖边界」——除随机外，手动加几组 n=1、全相等、已经有序
//   3. 结论要「逐元素比」——不要只比总和，两个相反的错误可能互相抵消
mt19937 rng(time(0));
int rnd(int l, int r) { return (int)(rng() % (r - l + 1)) + l; }
```
