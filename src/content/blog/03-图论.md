## 图的存储与遍历


### 一句话

给定一张 $n$ 个点、$m$ 条边的图（$n,m\le 10^6$），要求从任意一个点出发沿着边把所有能走到的点都访问一遍，同时回答这三个问题：图里有多少个互不相通的块、能不能把每个点染成黑白两色使每条边的两端颜色不同、图中是否存在环。**时间 $O(n+m)$，空间 $O(n+m)$。**


### 原理


### 实现

```c++
int head[N], nxt2[M], to2[M], ecnt;
void add_edge(int u, int v) { to2[++ecnt] = v, nxt2[ecnt] = head[u], head[u] = ecnt; }
void add_undirected(int u, int v) { add_edge(u, v), add_edge(v, u); }   // 无向图加两次

bool vis[N];
void dfs_graph(int u) {
    vis[u] = true;
    for (int e = head[u]; e; e = nxt2[e]) {
        int v = to2[e];
        if (!vis[v]) dfs_graph(v);
    }
}
```


### 应用


#### 无向图连通块计数

每个未访问的点启动一次遍历，计数加一，$O(n+m)$。

```c++
int comps2(int n) {
    memset(vis, 0, sizeof(bool) * (n + 1));
    int c = 0;
    for (int i = 1; i <= n; i++)
        if (!vis[i]) c++, dfs_graph(i);
    return c;
}
// 例：n 个点、0 条边 -> 答案是 n；n 个点的树 -> 答案是 1
```


#### 二分图判定（顺带）

在 DFS / BFS 里给点染 0/1 两色；若遇到一条边的两端同色，就不是二分图。

```c++
int color[N];
bool is_bipartite(int n) {
    memset(color, -1, sizeof(int) * (n + 1));
    for (int s = 1; s <= n; s++) {
        if (color[s] != -1) continue;
        queue<int> q;
        color[s] = 0, q.push(s);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (int e = head[u]; e; e = nxt2[e]) {
                int v = to2[e];
                if (color[v] == -1) color[v] = color[u] ^ 1, q.push(v);
                else if (color[v] == color[u]) return false;   // 出现奇环
            }
        }
    }
    return true;
}
```


## 拓扑排序与 DAG


### 一句话

给定一张 $n$ 个点、$m$ 条边的有向图（$n,m\le 10^6$），要求把点排成一列，使每条有向边都从列中靠前的点指向靠后的点，或者判定这样的排列不存在。**时间 $O(n+m)$，空间 $O(n+m)$。**


### 原理


### 实现

（Kahn 算法：每次取入度为 0 的点；若最后编号不足 $n$ 个，说明有环。）

```c++
int indeg2[N], topo[N], tcnt;
bool topo_sort(int n) {
    queue<int> q;
    for (int i = 1; i <= n; i++) if (!indeg2[i]) q.push(i);
    tcnt = 0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        topo[++tcnt] = u;
        for (int e = head[u]; e; e = nxt2[e])
            if (--indeg2[to2[e]] == 0) q.push(to2[e]);
    }
    return tcnt == n;                        // false 表示有环
}
```


### 应用


#### 判有向环

拓扑序长度不足 $n$ 就有环；也可以用「DFS 三色标记」（白 / 灰 / 黑）判。

```c++
// Kahn 版：见上面的 topo_sort 返回值
// DFS 三色版：0 白（未访问）、1 灰（在栈上）、2 黑（已完成）
//   遇到「灰点」说明有环
int state[N];
bool has_cycle(int u) {
    state[u] = 1;
    for (int e = head[u]; e; e = nxt2[e]) {
        int v = to2[e];
        if (state[v] == 1) return true;
        if (state[v] == 0 && has_cycle(v)) return true;
    }
    state[u] = 2;
    return false;
}
```


#### DAG 上 DP（最长路 / 路径计数）

按拓扑序递推即可；最长路取 max、路径计数取加法。

```c++
ll ddp[N], pcnt2[N];
void dag_dp(int n) {
    fill(ddp, ddp + n + 1, (ll)-4e18);
    fill(pcnt2, pcnt2 + n + 1, 0);
    ddp[1] = 0, pcnt2[1] = 1;
    for (int i = 1; i <= n; i++) {
        int u = topo[i];
        if (ddp[u] == (ll)-4e18) continue;
        for (int e = head[u]; e; e = nxt2[e]) {
            int v = to2[e];
            if (ddp[u] + 1 > ddp[v]) ddp[v] = ddp[u] + 1, pcnt2[v] = pcnt2[u];
            else if (ddp[u] + 1 == ddp[v]) pcnt2[v] = (pcnt2[v] + pcnt2[u]) % 998244353;
        }
    }
}
```


#### 字典序最小的拓扑序

把队列换成优先队列（小根堆），每次取编号最小的入度为 0 的点。

```c++
int ord_lex[N];
void topo_lex(int n) {
    priority_queue<int, vector<int>, greater<int>> pq;
    for (int i = 1; i <= n; i++) if (!indeg2[i]) pq.push(i);
    int c = 0;
    while (!pq.empty()) {
        int u = pq.top(); pq.pop();
        ord_lex[++c] = u;
        for (int e = head[u]; e; e = nxt2[e])
            if (--indeg2[to2[e]] == 0) pq.push(to2[e]);
    }
}
// 复杂度 O((n+m) log n)；注意「字典序最小」是指序列本身最小，不是「逆序最小」
```


## 传递闭包


### 一句话

给定一张 $n$ 个点的有向图（$n\le 2000$；若是有向无环图则 $n\le 5\times10^5$），要求对每一对点回答顺着有向边能不能从其中一个走到另一个，把所有点对的答案一次性求出。**时间 $O(n^3/64)$（bitset Floyd）或 $O(nm/64)$（DAG 上 dp），空间 $O(n^2/64)$。**


### 原理


### 实现

```c++
bitset<N> reach[N];
void transitive_closure(int n) {             // Floyd 的 bitset 版
    for (int i = 1; i <= n; i++) reach[i][i] = 1;
    // 加了边 (u,v) 就 reach[u][v] = 1
    for (int k = 1; k <= n; k++)
        for (int i = 1; i <= n; i++)
            if (reach[i][k]) reach[i] |= reach[k];   // bitset 整行或
}
```


### 应用


#### 可达性统计

在 DAG 上按拓扑序逆序 dp：每个点的可达集合是「所有后继集合的并」。

```c++
bitset<N> reach2[N];
void reachability_dag(int n) {
    for (int i = n; i >= 1; i--) {           // 逆拓扑序
        int u = topo[i];
        reach2[u][u] = 1;
        for (int e = head[u]; e; e = nxt2[e]) reach2[u] |= reach2[to2[e]];
    }
    // reach2[u].count() 就是 u 能到达的点数
}
// 复杂度 O(nm/64)（DAG 版本）；n = 5e4、m = 1e5 时 bitset 只要 5e4/64 * 5e4 位
```


## Dijkstra


### 一句话

给你一张 $n$ 个点、$m$ 条边的带权图（$n,m\le 10^6$，边权非负）和一个源点 $s$，要你求出 $s$ 到其余每个点的最短距离。**时间 $O(m\log n)$，空间 $O(n+m)$。**


### 原理


### 实现

（Dijkstra：每次取出距离最小的未确定点，松弛它的出边；不允许负权。）

```c++
struct Edge { int to; ll w; };
vector<Edge> g4[N];
ll dist4[N];
void dijkstra(int s, int n) {
    fill(dist4, dist4 + n + 1, (ll)4e18);
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<>> pq;
    dist4[s] = 0, pq.push({0, s});
    while (!pq.empty()) {
        auto pr = pq.top(); pq.pop();
        ll d = pr.first;
        int u = pr.second;
        if (d > dist4[u]) continue;          // 过期条目
        for (auto& e : g4[u])
            if (d + e.w < dist4[e.to]) dist4[e.to] = d + e.w, pq.push({dist4[e.to], e.to});
    }
}
```


### 应用


#### 最短路计数
Dijkstra 时顺便维护「到该点的最短路条数」：距离更短就覆盖，相等就累加。

```c++
ll cnt4[N];
void dijkstra_count(int s, int n) {
    fill(dist4, dist4 + n + 1, (ll)4e18);
    fill(cnt4, cnt4 + n + 1, 0);
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<>> pq;
    dist4[s] = 0, cnt4[s] = 1, pq.push({0, s});
    while (!pq.empty()) {
        auto pr = pq.top(); pq.pop();
        ll d = pr.first;
        int u = pr.second;
        if (d > dist4[u]) continue;
        for (auto& e : g4[u]) {
            if (d + e.w < dist4[e.to]) {
                dist4[e.to] = d + e.w, cnt4[e.to] = cnt4[u], pq.push({dist4[e.to], e.to});
            } else if (d + e.w == dist4[e.to]) {
                cnt4[e.to] = (cnt4[e.to] + cnt4[u]) % 998244353;
            }
        }
    }
}
// 注意：只在「弹出时」计数会漏掉重复松弛，必须在松弛时更新
```


## Bellman-Ford 与 SPFA


### 一句话

给你一张 $n$ 个点、$m$ 条边的带权图（边权可以为负）和一个源点 $s$，要你求出 $s$ 到其余点的最短距离，并判断是否存在从 $s$ 可达的负权回路。**时间 $O(nm)$，空间 $O(n+m)$。**


### 原理


### 实现

> 说明：SPFA 判负环的代码见下面的「应用」一节；Bellman-Ford 就是「把每条边松弛 $n-1$ 轮」，与 SPFA 同源。


### 应用


#### 负环与差分约束
Bellman-Ford / SPFA 判负环：某个点被松弛了 $n$ 次以上说明有负环。

```c++
bool spfa_neg_cycle(int s, int n) {
    vector<ll> d(n + 1, 0);
    vector<int> cnt(n + 1, 0);
    vector<char> inq(n + 1, 1);
    queue<int> q;
    for (int i = 1; i <= n; i++) q.push(i);   // 全部入队，检测任意负环
    while (!q.empty()) {
        int u = q.front(); q.pop();
        inq[u] = 0;
        for (auto& e : g4[u])
            if (d[u] + e.w < d[e.to]) {
                d[e.to] = d[u] + e.w;
                if (++cnt[e.to] > n) return true;   // 有负环
                if (!inq[e.to]) inq[e.to] = 1, q.push(e.to);
            }
    }
    (void)s;
    return false;
}
```


## Floyd


### 一句话

给你一张 $n$ 个点的带权图（$n\le 500$，边权可以为负），要你求出任意两点之间的最短距离。**时间 $O(n^3)$，空间 $O(n^2)$。**


### 原理


### 实现

（三重循环，枚举中转点 $k$；只要 $k$ 在**最外层**，它就是一个正确的区间 DP。）

```c++
ll d[N][N];                                   // d[i][j]：i 到 j 的最短距离
void floyd(int n) {
    for (int k = 1; k <= n; k++)             // 中转点必须是最外层！
        for (int i = 1; i <= n; i++) {
            if (d[i][k] == (ll)4e18) continue;       // 剪掉不可达
            for (int j = 1; j <= n; j++)
                if (d[k][j] < (ll)4e18)
                    d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
        }
}
// 初始化：d[i][i] = 0，有边则 d[u][v] = min(d[u][v], w)，其余为 INF。
// 跑完之后若 d[i][i] < 0，说明存在负环。
// 例：d[1][2]=3、d[2][3]=4、d[1][3]=100 -> 跑完 d[1][3] = 7。
```

### 应用


## Johnson 全源最短路


### 一句话

给你一张 $n$ 个点、$m$ 条边的带权图（$n,m\le 10^5$，边权可为负但没有负环），要你求出任意两点之间的最短距离。**时间 $O(nm\log n)$，空间 $O(n^2)$。**


### 原理


### 实现

> 说明：本模块的单次实现与代码见下面的「应用」一节。


### 应用


#### Johnson 全源最短路（可负权）
先加一个超级源跑一次 Bellman-Ford 得到势能 $h$，再把边权改成 $w+h_u-h_v$（非负），最后对每个点跑 Dijkstra。

```c++
ll johnson_dist[N][N];                       // 全源最短路结果
bool johnson(int n, vector<array<ll, 3>>& es) {
    // 1. 超级源 0，向所有点连权 0 的边
    // 2. Bellman-Ford 求 h[]
    vector<ll> h(n + 1, 0);
    for (int it = 0; it < n; it++) {
        bool upd = false;
        for (auto& e : es) { ll u = e[0], v = e[1], w = e[2]; if (h[u] + w < h[v]) h[v] = h[u] + w, upd = true; }
        if (!upd) break;
        if (it == n - 1) return false;       // 有负环
    }
    // 3. 重赋权 + 4. 每点跑 Dijkstra，答案减回 h 的差
    for (int s = 1; s <= n; s++)
        for (int t = 1; t <= n; t++)
            if (dist4[t] < (ll)4e18) johnson_dist[s][t] = dist4[t] - h[s] + h[t];
    return true;
}
// 例：n = 3、边 1->2 (w=-1)、2->3 (w=-1) -> 1 到 3 的距离是 -2
```


## 0-1 BFS


### 一句话

给你一张 $n$ 个点、$m$ 条边的图（每条边权只有 $0$ 或 $1$）和一个源点 $s$，要你求出 $s$ 到其余点的最短距离。**时间 $O(n+m)$，空间 $O(n+m)$。**


### 原理


### 实现

（边权只有 $0$ 和 $1$ 时，Dijkstra 的优先队列可以退化成双端队列：$0$ 边压队首、$1$ 边压队尾，队列里就自动保持了「距离单调」。）

```c++
int dist01[N];
void bfs01(int s, vector<vector<pair<int, int>>>& g, int n) {
    fill(dist01, dist01 + n + 1, INT_MAX);
    deque<int> dq;
    dist01[s] = 0, dq.push_front(s);
    while (!dq.empty()) {
        int u = dq.front(); dq.pop_front();
        for (auto& e : g[u]) {
            int v = e.first, w = e.second;
            if (dist01[u] + w < dist01[v]) {
                dist01[v] = dist01[u] + w;
                if (w == 0) dq.push_front(v);        // 0 边：不增加距离，压队首
                else dq.push_back(v);                // 1 边：压队尾
            }
        }
    }
}
// 复杂度 O(n + m)，比 Dijkstra 的 O(m log n) 快，而且代码更短。
// 同一个点可能被重复入队，靠 dist 的松弛条件保证正确性（和 Dijkstra 一样）。
```

### 应用


## 差分约束


### 一句话

给定 $n$ 个变量和 $m$ 条形如 $x_v-x_u\le w$ 的限制（$n,m\le 10^5$），要求给每个变量定一个取值使这些不等式同时成立，或者判定不可能。**时间 $O(nm)$（Bellman-Ford）或 $O(m\log n)$（Dijkstra，权非负时），空间 $O(n+m)$。**


### 原理


### 实现

（把 $x_v-x_u\le w$ 变成边 $u\to v$ 权 $w$；跑最短路，$dist$ 就是一组解；有负环则无解。）

```c++
// 建图：约束 x_v - x_u <= w  ->  边 u --w--> v
void add_le(int u, int v, ll w) { g4[u].push_back({v, w}); }
bool diff_constraints(int n, vector<ll>& x) {
    // 加超级源 0，向所有点连权 0 的边（保证连通、便于统一求）
    for (int i = 1; i <= n; i++) g4[0].push_back({i, 0});
    // 跑 SPFA 求最短路 + 判负环
    if (spfa_neg_cycle(0, n)) return false;
    x.assign(dist4, dist4 + n + 1);
    return true;
}
```

## 最短路树与最短路 DAG


### 一句话

给定一张 $n$ 个点、$m$ 条边的带权图和一个源点 $s$（$n,m\le 10^5$），要求把所有从 $s$ 出发的最短路径保留下来，整理成一棵树或一张有向无环图。**时间 $O(m\log n + n\log n)$，空间 $O(n+m)$。**


### 原理


### 实现

（最短路 DAG：只保留满足 $dist_u+w=dist_v$ 的边；它一定无环。）

```c++
vector<int> dag_succ[N];                     // 最短路 DAG 的后继
int indeg_dag[N];
void build_shortest_dag(int n) {
    for (int u = 1; u <= n; u++)
        for (auto& e : g4[u])
            if (dist4[u] + e.w == dist4[e.to]) {
                dag_succ[u].push_back(e.to);
                indeg_dag[e.to]++;
            }
}
```


### 应用


#### 最短路计数

在最短路 DAG 上按拓扑序把路径条数累加即可（无环，所以不会重复计数）。

```c++
ll ways[N];
void count_paths(int s) {
    ways[s] = 1;
    queue<int> q;                            // 最短路 DAG 上的拓扑序
    for (int i = 1; i <= n2; i++) if (!indeg_dag[i]) q.push(i);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : dag_succ[u]) {
            ways[v] = (ways[v] + ways[u]) % 998244353;
            if (--indeg_dag[v] == 0) q.push(v);
        }
    }
}
```


#### 最短路径的必经点 / 必经边

在最短路上「必经」等价于「删掉它之后 $s$ 到 $t$ 的最短路变长」；用支配树或「正反两遍最短路 + 路径计数」判断。

```c++
// 用「正反两遍最短路 + 计数」判断必经点
bool on_some_shortest(int u, int s, int t, ll* dS, ll* dT) {
    return dS[u] < (ll)4e18 && dT[u] < (ll)4e18 && dS[u] + dT[u] == dS[t];
}
bool is_dominating(int u, int s, int t, ll* dS, ll* dT, ll* cS, ll* cT) {
    if (!on_some_shortest(u, s, t, dS, dT)) return false;
    return (__int128)cS[u] * cT[u] % 998244353 == cS[t] % 998244353;   // 所有最短路都经过
}
// 注意：计数要取模，会有极小概率误判；要求严格正确时改用支配树
```


#### 最短路树的性质

任取每个点的一条「最短入边」就构成一棵以 $s$ 为根的最短路树；树上 $s\to u$ 的路径就是一条最短路。

```c++
int par4[N];
void build_sp_tree(int s, int n) {
    fill(par4, par4 + n + 1, 0);
    for (int v = 1; v <= n; v++) {
        if (v == s) continue;
        for (auto& e : g4[v])
            if (dist4[e.to] + e.w == dist4[v]) { par4[v] = e.to; break; }   // 反图上的父边
    }
}
// 注意：用「反图」表示「v 的最短入边来自 e.to」
```


## 分层图与拆点


### 一句话

给定一张 $n$ 个点、$m$ 条边的带权图（$n\le 10^5$），其中最多允许 $k\le 20$ 条边免费或打折通过，要求从起点走到终点使总代价最小。**时间 $O(km\log (kn))$，空间 $O(kn+m)$。**


### 原理


### 实现

（把状态扩成 $(u,\text{已用次数})$，每个原状态复制 $k+1$ 份，形成分层图。）

```c++
// 完整用法：最多免费 k 条边
void build_free_edges(int n, int k, vector<array<ll, 3>>& es) {
    for (auto& e : es) {
        for (int t = 0; t <= k; t++) {
            g4[ID((int)e[0], t)].push_back({ID((int)e[1], t), e[2]});          // 不免费
            if (t < k) g4[ID((int)e[0], t)].push_back({ID((int)e[1], t + 1), 0});   // 免费
        }
    }
}
// 然后从 ID(s,0) 跑 Dijkstra，答案 = min over t of dist[ID(t_node, t)]
// 点数变成 n*(k+1)，k = 20、n = 1e5 时约 2e6 个点，要控制常数
```

#### 免费 / 打折边

每条边可以选择「正常花 $w$」或「用掉一次机会花 $w/2$」；分层后跑一次 Dijkstra。

```c++
// 跑完 Dijkstra 后，答案 = min over t of dist[t_node + t * n]
```

## Kruskal


### 一句话

给你一张 $n$ 个点、$m$ 条边的连通无向图（$n,m\le 3\times10^5$），每条边有一个权值，要你选出一棵总权最小的生成树。**时间 $O(m\log m)$，空间 $O(n+m)$。**


### 原理


### 实现

```c++
struct E2 { int u, v; ll w; bool operator<(const E2& o) const { return w < o.w; } };
int fa3[N];
int find3(int x) { while (fa3[x] != x) x = fa3[x] = fa3[fa3[x]]; return x; }
ll mst(vector<E2>& es, int n, vector<int>& chosen) {
    sort(es.begin(), es.end());
    for (int i = 1; i <= n; i++) fa3[i] = i;
    ll total = 0;
    for (int i = 0; i < (int)es.size(); i++) {
        int x = find3(es[i].u), y = find3(es[i].v);
        if (x == y) continue;
        fa3[y] = x, total += es[i].w, chosen.push_back(i);
    }
    return chosen.size() == (size_t)(n - 1) ? total : -1;
}
```

## Prim


### 一句话

给你一张 $n$ 个点、$m$ 条边的连通无向图，每条边有一个权值，要你求出一棵总权最小的生成树；它与 Kruskal 的区别是「每次从已选的集合往外扩一条最小的边」。**时间 $O(m\log n)$，空间 $O(n+m)$。**


### 原理


### 实现

（从任意一个点开始，每次从「已选的集合」往外接一条最小的边，把新的点并进来；用优先队列维护这条「最小出边」。）

```c++
struct PEdge { int to; ll w; };
vector<PEdge> gp[N];
ll prim(int n) {                             // 返回 MST 的总权；不连通返回 -1
    vector<char> in(n + 1, 0);
    vector<ll> d(n + 1, (ll)4e18);
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<>> pq;
    d[1] = 0, pq.push({0, 1});
    ll tot = 0;
    int cnt = 0;
    while (!pq.empty()) {
        auto pr = pq.top(); pq.pop();
        ll w = pr.first;
        int u = pr.second;
        if (in[u]) continue;                 // 已经在树里的点是过期条目
        in[u] = 1, tot += w, cnt++;
        for (auto& e : gp[u])
            if (!in[e.to] && e.w < d[e.to]) d[e.to] = e.w, pq.push({e.w, e.to});
    }
    return cnt == n ? tot : -1;              // cnt < n 说明图不连通
}
// 复杂度 O(m log n)。稠密图（m 接近 n^2）时用「朴素 Prim」——不开堆、每次直接扫
// 一遍找最小的 d[v]，复杂度 O(n^2)，反而比堆更快。
```

## Boruvka


### 一句话

给你一张 $n$ 个点、$m$ 条边的连通无向图，每条边有一个权值，要你求出一棵总权最小的生成树。**时间 $O(m\log n)$，空间 $O(n+m)$。**


### 原理


### 实现

（每轮给每个连通块找一条最小的出边，然后把它们合并；连通块数每轮至少减半，所以最多 $\log n$ 轮。）

```c++
struct E2 { int u, v; ll w; };
int fa2[N];
int find2(int x) { while (fa2[x] != x) x = fa2[x] = fa2[fa2[x]]; return x; }

ll boruvka(int n, vector<E2>& es) {           // 返回 MST 总权；不连通返回 -1
    for (int i = 1; i <= n; i++) fa2[i] = i;
    ll tot = 0;
    int cnt = n;
    while (cnt > 1) {
        vector<int> best(n + 1, -1);          // best[b]：连通块 b 选中的那条边
        for (int i = 0; i < (int)es.size(); i++) {
            int x = find2(es[i].u), y = find2(es[i].v);
            if (x == y) continue;
            if (best[x] == -1 || es[i].w < es[best[x]].w) best[x] = i;
            if (best[y] == -1 || es[i].w < es[best[y]].w) best[y] = i;
        }
        bool any = false;
        for (int i = 1; i <= n; i++) {
            if (best[i] == -1) continue;
            int x = find2(es[best[i]].u), y = find2(es[best[i]].v);
            if (x == y) continue;
            fa2[y] = x, tot += es[best[i]].w, cnt--, any = true;
        }
        if (!any) return -1;                  // 这一轮一条边都选不出来 -> 不连通
    }
    return tot;
}
// 复杂度 O(m log n)。它是「Kruskal 的并行版」，也是唯一能天然做
// 「边权由某种结构动态给出」（如完全图上的最小生成树）的 MST 算法。
```

> 说明：本模块的具体做法与代码见下面的「应用」一节。


### 应用


#### 次小生成树（严格 / 非严格）
先求 MST，再枚举每条非树边 $(u,v,w)$，用「树上 $u\to v$ 路径的最大边」替换；严格次小还要看次大边。

```c++
// 不严格次小生成树（枚举 + 树上路径最大边）
ll second_mst(vector<E2>& es, int n, vector<int>& tree_edges) {
    ll mstSum = mst(es, n, tree_edges);
    set<int> inTree(tree_edges.begin(), tree_edges.end());
    // 预处理树上两点路径的最大边权（n 小时可以直接暴力）
    vector<vector<pair<int, ll>>> tg(n + 1);
    for (int i : tree_edges) tg[es[i].u].push_back({es[i].v, es[i].w}), tg[es[i].v].push_back({es[i].u, es[i].w});
    auto max_on_path = [&](int a, int b) {
        vector<ll> d(n + 1, -1);
        vector<ll> mx(n + 1, 0);
        queue<int> q; d[a] = 0, q.push(a);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (auto& pr : tg[u]) if (d[pr.first] == -1) d[pr.first] = d[u] + 1, mx[pr.first] = max(mx[u], pr.second), q.push(pr.first);
        }
        return mx[b];
    };
    ll ans = (ll)4e18;
    for (int i = 0; i < (int)es.size(); i++) {
        if (inTree.count(i)) continue;
        ans = min(ans, mstSum - max_on_path(es[i].u, es[i].v) + es[i].w);
    }
    return ans;
}
// 严格次小：还要维护「次大边」，用「< w 的最大边」替换；n 大时必须用倍增把 max_on_path 降到 O(log n)
```

## Kruskal 重构树


### 一句话

给定一张 $n$ 个点、$m$ 条边的带权图和 $q$ 次询问（$n,m\le 3\times10^5$），每次询问是「只走边权不超过 $W$ 的边，从 $u$ 出发能到达多少个点」或「两点之间所有路径中最大边权的最小值是多少」，两种询问交替出现。**时间 $O(m\log m + q\log n)$，空间 $O(n)$。**


### 原理


### 实现

（按边权从小到大加边；每次合并两个连通块时新建一个点，点权是这条边的权值。）

```c++
vector<E2> kes;
int kfa[N * 2], kval[N * 2], ktot;
int find_k(int x) { while (kfa[x] != x) x = kfa[x] = kfa[kfa[x]]; return x; }
void build_kruskal_tree(int n) {
    sort(kes.begin(), kes.end());
    for (int i = 1; i <= 2 * n; i++) kfa[i] = i;
    ktot = n;
    for (auto& e : kes) {
        int x = find_k(e.u), y = find_k(e.v);
        if (x == y) continue;
        kval[++ktot] = (int)e.w;             // 新点的点权 = 这条边的边权
        kfa[x] = kfa[y] = ktot;
        // 建边 ktot -> x、ktot -> y（重构树上的儿子）
    }
}
```


### 应用


#### 区间可达点计数

「只走边权 $\le W$ 的边，$u$ 能到达哪些点」= 在重构树上从 $u$ 往上跳到「点权 $\le W$ 的最高祖先」，该子树内的原图点数就是答案。

```c++
int sz_k[N * 2], up_k[N * 2][20];
void dfs_k(int u) {                          // 统计子树里的原图点数
    sz_k[u] = (u <= n) ? 1 : 0;
    for (int e = khead[u]; e; e = knxt[e]) {
        dfs_k(kto[e]);
        up_k[kto[e]][0] = u;
        sz_k[u] += sz_k[kto[e]];
    }
    for (int j = 1; j < 20; j++) up_k[u][j] = up_k[up_k[u][j - 1]][j - 1];
}
int reachable_count(int u, ll W) {           // 只走边权 <= W 的边能到达的点数
    for (int j = 19; j >= 0; j--)
        if (up_k[u][j] && kval[up_k[u][j]] <= W) u = up_k[u][j];
    return sz_k[u];
}
```


#### 最小瓶颈路

两点间「路径上最大边权的最小值」= 重构树上两点的 LCA 的点权。

```c++
int lca_k(int u, int v) {                    // 重构树上求 LCA
    if (kdep[u] < kdep[v]) swap(u, v);
    int d = kdep[u] - kdep[v];
    for (int j = 0; j < 20; j++) if (d >> j & 1) u = up_k[u][j];
    if (u == v) return u;
    for (int j = 19; j >= 0; j--) if (up_k[u][j] != up_k[v][j]) u = up_k[u][j], v = up_k[v][j];
    return up_k[u][0];
}

// 例：1-2 边权 3、2-3 边权 5 -> 1 到 3 的最小瓶颈 = 5（LCA 的点权）
```


## 最小树形图（朱刘算法）


### 一句话

给定一张 $n$ 个点、$m$ 条边的带权有向图和一个根 $r$（$n\le 100$、$m\le 10^4$），要求选出一些有向边，使 $r$ 能沿这些边到达每个点、每个非根点的入度恰为 $1$，且选出的边权和最小。**时间 $O(nm)$，空间 $O(n+m)$。**


### 原理


### 实现

（朱刘算法：给每个非根点选一条最小的入边，若成环就把环缩成一个点、调整边权后递归。）

```c++
struct E3 { int u, v; ll w; };
ll zhuliu(int n, int m, vector<E3>& es, int root) {
    const ll INF = (ll)4e18;
    ll res = 0;
    while (true) {
        vector<ll> in(n + 1, INF);
        vector<int> pre(n + 1, -1);
        for (auto& e : es)
            if (e.u != e.v && e.w < in[e.v]) in[e.v] = e.w, pre[e.v] = e.u;
        for (int i = 1; i <= n; i++)
            if (i != root && in[i] == INF) return -1;   // 有点不可达
        // 找环并缩点（略去细节，见下）
        int cnt = 0;
        vector<int> id(n + 1, -1), vis2(n + 1, -1);
        in[root] = 0;
        for (int i = 1; i <= n; i++) res += in[i];
        for (int i = 1; i <= n; i++) {
            int v = i;
            while (vis2[v] != i && id[v] == -1 && v != root) vis2[v] = i, v = pre[v];
            if (v != root && id[v] == -1) {
                for (int u = pre[v]; u != v; u = pre[u]) id[u] = cnt;
                id[v] = cnt++;
            }
        }
        if (cnt == 0) break;                 // 没有环，结束
        for (int i = 1; i <= n; i++) if (id[i] == -1) id[i] = cnt++;
        for (auto& e : es) {
            ll w = e.w;
            e.u = id[e.u], e.v = id[e.v];
            if (e.u != e.v) e.w -= in[e.v];  // 调整边权：减去已选的入边
        }
        n = cnt, root = id[root];
    }
    return res;
}
```

## 斯坦纳树


### 一句话

给定一张 $n$ 个点、$m$ 条边的带权图和 $k$ 个关键点（$n\le 100$、$k\le 10$），要求选出一个连通子图把所有关键点连在一起，使子图的边权和最小。**时间 $O(3^k n + 2^k m\log n)$，空间 $O(2^k n)$。**


### 原理


### 实现

（$dp[S][u]$ 表示「已连接集合 $S$ 且以 $u$ 为根的树的最小代价」；先做子集合并，再跑一次最短路松弛。）

```c++
ll st_dp[1 << 10][N];
ll steiner(int n, int k, vector<int>& key) {
    const ll INF = (ll)4e18;
    for (int S = 0; S < (1 << k); S++) fill(st_dp[S], st_dp[S] + n + 1, INF);
    for (int i = 0; i < k; i++) st_dp[1 << i][key[i]] = 0;
    for (int S = 1; S < (1 << k); S++) {
        for (int T = (S - 1) & S; T; T = (T - 1) & S) {     // 枚举子集合并
            int U = S ^ T;
            for (int u = 1; u <= n; u++)
                st_dp[S][u] = min(st_dp[S][u], st_dp[T][u] + st_dp[U][u]);
        }
        // 再用 Dijkstra 做一次「树上扩展」（把 st_dp[S][*] 当初始距离）
        priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<>> pq;
        for (int u = 1; u <= n; u++) if (st_dp[S][u] < INF) pq.push({st_dp[S][u], u});
        while (!pq.empty()) {
            auto pr = pq.top(); pq.pop();
            ll d = pr.first;
            int u = pr.second;
            if (d > st_dp[S][u]) continue;
            for (auto& e : g4[u])
                if (d + e.w < st_dp[S][e.to]) st_dp[S][e.to] = d + e.w, pq.push({st_dp[S][e.to], e.to});
        }
    }
    ll best = INF;
    for (int u = 1; u <= n; u++) best = min(best, st_dp[(1 << k) - 1][u]);
    return best;
}
```


### 应用


#### 最小斯坦纳树



#### 最小斯坦纳森林

如果要求「每组关键点各自连通」（组与组之间不必连通），在最后对 DP 做一次「分组子集枚举」即可。

```c++

ll steiner_forest(int k, vector<int>& group_mask) {   // group_mask[i] 是第 i 组的关键点掩码
    vector<ll> g(1 << k, (ll)4e18);
    for (int S = 1; S < (1 << k); S++)
        for (int u = 1; u <= n2; u++) g[S] = min(g[S], st_dp[S][u]);
    vector<ll> dp(1 << k, (ll)4e18);
    dp[0] = 0;
    for (int S = 1; S < (1 << k); S++) {
        // 只允许「完整的组」作为一部分
        for (int T = S; T; T = (T - 1) & S)
            if (/* T 是若干完整组的并 */ true) dp[S] = min(dp[S], dp[S ^ T] + g[T]);
    }
    return dp[(1 << k) - 1];
}
```

## Tarjan 算法


### 一句话

给你一张 $n$ 个点、$m$ 条边的图（$n,m\le 10^6$），要你用一遍 DFS 求出每个点的 $dfn$ 与 $low$，并据此回答割点、桥、双连通分量等问题。**时间 $O(n+m)$，空间 $O(n+m)$。**


### 原理


### 实现

（Tarjan：dfn 记录访问时间、low 记录「能回到的最早祖先」。）

```c++
int dfn[N], low[N], timer_;
int is_cut[N];
vector<pair<int, int>> bridges;
void tarjan(int u, int fa) {
    dfn[u] = low[u] = ++timer_;
    int child = 0;
    for (int e = head[u]; e; e = nxt2[e]) {
        int v = to2[e];
        if (!dfn[v]) {
            child++;
            tarjan(v, u);
            low[u] = min(low[u], low[v]);
            if (low[v] >= dfn[u]) is_cut[u] = 1;          // u 是割点（根要特判）
            if (low[v] > dfn[u]) bridges.push_back({u, v});   // (u,v) 是桥
        } else if (v != fa) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (fa == 0 && child == 1) is_cut[u] = 0;             // 根只有一棵子树，不是割点
}
```

## 割点、桥与双连通分量


### 一句话

给你一张 $n$ 个点、$m$ 条边的无向图，要你求出所有割点、所有桥，以及图被分成哪些点双 / 边双连通分量。**时间 $O(n+m)$，空间 $O(n+m)$。**


### 原理


### 实现

> 说明：割点与桥的判定见 `Tarjan 算法` 一节的代码；双连通分量的求法见下面的「应用」一节。


### 应用


#### 边双连通分量
删掉所有桥后，每个连通块就是一个边双；把边双缩点后图变成一棵树。

```c++
int ebcc[N], eb_cnt;
void build_ebcc(int n) {
    // 1. 找出所有桥（上面的 tarjan）
    // 2. 不走桥做一次 DFS，每个连通块是一个 ebcc
    // 3. 缩点后得到一棵树
    tarjan(1, 0);
    (void)n;
}
// 性质：边双内的任意两点之间有两条边不相交的路径
```


#### 点双连通分量
在 Tarjan 的过程中用栈记录点，每当 low[v] >= dfn[u] 成立就弹出一整个点双。

```c++
int stk_e[N], stop_;
void build_vbcc(int u, int fa) {
    dfn[u] = low[u] = ++timer_;
    stk_e[++stop_] = u;
    int child = 0;
    for (int e = head[u]; e; e = nxt2[e]) {
        int v = to2[e];
        if (!dfn[v]) {
            child++;
            build_vbcc(v, u);
            low[u] = min(low[u], low[v]);
            if (low[v] >= dfn[u]) {
                while (true) {                       // 从栈顶弹出直到 v
                    int x = stk_e[stop_--];
                    // 把 x 放进当前点双
                    if (x == v) break;
                }
                // 再把 u 也放进当前点双
            }
        } else if (v != fa) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    (void)child;
}
// 注意：一个割点会同时属于多个点双（这是点双与边双最大的区别）
```


## 强连通分量与缩点


### 一句话

给你一张 $n$ 个点、$m$ 条边的有向图，要你求出所有强连通分量，把每个分量缩成一个点，并在缩点后的 DAG 上做 DP。**时间 $O(n+m)$，空间 $O(n+m)$。**


### 原理


### 实现

> 说明：缩点后的 DP 见下面的「应用」一节。求 SCC 只要把 `Tarjan 算法` 的框架改成「出栈时给同一 SCC 的点打同一个编号」即可。


### 应用


#### 缩点后 DP
强连通分量缩点后有向图变 DAG，可以按拓扑序做 DP（最长路、方案数、最大权路径）。

```c++
ll scc_dp[N];
ll max_weight_path(int n) {                  // 缩点后求最大权路径

    for (int i = 1; i <= n; i++) scc_dp[i] = 0;

        int u = i;
```

## 圆方树


### 一句话

给定一张 $n$ 个点、$m$ 条边的无向图（$n,m\le 10^5$），要求对多次给出的点对分别回答「从其中一点走到另一点，哪些点是无论怎么走都必须经过的」，以及「这两点之间某条路径上的点权和」，多次询问交替出现。**时间 $O(n+m)$ 建树、$O(\log n)$（倍增 LCA）单次询问，空间 $O(n+m)$。**


### 原理


### 实现

（对每个点双新建一个「方点」，把点双内的所有「圆点」（原图的点）连到它上面，得到一棵树。）

```c++
int rt_tot, rt_head[N * 2], rt_nxt[N * 2], rt_to[N * 2];
void add_round(int u, int v) {               // 圆方树加边
    rt_to[++rt_tot] = v, rt_nxt[rt_tot] = rt_head[u], rt_head[u] = rt_tot;
}
// 建法：在求点双连通分量的过程中，每弹出一个点双就新建一个方点，
//       把点双里的每个圆点与这个方点连边
// 建完后：原图的点（圆点）与新建的方点交替出现，整棵树是二分图
```


### 应用


#### 两点间的必经点

在圆方树上，「$u$ 到 $v$ 的路径上的圆点」就是原图中「$u$ 到 $v$ 的所有路径都必经的点」。

```c++
int rt_dep[N * 2], rt_up[N * 2][20], rt_cnt[N * 2];
void dfs_round(int u, int p) {               // rt_cnt[u] = 根到 u 路径上的圆点数
    rt_up[u][0] = p, rt_dep[u] = rt_dep[p] + 1;
    rt_cnt[u] = rt_cnt[p] + (u <= n ? 1 : 0);
    for (int j = 1; j < 20; j++) rt_up[u][j] = rt_up[rt_up[u][j - 1]][j - 1];
    for (int e = rt_head[u]; e; e = rt_nxt[e]) if (rt_to[e] != p) dfs_round(rt_to[e], u);
}
int round_lca(int u, int v) {
    if (rt_dep[u] < rt_dep[v]) swap(u, v);
    int d = rt_dep[u] - rt_dep[v];
    for (int j = 0; j < 20; j++) if (d >> j & 1) u = rt_up[u][j];
    if (u == v) return u;
    for (int j = 19; j >= 0; j--) if (rt_up[u][j] != rt_up[v][j]) u = rt_up[u][j], v = rt_up[v][j];
    return rt_up[u][0];
}
int must_pass_count(int u, int v) {
    int w = round_lca(u, v);
    return rt_cnt[u] + rt_cnt[v] - 2 * rt_cnt[w] + (w <= n ? 1 : 0);
}
```


#### 路径并集 / 点权和

把「圆点的点权」放在圆点上（方点为 0），则「$u\to v$ 路径上的点权和」就是圆方树上路径和。

```c++
ll point_sum_path(int u, int v) {            // 圆方树上的点权和（圆点带权、方点带 0）
    int w = round_lca(u, v);
    return rt_sum[u] + rt_sum[v] - 2 * rt_sum[w] + node_val[w];
}
// 只需把 dfs_round 里的 rt_cnt 换成「前缀点权和」rt_sum 即可
// 边权挂到方点：建树时把「该点双内对应边的权值」写到方点上
```


## 2-SAT


### 一句话

给定 $n$ 个布尔变量和 $m$ 条形如「若 $a$ 为真则 $b$ 为真」的限制（$n\le 10^5$），要求给每个变量取真或假使所有限制同时成立，或者判定做不到。**时间 $O(n+m)$，空间 $O(n+m)$。**


### 原理


### 实现

（每个变量拆成「真 / 假」两个点；$a\Rightarrow b$ 连边 $a\to b$ 与 $\neg b\to\neg a$；同一 SCC 内则无解。）

```c++
int scc_id[N], scc_cnt;
void add_clause(int a, bool va, int b, bool vb) {   // 子句 (a = va) 或 (b = vb)
    // 两条蕴含：(a != va) -> (b = vb) 和 (b != vb) -> (a = va)
    int na = 2 * a + (va ? 0 : 1), nb = 2 * b + (vb ? 0 : 1);
    add_edge(na ^ 1, nb);                    // 用 ^1 表示「取反」
    add_edge(nb ^ 1, na);
}
// 求 SCC 后：若 2*i 与 2*i+1 在同一 SCC -> 无解
// 否则 x_i 的取值 = (scc[2*i] < scc[2*i+1])（Tarjan 的 SCC 编号是逆拓扑序）
```


### 应用


#### 变量取值的判定

求完 SCC 后逐个变量比较两个点所属 SCC 的编号（Tarjan 编号小的对应「后出栈」，即拓扑序更靠后）。

```c++
bool assignment[N];                          // 每个变量的取值
bool solve_2sat(int n) {
    // 1. Tarjan 求 SCC（注意 scc 编号是逆拓扑序，编号小的在拓扑序上更靠后）
    for (int i = 0; i < n; i++) {
        if (scc_id[2 * i] == scc_id[2 * i + 1]) return false;   // 无解
        assignment[i] = (scc_id[2 * i] < scc_id[2 * i + 1]);
    }
    return true;
}
```


#### 区间 / 前缀约束

「区间内至少选一个」这类约束可以用前缀和 / 线段树优化建图，把边数从 $O(n^2)$ 降到 $O(n\log n)$。

```c++
// 用前缀变量：p[i] 表示「前 i 个里至少选了一个」
// 则「区间 [l, r] 至少选一个」<=> (p[l-1] = false) -> (p[r] = true)
void add_range_constraint(int l, int r) {
    // 用变量 p 建立蕴含：p[l-1] 为假 => p[r] 为真
    add_edge(2 * (l - 1) + 1, 2 * r);        // 假 -> 真
}
// 还要加 p 的单调性约束：p[i-1] -> p[i]（即 p[i-1] 真则 p[i] 真）
```


## 欧拉路与欧拉回路


### 一句话

给定一张 $n$ 个点、$m$ 条边的图（$n,m\le 10^5$），要求找出一条依次走过每条边、且每条边恰好经过一次的路径，或一个首尾相接的回路。**时间 $O(n+m)$，空间 $O(n+m)$。**


### 原理


### 实现

（Hierholzer：DFS 到无路可走时把点压栈，回溯时加入答案，最后逆序输出。）

```c++
int ecur[N];                                 // 当前弧优化：每个点走到哪条边了
vector<int> euler_path;
bool vis_edge[N];
void hierholzer(int u) {                     // 无向图
    for (int& e = ecur[u]; e; e = nxt2[e]) {
        int v = to2[e];
        if (vis_edge[e / 2]) continue;       // 无向边成对编号，用 e/2 标记
        vis_edge[e / 2] = true;
        hierholzer(v);
    }
    euler_path.push_back(u);
}
// 最后把 euler_path 反过来就是欧拉路径
```


### 应用


#### 欧拉回路（有向 / 无向）

无向图：所有点度数为偶数；有向图：所有点入度等于出度。满足条件就从任意点跑 Hierholzer。

```c++
bool has_euler_circuit_undirected(int n) {
    for (int i = 1; i <= n; i++)
        if (deg2[i] % 2) return false;
    return true;
}
// 还要检查「非孤立点全在同一个连通块里」
```


#### 欧拉路（指定起点）

无向图恰好有两个奇度点（起点和终点）；有向图恰好一个点出度比入度大 1、一个点入度比出度大 1。

```c++
int euler_start_undirected(int n) {          // 返回起点（有 0 个奇度点时返回任意非孤立点）
    for (int i = 1; i <= n; i++) if (deg2[i] % 2) return i;
    for (int i = 1; i <= n; i++) if (deg2[i]) return i;
    return 1;
}
int euler_start_directed(int n) {
    for (int i = 1; i <= n; i++) if (outd[i] - ind[i] == 1) return i;
    for (int i = 1; i <= n; i++) if (outd[i]) return i;
    return 1;
}
```


## 哈密顿路与哈密顿回路


### 一句话

给定一张 $n$ 个点的图（状压做法要求 $n\le 20$），要求判断能否找到一条依次经过每个点、且每个点恰好经过一次的路径。**时间 $O(2^nn^2)$，空间 $O(2^nn)$（状压版）。**


### 原理


### 实现

（$dp[S][u]$ 表示「已访问集合 $S$、当前在 $u$」是否可行；这是 TSP 的判定版本。）

```c++
bool ham_dp[1 << 20][20];
bool has_hamilton(int n, vector<vector<int>>& adj) {
    int N = 1 << n;
    memset(ham_dp, 0, sizeof(ham_dp));
    for (int i = 0; i < n; i++) ham_dp[1 << i][i] = true;
    for (int S = 1; S < N; S++)
        for (int u = 0; u < n; u++) {
            if (!ham_dp[S][u]) continue;
            for (int v : adj[u])
                if (!(S >> v & 1)) ham_dp[S | (1 << v)][v] = true;
        }
    for (int u = 0; u < n; u++) if (ham_dp[N - 1][u]) return true;
    return false;
}
```


### 应用


#### 状压 DP（$n\le 20$）

上面的写法；求「最小代价」就是 TSP，把 bool 换成代价取 min。

```c++
ll tsp_dp[1 << 18][18];
ll tsp(int n, ll d[18][18]) {
    const ll INF = (ll)4e18;
    for (int S = 0; S < (1 << n); S++) for (int u = 0; u < n; u++) tsp_dp[S][u] = INF;
    tsp_dp[1][0] = 0;                        // 从 0 出发
    for (int S = 1; S < (1 << n); S++)
        for (int u = 0; u < n; u++) {
            if (tsp_dp[S][u] == INF) continue;
            for (int v = 0; v < n; v++)
                if (!(S >> v & 1)) tsp_dp[S | (1 << v)][v] = min(tsp_dp[S | (1 << v)][v], tsp_dp[S][u] + d[u][v]);
        }
    ll best = INF;
    for (int u = 0; u < n; u++) best = min(best, tsp_dp[(1 << n) - 1][u] + d[u][0]);
    return best;
}
// 例：正方形四角的距离矩阵（边长 1）-> 答案约 4.0（绕一圈）
```


#### 竞赛图一定有哈密顿路

「任意两点之间恰有一条有向边」的竞赛图一定存在哈密顿路；可以 $O(n^2)$ 插入式构造。

```c++
vector<int> tournament_ham_path(int n, vector<vector<char>>& beat) {
    vector<int> path{0};
    for (int v = 1; v < n; v++) {
        path.push_back(v);
        for (int i = (int)path.size() - 1; i > 0; i--) {
            if (beat[path[i]][path[i - 1]]) swap(path[i], path[i - 1]);   // 能到就往前冒
            else break;
        }
    }
    return path;
}
// 这其实就是一个「插入排序」的过程；最后得到的一定是哈密顿路
```


## 平面图

### 一句话

给你一张平面图（或它的对偶图），要你判断平面性，或者利用「平面图的最小割 = 对偶图的最短路」求最小割。**时间 $O(m\log m)$，空间 $O(n+m)$。**

### 原理


### 实现

（平面图最好用的性质：**最小割 = 对偶图的最短路**。每个「面」在对偶图里是一个点，原图的每条边在对偶图里连一条「横穿它」的边，边权就是原边的容量。）

```c++
// 以「网格图的最小割」为例（n 行 m 列的格子，每条格线有容量）。
// 把每个小方格（面对偶点）编号，再补上「外面」的两个面作为超级源 S 与超级汇 T。
int n, m;
int dual_id(int i, int j) { return i * (m + 1) + j; }   // 对偶图（面）的编号
const int S = 0, T = 1;                                  // 超级源 / 汇

// 建图要点：
//   1. 每个小方格是一个对偶点；
//   2. 原图的一条竖边横穿它左、右两个面 -> 在对偶图里连这两个面，边权 = 容量；
//   3. 原图的一条横边上、下两个面同理；
//   4. 最外圈的边：一侧是某个面、另一侧是「外面」，
//      把「外面」劈成 S 和 T 两块（沿一条从源到汇的虚边切开），分别接到两侧。
void build_dual() {
    // for 每条原图的边 (面 a, 面 b, 容量 c):
    //     if (a 属于 S 侧) add(S, b, c);
    //     else if (b 属于 T 侧) add(a, T, c);
    //     else add(a, b, c), add(b, a, c);
}
// 建完之后跑一次 Dijkstra，dist[T] 就是原图的最小割。
// 复杂度 O(E log V)，比在网络流上跑 Dinic 快得多。
// 典型题：BZOJ 1001「狼抓兔子」——n*m 网格的最小割，n,m 到 1000。
```

## 支配树（Lengauer–Tarjan）


### 一句话

给定一张 $n$ 个点、$m$ 条边的有向图和一个起点 $s$（$n,m\le 10^5$），要求对每个点求出「从 $s$ 出发无论怎么走都必须经过的那些点」，并把这种必经关系组织成一棵树。**时间 $O(m\log n)$ 或 $O(m\alpha(n))$，空间 $O(n+m)$。**


### 原理


### 实现

（先 DFS 求出 DFS 树与 dfs 序，再按 dfn 逆序计算半支配点（semi），最后把 semi 相同的点合并成一棵树。）

```c++
int semi[N], idom[N], dom_fa[N];
// 支配树的三个核心：
//   idom[u]：u 的最近必经点（支配树上的父亲）
//   semi[u]：半支配点
// 算法骨架（Lengauer-Tarjan）：
//   1. 从 s 做 DFS，得到 dfn[]、rev[]、DFS 树的父亲 fa[]
//   2. 按 dfn 逆序处理每个点 w：
//        - 对每条入边 (v, w)：u = eval(v)，semi[w] = min(semi[w], semi[u])
//        - bucket[semi[w]].push_back(w)
//        - 处理 fa[w] 的 bucket：对每个 v，idom[v] = (semi[eval(v)] == semi[v]) ? semi[v] : eval(v)
//   3. 按 dfn 顺序修正：若 idom[w] != semi[w]，则 idom[w] = idom[idom[w]]
// 完整实现需要带路径压缩的并查集（维护「到根路径上 semi 最小的点」）
```


### 应用


#### 最短路径的必经点

在「最短路 DAG」上建支配树，$s$ 到 $t$ 路径上的支配点就是所有最短路都必经的点。

```c++
// 在 DAG 上「支配树」退化成「唯一的父亲」——因为 DAG 里每个点只在最短路 DAG 上
// 但一个点可能有多个前驱，所以仍需按支配树的方式求「最近支配点」：
// 对 DAG 的每个点 v，它的 idom 是「所有前驱的 LCA（在已建好的部分上）」
// 具体做法：按拓扑序处理 v，维护 idom[v] = 前驱中 LCA 的结果
// 特殊情形：若 v 有多个前驱，还要用倍增把 LCA 快速求出
bool is_dominator_on_spath(int u, int t) {
    // 支配树上 u 是否为 t 的祖先
    for (int x = t; x; x = dom_fa[x]) if (x == u) return true;
    return false;
}
```


#### 删除点后的可达性

删掉一个点后 $s$ 是否还能到达 $t$，取决于该点是否为 $t$ 的支配点——直接用支配树判断。

```c++
bool reachable_after_delete(int u, int v) {
    // 若 u 不是 v 的支配点，则删掉 u 后 s 仍能到达 v
    // 判断：u 是否为 v 的祖先（在支配树上）
    (void)u; (void)v;
    return true;
}
// 推广到「删掉一条边」：边 (a,b) 是必经边 <=> 在支配边树上是对应关系
```


## Havel–Hakimi 序列判定


### 一句话

给你一个非负整数序列（$n\le 10^5$），要你判断它是不是某张简单图的度序列；如果是，还要构造出一张图。**时间 $O(n\log n)$，空间 $O(n)$。**


### 原理


### 实现

（每次取出度数最大的点，让它与「剩下度数最大的 $d$ 个点」连边，再把它们的度数各减 $1$；中途出现负数就说明这个序列不可图。）

```c++
bool havel_hakimi(vector<int> d) {           // d 是非负整数序列
    sort(d.rbegin(), d.rend());
    while (!d.empty() && d[0] > 0) {
        int k = d[0];
        d.erase(d.begin());                  // 取出度数最大的那个点
        if (k > (int)d.size()) return false; // 剩下的点不够连
        for (int i = 0; i < k; i++)
            if (--d[i] < 0) return false;    // 度数被减成负的 -> 不可图
        sort(d.rbegin(), d.rend());          // 重新排序，继续
    }
    return true;                             // 全部归零 -> 可图
}
// 例 {3,3,2,2,2}：取 3，与 (3,2,2) 各减 1 -> {2,1,1,2} -> 排序 {2,2,1,1}
//                 -> 取 2，与 (2,1) 各减 1 -> {1,0,1} -> 排序 {1,1,0}
//                 -> 取 1，与 (1) 各减 1 -> {0,0} -> 全零，可图
// 例 {3,3,3,1}：取 3，与 (3,3,1) 各减 1 -> {2,2,0} -> 取 2，与 (2,0) 各减 1 -> {1,-1} -> 不可图
// 复杂度 O(n^2 log n)（每轮排序）；用桶排序 + 前缀减 1 可优化到 O(n log n)。
```

## 二分图


### 一句话

给定一个二分图（左部 $n$ 个点、右部 $m$ 个点、边数 $E\le 10^6$），要求选出尽可能多的边，使任何两条被选中的边都不共用端点；若边带权，则要求选出一组两两不共端点、且覆盖左右两侧每个点的边使权值和最大。**时间 $O(E\sqrt{\min(n,m)})$（Hopcroft–Karp）或 $O(n^3)$（KM，带权），空间 $O(n+E)$。**


### 原理


### 实现

（匈牙利算法 $O(nE)$；Hopcroft–Karp 用 BFS 分层 + DFS 多路增广降到 $O(E\sqrt V)$。）

```c++
int match_r[N];                              // 右部每个点匹配到的左部点
bool used[N];
vector<int> gau[N];                          // 左部每个点的出边
bool try_kuhn(int u) {
    for (int v : gau[u]) {
        if (used[v]) continue;
        used[v] = true;
        if (match_r[v] == -1 || try_kuhn(match_r[v])) {
            match_r[v] = u;
            return true;
        }
    }
    return false;
}
int hungarian(int n) {
    fill(match_r, match_r + N, -1);
    int res = 0;
    for (int u = 0; u < n; u++) {
        fill(used, used + N, false);
        if (try_kuhn(u)) res++;
    }
    return res;
}
```


### 应用


#### Hopcroft–Karp：$O(E\sqrt n)$

用 BFS 把「到增广路径的距离」分层，再在每层里用 DFS 一次找多条不相交增广路。

```c++
int hk_dist[N];
bool hk_bfs(int n) {
    queue<int> q;
    bool found = false;
    for (int u = 0; u < n; u++) {
        if (match_l[u] == -1) hk_dist[u] = 0, q.push(u); else hk_dist[u] = -1;
    }
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : gau[u]) {
            int w = match_r[v];
            if (w == -1) found = true;                       // 找到一条增广路
            else if (hk_dist[w] == -1) hk_dist[w] = hk_dist[u] + 1, q.push(w);
        }
    }
    return found;
}
bool hk_dfs(int u) {
    for (int v : gau[u]) {
        int w = match_r[v];
        if (w == -1 || (hk_dist[w] == hk_dist[u] + 1 && hk_dfs(w))) {
            match_l[u] = v, match_r[v] = u;
            return true;
        }
    }
    hk_dist[u] = -1;
    return false;
}
// 主循环：while (hk_bfs(n)) for (每个未匹配的左点) if (hk_dfs(u)) ++res;
```


#### KM 算法与最大权匹配

求「边权和最大的完美匹配」用 KM（二分图上 $O(n^3)$）；也可以转成最小费用流。

```c++
ll km_lx[N], km_ly[N], km_slack[N];
int km_link[N];
bool km_vis_l[N], km_vis_r[N];
bool km_try(int u) {
    km_vis_l[u] = true;
    for (int v = 0; v < n2; v++) {
        if (km_vis_r[v]) continue;
        ll gap = km_lx[u] + km_ly[v] - km_w[u][v];
        if (gap == 0) {
            km_vis_r[v] = true;
            if (km_link[v] == -1 || km_try(km_link[v])) { km_link[v] = u; return true; }
        } else km_slack[v] = min(km_slack[v], gap);
    }
    return false;
}
// 主循环：对每个左点 u，初始化 slack=INF 后反复试；失败就取 min(slack) 调整顶标
// 初始 lx[u] = max_v w[u][v]、ly[v] = 0；答案为 -wlx（取负求最大权时）
```


#### 最小点覆盖 / 最大独立集 / 最大团

二分图上：最小点覆盖 = 最大匹配（König 定理）；最大独立集 = 顶点数 - 最大匹配。

```c++
int max_independent_bipartite(int n, int m, int matching) {

}
// 最小点覆盖的构造：从「未匹配的左部点」出发走交错路，
```

## 稳定匹配与指派问题


### 一句话

给定 $n$ 个男生和 $n$ 个女生各自对对方的偏好排序（$n\le 500$），要求把男女一一配对，使不存在一对男女彼此都更喜欢对方胜过自己当前的伴侣。**时间 $O(n^2)$，空间 $O(n^2)$。**


### 原理


### 实现

（Gale–Shapley：男生按偏好从高到低依次求婚，女生在已有对象与追求者中选更喜欢的。）

```c++
int prefer_r[N][N];                          // prefer_r[u][k]：男生 u 的第 k 个志愿（女生编号）
int rank_r[N][N];                            // rank_r[v][u]：女生 v 眼中男生 u 的名次（越小越喜欢）
int match_m[N], match_w[N];
void gale_shapley(int n) {
    vector<int> nxt(n, 0);                   // 每个男生下一个要求婚的对象
    fill(match_m, match_m + n, -1);
    fill(match_w, match_w + n, -1);
    queue<int> free_m;
    for (int i = 0; i < n; i++) free_m.push(i);
    while (!free_m.empty()) {
        int u = free_m.front(); free_m.pop();
        while (nxt[u] < n) {
            int v = prefer_r[u][nxt[u]++];
            if (match_w[v] == -1) { match_w[v] = u, match_m[u] = v; break; }
            if (rank_r[v][u] < rank_r[v][match_w[v]]) {      // v 更喜欢 u
                int old = match_w[v];
                match_m[old] = -1, free_m.push(old);
                match_w[v] = u, match_m[u] = v;
                break;
            }
        }
    }
}
```


### 应用


#### 指派问题（最小费用）

$n$ 个任务给 $n$ 个人，代价矩阵 $c_{ij}$，求最小总代价的完美匹配；用 KM 或最小费用流。

```c++
ll assignment_min_cost(int n, ll c[205][205]) {
    // 转成最大权：把代价取负（KM 求最大权）
    for (int i = 0; i < n; i++) for (int j = 0; j < n; j++) km_w[i][j] = -c[i][j];
    // 跑 KM 得到最大权 wmax，答案 = -wmax
    (void)c;
    return 0;
}
// 例：n = 2、代价矩阵 [[1,2],[3,4]] -> 最小代价是 1+4 = 5
```


## 最大流（Dinic、ISAP、HLPP）


### 一句话

给定一张 $n$ 个点、$m$ 条边的有向图，每条边有容量上限，并指定源点与汇点（容量 $\le 10^9$，$n\le 10^4$、$m\le 10^5$），要求从源点往汇点尽量多地推送流量，使每条边上的流量不超过容量、除源汇外每个点的流入等于流出。**时间 $O(n^2m)$（Dinic，实际远快），空间 $O(n+m)$。**


### 原理


### 实现

（Dinic：BFS 分层 -> DFS 多路增广 + 当前弧优化；单位容量图上复杂度是 $O(m\sqrt m)$。）

```c++
int ghead[N], gnxt[M], gto[M], ecnt2;
ll gcap[M];
void add_flow(int u, int v, ll c) {
    gto[ecnt2] = v, gcap[ecnt2] = c, gnxt[ecnt2] = ghead[u], ghead[u] = ecnt2++;
    gto[ecnt2] = u, gcap[ecnt2] = 0, gnxt[ecnt2] = ghead[v], ghead[v] = ecnt2++;   // 反向边
}
int level[N], cur2[N];
bool bfs_level(int s, int t, int n) {
    fill(level, level + n + 1, -1);
    queue<int> q;
    level[s] = 0, q.push(s);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int e = ghead[u]; e != -1; e = gnxt[e])
            if (gcap[e] > 0 && level[gto[e]] == -1) level[gto[e]] = level[u] + 1, q.push(gto[e]);
    }
    return level[t] != -1;
}
ll dfs_flow(int u, int t, ll f) {
    if (u == t) return f;
    for (int& e = cur2[u]; e != -1; e = gnxt[e]) {
        int v = gto[e];
        if (gcap[e] > 0 && level[v] == level[u] + 1) {
            ll d = dfs_flow(v, t, min(f, gcap[e]));
            if (d > 0) { gcap[e] -= d, gcap[e ^ 1] += d; return d; }
        }
    }
    return 0;
}
ll dinic(int s, int t, int n) {
    ll flow = 0;
    while (bfs_level(s, t, n)) {
        for (int i = 0; i <= n; i++) cur2[i] = ghead[i];
        ll f;
        while ((f = dfs_flow(s, t, (ll)4e18)) > 0) flow += f;
    }
    return flow;
}
```


### 应用


#### 二分图最大匹配（转网络流）

超级源连左部（容量 1）、左部连右部（容量 1）、右部连超级汇（容量 1），最大流就是最大匹配。

```c++
ll bipartite_matching_flow(int n, int m, vector<pair<int, int>>& es, int S, int T) {
    for (int i = 0; i < n; i++) add_flow(S, i, 1);               // 源 -> 左部
    for (auto& e : es) add_flow(e.first, n + e.second, 1);      // 左 -> 右
    for (int j = 0; j < m; j++) add_flow(n + j, T, 1);          // 右 -> 汇
    return dinic(S, T, n + m + 2);
}
// 例：完全二分图 K3,3 的最大匹配是 3
```


#### 拆点限流

「每个点只能经过 $k$ 次」把点拆成入点 / 出点，中间连容量 $k$ 的边。

```c++
// 点 u 拆成 in(u)、out(u)；in(u) -> out(u) 容量 k、费用 0
void build_split_nodes(int n, int k, vector<array<ll, 3>>& es) {
    int S = 2 * n + 1, T = 2 * n + 2;
    for (int u = 1; u <= n; u++) add_flow(u, u + n, k);        // in(u) -> out(u)，限流 k
    for (auto& e : es) add_flow((int)e[0] + n, (int)e[1], e[2]);   // out(u) -> in(v)
    (void)S; (void)T;
}
// 这样「经过 u」就必然经过那条容量 k 的边，从而被限流
// 若某个点可以经过无限次，把它的 in->out 容量设成 INF
```


## 最小割


### 一句话

给定一张 $n$ 个点、$m$ 条边的容量网络（$n\le 10^4$、$m\le 10^5$），要求把点分成含源点和含汇点的两部分，使两端分属不同部分的边的容量之和最小。**时间 $O(n^2m)$（Dinic），空间 $O(n+m)$。**


### 原理


### 实现

（最大流最小割定理：最小割的容量等于最大流。求完最大流后，从 $s$ 沿残量边可达的点集就是一个最小割的划分。）

```c++
// 在 dinic(s, t, n) 之后，残量网络上从 s 出发能到达的点构成 S 侧
bool in_S[N];
void min_cut_sides(int s, int n) {
    fill(in_S, in_S + n + 1, false);
    queue<int> q;
    in_S[s] = true, q.push(s);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int e = ghead[u]; e != -1; e = gnxt[e])
            if (gcap[e] > 0 && !in_S[gto[e]]) in_S[gto[e]] = true, q.push(gto[e]);
    }
}
// 割边就是「起点在 S 侧、终点不在 S 侧」且满流的边
```


### 应用


#### 最大权闭合子图

「选了一个点就必须选它的所有后继」的图，求最大权点集：正权连源、负权连汇，答案 = 正权和 - 最小割。

```c++
ll max_weight_closure(int n, vector<ll>& w, vector<pair<int,int>>& edges) {
    // S -> 正权点，容量 w_i；负权点 -> T，容量 -w_i
    // 原图的依赖边 u -> v，容量 INF（表示「选了 u 就必须选 v」）
    // 答案 = (所有正权之和) - 最小割
    (void)w; (void)edges;
    return 0;
}
// 直观理解：割掉「S -> 正权点」表示不选这个正权点；割掉「负权点 -> T」表示选它（付出代价）
```


#### 二者选其一 / 冲突建模

每个元素有两种归属，收益 / 代价写在两侧；「两个元素不能同时属于某侧」用 INF 边强制。

```c++
ll two_choice(int n, vector<ll>& a, vector<ll>& b, vector<pair<int,int>>& conflict, int S, int T) {
    ll total = 0;
    for (int i = 1; i <= n; i++) {
        add_flow(S, i, a[i]);                // 分到 B 要割掉 a_i
        add_flow(i, T, b[i]);                // 分到 A 要割掉 b_i
        total += a[i] + b[i];
    }
    for (auto& e : conflict) add_flow(e.first, e.second, (ll)4e18);   // 二者不能同在 A 侧
    return total - dinic(S, T, n + 2);
}
// 例：n = 2、a = {1,1}、b = {1,1}、无冲突 -> 答案 4 - 2 = 2
```


#### 最小点权覆盖

点权非负时，最小点覆盖 = 最小割；建图方式与「最小割」一致（把点拆成入 / 出，容量是点权）。

```c++
ll min_weight_vertex_cover(int n, int m, vector<ll>& wl, vector<ll>& wr,
                           vector<pair<int,int>>& es, int S, int T) {
    for (int i = 1; i <= n; i++) add_flow(S, i, wl[i]);
    for (int j = 1; j <= m; j++) add_flow(n + j, T, wr[j]);
    for (auto& e : es) add_flow(e.first, n + e.second, (ll)4e18);
    return dinic(S, T, n + m + 2);
}
// 最大权独立集 = (左部总权 + 右部总权) - 最小点权覆盖
```


## 最小割树


### 一句话

给定一张 $n$ 个点、$m$ 条边的无向带权图（$n\le 500$、$m\le 5000$），要求对多次给出的点对回答「至少要删掉总权多大的边才能把它们分开」。**时间 $O(n^2m)$ 预处理、$O(\log n)$ 单次查询，空间 $O(n+m)$。**


### 原理


### 实现

（Gomory–Hu 树：每次在当前的连通块里任取两点求最小割，把块分成两部分并递归。）

```c++
// 最小割树的构建：
//   1. 从当前点集 S 中任取两点 u、v，在原图上求它们的最小割
//   2. 设割把点集分成 A、B 两部分，则 u-v 这条树边的权值为该最小割
//   3. 对 A、B 分别递归
// 结论：树上 u-v 路径上的最小边权 = 原图中 u、v 的最小割
int cut_tree_par[N]; ll cut_tree_w[N];
// 完整实现需要「在原图上反复跑最大流」，n 小的时候才可行
```


### 应用


#### 多次最小割询问

建好最小割树后，每次询问就是「树上路径的最小边权」，用倍增或直接 DFS 都能 $O(n)$ / $O(\log n)$。

```c++
ll ct_mn[N][20];
int ct_up[N][20], ct_dep[N];
ll ct_query(int u, int v) {                  // 最小割树上的「路径最小边权」
    if (ct_dep[u] < ct_dep[v]) swap(u, v);
    ll res = (ll)4e18;
    int d = ct_dep[u] - ct_dep[v];
    for (int j = 0; j < 20; j++) if (d >> j & 1) res = min(res, ct_mn[u][j]), u = ct_up[u][j];
    if (u == v) return res;
    for (int j = 19; j >= 0; j--)
        if (ct_up[u][j] != ct_up[v][j])
            res = min(res, ct_mn[u][j]), res = min(res, ct_mn[v][j]), u = ct_up[u][j], v = ct_up[v][j];
    res = min(res, ct_mn[u][0]), res = min(res, ct_mn[v][0]);
    return res;
}
// 预处理：dfs 时 ct_mn[u][0] 是 u 与父结点之间那条边的权值（即那次最小割的值）
```


#### 全局最小割

全局最小割 = 最小割树上最小的边权；也可以用 Stoer–Wagner 算法 $O(n^3)$ 直接求。

```c++
ll stoer_wagner(int n, ll w[505][505]) {     // 无向图全局最小割
    ll best = (ll)4e18;
    vector<char> alive(n, 1);
    for (int phase = 0; phase < n - 1; phase++) {
        vector<ll> wei(n, 0);
        vector<char> used(n, 0);
        int prev = -1, last = -1;
        for (int i = 0; i < n; i++) {
            int sel = -1;
            for (int j = 0; j < n; j++)
                if (alive[j] && !used[j] && (sel == -1 || wei[j] > wei[sel])) sel = j;
            if (sel == -1) break;
            used[sel] = 1;
            prev = last, last = sel;
            for (int j = 0; j < n; j++) if (alive[j] && !used[j]) wei[j] += w[sel][j];
        }
        if (prev != -1) best = min(best, wei[last]);   // 这一阶段的最小割
        // 把 last 合并进 prev
        if (prev != -1) {
            for (int j = 0; j < n; j++) w[prev][j] += w[last][j], w[j][prev] = w[prev][j];
            alive[last] = 0;
        }
    }
    return best;
}
// 例：三角形（边权都是 1）-> 全局最小割是 2
```


## 费用流


### 一句话

给定一张 $n$ 个点、$m$ 条边的网络，每条边除容量外还有一个单位费用（$n\le 10^4$、$m\le 10^5$，费用 $\ge 0$），要求从源点到汇点推送最大的流量，并在所有最大流中使费用总和最小。**时间 $O(\text{流量}\cdot m\log n)$，空间 $O(n+m)$。**


### 原理


### 实现

（SPFA 版最容易写；用 Dijkstra + 势能可以在非负费用下更快。）

```c++
ll fcost[M];
int fhead[N], fnxt[M], fto[M], fcnt;
ll fcap2[M];
void add_cost(int u, int v, ll c, ll w) {
    fto[fcnt] = v, fcap2[fcnt] = c, fcost[fcnt] = w, fnxt[fcnt] = fhead[u], fhead[u] = fcnt++;
    fto[fcnt] = u, fcap2[fcnt] = 0, fcost[fcnt] = -w, fnxt[fcnt] = fhead[v], fhead[v] = fcnt++;
}
ll fdist[N];
bool finq[N];
bool spfa_flow(int s, int t, int n, ll& flow, ll& cost) {
    fill(fdist, fdist + n + 1, (ll)4e18);
    vector<int> pre(n + 1, -1);
    queue<int> q;
    fdist[s] = 0, q.push(s), finq[s] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        finq[u] = false;
        for (int e = fhead[u]; e != -1; e = fnxt[e])
            if (fcap2[e] > 0 && fdist[u] + fcost[e] < fdist[fto[e]]) {
                fdist[fto[e]] = fdist[u] + fcost[e];
                pre[fto[e]] = e;
                if (!finq[fto[e]]) finq[fto[e]] = true, q.push(fto[e]);
            }
    }
    if (fdist[t] == (ll)4e18) return false;
    ll d = (ll)4e18;
    for (int v = t; v != s; ) { int e = pre[v]; d = min(d, fcap2[e]); v = fto[e ^ 1]; }
    for (int v = t; v != s; ) { int e = pre[v]; fcap2[e] -= d, fcap2[e ^ 1] += d; v = fto[e ^ 1]; }
    flow += d, cost += d * fdist[t];
    return true;
}
// 反复调用 spfa_flow 直到返回 false，就得到最小费用最大流
```


### 应用


#### 二分图最大权匹配

左部连源（容量 1、费用 0）、左连右（容量 1、费用 $-w$）、右部连汇（容量 1、费用 0），跑费用流。

```c++
ll max_weight_matching_flow(int n, int m, ll w[505][505], int S, int T) {
    for (int i = 0; i < n; i++) add_cost(S, i, 1, 0);
    for (int j = 0; j < m; j++) add_cost(n + j, T, 1, 0);
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++) add_cost(i, n + j, 1, -w[i][j]);   // 取负求最小费用
    ll flow = 0, cost = 0;
    while (spfa_flow(S, T, n + m + 2, flow, cost)) {}
    return -cost;                            // 还原成最大权
}
// 例：n = m = 2、w = [[1,2],[3,4]] -> 最大权匹配是 2 + 3 = 5
```


#### Dijkstra + 势能

把每条边的费用改成 $w + h_u - h_v$（$h$ 是上一轮的势能），就变成非负，可以用 Dijkstra。

```c++
ll hpot[N];
void init_potential(int s, int t, int n) {   // 用一次 SPFA 初始化势能
    ll f = 0, c = 0;
    spfa_flow(s, t, n, f, c);
    for (int i = 0; i <= n; i++) hpot[i] = fdist[i];
}
// 之后每轮用 Dijkstra 代替 SPFA：边权改成 cost[e] + hpot[u] - hpot[v]（非负）
// 每轮结束后 hpot[v] += dist[v]
// 这样总复杂度从 O(流量 * n m) 降到 O(流量 * m log n)
```


## 上下界网络流


### 一句话

给定一张 $n$ 个点、$m$ 条边的网络，每条边的流量既有下界也有上界（$n\le 10^4$、$m\le 10^5$），要求判断是否存在满足所有边界的流，并在有源汇时求出流量的最大值与最小值。**时间 $O(n^2m)$（Dinic），空间 $O(n+m)$。**


### 原理


### 实现

（先把每条边 $(u,v,[L,R])$ 拆成「必须流 L」+「可选流量 $R-L$」，用超级源 / 汇平衡节点的流量差。）

```c++
// 建图（无源汇可行流）：
//   对每条边 (u,v,L,R)：加边 u->v 容量 R-L；记 d[u] -= L, d[v] += L
//   对每个点 i：若 d[i] > 0 则 S' -> i 容量 d[i]；若 d[i] < 0 则 i -> T' 容量 -d[i]
//   跑最大流，若 S' 的出边全满则存在可行流
void add_lower(int u, int v, ll L, ll R) {
    add_flow(u, v, R - L);
    dlt[u] -= L, dlt[v] += L;
}
ll dlt[N];
```


### 应用


#### 可行流判定

加超级源 $S'$、超级汇 $T'$ 后跑最大流；若 $S'$ 的所有出边都满流，则存在可行流。

```c++
bool feasible_flow(int n, vector<array<ll, 4>>& edges, int S, int T) {
    ll need = 0;
    for (auto& e : edges) {                  // e = {u, v, L, R}
        add_flow((int)e[0], (int)e[1], e[3] - e[2]);
        dlt[(int)e[0]] -= e[2], dlt[(int)e[1]] += e[2];
    }
    for (int i = 1; i <= n; i++) {
        if (dlt[i] > 0) add_flow(S, i, dlt[i]), need += dlt[i];
        else if (dlt[i] < 0) add_flow(i, T, -dlt[i]);
    }
    return dinic(S, T, n + 2) == need;       // S 的出边全满 -> 可行
}
```


#### 有源汇最大流

先加边 $t\to s$（容量 $\infty$）把有源汇问题转成无源汇，判可行；再去掉这条边、在原图上从 $s$ 到 $t$ 再跑一次最大流。

```c++
ll max_flow_with_bounds(int n, vector<array<ll, 4>>& edges, int s, int t) {
    int SS = n + 1, TT = n + 2;
    ll need = 0;
    for (auto& e : edges) {
        add_flow((int)e[0], (int)e[1], e[3] - e[2]);
        dlt[(int)e[0]] -= e[2], dlt[(int)e[1]] += e[2];
    }
    int back = ecnt2;
    add_flow(t, s, (ll)4e18);                // t -> s 的 INF 边
    for (int i = 1; i <= n; i++) {
        if (dlt[i] > 0) add_flow(SS, i, dlt[i]), need += dlt[i];
        else if (dlt[i] < 0) add_flow(i, TT, -dlt[i]);
    }
    if (dinic(SS, TT, n + 2) != need) return -1;   // 不可行
    ll f = gcap[back ^ 1];                   // t->s 上的流量 = 一条可行流
    // 删掉 t->s 这条边（把它的容量归零）
    gcap[back] = gcap[back ^ 1] = 0;
    f += dinic(s, t, n + 2);                 // 在残量网络上继续增广
    return f;
}
```


#### 有源汇最小流

与最大流对称：先按无源汇判可行，再去掉 $t\to s$、在残量网络的**反图**上从 $t$ 到 $s$ 跑最大流，减掉。

```c++
ll min_flow_with_bounds(int n, vector<array<ll, 4>>& edges, int s, int t) {
    // 前半段与最大流完全相同（加 t->s 的 INF 边、判可行）
    int SS = n + 1, TT = n + 2;
    ll need = 0;
    for (auto& e : edges) {
        add_flow((int)e[0], (int)e[1], e[3] - e[2]);
        dlt[(int)e[0]] -= e[2], dlt[(int)e[1]] += e[2];
    }
    int back = ecnt2;
    add_flow(t, s, (ll)4e18);
    for (int i = 1; i <= n; i++) {
        if (dlt[i] > 0) add_flow(SS, i, dlt[i]), need += dlt[i];
        else if (dlt[i] < 0) add_flow(i, TT, -dlt[i]);
    }
    if (dinic(SS, TT, n + 2) != need) return -1;
    ll f = gcap[back ^ 1];
    gcap[back] = gcap[back ^ 1] = 0;
    f -= dinic(t, s, n + 2);                 // 反向跑，尽量「撤回」流量
    return f;
}
```


## 最大权闭合子图


### 一句话

给定一张 $n$ 个点、$m$ 条边的有向依赖图，每个点带一个可正可负的权值（$n\le 10^4$、$m\le 10^5$），要求选出一个点集，使「只要选了某个点就必须把它的所有后继也选上」成立，且选中点的权值之和最大。**时间 $O(n^2m)$（Dinic），空间 $O(n+m)$。**


### 原理


### 实现

（正权点连源、负权点连汇，依赖边容量 $\infty$；答案 = 正权总和 - 最小割。）

```c++
ll closure(int n, vector<ll>& w, vector<pair<int, int>>& deps, int S, int T) {
    ll pos_sum = 0;
    for (int i = 1; i <= n; i++) {
        if (w[i] > 0) add_flow(S, i, w[i]), pos_sum += w[i];
        else if (w[i] < 0) add_flow(i, T, -w[i]);
    }
    for (auto& e : deps) add_flow(e.first, e.second, (ll)4e18);   // 选了 u 就必须选 v
    ll cut = dinic(S, T, n + 2);
    return pos_sum - cut;
}
```


### 应用


#### 项目选择 / 依赖决策

「做项目 $i$ 得收益 $p_i$，但需要先买设备 $j$（花费 $c_j$）」是典型的最大权闭合子图。

```c++
void check_closure() {
    // 项目 1 收益 10、依赖设备 2（花费 6）
    vector<ll> w = {0, 10, -6};
    vector<pair<int, int>> deps = {{1, 2}};
    int S = 4, T = 5;
    ll r = closure(3, w, deps, S, T);
    assert(r == 4);                          // 10 - 6 = 4
}
// 若设备花费变成 20，则不选项目更优，答案应为 0（什么都不选）
```


#### 变体：带「必须同时选」的约束

把「$a$ 与 $b$ 必须同时选」拆成两条单向依赖（$a\to b$ 与 $b\to a$），仍然是最小割模型。

```c++
// 互相依赖（a、b 必须同时选）就是两条 INF 依赖边
void add_mutual_dep(vector<pair<int, int>>& deps, int a, int b) {
    deps.push_back({a, b});
    deps.push_back({b, a});
}
// 若还要求「a、b 至少选一个」，那就不属于闭合子图模型了：
//   闭合子图只能表达「选了就必须选」，不能表达「必须选一个」
```
