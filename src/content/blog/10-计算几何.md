## 向量、点积与叉积


### 一句话

给定平面上的点与向量（坐标绝对值 $\le 10^9$），要你对它们做点积、叉积、模长与模长平方、单位化、绕原点旋转和极角排序，这些运算会在后面的算法里被反复调用。**时间 $O(1)$ 每次，空间 $O(1)$。**


### 原理


### 实现

```c++
const double EPS = 1e-9;
int sgn(double x) { return x > EPS ? 1 : (x < -EPS ? -1 : 0); }

struct P {
    double x, y;
    P(double x = 0, double y = 0) : x(x), y(y) {}
    P operator+(const P& o) const { return {x + o.x, y + o.y}; }
    P operator-(const P& o) const { return {x - o.x, y - o.y}; }
    P operator*(double k) const { return {x * k, y * k}; }
    P operator/(double k) const { return {x / k, y / k}; }
    bool operator<(const P& o) const { return sgn(x - o.x) ? x < o.x : y < o.y; }
    bool operator==(const P& o) const { return sgn(x - o.x) == 0 && sgn(y - o.y) == 0; }
};
double dot(P a, P b) { return a.x * b.x + a.y * b.y; }
double cross(P a, P b) { return a.x * b.y - a.y * b.x; }
double len(P a) { return sqrt(dot(a, a)); }
double len2(P a) { return dot(a, a); }
P unit(P a) { return a / len(a); }
P rotate(P a, double t) { return {a.x * cos(t) - a.y * sin(t), a.x * sin(t) + a.y * cos(t)}; }
double angle(P a) { return atan2(a.y, a.x); }

// 整数版本：坐标是整数时全程用 __int128，完全避免精度问题
struct IP {
    ll x, y;
    IP(ll x = 0, ll y = 0) : x(x), y(y) {}
    IP operator-(const IP& o) const { return {x - o.x, y - o.y}; }
};
__int128 idot(IP a, IP b) { return (__int128)a.x * b.x + (__int128)a.y * b.y; }
__int128 icross(IP a, IP b) { return (__int128)a.x * b.y - (__int128)a.y * b.x; }
```


### 应用


#### 极角排序

按 atan2 排序最简单；要求严格无精度误差时，用「先按象限、再按叉积」的比较函数。

```c++
bool cmp_angle(const P& a, const P& b) {
    int qa = (a.y < 0 || (a.y == 0 && a.x < 0)), qb = (b.y < 0 || (b.y == 0 && b.x < 0));
    if (qa != qb) return qa < qb;            // 先把下半平面排前面
    return cross(a, b) > 0;                  // 同一象限内按叉积（逆时针）
}
// 用法：sort(p.begin(), p.end(), cmp_angle);
```


#### 向量旋转

逆时针转 $t$ 弧度用旋转矩阵；转 $90^\circ$ 可以直接写成 $(x,y)\to(-y,x)$，不用三角函数。

```c++
P rotate90(P a) { return {-a.y, a.x}; }      // 逆时针 90 度
P rotate180(P a) { return {-a.x, -a.y}; }    // 180 度
P rotate270(P a) { return {a.y, -a.x}; }     // 顺时针 90 度（= 逆时针 270 度）
```


#### 叉积的符号（左转 / 右转）

叉积大于 0 表示 $a\to b\to c$ 是逆时针（左转），小于 0 是右转，等于 0 三点共线。

```c++
int turn(P a, P b, P c) {                    // 1：左转，-1：右转，0：共线
    double t = cross(b - a, c - a);
    return sgn(t);
}
// 凸包、线段相交、点在多边形内——几乎所有判定最终都落到这个符号上
```


#### 浮点比较与去重

浮点点集的去重要用 sgn 判定「距离小于 eps」，不能直接比较坐标；整数点集可以直接排序去重。

```c++
void dedup(vector<P>& p) {
    sort(p.begin(), p.end());
    vector<P> r;
    for (auto& q : p)
        if (r.empty() || !(r.back() == q)) r.push_back(q);
    p = r;
}
// 整数点集直接 unique 即可：
//   sort(p.begin(), p.end()); p.erase(unique(p.begin(), p.end(), [](P a, P b){ return a.x == b.x && a.y == b.y; }), p.end());
```


## 线段相交判定


### 一句话

给定平面上的点与线段（整数坐标，绝对值 $\le 10^9$），要你判断一个点是否落在线段上、两条线段是否相交，并求出点到直线的距离与两条直线的交点，这些判定会交替出现。**时间 $O(1)$ 每次，空间 $O(1)$。**


### 原理


### 实现

（沿用上一节的 P 与 sgn / dot / cross。）

```c++
bool on_seg(P a, P b, P p) {
    // 先判共线；再用 dot(p-a, p-b) <= 0 说明 p 落在 a、b 之间（两个方向不「同侧」）
    return sgn(cross(b - a, p - a)) == 0 && sgn(dot(p - a, p - b)) <= 0;
}
double dist_line(P a, P b, P p) { return fabs(cross(b - a, p - a)) / len(b - a); }
double dist_seg(P a, P b, P p) {
    if (sgn(dot(p - a, b - a)) <= 0) return len(p - a);
    if (sgn(dot(p - b, a - b)) <= 0) return len(p - b);
    return dist_line(a, b, p);
}
P line_inter(P a, P b, P c, P d) {           // 直线 ab 与 cd，保证不平行
    double s1 = cross(b - a, c - a), s2 = cross(b - a, d - a);
    double t = s1 / (s1 - s2);
    return c + (d - c) * t;
}
bool seg_inter(P a, P b, P c, P d) {         // 含端点、含共线
    if (sgn(cross(b - a, c - a)) == 0 && sgn(cross(b - a, d - a)) == 0)
        return on_seg(a, b, c) || on_seg(a, b, d) || on_seg(c, d, a) || on_seg(c, d, b);
    double d1 = cross(b - a, c - a), d2 = cross(b - a, d - a);
    double d3 = cross(d - c, a - c), d4 = cross(d - c, b - c);
    return sgn(d1) * sgn(d2) <= 0 && sgn(d3) * sgn(d4) <= 0;
}
```


### 应用


#### 跨立实验

两个叉积符号相反（或其中一个为 0）表示 c、d 在直线 ab 的两侧；两个跨立条件同时满足才相交。

```c++
bool straddle(P a, P b, P c, P d) {
    double d1 = cross(b - a, c - a), d2 = cross(b - a, d - a);
    double d3 = cross(d - c, a - c), d4 = cross(d - c, b - c);
    return sgn(d1) * sgn(d2) <= 0 && sgn(d3) * sgn(d4) <= 0;
}
// 注意这只判「所在直线相交」；两条线段还要加上坐标范围的重叠判断
```


#### 直线与线段的交点

先判断线段的两个端点是否在直线两侧（叉积异号），再套 line_inter。

```c++
bool seg_line_intersect(P a, P b, P p, P q, P& res) {
    double d1 = cross(q - p, a - p), d2 = cross(q - p, b - p);
    if (sgn(d1) * sgn(d2) > 0) return false; // 同侧，不相交
    res = line_inter(p, q, a, b);
    return true;
}
```


#### 共线判定

三点共线就是叉积为 0；再用点积确认「落在两个端点之间」才能判断点在线段上。

```c++
bool collinear(P a, P b, P c) { return sgn(cross(b - a, c - a)) == 0; }
// 共线之后：dot(p-a, p-b) <= 0 说明 p 在 a、b 之间
```


#### 整数几何版

坐标都是整数时，把所有判定改成 __int128 的叉积比较，完全避开浮点。

```c++
bool on_seg_i(IP a, IP b, IP p) {
    return icross(b - a, p - a) == 0 && idot(a - p, b - p) <= 0;
}
bool seg_inter_i(IP a, IP b, IP c, IP d) {
    __int128 d1 = icross(b - a, c - a), d2 = icross(b - a, d - a);
    __int128 d3 = icross(d - c, a - c), d4 = icross(d - c, b - c);
    if ((d1 > 0) != (d2 > 0) && (d3 > 0) != (d4 > 0)) return true;
    return on_seg_i(a, b, c) || on_seg_i(a, b, d) || on_seg_i(c, d, a) || on_seg_i(c, d, b);
}
```


## 多边形


### 一句话

给定一个按顺序给出 $n$ 个顶点的简单多边形（坐标是整数，$n\le 10^5$），要你求出它的面积与重心，并判断某个点是否落在多边形内部，多边形的顶点顺序已经排好。**时间 $O(n)$（凸多边形的内点判定为 $O(\log n)$），空间 $O(1)$。**


### 原理


### 实现

```c++
double polygon_area2(vector<P>& p) {         // 有向面积的两倍（逆时针为正）
    int n = p.size();
    double s = 0;
    for (int i = 0; i < n; i++) s += cross(p[i], p[(i + 1) % n]);
    return s;
}
P centroid(vector<P>& p) {
    int n = p.size();
    double a = 0, cx = 0, cy = 0;
    for (int i = 0; i < n; i++) {
        double t = cross(p[i], p[(i + 1) % n]);
        a += t;
        cx += (p[i].x + p[(i + 1) % n].x) * t;
        cy += (p[i].y + p[(i + 1) % n].y) * t;
    }
    if (sgn(a) == 0) return {0, 0};
    return {cx / (3 * a), cy / (3 * a)};
}
int point_in_poly(vector<P>& p, P q) {       // 0 外，1 内，2 边界
    int n = p.size(), cnt = 0;
    for (int i = 0; i < n; i++) {
        P a = p[i], b = p[(i + 1) % n];
        if (on_seg(a, b, q)) return 2;
        if (sgn(a.y - b.y) <= 0) swap(a, b); // 保证 a 在上
        if (sgn(q.y - b.y) > 0 && sgn(q.y - a.y) <= 0 && sgn(cross(b - a, q - a)) < 0) cnt ^= 1;
    }
    return cnt;
}
```


### 应用


#### 鞋带公式

面积等于 $\frac12\left|\sum_i(x_iy_{i+1}-x_{i+1}y_i)\right|$；逆时针为正、顺时针为负。

```c++
double polygon_area(vector<P>& p) { return fabs(polygon_area2(p)) / 2; }
// 顶点顺序决定符号：面积要取绝对值，但「有向面积」本身在凸包等问题里有用
```


#### 射线法判定

从待判点向一侧引射线，数它与多边形的交点个数；奇数在内、偶数在外；关键是「半开区间」处理，避免顶点被重复计数。

```c++
int ray_cast(vector<P>& poly, P q) {         // 0 外，1 内，2 边界
    int n = poly.size(), cnt = 0;
    for (int i = 0; i < n; i++) {
        P a = poly[i], b = poly[(i + 1) % n];
        if (on_seg(a, b, q)) return 2;
        if (a.y > b.y) swap(a, b);           // 统一成 a.y <= b.y
        if (q.y < a.y || q.y >= b.y) continue;   // 半开区间：上闭下开，顶点只算一次
        if (sgn(cross(b - a, q - a)) < 0) cnt ^= 1;   // 射线向右穿过这条边
    }
    return cnt;
}
```


#### 凸多边形的内点判定

凸多边形可以用「叉积同号」或者「先二分找扇形、再判」做到 $O(\log n)$。

```c++
bool in_convex(vector<P>& h, P q) {          // h 是逆时针凸包，n >= 3
    int n = h.size();
    if (sgn(cross(h[1] - h[0], q - h[0])) < 0) return false;          // 在第一条边右侧
    if (sgn(cross(h[n - 1] - h[0], q - h[0])) > 0) return false;      // 在最后一条边左侧
    int lo = 1, hi = n - 1;                  // 二分找到 q 落在哪个扇形里
    while (hi - lo > 1) {
        int mid = (lo + hi) >> 1;
        if (sgn(cross(h[mid] - h[0], q - h[0])) >= 0) lo = mid;
        else hi = mid;
    }
    return sgn(cross(h[hi] - h[lo], q - h[lo])) >= 0;
}
```


#### 多边形面积与皮克定理

顶点都在整点上时，$S=I+\frac B2-1$，于是 $I=\frac{2S-B}2+1$；边上整点数用 $\sum\gcd(|\Delta x|,|\Delta y|)$。

```c++
ll picks_interior(vector<IP>& p) {
    int n = p.size();
    __int128 a2 = 0;
    ll B = 0;
    for (int i = 0; i < n; i++) {
        IP u = p[i], v = p[(i + 1) % n];
        a2 += (__int128)u.x * v.y - (__int128)u.y * v.x;
        B += std::gcd(llabs(v.x - u.x), llabs(v.y - u.y));
    }
    if (a2 < 0) a2 = -a2;
    return (ll)((a2 - B) / 2 + 1);
}
```


## 凸包（Andrew、Graham）


### 一句话

给定 $n$ 个点（整数坐标，$n\le 10^5$），要你求出包住它们的凸包并按逆时针输出顶点，点一次全给出来。**时间 $O(n\log n)$，空间 $O(n)$。**


### 原理


### 实现

（Andrew 单调链：按横坐标排序后分别求上下凸壳。）

```c++
vector<P> convex_hull(vector<P> p) {
    sort(p.begin(), p.end());
    p.erase(unique(p.begin(), p.end(), [](P a, P b) { return sgn(a.x - b.x) == 0 && sgn(a.y - b.y) == 0; }), p.end());
    int n = p.size();
    if (n <= 2) return p;
    vector<P> h(2 * n);
    int k = 0;
    for (int i = 0; i < n; i++) {            // 下凸壳
        while (k >= 2 && sgn(cross(h[k - 1] - h[k - 2], p[i] - h[k - 2])) <= 0) k--;
        h[k++] = p[i];
    }
    for (int i = n - 2, t = k + 1; i >= 0; i--) {   // 上凸壳
        while (k >= t && sgn(cross(h[k - 1] - h[k - 2], p[i] - h[k - 2])) <= 0) k--;
        h[k++] = p[i];
    }
    h.resize(k - 1);                         // 最后一点与起点重复
    return h;                                // 逆时针
}
```


### 应用


#### 凸包周长与面积

周长是相邻顶点距离之和；面积用鞋带公式，都是 $O(n)$。

```c++
double hull_perimeter(vector<P>& h) {
    int n = h.size();
    if (n <= 1) return 0;
    double s = 0;
    for (int i = 0; i < n; i++) s += len(h[(i + 1) % n] - h[i]);
    return s;                                // n == 2 时会来回算一次，正好是两倍距离
}
double hull_area(vector<P>& h) {
    int n = h.size();
    if (n < 3) return 0;
    return fabs(polygon_area2(h)) / 2;
}
```


#### 凸包上的判定

判断点是否在凸包内：$O(\log n)$ 二分，或者检查「所有边叉积非负」。

```c++
bool inside_hull_slow(vector<P>& h, P q) {   // O(n)，无脑版
    int n = h.size();
    for (int i = 0; i < n; i++)
        if (sgn(cross(h[(i + 1) % n] - h[i], q - h[i])) < 0) return false;
    return true;                             // 对逆时针凸包成立
}
// n 很大、询问很多时换成上面「凸多边形的内点判定」的 O(log n) 版本
```


#### 保留共线点

把弹栈条件从「叉积小于等于 0」改成「小于 0」，就能把边上的点也留在凸包上。

```c++
vector<P> hull_with_collinear(vector<P> p) {
    sort(p.begin(), p.end());
    p.erase(unique(p.begin(), p.end(), [](P a, P b) { return sgn(a.x - b.x) == 0 && sgn(a.y - b.y) == 0; }), p.end());
    int n = p.size();
    if (n <= 2) return p;
    vector<P> h(2 * n);
    int k = 0;
    for (int i = 0; i < n; i++) {
        while (k >= 2 && sgn(cross(h[k - 1] - h[k - 2], p[i] - h[k - 2])) < 0) k--;   // 只弹「严格右转」
        h[k++] = p[i];
    }
    for (int i = n - 2, t = k + 1; i >= 0; i--) {
        while (k >= t && sgn(cross(h[k - 1] - h[k - 2], p[i] - h[k - 2])) < 0) k--;
        h[k++] = p[i];
    }
    h.resize(k - 1);
    return h;
}
// 需要「凸包边界上的所有点」时用这个；只要顶点就用原来的 <= 0
```


## 旋转卡壳


### 一句话

给定一个凸包（顶点数 $n\le 10^5$，顶点按逆时针排好），要你求出它的直径（最远点对距离）、最小宽度与最大面积内接三角形。**时间 $O(n)$，空间 $O(n)$。**


### 原理


### 实现

（用一对「对踵点」沿凸包旋转，每条边只推进一次。）

```c++
double area2(P a, P b, P c) { return fabs(cross(b - a, c - a)); }
double diameter2(vector<P>& h) {             // 返回最远点对距离的平方
    int n = h.size();
    if (n == 1) return 0;
    if (n == 2) return len2(h[0] - h[1]);
    double ans = 0;
    for (int i = 0, j = 1; i < n; i++) {
        P a = h[i], b = h[(i + 1) % n];
        while (area2(a, b, h[(j + 1) % n]) > area2(a, b, h[j])) j = (j + 1) % n;
        ans = max(ans, max(len2(h[i] - h[j]), len2(h[(i + 1) % n] - h[j])));
    }
    return ans;
}
```


### 应用


#### 最远点对

点集的最远点对一定在凸包上，所以先求凸包再卡壳；返回平方可以避免开根号的精度损失。

```c++
double farthest_pair(vector<P> p) {
    auto h = convex_hull(p);
    return sqrt(diameter2(h));
}
```


#### 最小宽度

最小宽度就是「最小外接矩形的短边」，可以用三对对踵点维护投影最左/最右/最远来求。

```c++
double min_width(vector<P>& h) {
    int n = h.size();
    if (n < 3) return 0;
    double ans = 1e100;
    int j = 1;
    for (int i = 0; i < n; i++) {
        P a = h[i], b = h[(i + 1) % n];
        while (area2(a, b, h[(j + 1) % n]) > area2(a, b, h[j])) j = (j + 1) % n;
        double H = area2(a, b, h[j]) / len(b - a);   // 点到这条边的最大距离 = 宽度
        ans = min(ans, H);
    }
    return ans;                              // 对所有边取最小
}
```


#### 最大面积三角形

固定一条底边 $i\to j$，第三个点满足决策单调性，可以 $O(n^2)$ 或更优地求出。

```c++
double max_triangle(vector<P>& h) {
    int n = h.size();
    if (n < 3) return 0;
    double ans = 0;
    for (int i = 0; i < n; i++) {
        int k = (i + 2) % n;
        for (int j = (i + 1) % n; (j + 1) % n != i; j = (j + 1) % n) {
            while (area2(h[i], h[j], h[(k + 1) % n]) > area2(h[i], h[j], h[k])) k = (k + 1) % n;
            ans = max(ans, area2(h[i], h[j], h[k]));
        }
    }
    return ans;
}
// 返回的是「两倍面积」，需要真实面积就除以 2
```


## 半平面交


### 一句话

给定 $n$ 个半平面（$n\le 10^5$，每个用一条有向直线表示「它的左侧」），要你求出这些半平面的交集（可能为空、也可能无界）并算出交集的面积，半平面一次给全。**时间 $O(n\log n)$，空间 $O(n)$。**


### 原理


### 实现

（把直线按极角排序、用双端队列维护，逐个加入并弹掉两端不合法的交点。）

```c++
struct Line {
    P p, v;                                  // 从 p 出发、方向是 v
    double ang() const { return atan2(v.y, v.x); }
    bool operator<(const Line& o) const { return sgn(ang() - o.ang()) < 0; }
    bool onleft(P q) const { return sgn(cross(v, q - p)) > 0; }   // q 在直线左侧
};
P line_inter(Line a, Line b) {
    double t = cross(b.p - a.p, b.v) / cross(a.v, b.v);
    return a.p + a.v * t;
}
vector<P> half_plane_inter(vector<Line> L) {
    sort(L.begin(), L.end());
    deque<Line> q;
    deque<P> pt;
    for (auto& l : L) {
        while (pt.size() >= 2 && !l.onleft(pt.back())) pt.pop_back(), q.pop_back();
        while (pt.size() >= 2 && !l.onleft(pt.front())) pt.pop_front(), q.pop_front();
        if (q.size() && sgn(cross(q.back().v, l.v)) == 0) {
            if (q.back().onleft(l.p)) { q.pop_back(); if (!pt.empty()) pt.pop_back(); }
            else continue;
        }
        if (q.size()) pt.push_back(line_inter(q.back(), l));
        q.push_back(l);
    }
    while (pt.size() >= 2 && !q.front().onleft(pt.back())) pt.pop_back(), q.pop_back();
    while (pt.size() >= 2 && !q.back().onleft(pt.front())) pt.pop_front(), q.pop_front();
    if (q.size() <= 2) return {};
    pt.push_back(line_inter(q.back(), q.front()));
    return vector<P>(pt.begin(), pt.end());
}
```

## 三角剖分

### 一句话

给定一个 $n$ 个顶点的多边形（$n\le 10^5$），要你把它剖分成若干三角形并给出剖分方案，多边形的顶点按顺序给出。**时间 $O(n\log n)$ 或 $O(n)$，空间 $O(n)$。**

### 原理


### 实现

（耳切法：每次找一个「耳朵」——连续三个顶点构成的三角形完全落在多边形内部——把它切掉，直到只剩一个三角形。）

```c++
// 判定点 p 是否在三角形 abc 内（含边界），要求 abc 逆时针
bool in_triangle(P p, P a, P b, P c) {
    double d1 = cross(b - a, p - a), d2 = cross(c - b, p - b), d3 = cross(a - c, p - c);
    bool neg = (d1 < 0) || (d2 < 0) || (d3 < 0);
    bool pos = (d1 > 0) || (d2 > 0) || (d3 > 0);
    return !(neg && pos);                     // 三个叉积同号（或为 0）就在里面
}
// 判断下标 i 是不是「耳朵」（p 是逆时针的简单多边形）
bool is_ear(const vector<P>& p, const vector<int>& idx, int i) {
    int n = idx.size();
    int a = idx[(i - 1 + n) % n], b = idx[i], c = idx[(i + 1) % n];
    if (cross(p[b] - p[a], p[c] - p[b]) <= 0) return false;   // 必须是凸顶点
    for (int j = 0; j < n; j++) {
        int t = idx[j];
        if (t == a || t == b || t == c) continue;
        if (in_triangle(p[t], p[a], p[b], p[c])) return false; // 别的顶点落在耳里
    }
    return true;
}
vector<array<int, 3>> ear_clipping(vector<P> p) {   // 要求 p 逆时针、无自交
    vector<int> idx(p.size());
    iota(idx.begin(), idx.end(), 0);
    vector<array<int, 3>> tri;
    while (idx.size() > 3) {
        bool cut = false;
        for (int i = 0; i < (int)idx.size(); i++) {
            if (!is_ear(p, idx, i)) continue;
            int n = idx.size();
            tri.push_back({idx[(i - 1 + n) % n], idx[i], idx[(i + 1) % n]});
            idx.erase(idx.begin() + i);       // 切掉这个耳朵
            cut = true;
            break;
        }
        if (!cut) break;                      // 退化多边形（有重复点 / 共线），需要更一般的算法
    }
    if (idx.size() == 3) tri.push_back({idx[0], idx[1], idx[2]});
    return tri;                               // 共 n-2 个三角形
}
// 复杂度 O(n^2)。凸多边形的三角剖分数是卡特兰数 C_{n-2}。
```

```c++
//   1. 顶点列表按逆时针排列
//   2. 对每个顶点 v[i]，若 v[i] 是凸点、且三角形 (v[i-1], v[i], v[i+1]) 内不含其他顶点，
```

### 一句话

给定圆（圆心与半径）、一条直线与另一个圆，要你求出圆与直线的交点、圆与圆的交点，并判断两圆的位置关系，这些求交与判定会交替出现。**时间 $O(1)$ 每次，空间 $O(1)$。**


### 原理


### 实现

```c++
vector<P> circle_line(P o, double r, P p, P q) {
    P v = q - p;
    double t = dot(o - p, v) / len2(v);
    P h = p + v * t;
    double d2 = len2(o - h);
    if (d2 > r * r + EPS) return {};         // 相离
    double dt = sqrt(max(0.0, (r * r - d2) / len2(v)));
    if (dt < EPS) return {h};                // 相切
    return {h - v * dt, h + v * dt};
}
vector<P> circle_circle(P o1, double r1, P o2, double r2) {
    double d = len(o2 - o1);
    if (d > r1 + r2 + EPS || d < fabs(r1 - r2) - EPS || (d < EPS && fabs(r1 - r2) < EPS)) return {};
    double a = (r1 * r1 - r2 * r2 + d * d) / (2 * d);
    double h2 = r1 * r1 - a * a;
    P mid = o1 + (o2 - o1) * (a / d);
    if (h2 < EPS) return {mid};
    P perp = P(-(o2 - o1).y, (o2 - o1).x) * (sqrt(h2) / d);
    return {mid - perp, mid + perp};
}
double circle_intersect_area(P o1, double r1, P o2, double r2) {
    double d = len(o2 - o1);
    if (d >= r1 + r2) return 0;
    if (d <= fabs(r1 - r2)) { double r = min(r1, r2); return PI * r * r; }
    double a1 = acos((d * d + r1 * r1 - r2 * r2) / (2 * d * r1));
    double a2 = acos((d * d + r2 * r2 - r1 * r1) / (2 * d * r2));

}
```

## 最小圆覆盖


### 一句话

给定平面上 $n$ 个点（$n\le 10^5$），要你找出一个半径最小的圆把所有点都盖住，输出它的圆心与半径，点一次给全。**期望时间 $O(n)$，空间 $O(n)$。**


### 原理


### 实现

（随机增量法：把点随机打乱，逐个加入；若新点在当前圆外，就以它为基础重新确定圆。）

```c++
P circumcenter(P a, P b, P c) {              // 三点外心（保证不共线）
    double a1 = 2 * (b.x - a.x), b1 = 2 * (b.y - a.y);
    double c1 = b.x * b.x + b.y * b.y - a.x * a.x - a.y * a.y;
    double a2 = 2 * (c.x - a.x), b2 = 2 * (c.y - a.y);
    double c2 = c.x * c.x + c.y * c.y - a.x * a.x - a.y * a.y;
    double d = a1 * b2 - a2 * b1;
    return {(c1 * b2 - c2 * b1) / d, (a1 * c2 - a2 * c1) / d};
}
P O;
double R;
void min_circle(vector<P> p) {
    mt19937 rng(chrono::steady_clock::now().time_since_epoch().count());
    shuffle(p.begin(), p.end(), rng);
    int n = p.size();
    O = p[0], R = 0;
    for (int i = 0; i < n; i++) {
        if (len(p[i] - O) <= R + EPS) continue;
        O = p[i], R = 0;
        for (int j = 0; j < i; j++) {
            if (len(p[j] - O) <= R + EPS) continue;
            O = (p[i] + p[j]) / 2, R = len(p[i] - O);
            for (int k = 0; k < j; k++) {
                if (len(p[k] - O) <= R + EPS) continue;
                O = circumcenter(p[i], p[j], p[k]);
                R = len(p[i] - O);
            }
        }
    }
}
```

## 平面最近点对


### 一句话

给定平面上 $n$ 个点（$n\le 2\times10^5$，坐标绝对值 $\le 10^9$），要你找出距离最近的一对点并输出它们之间的距离，点一次全给出来。**时间 $O(n\log n)$，空间 $O(n)$。**


### 原理


### 实现

（分治：按横坐标分成左右两半，递归求解后只检查「跨中线且横向距离小于当前答案」的点，并按纵坐标归并。）

```c++
vector<P> p, tmp;
double best;

void solve(int l, int r) {
    if (l >= r) return;                      // 至多一个点
    if (r - l == 1) {                        // 两个点：先算距离，再按 y 排好
        best = min(best, len(p[l] - p[r]));
        if (p[l].y > p[r].y) swap(p[l], p[r]);   // 必须保持按 y 有序，否则上层归并会失效
        return;
    }
    int mid = (l + r) >> 1;
    double midx = p[mid].x;
    solve(l, mid), solve(mid + 1, r);
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) tmp[k++] = (p[i].y < p[j].y ? p[i++] : p[j++]);
    while (i <= mid) tmp[k++] = p[i++];
    while (j <= r) tmp[k++] = p[j++];
    for (int t = l; t <= r; t++) p[t] = tmp[t];
    int cnt = 0;
    static P strip[N];
    for (int t = l; t <= r; t++)
        if (fabs(p[t].x - midx) < best) strip[cnt++] = p[t];
    for (int a = 0; a < cnt; a++)
        for (int b = a + 1; b < cnt && strip[b].y - strip[a].y < best; b++)
            best = min(best, len(strip[a] - strip[b]));
}
double closest_pair(vector<P> pts) {
    p = pts;
    sort(p.begin(), p.end(), [](P a, P b) { return a.x < b.x; });
    tmp.resize(p.size());
    best = 1e100;
    solve(0, p.size() - 1);
    return best;
}
```

```c++
// |dx| + |dy| = max(|du|, |dv|)，其中 u = x + y, v = x - y
// 于是「曼哈顿最近点对」变成「切比雪夫最近点对」：
//   按 u 排序，维护一个滑动窗口（u 之差 < best），窗口里对 v 用有序容器查前驱后继
double manhattan_closest(vector<P> pts) {
    vector<pair<double, double>> q;
    for (auto& a : pts) q.push_back({a.x + a.y, a.x - a.y});
    sort(q.begin(), q.end());
    multiset<double> win;
    double best = 1e100;
    size_t le = 0;
    for (size_t i = 0; i < q.size(); i++) {
        while (q[i].first - q[le].first >= best) win.erase(win.find(q[le].second)), le++;
        auto it = win.lower_bound(q[i].second);
        if (it != win.end()) best = min(best, *it - q[i].second);
        if (it != win.begin()) { --it; best = min(best, q[i].second - *it); }
        win.insert(q[i].second);
    }
    return best;                             // 切比雪夫距离
}
```

## 最小矩形覆盖

### 一句话

给定 $n$ 个点（$n\le 10^5$），要你找出一个能盖住所有点的矩形，使它的面积（或周长）最小，点一次全给出来。**时间 $O(n\log n)$，空间 $O(n)$。**

### 原理


### 实现

（结论：最小面积矩形一定有一条边与凸包的一条边重合。于是枚举凸包的每条边作为矩形的一边，把其余点投影到「沿边」与「垂直边」两个方向，取包围盒。）

```c++
double min_rect_area(vector<P> p) {           // p 是点集，返回最小覆盖矩形的面积
    p = convex_hull(p);                       // 先求凸包（逆时针）
    int n = p.size();
    if (n == 1) return 0;
    if (n == 2) return 0;                     // 退化成线段，面积为 0
    double best = 1e100;
    for (int i = 0; i < n; i++) {             // 枚举「矩形的一条边」所在的凸包边
        P a = p[i], b = p[(i + 1) % n];
        P d = b - a;
        double len = sqrt(dot(d, d));
        P u = d / len, v{-u.y, u.x};          // 沿边 / 垂直边的单位向量
        double mn1 = 1e100, mx1 = -1e100, mn2 = 1e100, mx2 = -1e100;
        for (const P& q : p) {
            double t1 = dot(q - a, u), t2 = dot(q - a, v);
            mn1 = min(mn1, t1), mx1 = max(mx1, t1);
            mn2 = min(mn2, t2), mx2 = max(mx2, t2);
        }
        best = min(best, (mx1 - mn1) * (mx2 - mn2));
    }
    return best;
}
// 上面是 O(n^2)（每个点都重新投影一遍），凸包点数不超过 5000 时够用。
// 优化：用「旋转卡壳」同时维护「最右、最上、最左、最下」四个极值点，
//       它们在枚举边的过程中都是单调推进的，于是总复杂度降到 O(n)。
// 改成最小周长只要把面积换成 2*((mx1-mn1)+(mx2-mn2)) 即可。
```

## 扫描线与矩形面积并


### 一句话

给定 $n$ 个轴对齐矩形（$n\le 10^5$，坐标绝对值 $\le 10^9$），要你求出它们并集覆盖的总面积，矩形一次全给出来。**时间 $O(n\log n)$，空间 $O(n)$。**


### 原理


### 实现

（扫描线：按横坐标切分，用线段树维护纵方向上「被覆盖至少一次」的总长度。）

```c++
struct Seg {
    double x, y1, y2;
    int d;                                   // +1 是左边界，-1 是右边界
    bool operator<(const Seg& o) const { return x < o.x; }
};
double ys[N];
int cnt[N << 2];
double covlen[N << 2];

void pushup(int o, int l, int r) {
    if (cnt[o] > 0) covlen[o] = ys[r + 1] - ys[l];
    else if (l == r) covlen[o] = 0;
    else covlen[o] = covlen[o << 1] + covlen[o << 1 | 1];
}
void update(int o, int l, int r, int ql, int qr, int v) {
    if (ql <= l && r <= qr) { cnt[o] += v, pushup(o, l, r); return; }
    int mid = (l + r) >> 1;
    if (ql <= mid) update(o << 1, l, mid, ql, qr, v);
    if (qr > mid) update(o << 1 | 1, mid + 1, r, ql, qr, v);
    pushup(o, l, r);
}
double rect_union_area(vector<array<double, 4>>& rects) {
    vector<Seg> seg;
    int m = 0;
    for (auto& r : rects) {                  // r = {x1, y1, x2, y2}
        ys[m++] = r[1], ys[m++] = r[3];
        seg.push_back({r[0], r[1], r[3], 1});
        seg.push_back({r[2], r[1], r[3], -1});
    }
    sort(ys, ys + m);
    m = unique(ys, ys + m) - ys;
    memset(cnt, 0, sizeof(int) * (4 * m + 4));
    memset(covlen, 0, sizeof(double) * (4 * m + 4));
    sort(seg.begin(), seg.end());
    double ans = 0;
    for (int i = 0; i + 1 < (int)seg.size(); i++) {
        int l = lower_bound(ys, ys + m, seg[i].y1) - ys;
        int r = lower_bound(ys, ys + m, seg[i].y2) - ys - 1;
        if (l <= r) update(1, 0, m - 2, l, r, seg[i].d);
        ans += covlen[1] * (seg[i + 1].x - seg[i].x);
    }
    return ans;
}
```

#### 矩形面积交

面积交不容易直接扫描，常用「对每个矩形，求它与其它矩形的交被覆盖的次数」或者用扫描线维护「被覆盖至少 k 次」的长度。

```c++
// 两个矩形面积交：直接算 max(0, min(x2)-max(x1)) * max(0, min(y2)-max(y1))
double rect_intersect_area(array<double,4>& a, array<double,4>& b) {
    double x1 = max(a[0], b[0]), x2 = min(a[2], b[2]);
    double y1 = max(a[1], b[1]), y2 = min(a[3], b[3]);
    if (x1 >= x2 || y1 >= y2) return 0;
    return (x2 - x1) * (y2 - y1);
}
// 多个矩形求交：对所有矩形的 x1 取 max、x2 取 min，y 同理
```

#### 离散化与整数坐标

坐标是整数时应当用整数离散化代替 double，**彻底避免「相等的坐标去重不干净」**；离散化后线段树的下标是段号。

```c++
vector<ll> xs, ys;
void discretize_sweep(vector<array<ll, 4>>& rects) {   // r = {x1, y1, x2, y2}
    for (auto& r : rects) {
        xs.push_back(r[0]), xs.push_back(r[2]);
        ys.push_back(r[1]), ys.push_back(r[3]);
    }
    sort(xs.begin(), xs.end()), xs.erase(unique(xs.begin(), xs.end()), xs.end());
    sort(ys.begin(), ys.end()), ys.erase(unique(ys.begin(), ys.end()), ys.end());
}
// 叶子区间是 [ys[i], ys[i+1]]（长度用整数差），所以线段树的范围是 [0, m-2]
// 面积累加时用 (x2 - x1) * 覆盖长度，全程整数，最后再决定要不要输出小数
```


## Pick 定理


### 一句话

给定一个顶点都是整点的多边形（坐标绝对值 $\le 10^9$），要你用皮克定理数出它内部有多少个整点，多边形的顶点按顺序给出。**时间 $O(n\log C)$（$\gcd$ 的代价），空间 $O(n)$。**


### 原理


### 实现

```c++
// 皮克定理：S = I + B/2 - 1  =>  I = S - B/2 + 1
ll picks_interior(vector<IP>& p) {
    int n = p.size();
    __int128 a2 = 0;                         // 两倍面积（保证是整数）
    ll B = 0;
    for (int i = 0; i < n; i++) {
        IP u = p[i], v = p[(i + 1) % n];
        a2 += (__int128)u.x * v.y - (__int128)u.y * v.x;
        B += std::gcd(llabs(v.x - u.x), llabs(v.y - u.y));
    }
    if (a2 < 0) a2 = -a2;
    return (ll)((a2 - B) / 2 + 1);
}
```


### 应用


#### 格点多边形的整点数

内部整点数用皮克定理；边上整点数用 $\sum \gcd(|\Delta x|,|\Delta y|)$，每一项就是这条边上的整点数。

```c++
ll points_on_boundary(vector<IP>& p) {
    int n = p.size();
    ll B = 0;
    for (int i = 0; i < n; i++) {
        IP u = p[i], v = p[(i + 1) % n];
        B += std::gcd(llabs(v.x - u.x), llabs(v.y - u.y));
    }
    return B;                                // 每个顶点被相邻两条边各算一次，正好抵消
}
```


## 三维计算几何


### 一句话

给定三维空间中的点与向量，要你对它们做点积、叉积、混合积，求点到直线与平面的距离、绕轴旋转，并求点集三维凸包的表面积与体积，点一次全给出来。**时间 $O(1)$（基本运算）或 $O(n^2)$（三维凸包），空间 $O(n)$。**


### 原理


### 实现

```c++
struct P3 {
    double x, y, z;
    P3(double x = 0, double y = 0, double z = 0) : x(x), y(y), z(z) {}
    P3 operator+(const P3& o) const { return {x + o.x, y + o.y, z + o.z}; }
    P3 operator-(const P3& o) const { return {x - o.x, y - o.y, z - o.z}; }
    P3 operator*(double k) const { return {x * k, y * k, z * k}; }
    P3 operator/(double k) const { return {x / k, y / k, z / k}; }
    bool operator<(const P3& o) const {
        if (sgn(x - o.x)) return x < o.x;
        if (sgn(y - o.y)) return y < o.y;
        return z < o.z;
    }
    bool operator==(const P3& o) const { return sgn(x - o.x) == 0 && sgn(y - o.y) == 0 && sgn(z - o.z) == 0; }
};
double dot3(P3 a, P3 b) { return a.x * b.x + a.y * b.y + a.z * b.z; }
P3 cross3(P3 a, P3 b) { return {a.y * b.z - a.z * b.y, a.z * b.x - a.x * b.z, a.x * b.y - a.y * b.x}; }
double len3(P3 a) { return sqrt(dot3(a, a)); }
double mixed(P3 a, P3 b, P3 c) { return dot3(a, cross3(b, c)); }

struct Face { int a, b, c; };
vector<P3> hp;
vector<Face> hf;
P3 fnormal(const Face& f) { return cross3(hp[f.b] - hp[f.a], hp[f.c] - hp[f.a]); }
bool fvisible(const Face& f, const P3& q) { return sgn(dot3(fnormal(f), q - hp[f.a])) > 0; }
void hull3d() {
    hf.clear();
    int n = hp.size();
    if (n < 4) return;
    int k = -1;
    for (int i = 2; i < n; i++) if (sgn(len3(cross3(hp[1] - hp[0], hp[i] - hp[0]))) > 0) { k = i; break; }
    if (k < 0) return;
    swap(hp[2], hp[k]);
    int m = -1;
    for (int i = 3; i < n; i++) if (sgn(fabs(mixed(hp[1] - hp[0], hp[2] - hp[0], hp[i] - hp[0]))) > 0) { m = i; break; }
    if (m < 0) return;
    swap(hp[3], hp[m]);
    P3 cen = (hp[0] + hp[1] + hp[2] + hp[3]) / 4;
    int t[4][3] = {{0, 1, 2}, {0, 2, 3}, {0, 3, 1}, {1, 3, 2}};
    for (auto& x : t) {
        Face fc{x[0], x[1], x[2]};
        if (fvisible(fc, cen)) swap(fc.b, fc.c);
        hf.push_back(fc);
    }
    for (int i = 4; i < n; i++) {
        size_t sz = hf.size();
        vector<char> vis(sz, 0);
        bool any = false;
        for (size_t j = 0; j < sz; j++) { vis[j] = fvisible(hf[j], hp[i]); any = any || vis[j]; }
        if (!any) continue;
        vector<pair<int, int>> horizon;
        for (size_t j = 0; j < sz; j++) {
            if (!vis[j]) continue;
            int e[3][2] = {{hf[j].a, hf[j].b}, {hf[j].b, hf[j].c}, {hf[j].c, hf[j].a}};
            for (auto& ed : e) {
                bool shared = false;
                for (size_t g = 0; g < sz && !shared; g++) {
                    if (vis[g]) continue;
                    int e2[3][2] = {{hf[g].a, hf[g].b}, {hf[g].b, hf[g].c}, {hf[g].c, hf[g].a}};
                    for (auto& ed2 : e2)
                        if (ed2[0] == ed[1] && ed2[1] == ed[0]) { shared = true; break; }
                }
                if (shared) horizon.push_back({ed[0], ed[1]});
            }
        }
        vector<Face> nf;
        for (size_t j = 0; j < sz; j++) if (!vis[j]) nf.push_back(hf[j]);
        for (auto& e : horizon) nf.push_back({e.first, e.second, i});
        hf = nf;
    }
}
```

#### 三维凸包的表面积与体积

```c++
pair<double, double> hull3d_area_volume() {
    double area = 0, vol = 0;
    for (auto& f : hf) {
        area += len3(cross3(hp[f.b] - hp[f.a], hp[f.c] - hp[f.a])) / 2;
```

叉积模长除以底边长度是点到直线距离；混合积除以底面面积是点到平面距离。


#### 三维旋转（罗德里格斯公式）

绕单位轴 $k$ 旋转 $t$ 弧度：$v' = v\cos t + (k\times v)\sin t + k\,(k\cdot v)(1-\cos t)$。


## 计算几何常用技巧


### 一句话

给定坐标绝对值到 $10^9$ 的几何判定题（例如「$n$ 个点中是否存在三点共线」「点是否在多边形内」「两线段是否相交」），要你全程只用整数运算做出判定、不引入浮点误差，这些判定要反复询问。**时间 $O(1)$ 每次判定，空间 $O(1)$。**


### 原理


### 实现

（核心思路：能用整数就绝不转 double；所有叉积、点积的比较都放在 __int128 里算。）

```c++
using i128 = __int128;
i128 icross(IP a, IP b) { return (i128)a.x * b.y - (i128)a.y * b.x; }
i128 icross(IP a, IP b, IP c) { return icross(b - a, c - a); }   // 三点共线 <=> 结果为 0
i128 idot(IP a, IP b) { return (i128)a.x * b.x + (i128)a.y * b.y; }
i128 idist2(IP a, IP b) { i128 dx = a.x - b.x, dy = a.y - b.y; return dx * dx + dy * dy; }

bool collinear(IP a, IP b, IP c) { return icross(a, b, c) == 0; }
bool on_seg_i(IP a, IP b, IP p) {
    return icross(a, b, p) == 0 && idot(a - p, b - p) <= 0;
}
bool seg_inter_i(IP a, IP b, IP c, IP d) {
    i128 d1 = icross(a, b, c), d2 = icross(a, b, d);
    i128 d3 = icross(c, d, a), d4 = icross(c, d, b);
    if (((d1 > 0) != (d2 > 0)) && ((d3 > 0) != (d4 > 0))) return true;
    return on_seg_i(a, b, c) || on_seg_i(a, b, d) || on_seg_i(c, d, a) || on_seg_i(c, d, b);
}
```


### 应用


#### 整数几何优先

只要所有坐标都是整数，判定类问题就全部可以用 __int128 解决，不要碰 double。下面给出完整的「点在多边形内（整数版）」。

```c++
bool on_seg_i2(IP a, IP b, IP p) {
    return icross(b - a, p - a) == 0 && idot(a - p, b - p) <= 0;
}
int point_in_poly_i(vector<IP>& poly, IP q) {   // 0 外，1 内，2 边界
    int n = poly.size(), cnt = 0;
    for (int i = 0; i < n; i++) {
        IP a = poly[i], b = poly[(i + 1) % n];
        if (on_seg_i2(a, b, q)) return 2;
        if (a.y > b.y) swap(a, b);
        if (q.y < a.y || q.y >= b.y) continue;
        if (icross(b - a, q - a) < 0) cnt ^= 1;
    }
    return cnt;
}
// 全程整数与 __int128，没有任何 eps；求交点坐标这类「输出」才转 double
```


#### eps 的选取

必须用浮点时，相对误差比绝对误差更可靠：把 eps 取成与坐标量级相关的值。

```c++
bool close_enough(double a, double b, double scale = 1.0) {
    return fabs(a - b) <= 1e-9 * max(1.0, scale);   // 按量级缩放
}
// 或者直接用「比较平方」代替「比较距离」来规避开根号带来的误差
```


#### 避免开根号

比较距离时一律用距离的平方；只有真正需要输出长度时才开根号。

```c++
bool closer(IP a, IP b, IP c) {              // a 到 c 是否比 b 到 c 更近
    return idist2(a, c) < idist2(b, c);      // 全程整数，没有 sqrt
}
// 排序、最值判定、凸包方向都只需要比较大小
```


#### 判等与去重

浮点点集的去重要用 sgn 判定「距离小于 eps」，而不是直接比较坐标是否相等。

```c++
bool same_point(P a, P b) { return sgn(a.x - b.x) == 0 && sgn(a.y - b.y) == 0; }
void dedup_float(vector<P>& p) {
```
